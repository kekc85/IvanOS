# decision-making — стратегические решения соло-предпринимателя

Совет директоров по принятию решений: мыслители, на которых стоит дисциплина выбора под неопределённостью. Когда автор решает крупную задачу — куда вложить месяц, какой оффер, какую ставку сделать, копировать ли чужой кейс, продолжать или закрыть — он проваливается сюда и берёт конкретный метод (инверсию Мангера, premortem Канемана, ставки Дьюк, barbell Талеба, 5-шаговый процесс Далио), накладывая его на свой контекст. Это головы за столом для решений, а не для производства.

Каждый файл = один автор × 1-3 применимых метода с пошаговым алгоритмом.

## Авторы за столом

- [[munger]] — **Чарли Мангер**: инверсия (думай от провала), круг компетентности, latticework моделей + сила стимулов.
- [[kahneman]] — **Даниэль Канеман**: Система 1/2, чек-лист искажений (якорь/доступность/потери/база/обрамление), premortem.
- [[naval]] — **Наваль Равикант**: рычаги (код/медиа), specific knowledge, долгие игры с долгими людьми.
- [[annie-duke]] — **Энни Дьюк**: решения как ставки, resulting (исход ≠ качество решения), мыслить вероятностями.
- [[nassim-taleb]] — **Нассим Талеб**: антихрупкость и barbell, via negativa (убрать, а не добавить), шкура на кону.
- [[ray-dalio]] — **Рэй Далио**: 5-шаговый процесс (цель→проблема→диагноз→дизайн→действие), радикальная правда, вес мнений по доверию.
- [[shane-parrish]] — **Шейн Пэрриш**: первопринципы, мышление второго порядка («и что потом?»), карта ≠ территория.
- [[rolf-dobelli]] — **Рольф Добелли**: каталог ловушек как чек-лист (выживший, подтверждение, утопленные затраты, стадность).
- [[gigerenzer]] — **Герд Гигеренцер**: быстрые экономные эвристики, «меньше = больше», recognition heuristic.
- [[tetlock]] — **Филип Тетлок**: прогноз числом + обновление малыми шагами, декомпозиция на под-вопросы, счёт по Brier.
- [[feynman]] — **Ричард Фейнман**: «не обмани сам себя», техника Фейнмана (объясни просто → найди дыры), строй с нуля.

## Как пользоваться

1. Крупное/необратимое решение, страшно ошибиться → [[kahneman]] (Система 2 + premortem), [[munger]] (инверсия).
2. Куда вложить время/деньги, выбор актива → [[naval]] (рычаг), [[nassim-taleb]] (barbell).
3. Распределить ставки между безопасным и рискованным → [[nassim-taleb]], [[annie-duke]].
4. Разобрать закрытый запуск, не путать удачу и навык → [[annie-duke]] (resulting), [[ray-dalio]] (диагноз причины).
5. Застрявшая повторяющаяся проблема → [[ray-dalio]] (5 шагов), [[feynman]] / [[shane-parrish]] (первопринципы).
6. Оценить хайповый чужой кейс перед копированием → [[rolf-dobelli]] (ошибка выжившего), [[kahneman]] (базовая ставка).
7. Спрогнозировать результат в числах → [[tetlock]], [[annie-duke]].
8. Паралич анализа, бесконечный ресёрч перед стартом → [[gigerenzer]] («меньше = больше»).
9. Просчитать последствия тактики (скидка, агрессивный рост) → [[shane-parrish]] (второй порядок).
10. Лезть ли в новую нишу/инструмент → [[munger]] (круг компетентности), [[feynman]] (честность с собой).
11. Кому из советников/менторов верить → [[nassim-taleb]] (шкура на кону), [[ray-dalio]] (вес по доверию).
