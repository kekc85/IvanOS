# persuasion-psychology — почему мозг говорит «да» (рычаги влияния)

Совет директоров по психологии убеждения: мастера, которые разобрали, как принимается решение «да» — до логики, на уровне эмоций, автоматизмов и самооценки. Когда автор проектирует оффер, прогрев, продающий текст, тариф или отрабатывает возражение — он проваливается сюда и берёт конкретный рычаг (принцип Чалдини, эмпатию Восса, модель Фогга, якорь Ариели), накладывая его на голос и нишу. Инструмент-агностично: это про механику решения, а не про конкретный канал. Этично: рычаг включается только на реальном основании, а не фабрикуется.

Каждый файл = один автор × 1-3 применимых метода с пошаговым алгоритмом.

## Авторы за столом

- [[cialdini]] — **Роберт Чалдини**: 7 принципов влияния, foot-in-the-door (малое да → большое), pre-suasion (фрейм ДО сообщения).
- [[voss]] — **Крис Восс**: тактическая эмпатия (mirroring + labeling), калиброванные вопросы «Как/Что», accusation audit.
- [[blair-warren]] — **Блэр Уоррен**: формула 27 слов — пять рычагов (мечта / провал / страх / подозрение / враг) как смысл и каркас текста.
- [[dale-carnegie]] — **Дейл Карнеги**: дай почувствовать важность, не критикуй, говори об интересах человека.
- [[robert-greene]] — **Роберт Грин**: законы власти (маскируй намерение, дефицит спроса, играй на желаниях), фазы соблазнения аудитории.
- [[bj-fogg]] — **БиДжей Фогг**: модель B=MAP (Поведение = Мотивация × Способность × Подсказка), делай действие крошечным, ставь подсказку на якорь.
- [[dan-ariely]] — **Дэн Ариели**: якорение и относительность ценности, эффект приманки (decoy), сила слова «бесплатно».
- [[zig-ziglar]] — **Зиг Зиглар**: продажа = передача чувства, возражение как повод, «помоги другим получить желаемое».
- [[vanessa-van-edwards]] — **Ванесса Ван Эдвардс**: харизма = тепло + компетентность, сигналы первого впечатления, cues доверия.
- [[roger-dooley]] — **Роджер Дули**: нейромаркетинг — боль оплаты, контраст-якоря, сила конкретики и образов.
- [[kevin-hogan]] — **Кевин Хоган**: omega-стратегии — снимать сопротивление, а не усиливать давление.

## Как пользоваться

1. Проектируешь оффер / прогрев / продающий текст → [[cialdini]] (7 принципов + pre-suasion), [[blair-warren]] (5 рычагов = каркас), [[zig-ziglar]] (передача чувства).
2. Ставишь цену / тарифную сетку → [[dan-ariely]] (якорь + decoy + «бесплатно»), [[roger-dooley]] (боль оплаты, контраст-якоря).
3. Строишь воронку из микро-шагов (подписчик → клуб → запуск) → [[cialdini]] (foot-in-the-door), [[bj-fogg]] (B=MAP, крошечное действие, якорь).
4. Настраиваешь первый абзац / разогрев ПЕРЕД оффером → [[cialdini]] (pre-suasion), [[blair-warren]] (подтверди подозрение), [[voss]] (accusation audit).
5. Отрабатываешь возражения / диалог со скептиком → [[voss]] (эмпатия, калиброванные вопросы), [[zig-ziglar]] (возражение как повод), [[kevin-hogan]] (снять барьер, не давить).
6. Дожимаешь без давления / работаешь с искушённой аудиторией → [[kevin-hogan]] (omega), [[robert-greene]] (маскируй намерение).
7. Упаковываешь личный бренд / харизму / первое впечатление → [[vanessa-van-edwards]] (тепло+компетентность, cues), [[dale-carnegie]] (важность, искренний интерес).
8. Выстраиваешь долгий прогрев / притяжение аудитории во времени → [[robert-greene]] (фазы соблазнения), [[zig-ziglar]] (польза первой).

> Связка с copywriting: рычаги отсюда определяют, ЧТО и в каком эмоциональном порядке сказать; copywriting ([[ogilvy]], [[halbert]], [[schwartz]], [[kennedy]], [[bencivenga]]) — КАК это упаковать в заголовок, оффер и текст.
