# Тьяго Форте — второй мозг и управление знанием

## Кто это
Основатель Forte Labs, автор «Building a Second Brain» (2022) и курса по продуктивности на знании. Тезис: в мире информационной перегрузки ценность создаёт не запоминание, а система внешнего хранения и переработки знания в результат. «Второй мозг» — внешняя память, которая освобождает голову для мышления. Источник методов — «Building a Second Brain».

## Метод 1: PARA — организация по действию, не по теме
**Суть:** заметки и файлы раскладываются не по темам (это плодит вечные «разное»), а по степени действенности — насколько информация близка к делу. Четыре категории покрывают всё.
**Шаги:**
1. **Projects (Проекты)** — то, над чем работаешь сейчас, с дедлайном и результатом (запуск, лендинг).
2. **Areas (Области)** — зоны постоянной ответственности без финиша (здоровье, финансы, контент-завод).
3. **Resources (Ресурсы)** — материалы по темам на будущее (референсы, исследования).
4. **Archive (Архив)** — завершённое и неактивное из первых трёх.
5. Раскладывай любой новый файл по принципу «где это пригодится для действия», а не «к какой теме относится». Завершил проект → в архив.
**Когда применять:** когда `.business/`, заметки и материалы превращаются в свалку — PARA даёт единую логику для всех хранилищ.

## Метод 2: CODE — конвейер от захвата к результату
**Суть:** знание проходит четыре стадии от сырья к продукту. Без конвейера информация копится, но не превращается в результат.
**Шаги:**
1. **Capture (Захват)** — сохраняй только то, что откликнулось/пригодится, а не всё подряд. Фильтр — «это resonates?».
2. **Organize (Организуй)** — клади захваченное в PARA по действенности, в первую очередь к активным проектам.
3. **Distill (Дистилляция)** — выделяй суть (см. Метод 3), чтобы будущий ты нашёл ядро за секунды.
4. **Express (Выражение)** — главная стадия: превращай накопленное в результат (пост, продукт, методологию). Цель всей системы — выход, а не коллекция.
**Когда применять:** когда исследований/референсов много, а на выходе ничего — прогоняй сырьё по CODE до Express.

## Метод 3: Прогрессивное обобщение
**Суть:** заметку делают полезной слоями выделения, добавляемыми постепенно при каждом возврате. Не нужно сразу конспектировать — слои наращиваются, когда заметка снова всплывает в работе.
**Шаги:**
1. Слой 1: сохрани исходный текст/цитату.
2. Слой 2: при следующем чтении выдели жирным ключевые фразы.
3. Слой 3: выдели маркером самое важное из жирного.
4. Слой 4: своими словами напиши 1-2 строки резюме сверху.
5. Слой 5 (редко): преврати в готовый блок для контента/продукта.
**Когда применять:** при работе с длинными исследованиями и свёртками — чтобы вернувшись через месяц взять суть за 10 секунд, а не перечитывать всё.
