# Гэри Бенсивенга — доказательства и буллеты

## Кто это
Которого многие называют «величайшим из живущих копирайтеров». Ушёл на пике, оставив легендарные «Bencivenga Bullets». Бил конкурентов в сплит-тестах десятилетиями. Его философия: реклама — это не искусство убеждения, а **искусство доказательства**. Скепсис рынка побеждается не громкостью, а пруфами.

## Метод 1: Доказательства превыше всего
**Суть:** «Гениальный текст без доказательств проиграет среднему тексту с горой доказательств». Люди не верят обещаниям — верят пруфам.
**Шаги:** под каждое обещание подложи доказательство из арсенала:
1. Конкретные цифры и факты (не «много» → «4 217»).
2. Кейсы и результаты клиентов.
3. Отзывы и социальное доказательство.
4. Демонстрация механизма («почему это работает»).
5. Гарантия как перенос риска на себя.
6. Авторитет, регалии, упоминания.
Правило: больше пруфов → меньше сопротивления → выше отклик.
**Когда применять:** весь продающий текст, особенно для холодной/искушённой аудитории.

## Метод 2: Буллеты-интриги (fascinations)
**Суть:** буллет — это мини-заголовок, который продаёт любопытство, не раскрывая ответа. Создаёт «информационный зуд» — желание узнать.
**Шаги:**
1. Бери факт/выгоду из продукта.
2. Переформулируй так, чтобы был **результат + интрига, но без ответа** («Что НИКОГДА нельзя говорить на собеседовании — стр. 14»).
3. Добавь конкретику (число, страницу, срок) для правдоподобия.
4. Собери блок из 5-15 буллетов по нарастанию силы.
**Когда применять:** блок «что внутри», список выгод оффера, тизер продукта/лид-магнита.

## Метод 3: Продавай пункт назначения, не самолёт
**Суть:** клиенту не нужен продукт (самолёт) — ему нужен результат (пункт назначения). Продавай конечное состояние.
**Шаги:**
1. Выпиши характеристику продукта (фичу).
2. Переведи её в выгоду, затем в **конечный образ жизни/результата**.
3. В тексте говори об этом образе, фичу давай как доказательство достижимости.
**Когда применять:** формулировка обещания, заголовок, отстройка «фича vs результат».
