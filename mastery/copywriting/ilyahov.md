# Максим Ильяхов — «Пиши, сокращай»: информационный стиль

Главный русскоязычный мастер чистки текста. Накладывается на ЛЮБОЙ RU-текст для аудитории ПОСЛЕ написания — вычищает воду до фактов. Применять ВСЕГДА.

## Метод 1 — Факт вместо оценки
Оценочные слова («хороший», «эффективный», «мощный», «невероятный», «качественный», «лёгкий») ничего не сообщают — это мнение автора. Заменяй фактом, цифрой или действием, из которого читатель сам сделает вывод.
- Плохо: «эффективный протокол хорошо снижает стресс»
- Хорошо: «10 минут света в первый час после подъёма сдвигают пик кортизола на утро»
Алгоритм: каждое прилагательное/наречие → вопрос «это факт или моя оценка?». Оценка без факта → удалить или заменить цифрой/действием.

## Метод 2 — Чистка от стоп-слов
Удаляй вводные («на самом деле», «как известно», «стоит отметить»), усилители («очень», «довольно», «крайне», «реально», «просто»), канцелярит («осуществлять», «является»), штампы. Тест: убери слово — смысл изменился? Нет → удалить.

## Метод 3 — Схлопни синонимичные пары
«X и Y», где Y дублирует X — вода. Тест: второй член несёт НОВЫЙ факт? Нет → вычеркнуть второй. (Память: `feedback_ilyahov_no_water_synonyms`.)

## Метод 4 — Сильный глагол вместо отглагольного
«производит снижение» → «снижает». «делает анализ» → «разбирает». Глагол двигает, отглагольное существительное замораживает.

## Метод 5 — Конкретика: цифра, срок, действие
Вместо обобщения — число/имя/срок. «многие» → «к 40 годам», «быстро» → «за 21 день», «полезно для сна» → «магний глицинат сокращает время засыпания». Один абзац — одна мысль.

## Прувный гейт (по mastery/PROTOCOL)
Методы 1 и 5 требуют ФАКТА. Факт тянуть из источника проекта (паспорт / наука / story-bank), не выдумывать. Нет факта → пометить `proof-gap`, не подменять оценкой.

## Evidence для верификатора
В готовом тексте: 0 оценочных прилагательных без факта · есть конкретные цифры/действия · нет синонимичных пар-дублей · нет усилителей-стоп-слов.

## Когда применять
Всегда на RU-тексте для аудитории, финальным проходом мастеров перед humaniser.
