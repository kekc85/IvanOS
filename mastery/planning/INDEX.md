# planning — как планировать и управлять движением к цели

Совет директоров по планированию: как одному человеку выстроить каскад «год → 12 недель → неделя → день → спринты проектов» так, чтобы каждый день двигал ключевую цель, а не имитировал занятость. Это область *связки*: 12 Week Year — лишь одна из методологий, здесь они синтезированы в единую операционную систему.

> **Главный документ области — [СИСТЕМА.md](СИСТЕМА.md): применённая операционная методология планирования автора.** Author-файлы ниже = головы за столом; СИСТЕМА = как их методы собраны в один рабочий процесс и вшиты в `tasks/`.

Каждый файл = один автор × 1-3 применимых метода. Область намеренно не дублирует мастеров: планировщики-исполнители уже сидят в `solopreneur-systems/`, приоритизаторы-решатели — в `decision-making/`; здесь — только то, чего там нет, плюс синтез.

## Новые головы за столом (планирование-специфичные)

- [[drucker]] — **Питер Друкер** (MBO): цель ведёт действие, систематический отказ от вчерашнего, анализ обратной связи. Прародитель OKR и execution-логики.
- [[doerr]] — **Джон Доерр + Энди Гроув** (OKR): Objective + 3-5 числовых Key Results, commit vs stretch (0.7 = успех), CFR-такт еженедельной сверки.
- [[gary-keller]] — **Гэри Келлер** (The ONE Thing): фокусирующий вопрос, эффект домино (секвенирование «ключевое первым»), тайм-блок под одно дело.

## Как пользоваться

1. Нужна сама система движения день/неделя/цикл → открой [СИСТЕМА.md](СИСТЕМА.md).
2. Ставишь цели нового 12-недельного цикла → [[brian-moran]] + [[doerr]] + [[annie-duke]], результат в `tasks/12wy/current.md`.
3. Не знаешь, что делать первым на горизонте → [[gary-keller]] (фокусирующий вопрос).
4. Перегруз, тянет вчерашнее → [[drucker]] (систематический отказ) + [[greg-mckeown]].
5. Раскладываешь проект на спринты → таблица «Спринты по проектам» выше.
