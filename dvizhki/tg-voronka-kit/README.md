# Кит «Воронки и рассылки в Telegram»

Свой движок воронок вместо арендованного конструктора. Человек пишет боту кодовое слово, бот ведёт его по цепочке сообщений с кнопками и таймингами, а тех, кто не дошёл до цели, догоняет дожимом. Плюс рассылки по своей базе с сегментами и общим списком исключений

Данные твои и лежат у тебя на сервере. Нет ни абонентской платы, ни лимита на подписчиков, ни чужого кабинета, из которого однажды закроют доступ

## Что внутри

| Папка | Что там |
|---|---|
| `engine/` | машина состояний воронки: импорт JSON, разбор узлов, тайминги |
| `app/` | бот-слой: обработчики, база, рассылка, короткие ссылки, реестр исключений |
| `funnels/` | воронки. Внутри лежит `voronka-DEMO.json` - готовый пример на 14 узлов |
| `tests/` | смоук-тесты, включая офлайн-прогон воронки без единого обращения к Telegram |
| `install.sh` | установка на сервер Ubuntu одной командой |
| `.env.example` | образец настроек: копируешь в `.env` и вписываешь токен |

## Три шага старта

1. Скопируй папку на сервер и запусти `bash install.sh`
2. Впиши токен бота в `/opt/voronka/.env` (токен даёт `@BotFather`)
3. `sudo systemctl enable --now voronka-bot`

Подробно, со скринами и разбором «что если не получилось» - в `КАК-УСТАНОВИТЬ.txt`

## Как это работает

Воронка это один JSON-файл. В нём узлы: `A0` - первое сообщение, `B0` - выдача обещанного, `C1-C4` - цепочка в первые сутки, `D1-D7` - дожим по дням. У каждого узла текст, кнопки и время, через которое он уходит

Файл кладётся в `funnels/` под именем `voronka-СЛОВО.json`, где `СЛОВО` это кодовое слово. Человек пишет боту это слово - и попадает в свою цепочку. Слов может быть сколько угодно, каждое ведёт в свою воронку

Свою воронку можно собрать скиллом `tg-voronka` в IvanOS: он спрашивает про нишу и оффер и выдаёт готовый JSON, который движок принимает как есть

## Проверить, что всё живо

```
cd /opt/voronka && .venv/bin/python -m pytest
```

Прогон не ходит в сеть: он проверяет машину состояний, импортёр, рассылку, безопасность и разворачивает воронку офлайн-двойником

## Что кит НЕ делает

Он не пишет за тебя тексты воронки и не решает, кому и что слать. Сообщения людям уходят только по твоей команде: ни одной автоматической отправки без твоего действия в ките нет

ИИ-ответчик на живые сообщения в комплекте идёт каркасом: механика готова, а персону (кто ты, как говоришь, что продаёшь) вписываешь ты в `app/ai_responder.py`. Пока она пуста, живые сообщения просто пересылаются тебе
