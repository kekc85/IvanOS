# Mastery Gate — линза мастеров области (HARD)

> Переиспользуемый гейт для всех скиллов-писателей. Полный регламент — `mastery/PROTOCOL.md`. Источник: память `feedback_mastery_real_application_with_verification`, решение автора 2026-05-31.

## Когда применять
Текст для аудитории (пост / письмо / карусель / твит / пуш / сценарий / caption) → тематический mastery = `mastery/copywriting/`. Перед написанием — обязательно по шагам ниже.

> **Graceful degradation (если `mastery/copywriting/` отсутствует).** Папка `mastery/copywriting/` и `mastery/PROTOCOL.md` - опциональный вход. ЕСЛИ `mastery/copywriting/` существует → полный протокол Inventory→Select→Apply→Evidence ниже (читать INDEX.md и файлы авторов). ЕСЛИ её нет (например, у ученика без mastery-пакета) → НЕ ошибаться на file-not-found: опереться на встроенный список 12 авторов в этом файле (см. шаг 1), вывести в чат одну строку «mastery/copywriting не найден, опираюсь на встроенный список авторов» и продолжить Select→Apply→Evidence по встроенному списку. Строгий протокол остаётся в силе там, где папка есть.

## Фаза до написания (bind во время draft)
1. **Inventory ВСЕХ авторов** области (не 1-2 по памяти): если есть `mastery/copywriting/` - `Read(mastery/copywriting/INDEX.md)`, выписать каждого + методы; если папки нет - взять встроенный список ниже. Сейчас 12: Огилви / Шугерман / Кэплз / Халберт / Шварц / Хопкинс / Кольер / Бенсивенга / Кеннеди / Райс-Траут / Бёрд / Шваб.
2. **Select с обоснованием** — по каждому пометка `применяю / не применяю + почему` под ЭТУ задачу (жанр, платформа, длина). «Рассмотреть всех» ≠ «впихнуть всех»: неподходящий метод осознанно отсекается с причиной.
3. **Apply** — каждый выбранный метод по его алгоритму (читать файл автора), привязка к блокам текста.
4. **Правило пруфа:** методы-факты (Хопкинс reason-why / Бенсивенга пруф / Огилви конкретика) тянут реальный факт из источников. Нет факта → это Context-gap (`_shared/context-gap-gate.md`), спросить автора, не выдумывать мягкий пруф.

## Фаза проверки (после draft, до humaniser)
5. **Evidence Report** — таблица `автор · метод → дословная цитата из готового текста`. Пустая цитата = метод не применён → доработать или честно снять с причиной.
6. **Независимый верификатор** (запускается ВСЕГДА, v4.2 — `--fast` устранён) — отдельный субагент (`Agent` tool, general-purpose), который НЕ писал текст, получает текст + Evidence Report, по каждому методу выносит PASS/FAIL с цитатой (скептик: сомнение = FAIL). Любой FAIL → доработка. ≥2 «слабо» (даже при PASS) → revision recommended.

## Порядок в пайплайне
…structure → **Mastery (Inventory+Select)** → write+bind → review → **Mastery (Evidence+Verifier)** → Humaniser → output.
