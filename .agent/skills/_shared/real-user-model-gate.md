# Real-User-Model Gate - модель реального пользователя ДО постройки (HARD)

> Переиспользуемый гейт. Читается ПЕРВОЙ фазой для любого student-facing / дистрибутив-артефакта,
> ДО первой строки кода, не аудитом постфактум. Источник: feedback_real_user_model_before_building,
> корневой разбор сессии по решению автора (мета-корень: «готово» = «я прочитал свою модель» вместо
> «я прогнал путь пользователя на ЕГО рантайме и увидел результат»).

## Когда применять (триггер)

Артефакт запустит/откроет НЕ я на СВОЕЙ машине: дистрибутив/установщик/zip, публичный скилл,
гайд «открой в X», лендинг-инструкция, любой student-facing артефакт.

**Лёгкость-исключение (Правило №1 не душить):** правка обратима <5 мин И не трогает ни одного
исполняемого пути адресата (текст карточки, опечатка README) → пропускаю.

## 4 строки персоны в чат ДО постройки

1. **КТО** запустит: новичок, ноль контекста, возможно с телефона.
2. **РАНТАЙМ по умолчанию ВРАЖДЕБНЫЙ:** чистая Windows без brew/python/bash, кириллица+пробелы в
   путях, ЧУЖОЙ аккаунт/ключи (не мои), ноль моих прошлых сессий, Gatekeeper/SmartScreen/карантин.
3. **СОСТОЯНИЕ ПОСЛЕ установки:** что физически лежит, первый экран, какая кнопка НЕ очевидна.
4. **END-TO-END walkthrough первой минуты:** скачал → открыл → нажал → первый результат на ЕГО рантайме.

## Правило готовности

«Готово» = walkthrough ПРОИГРАН строкой в чате и упёрся в КОНКРЕТНЫЙ шаг (а не «я не вижу проблемы»).
Пока не проигран - не строю и не говорю «готово / из коробки / одно действие».
Правило обезличивания «для автора» НИКОГДА не применять к ИСПОЛНЯЕМОМУ коду адресата
(прецедент: HEYGEN_AVATAR_ID → <SERVICE> сломал bash-скрипт у всех учеников).
