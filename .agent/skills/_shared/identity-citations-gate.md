# Identity-Preservation + Verbatim-Citations Gate

Shared snippet для review-стадии всех writer skills. Источник: SOLO Алекс `pisatel-*` + `issledovanie-ca` patterns (каннибализация по решению автора).

Применяется в дополнение к `_shared/4-tests-headline.md` (если используется) перед humaniser-фазой.

## Gate 1 — Identity-preservation (BLOCKING)

Финальный текст НЕ должен требовать от ICP смены профессии / идентичности.

**Проверка:** прочитай текст и ответь на 2 вопроса:

1. **Психолог-нутрициолог-коуч-эксперт, читая этот текст, остаётся собой?** Или текст подразумевает «теперь ты становишься X» (вайбкодером / маркетологом / digital-предпринимателем / контент-мейкером)?
2. **Продукт / результат в тексте описан как УСИЛЕНИЕ существующей экспертизы или как ЗАМЕНА её на новую идентичность?**

Если ответ на вопрос 1 = «нет, текст подразумевает смену проф./идентичности» → **FAIL**, переписать с identity-preservation pattern: «Психолог остаётся психологом. Просто теперь у него есть продукт, который продаёт пока он спит».

Если ответ на вопрос 2 = «замена» → **FAIL**, переписать как усиление.

**Эталонные формулировки:**
- ✅ «Психолог собирает свой AI-помощник по тревожности. Психологом остаётся.»
- ✅ «Нутрициолог запускает калькулятор рациона. Нутрициологом остаётся.»
- ❌ «Стань AI-разработчиком за 6 недель» (требует смены идентичности — FAIL)
- ❌ «Превратись в digital-предпринимателя» (требует смены — FAIL)

## Gate 2 — Verbatim citations (BLOCKING если в тексте есть цитаты ICP)

Если текст содержит цитаты / прямую речь ICP (например в Hook / Story / Social proof) — они должны быть **дословными** из банка (`.business/voice-corpus/` или `.business/запуски/<launch>/1-Аудитория.md` Блок 6 или эквивалентный artefact). Не парафраз.

**Проверка для каждой цитаты в тексте:**

1. Цитата длиной 15-40 слов (короче = lose context, длиннее = lose punch)?
2. Цитата помечена пометкой источника (q7 №N / Hidden Gem #N / волна-N респондент-X)?
3. Цитата совпадает дословно с банком (grep по source файлу)?

Если 1 ответ «нет» → переписать на нужную длину.
Если 2 ответ «нет» → добавить пометку источника или удалить цитату.
Если 3 ответ «нет» (AI парафраз вместо дословного цитирования) → **FAIL**, заменить на дословную из банка или удалить.

**Анти-паттерн:** AI-парафраз цитаты под красоту фразы — теряет голос ICP, делает текст generic.

## Использование в review

В review-стадии writer skill добавь Pass перед humaniser:

```
### Pass X.Y — Identity + Citations Gate (BLOCKING)
Read ~/.claude/skills/_shared/identity-citations-gate.md, применяй Gate 1 + Gate 2.
Если хоть один FAIL → revision, не proceed на humaniser.
```

## Когда НЕ применять

- Skill не генерирует публичный текст для ICP (data processing / config / scraping skills)
- Текст явно не содержит позиционирование / identity-claims / цитаты ICP (например internal status report)
