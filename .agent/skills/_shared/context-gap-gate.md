# Context-Gap Gate — нет реального контекста → СПРОСИ, не выдумывай (HARD)

> Переиспользуемый гейт для всех скиллов-писателей. Читается на стадии brief/structure ДО написания текста. Источник правила: память `feedback_ask_for_missing_context_never_invent`, решение автора 2026-05-31.

## Правило (обязательное при работе с текстом)

Если для качественного текста не хватает **реального контекста** — я **НЕ придумываю** его. Я останавливаюсь и **спрашиваю автора** конкретным списком. Лучше один точный вопрос и пост, который не нужно редактировать, чем выдуманный факт под его именем.

Это особенно критично для учеников курса: скилл должен **запрашивать** недостающее, а не галлюцинировать.

## Что считается «контекстом, который нельзя выдумывать»

- **Цифры и метрики:** число подписчиков/учеников/клиентов, охваты, выручка, конверсии, цены, проценты, сроки, «N человек забрали», результаты кейса.
- **Актуальные инфоповоды и новости:** что сейчас происходит на рынке, свежие события, блокировки, апдейты площадок, «сегодня вышло X».
- **Конкретные факты о продукте/запуске:** дедлайны, состав оффера, бонусы, даты эфиров.
- **Личные сцены и кейсы:** реальная история, дословная цитата ученика/аудитории, конкретный вопрос из ДМ.
- **Имена, названия, ссылки.**

## Алгоритм гейта (до draft)

1. Собери список фактов, которых требует выбранный угол/жанр поста.
2. Для каждого проверь: он есть в источниках (config / карта смыслов / story-bank / транскрипт / то, что автор дал в чате)?
3. Сформируй секцию **Context-gap:**
   - Если всё есть → `Context-gap: нет, контекст полный` → продолжай.
   - Если чего-то нет → **СТОП.** Не писать draft. Вывести в чат нумерованный список «нужно от тебя:» с конкретными вопросами (какие именно цифры/факты/новости нужны и куда они встанут в пост).
4. **Запрещено:** выдумывать цифру, подставлять «примерную», округлять до правдоподобной, ставить плейсхолдер вида «N человек» в финальный текст без явной пометки, изобретать инфоповод/новость, сочинять кейс или цитату.
5. Получив факты от автора → встроить дословно, написать пост, который не нужно редактировать.
