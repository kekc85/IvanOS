# Склей-отрывки - пакетная сборка дублей в один ролик

Берёт папку с отрывками (например запись урока/эфира на N дублей), в каждом обрезает
лишнюю тишину в начале и конце, склеивает по порядку в один плотный ролик. Без музыки.
Внутренние паузы внутри дубля НЕ трогает (рез внутри дубля порубил бы предложение).

Детерминированный конвейер: запускается одной командой и доводит до готового файла,
вопросов не задаёт. Прецедент сборки - 33 клипа урока по вайбкодингу, по решению автора.

## Когда применять

Триггеры:
- «склей отрывки/дубли в один ролик», «смонтируй клипы из папки»
- «собери длинный ролик из нарезок», «обрежь паузы и склей»
- «у меня N отрывков на столе, сделай один ролик»
- `/склей-отрывки <папка>`
- "montage these takes / clips into one video"

Не применять:
- интерактивный покадровый монтаж с обсуждением → `[[video-use]]`
- нарезать ОДНО длинное видео на куски-шортсы → `[[cut-from-long-form]]`
- наложить субтитры/оверлеи → `[[embedded-captions]]`, `[[graphic-overlays]]`

## Что делает (один режим)

Один скрипт `scripts/montage.py` делает весь конвейер:

1. **Discovery + порядок** - находит видео в папке/по glob, сортирует (natural по числам в имени = 1,2,…,10, не 1,10,2)
2. **План реза по РЕЧЕВОЙ ПОЛОСЕ** - `silencedetect` крутится на отфильтрованном через полосу голоса аудио (`highpass=200,lowpass=3500` = `SPEECH_BAND`), а НЕ на полном. Иначе пододвигание ноутбука / стук стола / гул (НЧ-шум -35..-40dB) считается «звуком» и край не режется. В полосе голоса этот шум падает до -50dB, речь остаётся -25..-33dB → порог `--noise -38dB` их чисто разделяет
3. 🔴 **Voiced-blocks: НИ ОДИН блок речи не выбрасывается** - из тишин строим звуковые блоки, и в keep-окно попадает КАЖДЫЙ, даже длиной 0.15с. `--min-voice` больше НЕ отбрасывает короткие блоки: он зажат потолком 0.12с и снимает только одиночный клик, у которого в радиусе 0.6с нет другой речи. Дальше идёт **итеративный откат** (`rollback_edges`): если у границы реза слышен звук громче -40dB, граница отодвигается НАРУЖУ шагом 0.15с, пока перед резом не станет чистая тишина. Любое сомнение решается в пользу сохранения материала

   **Почему так, а не «поднять min-voice»:** в монтаже «Модуль2-Урок1» пропало «бренд ДНК», по решению автора в подготовительном уроке - начало фразы «Самое простое…». Оба раза причина одна: блок речи короче порога (0.44-0.53с) считался шумом и уезжал в мусор вместе с тишиной. Русские слова «да», «так», «вот», «самое» звучат ровно 0.3-0.5с. **Поднимать `--min-voice` ради борьбы с возней ЗАПРЕЩЕНО** - это прямой путь к съеденным словам; возня отсекается спектром (см. п.3б), а не длиной

3б. **Отсев неречевых звуков по спектру** - кряхтение, «ух-хм», кашель, прочистка горла ГРОМКИЕ (до -20dB), порогом тишины их не убрать. Отличаются от речи спектром: энергия в низах (80-250Гц), провал в полосе разборчивости (800-3500Гц). Замер на живом материале: кряхтение низ -24.8 / верх -37.8 (перевес +13dB), речь низ -33.1 / верх -28.1 (перевес -5dB). Порог `GRUNT_TILT_DB=10` + защита `GRUNT_HIGH_FLOOR=-34` (есть разборчивость в верхах → это речь, не трогаем). Снимается только с ГОЛОВЫ и только если после блока есть пауза
4. **Нормализация + энкод** - каждый сегмент к целевому формату (scale+pad+fps первого клипа), libx264, в MPEG-TS интермедиат (параллельно)
5. **Склейка** - concat TS с `-c copy` + `aac_adtstoasc`. Каждый сегмент внутри синхронен и якорится на стыке → рассинхрон НЕ накапливается по стыкам
6. 🔴 **Аудит краёв ДО энкода + ЖЁСТКИЙ ГЕЙТ** - `edge_audit` гоняется ПО ПЛАНАМ ещё до кодирования (раньше он шёл после склейки и просто печатал ⚠, а файл всё равно уезжал как «ГОТОВО» - так брак и попал в оба ролика). Проверка **сплошная**: сканируется ВСЯ выброшенная голова и ВЕСЬ выброшенный хвост шагом 0.10с, а не только окно у самой границы (прецедент «бренд ДНК»: блок речи лежал в 0.5с ОТ реза, узкое окно его не видело). Звук громче -40dB в выброшенной зоне = срез речи. Нашли - клип автоматически пересобирается с расширенными границами, в пределе берётся ЦЕЛИКОМ. Если после всех попыток срез остаётся, скрипт печатает `БРАК: СРЕЗ СЛОВА` и **выходит с кодом 1**, а не «ГОТОВО». Обход только явным `--allow-word-cut`

6в. 🔴 **ГЕЙТ ПУСТОТЫ: скан ВСЕГО финала на тишину** - после склейки весь таймлайн сканируется
`silencedetect` по речевой полосе (`noise=-38dB:d=1.0`). Любая пауза >1с = `БРАК: ПУСТОТА В РОЛИКЕ`,
выход с кодом 1, обход только `--allow-dead-air`. **`edge_audit` эту беду НЕ ловит** - он проверяет
ровно одну сторону (не срезал ли слово) и оставленную тишину не видит физически. Однажды зелёный
`edge_audit` закрыл сдачу, в которой висело 12,3с молчания в камеру (07:06-07:20) - автор нашёл
руками. Обе беды теперь симметричны: срез слова и оставленный воздух валят сдачу одинаково

6б. **Независимая пословная сверка** - `scripts/verify_words.py` транскрибирует whisper-ом каждый исходник и каждый выброшенный кусок, сверяет слова и возвращает код 1 при любой потере. Мычание («ух-хм», «м-м-м») и галлюцинации whisper на тишине («Продолжение следует…», «Спасибо.») потерей НЕ считаются - иначе ложная тревога валит чистый монтаж. Запуск: `verify_words.py --plan plan.json` (проверка резов) или `--sources ПАПКА --final ФАЙЛ` (проверка готового)
7. **Отчёт** - человекочитаемый + строка `RESULT_JSON={...}` (с полем `edge_audit`) для парсинга

### Запуск

```bash
python3 ~/.claude/skills/склей-отрывки/scripts/montage.py "<папка или glob>"
# напр.: python3 .../montage.py ~/Desktop --order natural
```

Частые опции (полный список в шапке скрипта): `--out PATH` (вывод; на Desktop запрещено),
`--order natural|name|mtime`, `--noise -38dB` (порог на речевой полосе), `--min-voice 0.45`
(мин. длина блока речи), `--pad-lead 0.10`, `--pad-trail 0.18`, `--gap-merge 0.12`, `--workers 4`.
Шумные записи (громкий фон/возня) - детект уже по полосе голоса; если возня всё же остаётся в
начале, поднимай `--min-voice` (0.5-0.6) - длиннее порог = жёстче отсекаются вводные буркания.

Вывод по умолчанию: `~/montage_final/<имя-папки>-montage.mp4` + `~/montage_final/contact_sheet.png`.

🔴 **Доставка финала = ВСЕГДА копия на `~/Desktop/`.** Скрипт сам дублирует готовый ролик на стол
(поле `desktop_copy` в RESULT_JSON) - это точка забора автора, приказ «монтаж всегда класть на рабочий
стол» (по решению автора, дважды). В сдаче проверить, что копия легла, и назвать ОБА пути.
Запрет Desktop касается только `--out` и промежуточных файлов, НЕ финальной копии.

## Принципы

1. **Режем голову, хвост И длинное молчание внутри дубля.** Короткие паузы между фразами (дыхание, до ~1с) - часть речи, не трогаем. Но пауза внутри дубля длиннее ~1с - это автор молча смотрит в камеру, и её режем так же, как воздух между дублями. Формулировка «внутренние паузы НЕ трогаем» в старой версии стоила сдачи по решению автора: в клипе `17-28-59` осталась дыра 3.9с внутри плюс 7.2с в голове (детект принял шорох за речь и поставил `keep 0.00`), итого 12,3с молчания в финале. Цель - плотный урок без пустоты, а не буквальное следование «только края»
2. **Отличать РЕЧЬ от ВОЗНИ - детект в полосе голоса, не на полном аудио.** Пододвигание ноутбука, стук стола, гул, шорох в начале дубля по полному уровню громкие как речь (-35..-40dB), но это НЧ-шум. Фильтр `SPEECH_BAND` (200-3500Гц) их гасит до -50dB, речь остаётся → их видно врозь. Главный урок по решению автора: первый монтаж оставил «шумлю и не начинаю говорить» в началах именно потому, что детект шёл по полному аудио и считал возню речью
3. **Никогда не резать слово.** Рез ставится ДО первого устойчивого блока речи (≥`--min-voice`) и ПОСЛЕ последнего, плюс паддинг. Встроенный `edge_audit` пост-фактум проверяет каждый рез по речевой полосе и сигналит, если речь шла непрерывно через рез. Лучше оставить 0.1с воздуха, чем срезать слог
3. **Без музыки.** Только оригинальный звук дублей, ничего не добавляем
4. **Синхрон через сегменты.** Каждый клип энкодится целиком (видео+звук вместе) → внутри синхронен; склейка copy якорит на стыке → дрейф не копится. Норма A/V расхождения на всё видео < ~50мс
5. **Доводить до готового файла без вопросов.** Недостающий клип в нумерации, пустой звук, смешанные форматы - обрабатываются сами, блокер - одной строкой в отчёте
6. **Доказательство сборки.** Контактный лист показать инлайн в чат (Read png), путь к файлу - простым текстом/код-блоком, НЕ markdown-ссылкой на локальный путь

## Anti-patterns

- **`--out`/промежуточное на Desktop** - запрещено (скрипт сам отклоняет), хлам бьёт пути автора. НО финальную копию скрипт кладёт на стол ОБЯЗАТЕЛЬНО - не путать: хлам нельзя, финал must
- **Сдать монтаж без копии на ~/Desktop** - автор забирает ролики СО СТОЛА, файл только в `~/montage_final/` = «я не вижу ничего» . Проверить `desktop_copy` в RESULT_JSON
- **Markdown-ссылка на локальный mp4** - на телефоне не кликается = пустая доставка. Путь только текстом, доказательство = инлайн контактный лист
- **Резать внутренние паузы** - меняет смысл речи, не просили
- **Детект границ на ПОЛНОМ аудио** - громкая возня (пододвигание ноутбука/стук/гул, -35..-40dB) сходит за речь, край не режется, в начале остаётся «шумлю и не говорю». Детект ВСЕГДА по полосе голоса `SPEECH_BAND`
- **Сдавать монтаж не послушав края** - заявить «готово» по контактному листу (он только видео, аудио-пустоты не видит). Перед сдачей - читать `edge_audit` в отчёте; `⚠` = открыть проблемный клип, не игнорить. Прецедент по решению автора: дважды сдал с возней в началах
- **Проверять выборкой кадров глазами** - верификация машинная по всему таймлайну (скан пауз, A/V skew, аудит краёв)
- **Заявлять «готово» без улики** - всегда путь + длительность + A/V skew + аудит краёв + контактный лист
- **Переименовать/перезаписать монтаж не убрав старую копию** - две версии с похожими именами = автор думает что ничего не менялось. Новой версии - новое имя, старую убрать (обратимо: `trash`/датированный бэкап). Прецедент по решению автора
- **concat-copy при смешанных форматах без нормализации** - ломает поток; скрипт нормализует каждый сегмент к целевому W×H×fps
