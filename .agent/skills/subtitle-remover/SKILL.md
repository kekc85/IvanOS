# subtitle-remover

Чистое удаление вшитых субтитров из видео. Заточен под вертикальные рилзы с подписями в нижней/центральной полосе.

## Когда использовать
- Забрать чистую вырезку из чужого ролика (свои субтитры наложим потом).
- Снять караоке-подписи перед репликацией/ремиксом.
НЕ для: добавления субтитров (это embedded-captions), не для подписей, лежащих ВСЮ длительность на лице/объекте без единого чистого кадра (нерешаемо инпейнтингом — честно сказать).

## Уроки, вшитые в пайплайн (почему прошлый раз вышло грязно)
1. **Мелкие чанки убивают качество.** ProPainter восстанавливает фон, подсматривая соседние кадры; в окне 25 кадров чистого донора нет → смаз/призрак. → Здесь окно широкое (`subvideo_length`=весь чанк, `neighbor_length`≤18, `ref_stride` 6), а чанк максимально большой, какой влезает в RAM.
2. **Хрупкий детектор пропускал ~26% кадров и жёлтые подписи.** → EAST-модель ловит текст любого цвета/без плашки/не по центру.
3. **Не проверяли ВЫХОД.** → OCR-селф-тест на выходной полосе; «готово» только при PASS.
4. **Краш по памяти.** → страж: разрешение и чанк выбираются под свободную RAM (`vm_stat`), при <8ГБ — стоп. Никогда не запускать тяжёлый прогон под открытыми Chrome/VS Code автора (и инцидент по решению автора).

## Конвейер (`scripts/run.sh <in.mp4> <out.mp4> [workdir]`)
1. Кадры (ffmpeg 30fps).
2. **detect.py** — EAST(текст в полосе) ∪ плашка, затем посценовый временной фильтр (субтитр меняется кадр-к-кадру → держим; статичный UI/бейджи → гасим). Пишет `report/MASK_PREVIEW.mp4`.
3. 🔴 **ГЕЙТ превью:** глазами проверить `MASK_PREVIEW.mp4` — стирается ли всё нужное и не задет ли контент — ДО тяжёлого инпейнта. Дёшево, ловит пере/недомаскинг.
4. Инпейнт ProPainter, чанки под RAM, широкое окно, resume по кадрам.
5. Склейка + оригинальный звук.
6. **selftest.py** — EAST по выходной полосе. Остался текст/призрак → exit 2 (FAIL), «готово» НЕ заявлять, чинить (шире маска `mask_dilation`, ниже `CHANGE_THRESH`, крупнее чанк).

## Параметры (env)
`BAND_TOP`/`BAND_BOT` полоса субтитров (доли высоты), `EAST_CONF`, `CHANGE_THRESH` (порог «движения» для временного фильтра), `CUT_THRESH` (детект склейки), `TEMPORAL=0` выключить временной фильтр, `OMP_NUM_THREADS` (щадящий режим — 8).

## Движок
ProPainter в `~/propainter-lab` (веса на месте), EAST в `models/`. MPS на маке сломан → CPU (медленно, но стабильно), поэтому тяжёлые прогоны — ночью на свободной машине.
