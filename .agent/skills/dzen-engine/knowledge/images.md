# Картинки к дзен-статье

Тракт генерации проверен живьём по решению автора боевой генерацией (SAVED, 1.8 МБ, exit 0)

🔴 Правка канала по решению автора (причина: окна браузера мешали владельцу работать за
компьютером). Раньше единственным трактом был живой CDP-браузер. Теперь по умолчанию
генерация идёт тихим headless-каналом без единого открытого окна, живой браузер остаётся
запасным путём под явным флагом. Ниже - актуальный порядок

## 1. Сколько и чего нужно

| Что | Размер | Обязательность |
|---|---|---|
| Обложка (карточка в ленте) | 1920×1080, 16:9, минимум 960×540, до 10 МБ | 🔴 обязательна: без неё серый квадрат в ленте и убитый CTR |
| Внутренние иллюстрации | ширина от 300 px, до 30 МБ каждая | лонгрид-топ держит 9-13 штук, детонатор 1-2 |

Обложка без мелких деталей: карточка в ленте маленькая, мелочь не читается. Анимация запрещена,
шок-контент запрещён

## 2. Основной тракт: тихий headless-канал (codex_image.py)

Генератор по умолчанию - `.business/scripts/codex_image.py`. Внутри: `codex exec` →
системный скилл imagegen → встроенный инструмент image_gen. Логин тот же ChatGPT-аккаунт
владельца, ключ API не нужен, окно браузера не открывается вообще - ни до генерации, ни во
время, ни после. Замер живьём по решению автора: фото-обложка 3:2 вышла ровно 1536×1024 за 78 секунд,
окон Chrome до и после - ноль

```bash
python3 .business/scripts/codex_image.py \
  --prompt "<промпт>" \
  --out work/<slug>/images/NN-название.png \
  --size og
```

Размеры (флаг `--size`): `og` = 1536×1024, `square` = 1024×1024, `slide` = 1024×1280,
`story` = 1024×1536. Дзен-обложке 16:9 ближе всего `og` - после генерации крой/масштаб до
1920×1080 при необходимости. Можно передать до 5 файлов-референсов флагом `--ref`

Проверка готовности канала БЕЗ расхода генераций:

```bash
python3 .business/scripts/codex_image.py --selftest
```

🔴 Изолированный дом `~/.codex-image` обязателен и держится движком сам: обычный `codex`
подтягивает `~/.codex/AGENTS.md` (навигацию системы) и вместо картинки уходит проводить
онбординг. Проверено живьём, отдельно настраивать ничего не нужно - скрипт готовит свой
`CODEX_HOME` автоматически

Код возврата скрипта: `0` = SAVED (картинка сохранена), любой другой = ОШИБКА, причина
печатается текстом в stderr после `ОШИБКА:` (`--help` эту причину не покажет, коды не
вынесены в таблицу - у скрипта их всего два). Ненулевой код = повторить запуск или честно
доложить блокер. Запрещено выдавать статью «с картинками», когда картинок нет

🔴 **Лимит аккаунта Codex может быть выжжен.** Тогда вместо картинки скрипт честно печатает
`ЛИМИТ АККАУНТА CODEX выжжен` с датой, когда лимит откроется - это внешний блокер, не брак
промпта. Проверить состояние заранее без расхода генераций: `python3
.business/scripts/codex_image.py --selftest`. Пока лимит закрыт - картинки идут
запасным браузерным каналом (раздел 2.1)

**Общего ресурса больше нет.** Раньше все генерации шли через один живой Chrome и держали
межпроцессный лок - предупреждения «работай в одной вкладке», «жди пока откроется окно», «один
прогон за раз» относились именно к нему. Для тихого канала это не действует: параллельные
прогоны не делят браузер, не делят буфер обмена и не встают в очередь друг за другом - можно
генерировать несколько картинок статьи одновременно

## 2.1 Запасной путь: живой браузер (CDP :9222), только под явным флагом

Держать браузер как основной путь запрещено - именно открытые окна мешали владельцу работать
за компьютером, отсюда и вся правка 03.08.2026. Живой канал остаётся доступным на случай отказа
тихого: та же механика, что раньше (рендер-Chrome по CDP :9222, профиль
`~/.chrome-cdp-profile`, скрипт `~/.claude/skills/post-image/scripts/gen-chatgpt-image-cdp.py
--engine browser`), но вызывать её нужно осознанно, а не по умолчанию. Если тихий канал
недоступен (селфтест не прошёл) - сначала чинить его, и только если починить нельзя за разумное
время, объявлять о переходе на браузер и работать в СВОЕЙ новой вкладке, не трогая чужие

🔴 Запреты на этом пути:
- НЕ звать `gen-chatgpt-image.py` без `--engine browser` (или старый флаг `-cdp` на прежних
  вызовах): без него скрипт открывает изолированный профиль без логина и всегда даёт
  NO_IMAGE_TIMEOUT, который ВЫГЛЯДИТ как «профиль разлогинился». Ложный диагноз, хук
  `gpt-image-wrong-browser-guard.sh` блокирует такой запуск (exit 2)
- НЕ звать higgsfield - заблокирован хуком no-higgsfield-without-permission.sh (кредиты = деньги,
  exit 2)
- работать только в своей новой вкладке рендер-Chrome (скрипт делает это сам и закрывает её)

Коды возврата `gen-chatgpt-image-cdp.py` на этом пути (из докстринга скрипта, `--help` их не
печатает):

| Код | Значение |
|---|---|
| 0 | SAVED - картинка сохранена |
| 2 | NO_EDITOR - поле ввода ChatGPT не найдено (не залогинен/страница не та) |
| 3 | NO_IMAGE_TIMEOUT - картинка не появилась за timeout |
| 4 | NO_SRC - у картинки нет src |
| 5 | DOWNLOAD_FAIL - скачивание сорвалось |
| 6 | ERROR - прочая ошибка |
| 7 | CDP_DEAD - рендер-Chrome на :9222 не отвечает |
| 8 | тихий канал не сработал, а откат запрещён флагом `--no-fallback` |

Не-ноль = повторить запуск или честно доложить блокер

## 3. Куда класть

- Рабочая папка: `work/<slug>/images/` внутри скилла
- 🔴 НИКОГДА в `.business/growth/produced` - хук блокирует запись (exit 2)
- 🔴 НИКОГДА не отдавать автору картинку markdown-ссылкой на локальный путь - Stop-хук бракует
  ответ. Показывать инлайн через Read или открываемым файлом

## 4. Промпт-канон

Эталон - живая editorial-документалка, не wellness-сток:

- фотореализм editorial: плёнка Kodak Portra 400 / 35mm, мягкое зерно
- живая кожа: поры, текстура, лёгкая асимметрия, без ретуши-глянца
- реальный свет: от окна, раннее утро, пасмурно; мягкие направленные тени, без студийной вспышки
- кадр-репортаж: чуть несимметрично, воздух, реальный бытовой интерьер
- БЕЗ текста и букв на картинке

Negative (вписывать в промпт): plastic skin, CGI, 3D render, stock smile, glossy retouch,
oversaturated, text, letters, watermark, extra fingers

Скриншоты интерфейсов нейросетью НЕ генерить. Либо реальный скриншот, либо честная
схема-диаграмма. Фейковый скрин = обман читателя и брак

## 5. QA-гейт картинок (блокирующий)

Открыть и посмотреть КАЖДУЮ картинку через Read - не по имени файла, глазами:

1. кожа живая, не пластик и не воск
2. пальцы целые, текста на картинке нет, артефактов нет
3. вотермарок нет
4. размер: `sips -g pixelWidth -g pixelHeight <файл>` - обложка 1920×1080, внутренние от 300 px
5. вес: обложка до 10 МБ, внутренние до 30 МБ

Провал любого пункта = перегенерить. Выдавать брак запрещено

## 6. Alt-тексты

Каждой картинке - alt до 120 знаков: что на картинке и зачем она в этом разделе, без слов
«изображение», «картинка», «фото». Хранить рядом: `work/<slug>/images/alts.md`
