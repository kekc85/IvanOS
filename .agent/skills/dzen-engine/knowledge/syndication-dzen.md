# Порядок «свой сайт → Дзен»

Факты проверены живьём по решению автора: справки Google, Яндекса, Дзена, живой HTML площадки.
Это документированные правила систем, не мнение

## 1. Почему нельзя просто скопировать

**Дзен: копипаст убивает охват на самой площадке.** Дословно из
dzen.ru/help/ru/requirements/copypaste.html: заимствованный контент - публикации, «по содержанию
полностью или почти полностью совпадающие с публикациями, уже размещёнными в Дзене»
и «опубликованные на нескольких каналах, даже если все эти каналы принадлежат одному автору».
Такие материалы «будут показаны ТОЛЬКО ПОДПИСЧИКАМ». Копия 1:1 мертва внутри Дзена

**Google: технической защиты от синдикации нет.** Дословно из developers.google.com:
«The canonical link element is not recommended for those who want to avoid duplication by
syndication partners... The most effective solution is for partners to block indexing of your
content». На Дзене нельзя поставить ни canonical на свой сайт, ни noindex. Значит единственная
защита - разведение запросов

**Яндекс: межсайтовой склейки нет, но выдачу выиграет траст.** Дословно: «Дублями признаются
страницы в рамках одного сайта». Кросспост санкцией не считается, но если статья и её копия
бьют в один запрос - выдачу заберёт более трастовый домен, то есть Дзен, а не свой сайт.
Инструмент «Оригинальные тексты» мёртв с этой редакции, замена - «Переобход страниц» + «Обход
по счётчикам Метрики»

## 2. Порядок публикации (жёсткий, шаги не переставлять)

1. Полная версия выходит на СВОЁМ сайте первой (через `lead-magnit`) - она канон
2. Сразу переобход: Яндекс.Вебмастер «Переобход страниц» + GSC «Запросить индексирование»
3. Ждать ФАКТА индексации: `site:домен/слаг` в Яндексе И Google. Ждём факт, не таймер -
   «прошло 3 дня» не аргумент
4. Только после индексации - Дзен: рерайт 30-50%, свой заголовок под другой запрос, свой угол
5. Ссылка на полную версию у себя - встроенная в смысл текста. Образец: Хабр сам постит
   в свой Дзен-канал тизер + ссылку на полную версию (проверено живьём dzen.ru/b/amnVDM)

## 3. Разведение запросов

Единственная реальная защита своего сайта. Свой сайт и Дзен НЕ должны конкурировать за один запрос:

| Где | Какой запрос | Пример заголовка |
|---|---|---|
| Свой сайт | коммерческий или целевой ключ | «Как настроить контент-завод на Claude: пошаговый план» |
| Дзен | смежный читательский угол | «Я месяц не писал посты руками - что из этого вышло» |

Проверка перед публикацией: положить два заголовка рядом и спросить «по какому запросу их
найдут?» Один и тот же ответ = заголовок для Дзена переделать

## 4. Проверка рерайта (блокирующий гейт)

```bash
python3 ~/.claude/skills/lead-magnit/tools/originality-check.py \
  work/<slug>/adapted.md <исходник> --max-cosine 1.0
```

Порог: **ngram не выше 0.3** против исходной статьи. Cosine-ось отключена осознанно
(`--max-cosine 1.0`): адаптация своей статьи на ту же тему всегда даёт высокий cosine - тот же
словарь. Парадокс: в `lead-magnit` этот чекер ловит похожесть на чужое, здесь наоборот - слишком
похоже на СВОЮ исходную статью = FAIL, адаптация недостаточно переписана. Провал = дорерайтить,
не публиковать

## 5. Темп

Google с 2024-2025 наказывает site reputation abuse: массовую штамповку SEO-текстов на чужом
трастовом домене ради ранжирования. Разовые экспертные статьи - не нарушение. Ограничитель:
1-2 статьи в месяц, не пачками

## 6. Что Дзен даёт на самом деле

Проверено в живом HTML площадки:

| Параметр | Дзен |
|---|---|
| canonical | self, даже на перепечатке |
| внешние ссылки | /away?to= + nofollow + Disallow: /away в robots.txt |
| ссылочный вес | нет |
| индексация статей | есть (/b/... открыты) |
| страницы каналов | noindex |

Публикуемся ради охвата, E-E-A-T (репутация автора по Quality Rater Guidelines
оценивается ВНЕ его сайта), брендовых запросов и AI-цитирования. НЕ ради ссылочного веса -
его Дзен не отдаёт

AI-краулеров Дзен не блокирует (robots.txt: GPTBot, PerplexityBot, ClaudeBot в запретах нет),
а ИИ-движки системно предпочитают крупные UGC-площадки

И ещё: Дзен с этой редакции принадлежит VK, не Яндексу. Миф «Дзен свой для Яндекса и его любит
поиск» мёртв
