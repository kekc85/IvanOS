# Режим D — банк тем

Читай этот файл, когда эксперт явно попросил «банк тем» или «наполнить запас идей без привязки к датам».

Режим редкий, намеренное планирование без слотов и дат. Включается только в **осмысленном** режиме глубины — это не быстрая сборка.

## Параметры

Спроси у эксперта:

- **Горизонт банка** — 1, 2 или 3 месяца
- **На какой архетип фокус** — если в Профиле ЦА несколько архетипов

## Что генерирует скилл

20–30 тем без привязки к слотам и датам. Под каждую тему:

- название (одной короткой формулировкой, до 12 слов)
- функция (информационный / прогрев / продажа / отношения / рефлексия)
- формат-кандидат (рилз-разговор / рилз-overlay / карусель / TG-длинный / TG-короткий)
- сегмент ЦА (из Профиля ЦА)
- источник (RAC wikilink: свёртка / разбор / темник / ресёрч / личный опыт)

Тесты тем те же что в Фазе 4.4 (самодостаточность, конкретное действие, простой русский, не сужает ширину).

## Куда записывать

Путь файла: `.business/growth/production/Сетка/банк-тем-<YYYY>-<MM>.md`

Шаблон тела файла — см. `references/file-format.md`, раздел «Тело файла для режима D».

После записи обновить `.business/growth/production/Сетка/_index.md` строкой про этот банк тем.

## Чем отличается от обычной сетки

- Нет слотов по дням → нет решётки из «Ритма публикаций»
- Нет CTA-распределения и точек сбора заявок
- Нет защиты от повтора последних 14 дней (банк копится впрок)
- Нет резерва 20% (это и есть резерв)
- Баланс функций считается ориентировочно, не привязан к целевому % из Ритма

## После банка тем

Когда эксперт начнёт делать обычную сетку (режим A) — темы из банка можно использовать как один из источников идей наряду с Темником, разборами и свёртками.
