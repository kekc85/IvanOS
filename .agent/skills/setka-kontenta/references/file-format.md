# Формат файла сетки

Шаблоны для записи итоговой сетки в `.business` — Фаза 7 «Запись в `.business`».

## Путь к файлу

**Режимы A и B:**
- неделя → `.business/growth/production/Сетка/<YYYY>-W<NN>.md`
- месяц → `.business/growth/production/Сетка/<YYYY>-<MM>.md`

**Режим D:**
- `.business/growth/production/Сетка/банк-тем-<YYYY>-<MM>.md`

## YAML-frontmatter для режимов A и B

```yaml
---
тип: сетка
период: 2026-W21
даты: 2026-05-18 — 2026-05-24
режим: A | B
статус: черновик | утверждена | в работе | закрыта
ритм:
  рилзы: 3
  карусели: 1
  TG_длинные: 2
  TG_короткие: 3
слотов_всего: 9
слотов_резерв: 2
баланс_функций_фактический: { информационный: 50%, прогрев: 0%, продажа: 0%, отношения: 30%, рефлексия: 20% }
баланс_функций_целевой: { информационный: 50%, прогрев: 20%, продажа: 0%, отношения: 20%, рефлексия: 10% }
прогрев_к: <продукт>          # только для режима B
длительность_прогрева: 2 нед   # только для режима B
дата_старта_продаж: 2026-06-01 # только для режима B
лидмагнит: <название>          # только если в режиме A включён ЛМ
кодовое_слово: <слово>         # если лидмагнит
---
```

## Тело файла для режимов A и B

```markdown
# Сетка W21 (18–24 мая)

## Краткое резюме

- Режим: <A/B>
- Период: <даты>
- Слотов: <N> (+ <M> в резерве)
- Главные акценты: <2-3 строки про функцию-приоритет, темы-блоки>
- Если прогрев: цель серии, продукт, шаг канвы по дням

## Слоты

### Понедельник, по решению автора
- **Рилз-разговор**: «<тема>»
  - Функция: <функция> | Структура: <название из арсенала> | Сегмент: <сегмент>
  - CTA: <тип> (<кодовое слово или цель если есть>)
  - Источник: [[путь_к_свёртке]] + [[путь_к_разбору]]
  - Контекст серии (если B): позиция 1/7, шаг «открытие истории»

### Среда, по решению автора
- **Карусель**: «<тема>»
  - ...

[... все слоты по дням ...]

---

## Резерв (20%, для ситуативного)

- Тема 1: «<резервная тема>»
- Тема 2: «<резервная тема>»

## Точки сбора заявок (только B — прогрев)

- День 7: открытие листа ожидания
- День 14: ранняя запись со скидкой
- День 18: основной старт продаж
- День 20: дожим перед закрытием
```

## Тело файла для режима D (банк тем)

```markdown
# Банк тем 2026-Q2

## 25 тем для будущих сеток

1. **<тема 1>** — функция: <функция>, формат-кандидат: <формат>, сегмент: <сегмент>, источник: [[ссылка]]
2. ...
```

## Обновление единого `_index.md`

Открой `.business/growth/production/Сетка/_index.md`, найди секцию `## Записи`, добавь в начало:

```markdown
- [[<имя файла>|<период / описание>]] — режим: <A/B/D>, слотов: N, статус: черновик
```
