# Режим B — прогрев к запуску

Читай этот файл, когда определил режим B в Фазе 0.5 (запуск в окне 0–8 недель).

## Параметры (всегда уточняй, в любом режиме глубины)

- **Продукт** — из «Сетки продуктов и оффера» или новый
- **Дата старта продаж** — когда открываются двери
- **Длительность прогрева** — определяет структуру по фазам (см. ниже)
- **Цель запуска** — мест / денег / лидов (опционально, для интенсивности)

## Длительность прогрева → структура по фазам

### Короткий (3–7 дней)
Когда: тёплая аудитория, маленький продукт.
Структура: **40 / 40 / 20**
- 40% — обострение проблемы
- 40% — демонстрация решения
- 20% — предзапуск

### Стандартный (2–4 недели) — дефолт
Структура: **25 / 35 / 25 / 15**
- 25% — привлечение
- 35% — обучение
- 25% — кейсы
- 15% — предзапуск

### Длинный (1–2 месяца)
Когда: дорогой/сложный продукт, холодная аудитория.
Структура: **20 / 30 / 25 / 15 / 10**
- 20% — знакомство
- 30% — образовательная серия
- 25% — кейсы
- 15% — возражения
- 10% — предзапуск

## Спецотличия слотов в режиме B (Фаза 4.5)

- Структура по фазам 4-фазной канвы: открытие → проблема → агитация → решение → продажа
- Каждому слоту присваивай `позиция_в_серии: N/M` и `канва_шаг: <шаг>`
- Точки сбора заявок прописаны: лист ожидания → ранняя запись → старт продаж → дожим
- Механики на каждую фазу: повышение осознанности / доверие / снятие возражений / дефицит и FOMO
- Эти данные передаются писателям через YAML слота

## Что проверить перед показом (Critic для B)

В дополнение к общему чек-листу из Фазы 5:
- Фазы серии распределены по длительности (проценты соблюдены)
- У каждого слота есть `позиция_в_серии` и `канва_шаг`
- Точки сбора заявок прописаны в теле файла
- Механики (осознанность / доверие / возражения / дефицит) разнесены по фазам, не свалены в кучу
