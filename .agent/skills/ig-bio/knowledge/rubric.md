# Rubric: works vs vanity (доказательная, из ресёрча 56 шапок)

Оценивай шапку по каждому критерию **0-2** (0 = vanity/отсутствует, 1 = частично, 2 = чёткий рабочий сигнал), умножай на вес, суммируй: `score = Σ(балл/2 × вес) × 100%`.

**Пороги:**
- **≥75%** — конвертящая шапка (несёт работу сама, без опоры на узнаваемость).
- **50-74%** — рабочая основа с дырами (обычно проседают CTA, link-оффер, target callout).
- **<50%** — vanity/декор (опирается на контент и узнаваемость; холодный трафик не конвертит).

**Жёсткое правило:** если «ясность за 3 сек» = 0 → общий потолок 50%, сколько бы ни было ключей. Нечитаемая за 3 сек шапка не конвертит холодный трафик.

## working_vs_vanity — как отделить (главная ловушка)

У крупного автора трафик и клики идут с контента/виральности/узнаваемости, а bio часто декоративна. Копируя её — копируешь декор без двигателя. Дискриминаторы:

1. **Тест холодного визитёра.** Закрой имя/аватар/число подписчиков, прочитай только текст. Понятно за 3 сек кто/что/зачем? Нет → vanity (узнаваемость несёт, не шапка).
2. **Пруф = результат метода или дубль подписчиков?** «helped 10,000 people» работает; «Trusted by 1.5M followers» — пустая строка (число и так видно).
3. **Есть глагол-команда CTA?** Нет CTA / «link in bio» / 3 ссылки = vanity конверсионно, даже при сильном value.
4. **Первая строка = исход зрителю или титул автора?** «CEO of…», «Главный по…» = место под зрителя занято собой = vanity.
5. **Name-поле заряжено ключом или голое?** Голое имя у новичка = слив discoverability (крупному прощается — его ищут по бренду).

**Размер не предсказывает качество.** В корпусе works есть и у малых (dickiebush 88, ai.withphil 79), и у крупных (amjad_masad 76, 40M users); vanity тоже у обоих. Это НЕ закон «чем больше, тем хуже». Оценивай по дискриминаторам выше, а не по числу подписчиков, и отделяй вклад шапки от вклада узнаваемости.
