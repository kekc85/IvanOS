# Mastery-линза: методы топ-маркетологов → применение в bio

Источник: workflow wpmfxlsxr (6 областей `mastery/`, адверсари-верификатор, дословные цитаты сверены, 0 rejected, 2 weak отсеяно). Применять по `mastery/PROTOCOL.md` (Select → Apply → Evidence → verify). Ниже — отобранные confirmed-методы, каждый ложится на конкретное поле шапки.

## Positioning (рамка и одна идея)

- **April Dunford — категория как рамка восприятия.** «<продукт> — это <категория> для <сегмент>». → Name-поле = категория-рамка; строка 1 раскрывает «это X для Y».
- **Marty Neumeier — Onlyness + тест подстановки конкурента.** «единственный <категория>, который <отличие> для <аудитории>». → Строка 1 = сжатый onlyness. **Тест: подставь конкурента — если фраза остаётся правдой, она слабая, ужесточай до правды только про тебя.**
- **Ries-Trout — владеть одним словом.** Volvo=безопасность. → Шапка подчинена ОДНОМУ слову-якорю (name+строка1+CTA), запрет на 4-5 разнородных пунктов.
- **Seth Godin — Smallest Viable Market.** «люди как ___ выбирают ___, чтобы ___». → Строка-исход адресно узкому сегменту; фраза НЕ должна подходить «тоже мог бы».
- **Youngme Moon — hostile / отличие как жертва.** → Хвост шапки = честный «не для всех», сужение без извинений (фильтрует холодных, поднимает ценность).
- **Rory Sutherland — рефрейминг.** → Возражения («нет команды/без кода/нет денег») переобрамить из минуса в позицию.

## Copywriting (первая строка, пруф, чистка)

- **Ogilvy — заголовок = 80 центов с доллара.** выгода + конкретика + слово-адресат, без каламбуров, ясность > остроумия. → Строка 1 = заголовок: на ней решают подписаться.
- **Sugarman — скользкая горка.** первое предложение продаёт второе. → Bio из 3-4 строк = мини-горка: строка-исход тянет в пруф, пруф в CTA. Каждый стык: «зачем читать дальше?».
- **Bencivenga — доказательства + продавай пункт назначения.** «средний текст с горой пруфов > гениальный без». → Строка-пруф конкретным числом (из реальных данных); выгода = конечное состояние, фича = доказательство достижимости.
- **Drayton Bird — пиши одному человеку + R/I/E в CTA.** → Bio на «ты», не «мы»; CTA через Relevance/Incentive/Ease (для кого / что за клик / один линк-одно действие).
- **Ильяхов — факт вместо оценки, без воды.** → См. `anti-water.md`. Финальный проход.

## Persuasion-psychology (3-сек считывание, доверие)

- **Kahneman — WYSIATI + когнитивная лёгкость.** System 1 строит вердикт из минимума видимого. → Короткие частотные слова без жаргона; одна мысль на строку, не рваный список регалий.
- **Cialdini — social proof + authority + единство (№7).** → Пруф с числом «таких же» = social proof; идентичность «соло-эксперт как ты» = единство (сильнее симпатии). Только реальные цифры (этический гейт самого Чалдини).
- **Roger Dooley — некруглые числа.** «4 217» доверяют больше «многих». → Пруф несёт точное некруглое число.
- **Vanessa Van Edwards — тепло + компетентность.** Файл прямо называет bio зоной применения. → Баланс: компетентность = пруф, тепло = человеческая деталь/«мы такие же».
- **BJ Fogg — B=MAP, крошечное действие.** → Последняя строка = ОДНА подсказка на ОДНО низкофрикционное действие (бесплатный гайд + один тап), без трёх ссылок.

## Storytelling (трансформация А→Б в одну строку)

- **Blake Snyder — логлайн.** история в одном предложении с крючком. → Донор для name-поля и строки 1; тест «хочу узнать дальше».
- **Nancy Duarte — sparkline.** качание «что есть ↔ что могло бы быть», финал = новая норма (устойчивое состояние, не метрика). → Микро-sparkline А→Б за одно колебание; CTA на гребне «что могло бы быть».
- **McKee — controlling idea.** одно управляющее утверждение (ценность+причина), не тема. → Перечень тем «вайбкодинг, ИИ» = рыхло → заменить на кредо.
- **Will Storr — сакральный изъян + «что если?».** → Изъян в точку А для идентификации ЦА; CTA как открытая петля.
- **Kindra Hall — норма→взрыв→новая норма + конкретная деталь-момент.** → Маршрут «было→поворот→стало» за секунду; конкретная деталь против обобщения.
- **Donald Miller — SB7: клиент-герой, ты-проводник.** → Bio как проводник: «я прошёл твой путь» + один компактный пруф, не список регалий.

## Offer-design (CTA и лид-магнит)

- **Hormozi — value equation.** мечта-результат словами клиента + знаменатель (без камеры / без кода / за вечер). → Строка-исход = мечта-результат с вшитыми рычагами Время+Усилия.
- **Hormozi — lead-magnet + CTA = «что сделать + причина сейчас».** give away secrets / sell implementation. → CTA ведёт на бесплатный лид-магнит (решает узкую проблему, вскрывает следующую → продукт).
- **Russell Brunson / Todd Brown — уникальный механизм с ИМЕНЕМ.** → Name-поле несёт имя механизма; строка 1 = big idea, проходящая тест незаменимости.
- **Dan Kennedy — takeaway-selling / премиум-позиционирование.** → Строка квалифицирует, а не уговаривает; язык отбора поднимает ценность.
- **Dean Jackson / Frank Kern — results in advance.** → Единственная ссылка ведёт строго на lead-gen оффер с реальной пользой, не на продажу.
- ⚠️ Blair Enns anchoring — отсеян (weak): про презентацию цены, в bio без цены не ложится.

## Solopreneur-systems (идентичность / lifestyle как рычаг)

- **Justin Welsh — results-focused bio + один CTA + единый лид-магнит.** Метрика = visitor→subscriber. → Шапка как мини-воронка с ОДНИМ действием; name = results-focused заголовок.
- **Dan Koe — identity + goal + problem.** → Триада КОМУ (identity) + ЦЕЛЬ + ПРОБЛЕМА; «я делаю X — ЧТОБЫ ТЫ смог [цель]».
- **Dan Koe — lifestyle как рычаг, не хвастовство.** → Lifestyle подаётся как доказательство метода/обещание, обрамлён одной идеей. (⚠️ только конкретным фактом — см. `anti-water.md`).
- **Dan Koe — одна идея сквозь всё.** → Лишние под-темы отсекать: «служит одной идее?».
- **Greg McKeown — меньше но лучше, «не явное ДА → нет».** → Каждую строку через правило 90%; из 5 регалий оставить одну.
- ⚠️ Welsh PAIPS — отсеян (weak): связка взята из web, не из mastery-цитаты.
