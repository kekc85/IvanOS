# BUILD: создание шапки Instagram (пошаговый workflow)

## Вход (собрать ДО генерации — context-gap gate)

Нужны реальные данные. Чего нет — СПРОСИТЬ списком, НЕ выдумывать (`_shared/context-gap-gate.md`). Для bio критично: каждая цифра/кейс под именем = публичное обещание.

1. **Имя** (как в name-поле).
2. **Ниша + рыночные ключи** (как ищет ЦА; RU обязательно «нейросети»/«ИИ» если в теме).
3. **Кому именно служит** (сегмент-адресат).
4. **Реальные пруфы** — цифры/результаты/кейсы. Источник: пользователь / `.business/Распаковка бренда.md`. Если нет — спросить, не сочинять. Что из реальных фактов публиковать (напр. доход) — решает эксперт; уважать границы приватности.
5. **Цель ссылки** — на что ведём (лид-магнит / клуб / продукт). Если ссылки/лид-магнита нет — пометить CTA-заглушку и сказать пользователю, что нужно.
6. **Язык(и):** RU / EN / оба.
7. **Платформа** (дефолт IG: name ≤30, bio ≤150).

## Шаги

### 1. Выбрать угол (`knowledge/formula.md`)
outcome-first (дефолт) / proof-story / target-callout / identity-lifestyle (Welsh). Часто 2-3 варианта разными углами.

### 2. Применить mastery-линзу (`knowledge/mastery-lens.md`)
Select 3-5 методов под задачу. Прогнать onlyness через тест подстановки конкурента (Neumeier). Зафиксировать Evidence (метод→как лёг) для выдачи.

### 3. Собрать по формуле (`knowledge/formula.md`)
- Name-поле = `[Имя] | [1-2 ключа]`.
- Строка 1 = benefit-исход с глаголом (Ogilvy: выгода+конкретика+адресат).
- Строка 2 = один пруф-результат под обещание (Bencivenga; некруглое число — Dooley).
- Строка 3 = один CTA с глаголом → один лид-магнит (Fogg/Welsh; RU = код-слово).
- Скользкая горка (Sugarman): каждый стык тянет дальше.

### 4. Анти-вода (`knowledge/anti-water.md`) — HARD
Прогнать чек-лист: бан-лист клише, тест «факт vs штамп» для каждого личного маркера, трансформация = событие не статус, проход Ильяхова. Любой штамп → переписать на факт или вырезать.

### 5. Подсчёт длины (ОБЯЗАТЕЛЬНО программно)
```python
def chk(name, bio):
    return len(name), len(bio)  # name<=30, bio<=150 (включая \n и эмодзи)
```
Превышение → ужать (Ильяхов: оценки→факты, дубли схлопнуть), пересчитать. Не на глаз.

### 6. Self-score по rubric (`knowledge/rubric.md`)
Каждый вариант → 9 критериев → % + verdict (works/mixed/vanity). Цель ≥75%. Если <75 — назвать дыру (обычно CTA/link/target) и закрыть.

### 7. Humaniser — финальный антиклише-проход
Прогнать текст шапки. Особо: маркетинговые штампы, fake-энергия, staccato. Для RU — голос из `.business/voice-corpus/_voice-profile.md`.

### 8. Выдача
- 2-4 варианта на язык, каждый: name (длина) + bio (длина) + self-score + 1 строка «угол».
- Evidence-блок: какие mastery-методы применены.
- Рекомендация + что осталось от пользователя (ссылка/код-слово).
- НЕ закрывать «готово» без предъявления текста.

3. Конкретные правки по формуле + анти-вода.
