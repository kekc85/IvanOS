# SEO-движок: система холодного трафика из поиска

Этот скилл - выжимка живой SEO-системы автора: она построена на реальном сайте, набила реальные шишки, и здесь собраны только проверенные ходы. Твой Claude по этой инструкции поднимает такую же систему на ТВОЁМ сайте.

## Зачем это тебе

Одна SEO-статья - это страница. SEO-движок - это конвейер, где каждая статья:
- ловит людей, которые УЖЕ ищут решение в Яндексе (бесплатно и годами)
- ведёт их через код-слово в твой Telegram-бот и дальше к твоему офферу
- работает второй дверью для той же воронки, что твои рилзы и карусели

Воронка целиком: поиск → статья-гайд → код-слово → бот → твой оффер

## Главный закон движка (выстрадан практикой)

🔴 **Тема без замеренного спроса в работу не идёт.** На живой системе первый сплошной замер показал: 54 темы из 103 в очереди имели меньше 100 запросов в месяц - рабочие дни уходили на статьи без единого читателя. С тех пор правило железное: сначала цифра спроса из Wordstat, потом статья. И гейт спроса это ЛЕСТНИЦА, а не один порог: интент-стоп → минимум → резерв → производственная норма → приоритет (Фаза 1, шаг 4)

## Ещё три закона (свод рынка, деталь в knowledge/playbook-2026-08.md)

🔴 **Каденс: залп без крейсерского темпа после него - мёртвый вес.** Волна из 10 статей ценна не сама по себе, а тем, продолжается ли темп после неё. Массу наращивать ТОЛЬКО внутри своей ниши, и до постановки темы гнать её через тест «мог ли это написать любой сайт»: ответ «мог» - тема не берётся

🔴 **Интент-реестр - гейт на входе в производство, а не разбор после.** Один URL = один интент; перед постановкой темы три сверки: по реестру, по заголовкам живого корпуса, по выгрузке запросов вебмастера. Без реестра конвейер обязан начать спорить сам с собой - на живом доноре шесть статей делили один интент

🔴 **GEO живёт в теле страницы, а не в файле.** Быстрый ответ 40-60 слов под H1, FAQPage с дословным совпадением видимого текста и разметки, таблицы, нумерованные шаги, чек-лист. robots с поимённым Allow ИИ-ботам, llms.txt со свежими числами и speakable - дешёвые дополнения, а не замер зрелости

## Чек-лист статуса (как понять, где мы)

- Нет сайта → сначала скилл `website` (лендинг + раздел под гайды), потом сюда
- Сайт есть, но нет sitemap/robots/Вебмастера → Фаза 0
- Инфраструктура есть, очередь тем пуста или без цифр спроса → Фаза 1
- Очередь есть, статей меньше плана → Фаза 2-3
- Статьи выходят регулярно → Фаза 4 (недельный ритм)
- Показы появились у 20-30 страниц → плюс Фаза 5 еженедельно, параллельно производству

## Правила поведения (обязательные)

- **Интерфейсы Яндекса не выдумывать.** Вебмастер, Метрика, Wordstat - живые интерфейсы, их разделы меняются. Не сочиняй «куда нажать» из головы: открой живой экран вместе с учеником или попроси скриншот и веди по факту
- **Цифры не выдумывать.** Спрос - только снятая с Wordstat цифра или честное «не измерено». У класса «свежая узкая тема» истории спроса в Wordstat ещё нет по природе, поэтому Wordstat такую тему не блокирует, а спрос валидируется лестницей: донор с измеренным трафиком → признаки верхнего дециля → живые показы страницы за 1-3 дня → обязательный перезамер Wordstat, когда история набежит (порядок - workflow/01-semantika.md). Позиции и визиты - только из Вебмастера и Метрики
- **Одна статья = один интент = один URL.** Разные формулировки одного намерения склеиваются в одну статью, иначе свои же страницы конкурируют в выдаче (каннибализация) и Яндекс понижает обе. Проверка идёт по интент-реестру ДО постановки темы, а не после публикации
- **Никакой массовой генерации под шаблон.** Прецедент в практике: массовая генерация однотипных страниц под шаблон ведёт под деиндексацию. Закон - о качестве каждой страницы, а не о числе: темп читается из `config.md` как настройка, и его потолком служит пропускная способность гейтов качества конвейера (каждая статья проходит все гейты), а не пачка шаблонных страниц разом
- **Накрутка поведенческих запрещена.** Боты-кликеры - самый жёсткий бан Яндекса
- **Массовые правки сайта - не больше 10-15 страниц за раз** с недельным интервалом и проверкой каждого URL после заливки: файлы недоезжают молча
