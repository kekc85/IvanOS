# Фаза 4. Ритм: замеры и CTR-контур

Система без замеров - это вера, а не система. Ритм держится на одном недельном замере и одном месячном разборе.

## Еженедельно (понедельник) - три среза

| Срез | Откуда | Что снимаем |
|---|---|---|
| 1. Поисковые визиты | Метрика | визиты/день строго в срезе «Переходы из поисковых систем»; топ страниц входа |
| 2. Показы и клики | Вебмастер, статистика запросов | показы, клики, CTR; новые запросы, по которым появились показы |
| 3. Ранний сигнал | Вебмастер, диагностика | счётчик «малополезных» страниц - главный детектор недовольства Яндекса |

🔴 Правило единиц: поисковые визиты и весь трафик сайта - РАЗНЫЕ цифры, не смешивать. На живой системе цель однажды поставили на неверной базе, приняв весь трафик за поисковый - реальная база оказалась в 6 раз меньше. Каждую цифру пиши с указанием среза

Результат замера - 3 строки в `zhurnal.md` с датой. Рост «малоценных» страниц - стоп-сигнал: разбор до любых новых публикаций

🔴 Тот же понедельничный срез сразу уходит в Фазу 5: один поход за данными, две работы. Здесь мы смотрим на корпус целиком (растёт или нет), там - на каждую страницу отдельно (что чинить первым)

## CTR-контур вырос в отдельную фазу

Когда у сайта появились показы - дешевле поднять кликабельность существующих показов, чем писать новые статьи. Арифметика живой системы: подъём CTR с 3,4% до 8% на существующих показах дал бы рост поискового трафика в 2,3 раза без единой новой страницы.

Но отбирать страницы плоским правилом «CTR меньше процента» нельзя: норма кликабельности разная на разных позициях, и плоский порог одновременно тащит здоровые страницы и пропускает больные. Поэтому весь контур - нормы по полосам позиций, семь классов, очередь по приоритету, волна, вердикт «было / стало» - живёт отдельной фазой: **`workflow/05-dokrutka.md`**

Здесь остаётся триггер и три правила, которые нельзя потерять:
- показы появились у 20-30 страниц - включай Фазу 5 еженедельно, дальше она идёт параллельно производству
- волна 5-6 страниц, не больше: вердикт по волне должен быть измерим
- 🔴 страницы-двери под код-слова из рилзов/каруселей в волны НЕ попадают: их заголовок связан с воронкой, правка ломает её. В Фазе 5 это машинный гейт со списком дверей

## Ежемесячно

- сверка факт/план: сколько дают новые статьи, сколько правленые старые (Метрика, топ страниц входа)
- замер видимости в ИИ-ответах: задай 10-15 контрольных вопросов по своим темам Алисе/ChatGPT - называют ли твой сайт. Записать в журнал
- актуализация старых статей: берётся НЕ по вкусу, а из класса REFRESH очереди Фазы 5 (не правилась 180+ дней и позиция просела). Засчитывается только сменой факта в заголовке или теле при сохранённом URL - правка одной даты рефрешем не является
- пересборка длинного окна-подтверждения для Фазы 5, иначе класс нулевиков начнёт ловить новичков

## По триггеру

| Триггер | Действие |
|---|---|
| Очередь тем ступени 3 и выше тоньше 3 недель производства | досбор ядра (Фаза 1) |
| Показы появились у 20-30 страниц | включить Фазу 5, дальше еженедельно |
| Волна залита 2-4 недели назад | замер «было / стало» и вердикт волне (Фаза 5, шаг 8) |
| Массовая правка страниц | живой обход всех правленных URL |
| Сбой/восстановление хостинга | переснять контроль корпуса - хостинг мог откатить файлы к бэкапу |
| Большое событие в нише (релиз, изменение цен) | новостная статья в течение 24 часов + мгновенный IndexNow |

## Честный темп

1-2 статьи в рабочий день, ровно, без пачек и без догона пропущенных дней. Первые поисковые визиты - через 2-4 недели после первых публикаций, устойчивый рост - месяцы. SEO - компаундящий актив, не спринт: статья, вышедшая в топ, работает годами без ежедневных вложений
