# Фаза 0. Настройка: сайт становится виден поиску (один раз)

Цель фазы: после неё Яндекс знает о твоём сайте, умеет быстро узнавать о новых страницах, а ты видишь цифры трафика. Без этой фазы статьи уходят в пустоту: поиск узнаёт о них через 2-3 недели или никогда.

## Шаг 1. Раздел под гайды

На сайте появляется постоянное место для статей: адреса вида `<домен>/guide-<slug>/` (или `/guides/<slug>/` - выбери один формат и держись его). Правила:
- чистый URL без `.html` на конце - единый формат всего корпуса, дубли форматов плодят страницы-конкуренты
- каждая статья = папка со своим `index.html` (или страница твоей CMS)
- проверка: опубликуй тестовую страницу и убедись `curl -s -o /dev/null -w "%{http_code}" https://<домен>/<тест-адрес>/` = 200

## Шаг 2. robots.txt

Файл `https://<домен>/robots.txt`. Минимум:
```
User-agent: *
Allow: /
Sitemap: https://<домен>/sitemap.xml
```
Плюс открой доступ роботам нейросетей (GPTBot, YandexBot и другим) - всё больше людей получают ответы от ИИ, и туда попадают только сайты, которые ботам читать разрешено. Не закрывай их без причины

## Шаг 3. sitemap.xml

Карта сайта - список всех страниц для робота. Лежит в корне: `https://<домен>/sitemap.xml`. Правила:
- в карте КАЖДАЯ статья: страница вне карты выпадает из контроля и проверок
- пересобирается при каждой публикации (Фаза 3, шаг 4)
- формат стандартный XML sitemap, Claude собирает его скриптом по списку живых страниц сайта, не руками

## Шаг 4. Ключ IndexNow

IndexNow - способ мгновенно сообщить Яндексу «появилась новая страница»: индексация за 1-3 дня вместо 2-3 недель. Настройка:
1. Сгенерируй ключ: любая случайная hex-строка 32 знака (`python3 -c "import secrets; print(secrets.token_hex(16))"`)
2. Положи в корень сайта файл `<ключ>.txt`, содержимое = сам ключ
3. Проверь: `curl -s https://<домен>/<ключ>.txt` возвращает ключ
4. Запиши ключ в config.md этого скилла

## Шаг 5. Яндекс.Вебмастер

Главный пульт SEO: показывает, по каким запросам сайт видят, сколько кликают, что сломано. Ученик регистрирует сайт сам под СВОИМ Яндекс-аккаунтом (webmaster.yandex.ru → добавить сайт → подтвердить права файлом или мета-тегом). 

🔴 Claude: не выдумывай названия кнопок и разделов - интерфейс меняется. Веди ученика по живому экрану: он открывает страницу, ты смотришь скриншот или описание и подсказываешь следующий шаг по факту. После верификации подай sitemap в Вебмастер

## Шаг 6. Яндекс.Метрика

Счётчик визитов: metrika.yandex.ru → создать счётчик → код счётчика на ВСЕ страницы сайта (в шаблон, чтобы новые статьи получали его автоматически). Номер счётчика запиши в config.md. Тот же принцип: интерфейс по живому экрану, не по памяти

## Шаг 7. Google Search Console (по желанию, вторым приоритетом)

Для рунета главный поиск - Яндекс, Google подключается тем же способом (search.google.com/search-console) когда Яндекс-контур заработал. Не распыляйся на два фронта сразу

## Шаг 8. llms.txt (бонус: видимость в ИИ-ответах)

Файл `https://<домен>/llms.txt` - краткая машиночитаемая справка о сайте для нейросетей: кто автор, о чём сайт, главные страницы списком. Простой markdown-файл, собирается за 10 минут, помогает попадать в ответы Алисы/ChatGPT/Perplexity

- [ ] файл ключа IndexNow отдаётся
