# replicate-viral — REBUILD SPEC (root-cause-driven)

> Trigger: reel-DXBt1opj отвергнут 7+ раз за ОДНИ И ТЕ ЖЕ дефекты. Реальное ревью (2 независимых агента, 2026-06-15) вскрыло первопричины. Этот файл = контракт переделки. WHAT/WHY, не HOW.

## Первопричины (доказаны ревью, с уликами)

**RC-1 — Строилась НЕ ТА композиция (источник «не соответствует эталону»).**
Замер оригинала `DXBt1opjDH2.mp4` покадрово: в оригинале **НЕТ top/bottom сплита**. Спикер — **full-frame фон весь ролик**, сайты/UI/цена — **плавающие анимированные карточки-оверлеи поверх** (с полями, иногда near-full-takeover на чистых UI-битах). Сплит «верх-сайт/низ-я-в-рамочке» был выдуман и не существует в эталоне. Отсюда «сайт обрывается на пол-экрана» (пихал сайт в несуществующую верхнюю половину) и борьба с вырезкой.
Улика: `_benchmark/pair_*.png` (LEFT=оригинал), `benchmark-verdict.json` (motion FAIL 5/6).

**RC-2 — Гейты опциональны и оператор-зависимы → молча превращаются в no-op.**
Все 4 спеки (`scan-spec.json`/`contract.json`/`motion-spec.json`/`subs-manifest.json`) оператор пишет РУКАМИ; на reel-DXBt1opj они отсутствовали → каждый блокирующий чек за `[ -f "$SPEC" ]` не исполнялся. Гейты не запускались НИ РАЗУ за 7 отказов. Вердикты на диске устарели на 27ч, ссылались на удалённый рендер.

**RC-3 — Хук-блокиратор физически не видит проект.**
`reel-honesty-check.sh` глобит `*-reel`; проект `reel-DXBt1opj` не матчится. Хук читал чужие вердикты + принимал любой `*-reel` PASS ≤30мин без проверки принадлежности.

**RC-4 — Нет контракта композиции, выведенного из эталона и вмороженного ДО сборки.**
Геометрия выдумывалась на ходу и слабо/опционально/задним числом проверялась внутри оператором же выбранного box. «Верность источнику» делегировалась vision-критику-подхалиму, без числового соответствия геометрии ref↔наш.

**RC-5 — fill-чек ловит только сплошную яркую/чёрную полосу.**
Реальный сайт в неверной зоне (текстурный, не uniform) проходит. `blackband` ловит только pure #000 (dark-UI luma>10 проходит).

## Deepest root cause
**Любой гейт/канон/контракт, который зависит от того, напишет ли его оператор или вспомнит ли запустить — это тир-ноль (no-op под нагрузкой).** Лечится только так: **спеки — это ВЫХОД рендерера, а не вход; контракт выводится из источника и мороз­ится ДО сборки; вердикт ре-деривится из ПИКСЕЛЕЙ текущего рендера каждый раз; хук резолвит проект по идентичности.**

## Контракт композиции (вмораживается, выводится из эталона+бенча)

Система = **SINGLE_FULLBLEED_PERSON + FLOATING_OVERLAY** (как оригинал; НЕ сплит):
- `person`: full-bleed x0..1080 y0..1920 КАЖДЫЙ кадр. Никакой рамочки/нижней полосы. (Здесь full-frame аватар КОРРЕКТЕН — вырезка не нужна, поэтому правило «не full-frame для cutout» тут неприменимо. Для будущих проектов с реальной вырезкой — V5 medium-shot,.)
- `overlay` (сайт/UI/цена): ПЛАВАЮЩАЯ анимированная карточка поверх. Геометрия по актам ВАРИАТИВНА (карточка с полями ИЛИ near-full takeover на чистых UI-битах) — но всегда в движении (scroll/zoom/cursor), motion ≥70% от ref/акт.
- `caption/price`: на торсе/груди (y≈640-760 хук-цена; y≈1500-1700 нижняя треть), НИКОГДА не на лице (chin bbox).
- Инвариант (единственное жёсткое правило всех актов): **person = full-bleed подложка; сайт/UI/цена = плавающий слой поверх; нет фиксированной горизонтальной линии раздела; спикер НИКОГДА не в нижней карточке/полосе.**
- Точные числа карточек по актам — ЗАМЕРИТЬ из ingest-кадров `~/.business/growth/ingest/2026-06-13-DXBt1opjDH2/` при деконструкции, не выдумывать.

## Что должен гарантировать переделанный скилл (acceptance)

1. **Contract-first.** Деконструкция источника эмитит `contract.json` с машинными координатами (layout_system, person_box, overlay geom/act, caption_zone, motion_floor, инвариант) ДО сборки. Сборка ЧИТАЕТ контракт, не выдумывает геометрию.
2. **Specs = выход рендерера.** Рендер-степ сам пишет `scan-spec.json`/`subs-manifest.json` из фактической композиции (знает каждый Y субтитра, каждый бит). Оператор их не пишет. Отсутствие = невозможно при наличии рендера.
3. **Гейты не-обходимы.** `selftest.sh`: при наличии рендера отсутствие любой спеки = безусловный HARD FAIL (не `[ -f ]`→skip). Вердикт ре-деривится из текущего рендера (mtime(verdict) ≥ mtime(newest mp4), render-path существует и = новейший).
4. **Хук видит проект по идентичности.** `reel-honesty-check.sh`: резолв активного проекта (registry/cwd), читать ТОЛЬКО его вердикт, проверять что render свежий и принадлежит проекту. Убрать `*-reel` глоб и cross-project приём.
5. **Layout-invariant gate.** Машинный чек: person near-full-bleed (площадь ≥ X% кадра), нет фикс. линии раздела, спикер не в нижней полосе. Девиация = exit 2, не-tunable.
6. **Геометрическое соответствие ref↔наш.** Гейт сверяет overlay-box/motion наш vs contract (из эталона) в пределах ±N. LLM-eyeball не заменяет числа.
7. **fill/coverage по content-density** (edge/variance), а не только uniform-luma; ловит текстурный-но-неверный fill и тёмный филлер.
8. **Cross-act consistency:** все акты инстанцируют один layout-template (инвариант), drift = exit 2.
