## ПЕРВОПРИЧИНЫ (root cause, не симптомы)

| # | Симптом | ПЕРВОПРИЧИНА | Кластер |
|---|---|---|---|
| RC-A | Скролл вместо зума; статика вместо видео; перепутал чью рамку | **Строю на ДОГАДКЕ о механике эталона** — не делаю ВЕРИФИЦИРОВАННУЮ покадровую деконструкцию (что статично/видео, тип движения, чья рамка, % раскладки) ДО сборки | Build-on-guess |
| RC-B | Linear/Stripe вместо сайтов автора; статичные скрины | **Подменяю ассет удобным** вместо извлечения того, что РЕАЛЬНО в источнике (Goodhart: похоже ≠ то же). Видео-контент реплицирую статикой | Asset-substitution |
| RC-C | Перепутал рамку (вокруг сайта, не вокруг меня); глаза не внутри карточки | **Игнорирую СОБСТВЕННЫЙ канон** — правило K3 (п.2г SKILL.md: «за грань только лоб, глаза внутри ЕГО карточки») уже написано, я его не загрузил/не применил | Ignore-own-canon |
| RC-D | Аватар закрыл сайты; 65%; кривые субтитры — и я всё равно ПОКАЗАЛ | **Самопроверка штампует PASS** на очевидном браке; показываю автору недоведённое | Rubber-stamp-review |
| RC-E | 65% (ни полный, ни половина) | **Нет числового правила пропорций** — раскладка «на глаз» дрейфует | Proportion-drift |

**МЕТА-ПЕРВОПРИЧИНА:** критические правила в скилле живут ПРОЗОЙ → под нагрузкой я их пропускаю, и ничто МАШИННО не блокирует ни сборку на догадке, ни показ брака. Прозу я нарушаю, машину — нет. → Решение: ЛЭЙАУТ-КОНТРАКТ (заполнить и верифицировать ДО сборки) + машинный гейт `scripts/layout-contract-check.py` (блокирует показ при нарушении пропорций/окклюзии/статики-вместо-видео).

**🔴 ГЛУБЖЕ (автор):** даже МАШИННЫЙ гейт не спасает, если его НАДО ВСПОМНИТЬ запустить — под нагрузкой я скипаю и это (прецедент Vevara: `layout-contract-check.py` был, не прогнал, показал брак). Обещание «буду дисциплинирован» меняет ноль — фактор лени остаётся. **Единственный тир, переживающий мою лень — АВТОМАТИЧЕСКИЙ хук, срабатывающий БЕЗ моего выбора.** → `reel-show-gate.sh` (Stop-хук) на АКТ ПОКАЗА ролика/сегмента САМ гонит `chunk-review-gate.py` и блокирует, пока кусок 3-5с не прошёл ПЕРЕпроверенный полный ревью. Закон: всё, что зависит от моей воли/памяти (обещание, проза, гейт-который-надо-вызвать) = тир ноль; доверять только авто-хукам + независимому критику-скептику + финалу автора. Авто-хук обязан быть ТОЧНЫМ (тест happy/negative/edge), иначе ложные срабатывания → его отключат → принуждение в ноль (прецедент post-phase-gate).

**🔴 ЕЩЁ ГЛУБЖЕ — ФОРМАТ-КАНОН (автор, брак chunk_0 Vevara):** я собрал аватар МИМО формат-канона (как располагать автора: пропорция half · рамка K3 вокруг спикера · лоб за гранью), хотя `contract.json` был заполнен и `layout-contract-check.py` существовал — просто сборка их НЕ принуждала. Это частный случай генерализованного корня: **любой канон/спека/правило, которое УЖЕ ЕСТЬ, но зависит от того, вспомню ли я его загрузить и применить = тир ноль (скиплю под нагрузкой).** Корневое решение класса: каждый канон = (1) ОБЪЯВЛЕННЫЙ артефакт (`contract.json` формат-канон · `deconstruction.md` вход · `_canon.md`/`montage-lexicon.md` эталон) + (2) АВТО-форс гейтом per chunk: `chunk-review-gate.py` сам гонит **L-FORMAT** (`layout-contract-check`) + scene-audit + benchmark[A,B,C] + критик-с-якорем. Конформность канону машинно-принуждена, не из памяти. Смежные кластеры закрыты тем же: reused-asset (L-FORMAT проверяет рендер, не источник), identity/look (контракт несёт look_ref/voice_id + критик-ось avatar подтверждает).

## ДРУГИЕ КЛАСТЕРЫ, где та же первопричина даст брак (предотвратить заранее)

Все сводятся к двум законам: **(1) ВЕРНОСТЬ ИСТОЧНИКУ** (реплицируем то и так, как в оригинале — не подменяем, не упрощаем динамику до статики) и **(2) ВЕРНОСТЬ СВОЕМУ КАНОНУ** (K3-геометрия, пропорции, субтитры). Где ещё это всплывёт:

- **Аудио/музыка/SFX:** подменить дорожку «похожей» вместо ритма/настроения источника (Asset-substitution).
- **Палитра/градиенты:** не свериться с цветами источника, выдать «примерно похоже» (Build-on-guess).
- **Тайминг/биты:** каты/смены не по реальным битам источника, а «на глаз» (Build-on-guess + Proportion-drift во времени).
- **Любой анимированный элемент источника** (бегущий UI, печать, видео-фон) → реплицировать статикой = тот же RC-B. Закон: **динамику реплицируем динамикой.**
- **Любая «карточка/рамка/оверлей»** → перепутать слои/чья рамка/что поверх = RC-C. Закон: свериться с эталоном слоёв (K3 п.2г) ПОИМЕННО.
- **Показ автору:** любой «тест/черновик» мимо полного гейт-конвейера = RC-D. Закон: автор НЕ QA, показываю только прошедшее машинный гейт.

## ЖЁСТКИЕ ПРАВИЛА (нарушение = FAIL, не показывать; страхуются `layout-contract-check.py`)

1. **ПРОПОРЦИЯ АВАТАРА = строго ПОЛНЫЙ ЭКРАН (100%) ИЛИ ПОЛОВИНА (50% ±3%).** Никаких 60/65/70%. (E1)
2. **РАМКА — ВОКРУГ СПИКЕРА, не вокруг контента.** Лоб (волосы+лоб до середины, ~70-90px) вылезает над ВЕРХНЕЙ гранью КАРТОЧКИ СПИКЕРА; глаза/нос/уши ВНУТРИ карточки. Канон K3 SKILL.md п.2г. (E2, E3-рамка)
3. **КОНТЕНТ (сайт/UI) ДОЛЖЕН БЫТЬ ВИДЕН.** Спикер НЕ перекрывает контент-зону (окклюзия контента спикером > 12% = FAIL). Контент — отдельная зона, не подложка под лицо. (E5)
4. **ВЕРНОСТЬ ИСТОЧНИКУ ПО ДИНАМИКЕ:** если в источнике элемент = ВИДЕО/анимация → реплицируем видео/анимацией, НЕ статичным скриншотом. Статичная картинка там, где источник двигался = FAIL. (E4)
5. **ПРОВЕНАНС АССЕТОВ:** каждый контент-ассет (сайт) мапится на таймкод источника и реплицирует ИМЕННО его (тот сайт, та анимация). Подмена на сторонний сайт = FAIL. (E3)
6. **ВЕРИФИЦИРОВАННАЯ ДЕКОНСТРУКЦИЯ ДО СБОРКИ:** заполнить `REFERENCE CONTRACT` (ниже), проверить против покадровых кадров источника, подтвердить вторым агентом-скептиком. Без заполненного контракта сборка НЕ стартует. (RC-A)
7. **СУБТИТРЫ — по канону v3 п.5** (один стиль, без точек, без «трёх этажей», группы ≥0.25с), сверка кадром. (E6)

## REFERENCE CONTRACT (заполнить ДО сборки, проверить агентом-скептиком)

```
RC-LAYOUT:    аватар = [FULL | HALF]; контент-зона = [где, % экрана]; рамка вокруг = [СПИКЕРА]; что вылезает за грань = [только лоб]
RC-CONTENT:   что в контент-зоне = [перечислить ассеты]; источник каждого = [таймкод в ref.mp4]; динамика каждого = [VIDEO/анимация | статика] (как в источнике!)
RC-MOTION:    тип движения контента = [зум push-in/out | кат | реальное видео]; НЕ скролл, если в источнике не скролл
RC-OCCLUSION: спикер перекрывает контент? = [НЕТ / только грань рамки]
RC-CAPTIONS:  стиль = [канон v3 п.5]; позиция = [y]; цвет акцента = [#]
RC-PROPS:     пропорция аватара числом = [100% | 50%]
ПРОВЕРКА:     второй агент сверил контракт с кадрами источника? = [PASS/FAIL + что поправил]
```

Сверять заполненный контракт против РЕАЛЬНЫХ покадровых кадров источника (`ffmpeg -ss N -frames:v 1`), не против памяти/догадки. Расхождение контракт↔источник = переписать контракт, сборку не начинать.
