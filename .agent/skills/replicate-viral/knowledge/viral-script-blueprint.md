# Фаза 2 — BLUEPRINT вирального скрипта (роль-автор)

Добавлен по решению автора (мандат автора). **Корень:** Фаза 2 = только `adaptation`, а он адаптирует СУЩЕСТВУЮЩИЙ транскрипт. Немой/скринкаст-оригинал → транскрипта нет → раньше скрипт писался отсебятиной = «звонок мамонту» (невиральный). Этот blueprint = определённая роль-автор, чтобы скрипт был ВИРАЛЬНЫМ, а не ад-либом.

## Когда этот путь (а не `adaptation`)
- Оригинал НЕМОЙ / скринкаст / текст-на-экране без речи → пишем С НУЛЯ по этому blueprint.
- Оригинал говорящий с сильным транскриптом → `adaptation` (C.1), blueprint только для хука/CTA.

## Вход
1. `deconstruction.md` (Г2) — **виральный механизм оригинала** (что собрало комменты).
2. Факт-чек инфоповода (ОБЯЗАТЕЛЕН, прецедент «Mythos»): цифры/клеймы из источника проверить вебом ДО скрипта. Не выдумывать числа/имена/статистику.
3. `voice-corpus/_voice-profile.md` — голос автора (на «ты», тёплый-инженерный, без точек в конце, проза а не рубка).

## Метод (роль-автор; исполняет оркестратор Opus, механику вниз)
1. **Вытащить ВИРАЛЬНУЮ ФОРМУЛУ оригинала** из деконструкции: хук-паттерн · обещание · что показано как пруф · эскалация. Это ДОКАЗАННЫЙ сигнал (N комментов) — реплицируем формулу, не угадываем.
2. **Хук через `Skill('hook-generator')`** — 10 вариантов (первые 1.5-3с = 71-90% охвата). Отбор: curiosity + specificity (точная цифра > общего) + stakes, в голосе автора, зеркаля выигрышную формулу оригинала. НЕ generic («вот крутой инструмент»).
3. **Тело скрипта 3 акта:** жирный клейм/обещание → витрина-пруф (показываем товар) → плата+CTA (кодовое слово). Голос автора: факты не оценки, без точек в конце, проза.
4. **Калибровка угла = редакторское право ВЛАДЕЛЬЦА бренда.** автор перекрыл хеджирование: для виральности угол подаётся ПРОСТО и СМЕЛО, без оговорок-«занудства» («это работает на minimax, а Claude платно» — зритель не поймёт, убивает виральность). ЗАПРЕТ остаётся только на ВЫДУМАННЫЕ факты/числа/статистику. Клейм-обёртку (что выносим в хук) решает автор, не агент. Если фактура реально против клейма — флаг автору ОДНОЙ строкой, решает он, не спорим повторно.
5. **`Skill('humaniser')`** финальным проходом ПЕРЕД выдачей (HARD-гейт всех text-skills).
6. **Хронометраж:** наш talking-head + перемены сплита + вставки → ~оригинал +15-25% (немой 26с → наш ~30-32с). Назвать число.

## Выход — `script.md`
- 10 hook-вариантов + выбранный (почему)
- Дословный скрипт по сегментам с тайм-кодами
- Блок «Что улучшить vs оригинал»

## 🔴 ГЕЙТ Ф2 (машинный, phase-gate.py)
Скрипт — **отдельно согласуемый артефакт ДО концепта и производства**. После апрува автора создать `script-approved.flag`:
```json
{"artifact":"script.md","md5":"<md5 script.md>","approved_by":"автор","date":"YYYY-MM-DD"}
```
`phase-gate.py` Ф2 сверяет md5 (анти-stale: согласован текущий текст, не старый). Нет флага → Ф2 MISS → производство (Ф4.6/5/6) заблокировано, Stop-хук не даст «готово». То же для концепта — `concept-approved.flag` (Ф2c).

## Анти-паттерн (что НЕ делать)
- Писать скрипт отсебятиной без формулы оригинала + hook-generator = мамонт .
- Лезть в производство без `script-approved.flag` .
- Занудное хеджирование ради «честности формулировки» в ущерб виральности (угол — за автором).
