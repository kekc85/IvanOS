# (рубрика: эталоны → планки суждения)

**Зачем (автор):** «vision-суждение машина не вынесет» — отговорка. Суждение делается
СТРОГИМ, если эталоны конкурентов РАСШИФРОВАНЫ в лексикон: что за объект, какая ставка, какой
эталонный уровень числом/техникой. Тогда критик не «красиво/некрасиво», а **декодирует кусок в
этих терминах и сверяет с эталонным уровнем** против (A) ролика-источника, который реплицируем,
и (B/C) эталонов-конкурентов. Не нужен интернет — эталоны автор уже дал, они в
`~/.business/growth/materials/reel-design-corpus/_canon.md` + покадровые разборы рядом.

**Как критик L5 это применяет (обязательно):** для каждой из 10 категорий → (1) ДЕКОДИРОВАТЬ, что
в нашем кадре по термину лексикона; (2) сверить с ПЛАНКОЙ (число/техника + якорь-конкурент);
(3) сверить с тем же объектом в ролике-источнике; (4) вердикт PASS/FAIL + заметка ОБЯЗАНА назвать
якорь-эталон и конкретную планку (не «хорошо» — а «темп 0.7 смен/с < Cintas ≈1/с = FAIL»).

**Иерархия эталонов (какой когда):** **rpn** = общая планка качества/кинематограф · **Steve Tan**
= наш talking-head формат (overlap «лоб за плашкой» + тройная типографика) ДЕФОЛТ для разборов
инструментов · **Cintas** = split AI-product-demo без overlap (чистая демонстрация UI) ·
**DUqeScpDAHW** = overlap-card collage (тёмный, стопки картинок). Источник планок — `_canon.md`.

## Связь с тремя опорами бенчмарка (L3/L4)
- **A (ролик-источник, который реплицируем)** — декодируем ЕГО по этим 10 категориям (через `deconstruction.md`) и держим наш кусок НЕ ниже него.
- **B (эталон формата)** — Steve Tan / Cintas / rpn / DUqeScpDAHW по иерархии выше; планка из таблицы.
- **C (канон 36 виралок)** — оси A-F `_canon.md`, числа pace/шрифты/позиции.
Вердикт критика по категории = **max(планка источника, планка эталона)**; ниже любой = FAIL.
