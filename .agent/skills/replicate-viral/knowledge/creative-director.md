# Фаза 2c — Креатив-директор (концепт до производства)

Добавлена по решению автора. Место: ПОСЛЕ Фазы 2 (adaptation, скрипт готов) и ДО любого производства (Фаза 3 моушн, 3a добыча, 4 озвучка, 5 HeyGen, 6 сборка). Принцип v2.0: сильная модель решает ЧТО (концепт), конвейер исполняет КАК. Правка концепта словами = 0 кредитов; правка после производства = рендеры и кредиты.

## Выход фазы: КОНЦЕПТ (один экран в чат автору, защита обязательна)

0. **🔴 ДЕКОНСТРУКЦИЯ ИСТОЧНИКА (артефакт №0, ВХОД тропинки, блупринт по решению автора)** — покадровая EDL-карта источника (`deconstruction.md`, формат `knowledge/source-deconstruction.md`): каждые ≤0.5с на хуке / по битам дальше → реальный кадр (`ffmpeg -ss`) → что показано → МЕХАНИЗМ → резолв в enum-блок. Прогнать `deconstruction-check.py` (PASS обязателен — phase-gate Ф2c блокирует без него). На концепт-экране показать сетку по битам **[источник делает X | мы делаем Y | бенчмарк A/B/C]** — автор согласует КАЖДУЮ миллисекунду ДО сборки. Без покрытой деконструкции сборка (Фаза 6) не стартует — убивает Build-on-guess (RC-A).
1. **Суть** — смысл/инфоповод, целевая эмоция, честный вердикт «стоит ли делать» (kill на концепте = валидный выход, дешевле посредственного ролика)
2. **Структура по битам** — посекундная карта (по Г2-деконструкции) + раскладка визуальных каналов: где верх-сплит работает, где «автор один в кадре»
3. **VFX-решение** — да/нет по критериям ниже; если да: фраза-носитель · какая наглядность добавляется · эффект · длительность · цена в кредитах по сетке
3b. **РЕШЕНИЕ ДВИЖКА ПО КАЖДОЙ ВСТАВКЕ** (автор) — на раскадровке размечаю каждый небазовый бит движком по природе данных: 🟢 Higgsfield Infographic Animator (`[[motion-design-prompter]]`) / ⬜ HyperFrames-отрисовка / 🚫 захват браузером. Критерий — раздел «Выбор движка вставки» ниже. На концепт-экране в сетке битов колонка «движок + почему»
4. **Сегментация и локации спикера** — бью скрипт на 2-4 смысловых сегмента (дефолт для 30с; 15с → 2; 1 сегмент только если ролик = одна неразрывная мысль) по ЛОГИКЕ скрипта, не по таймеру; каждому сегменту своя локация под ЭТОТ бит и ПОЧЕМУ (защита обязательна, не «следующая по списку»): связь с темой/инфоповодом · целевая эмоция/тон · контраст с прошлыми ~5 роликами по `speaker-locations-journal.md` И между сегментами внутри ролика. Карта «бит → тайминг → локация → 1-2 строки обоснования». Этот набор → утверждается автором здесь и исполняется в Фазе 4.6 (N кадров) + Ф4 (нарезка озвучки по границам битов), повторно НЕ выбирается
5. **Анти-шаблон-чек** — сверка с `~/.business/growth/materials/reel-design-corpus/vfx-journal.md` (VFX: эффект/место/тип) + `speaker-locations-journal.md` (локация спикера): не повторяют последние 5 роликов; что нового в этом
6. **Бюджет** — ТОЛЬКО кредиты Higgsfield (VFX+реролл + кадр локации спикера ~1 кр; это деньги). Токены НЕ бюджетируем (отменено по решению автора — приоритет качество, оптимизация токенов потом).

**ГЕЙТ: производство не стартует без апрува автора по концепту.** Это единственное санкционированное подтверждение в конвейере (исключение из Г1, оформлено автором); после апрува концепта Г1 действует в полную силу — до результата без вопросов.

## Критерии целесообразности VFX (нет критерия → «VFX: нет» одной строкой, ноль кредитов)

VFX оправдан, когда:
- в скрипте есть **абстракция, которой нужна наглядность**, и футажом её не показать («система собирается», «деньги капают», «страх держит») — эффект = визуализация смысла
- **соло-сегмент автора длиннее ~5-7с** — вставка оживляет кадр, работая вторым визуальным каналом наравне со сплитом
- инфоповод сам про визуальную трансформацию

VFX НЕ оправдан: ролик плотно набит скринкастом/футажом (канал занят) · новостной формат, скорость важнее · серьёзный/доверительный тон, который эффект удешевит.

## Выбор движка вставки: HyperFrames (детерминизм) vs Higgsfield (зелёная зона) — автор 

Полный закон — в `SKILL.md` раздел «ДВА ДВИЖКА ВСТАВОК». Здесь — рабочий критерий креатив-директора на раскадровке. Решаю по ПРИРОДЕ ДАННЫХ бита:

| Что в бите | Движок | Почему |
|---|---|---|
| Абстрактный смысл без точных данных (деньги капают, рост, «система собирается», концепт-метафора) | 🟢 Higgsfield Infographic Animator + `[[motion-design-prompter]]` | важен слик-вау, точность данных не нужна |
| Стат-ревил / титр-заставка как графика, мотион-переход, стингер между сегментами | 🟢 Higgsfield Infographic Animator | графика по природе, ОБЯЗАТЕЛЬНО через Higgsfield |
| Точная дата-виз: цифры/метрики ИМЕННО этого инструмента, реальные бренд-SVG, печать реального кода, привязка к UI | ⬜ HyperFrames (scene-assemble.py) | генеративка цифры и логотипы исказит, нужен детерминизм |
| Несущий спайн: сплит, субтитры, аватар-композит, скелет-биндинг | ⬜ HyperFrames | базовая механика, не вставка |
| Реальный инструмент / репо / интерфейс нейросети | 🚫 захват браузером (Г4/Г5) | НИ один движок не рисует поддельный продукт |

**🟢-путь:** статичный дизайн-кадр (Pinterest / Nano Banana / GPT Image) → `motion-design-prompter` пишет промпт → Higgsfield Infographic Animator оживляет (браузером, я сам вожу Playwright) → готовый клип-ассет в бит скелета как футаж.

**🔴 ПРЕДОХРАНИТЕЛЬ:** боевой тест Infographic Animator на тексте/цифрах ещё не пройден. (а) перед первым продом — тест-клип, проверить держит ли подписи; (б) стат-ревил с числами — текст ОВЕРЛЕЕМ кодом поверх Higgsfield-фона (гибрид: Higgsfield = фон/движение, текст = детерминированный оверлей), генеративке текст-носитель не отдавать.

На концепт-экране сетка по битам получает колонку «движок + 1 строка почему» — автор апрувит движок каждой вставки вместе с раскладкой.

## Сегментация спикера по битам + локации (выбирает креатив-директор, защищает на апруве)

🔴🔴 **АВАТАР-БУКЕНДЫ — ДЕФОЛТ для скринкаст/демо-реплик (автор, см. SKILL.md «ПРАВИЛО АВАТАР-БУКЕНДЫ»).** Когда несущая сила ролика = футаж инструмента (скринкаст), аватар HeyGen показываем ТОЛЬКО 2 раза: (1) затравка ~3-5с с ранним переключением заголовок→лицо (дофамин), (2) CTA ~3с. Середина = скринкаст + анимир-UI + VO поверх. 2 генерации HeyGen, 2 локации, НЕ per-segment. Мульти-сегментная схема ниже (локация на каждый бит) — для ЧИСТО talking-head оригиналов без сильного контента-носителя.

🔴 **автор в даты запуска.2026:** локации спикера выбирает НЕ Фаза 4.6 механически («следующая из банка»), а креатив-директор — осознанно, под концепт, и ДОКАЗЫВАЕТ выбор автору. по решению автора расширено до сегментации: ролик режется на 2-4 смысловых бита, спикер в каждом — в НОВОЙ локации (кадр генерится заново, Higgsfield image-to-image от реального фото, Фаза 4.6).

**Зачем сегментация (механика удержания):** статичная говорящая голова 30с — худший формат по удержанию; каждые ~10с зритель заново решает «листать или нет». Смена локации на границе смыслового бита = pattern interrupt: визуальный сброс ровно когда внимание падает, плюс подкрепляет структуру (зритель чувствует «новый блок»). Цена по HeyGen-секундам та же (N×короткий = 1×длинный), доплата только Higgsfield-кадры (~1 кр/бит).

**Как сегментировать:**
1. **Граница — по ЛОГИКЕ скрипта, не по таймеру.** Новая мысль/акт = новый сегмент. Не «механически каждые 10с»: сегменты ложатся как 8/13/9с по смыслу. 2-4 на 30с, 2 на 15с; дробить 15с на 3 = мельтешит. 1 сегмент — только если ролик одна неразрывная мысль.
2. **Самый сильный бит и локация — ПЕРВЫМИ** (первые 3с решают всё).

**Как выбирать локацию каждого бита (не наугад):**
1. **Под смысл/тон бита** — локация работает фоном-аргументом: разговор про деньги/систему → рабочий лофт-офис, доверительная история → гостиная вечером, динамичный инфоповод → улица города. Не «красивый фон ради фона». Локация поддерживает смысл, а не тянет внимание на «где это он».
2. **Контраст с прошлым И между сегментами** — прочитать `~/.business/growth/materials/reel-design-corpus/speaker-locations-journal.md`, локацию последних ~5 роликов НЕ брать, и локации внутри одного ролика не повторять между собой. Пул жжём быстрее (N за ролик) — банк идей в шапке журнала.
3. **Реализуемость image-to-image** — обстановка, в которую реально перенести лицо автора без слома (интерьеры/улицы/природа — да; экзотика с тяжёлой геометрией за спиной — риск).

**Инварианты сегментации (защищать на концепте):** лицо+голос (`«<your name> -- 10»`)+лук-одежда ИДЕНТИЧНЫ на всех сегментах — меняется только локация/фон (иначе склейка = «3 разных человека»). Стык сегментов = чистый match/J-cut (Ф6). Аудио режется по границам битов, каждый сегмент несёт своё (инвариант v3, см. SKILL.md Ф4/v3 п.2).

Защита на концепт-экране = карта «бит → тайминг → локация + 1-2 строки почему эта под этот бит + чем отличается от последних и от соседних сегментов». автор апрувит → Фаза 4.6 генерит N кадров и пишет строки в журнал, Ф4 режет озвучку, повторно не выбирается.

## Анти-шаблонность (три механизма, не пожелание)

1. **Эффект привязан к фразе** — фразы у роликов разные, значит место вставки каждый раз разное само собой. Фиксированных «всегда на 3-5 секунде» НЕТ.
2. **Журнал приёмов** `reel-design-corpus/vfx-journal.md` — после каждого ролика дописывать строку (дата · ролик · эффект · место · фраза). Повтор эффекта/места из последних 5 = FAIL анти-шаблон-чека концепта.
3. Каталог ниже = **меню вдохновения**, не обязательный список — креатив-директор может предложить новый приём (и тогда он войдёт в каталог после ролика).

## Промпт-паттерны (из официальных туториалов Higgsfield, research 2026-06-11)

**Каркас промпта правки** (порядок важен):
```
Keep the person's face, identity, lighting and the locked camera frame unchanged.
[Around second N,] <ОДНО главное событие, короткой командой над объектом>.
No cuts, no zooms, no camera movement. The person keeps talking naturally.
Photoreal, no 3D, no cartoon.
```
- Команда правки = короткая и предметная: `change the outfit to ...`, `change the background behind the person to ...`, `a glowing X materializes beside him`
- **Keyframe-закон («garbage in, garbage out»):** 80% качества = стартовый кадр. Эффект класть на РЕАЛЬНОЕ/реалистичное сырьё; не вылизывать промпт на слабом кадре
- Один главный экшен на вставку; последовательность из 2-3 событий возможна (тест по решению автора: костюм→паук→чисто прошёл), но риск скомкивания растёт
- Быстрый экшен → просить slow motion и ускорять в монтаже (анти-морфинг)
- Локальная правка без риска лицу → зона Draw в UI
- Лицо на серии держать референсом/цепочкой previous-video, не словами

## Реализм-мандат (инсайт автора: эффект на AI-кадре выглядит хуже)

1. **Каждый промпт генерации сцен/картинок с автором** заканчивается реализм-суффиксом: `photoreal, hyper-realistic, natural skin texture, film grain, 35mm look, natural lighting, no 3D, no cartoon, no plastic skin`
2. **Сырьё от реального**: сцены с автором строить от реального фото/кадра как референса, генерация — поверх. Реальное сырьё → реалистичный эффект (keyframe-закон)
