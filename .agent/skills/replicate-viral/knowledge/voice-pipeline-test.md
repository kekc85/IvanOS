# Голос-тест: каким путём генерить озвучку аватара (поставлен автором)

Проблема: HeyGen иногда коверкает слова . Машина фонетику не меряет (whisper дал ru p=0.998 на украинском звучании) — судья только ухо. Нужно один раз замерить пути и выбрать канон.

## Пути

| Путь | Генерация | Липсинк | Гипотеза риска |
|---|---|---|---|
| **A** | OmniVoice локально (референс `~/omnivoice-ivan/ref_short.wav`) → WAV | HeyGen режим **upload audio** (аватар читает загруженное аудио) | OmniVoice без меток ударения → возможны кривые ударения русских слов; зато голос «потрясающе одинаковый» |
| **B** | Текст прямо в HeyGen, клон-голос автора | родной TTS+липсинк одним шагом | фонетика клона может уехать ; КАЖДЫЙ клон из списка звучит по-разному — выбирать заранее, ID фиксировать |

⚠️ НЕ путать путь A с «наложить WAV на ГОТОВЫЙ рендер» — это липсинк не даёт (проверено, отвергнуто). Upload-audio = аудио загружается ДО рендера, HeyGen сам строит липсинк по нему.

## Протокол

1. Текст-линт: `python3 scripts/tts-textlint.py --file <фраза>` — PASS до генерации.
2. Путь A: OmniVoice → WAV → whisper round-trip (`tts-verify.py`, смотреть detected-lang и p) → HeyGen upload-audio → короткий рендер.
3. Путь B: открыть список голосов автора в HeyGen, ДЛЯ КАЖДОГО клона зафиксировать имя/ID → рендер той же фразы каждым кандидатом (короткие).
4. Все mp3/mp4 — на Рабочий стол с человеческими именами (`голос-тест-A.mp4`, `голос-тест-B-<имя клона>.mp4`) + таблица в чат.
5. автор слушает, выбирает канон (путь + конкретный голос).
6. Вердикт записать в SKILL.md Фаза 4 (реестр проб) — тест закрыть, канон применять без повторных вопросов.

## 🔴 Правило источника финального звука (автор)

Финальную дорожку в энкод брать ТОЛЬКО из нативного HeyGen-рендера (48кГц стерео):
`ffmpeg -i heygen/twin_raw.mp4 -vn -af "atempo=<factor>" -ar 48000 ru_final.wav`.
НИКОГДА не `*16k.wav` (даунсэмпл под whisper-транскрипт, полоса 8кГц → робот; upsample высоких не вернёт).
Перед энкодом `ffprobe sample_rate` источника: 16000 = это whisper-файл, не финал. Метку промпта про
язык дорожки сверять whisper, не верить вслепую (нативная `twin_raw.mp4` была русской 48к, хотя промпт
пометил её english).
