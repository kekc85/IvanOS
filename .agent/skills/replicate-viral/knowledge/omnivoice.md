# OmniVoice — клон голоса автора (бесплатно, локально)

Open-source voice clone `k2-fsa/OmniVoice`, крутится локально на MacBook M4 Max (MPS + bfloat16). Бесплатно, без ElevenLabs ($99/мес → $0). Валидировано по решению автора («потрясающе одинаковые с оригиналом»).

Рабочий прототип: `~/.business/processes/omnivoice-test/clone.py` (+ venv симлинк на `~/_venvs/omnivoice-venv`).

## Как работает

1. Референс голоса автора: **3-10 сек** чистой записи (тихая комната, один дубль) → `ref_voice.wav`. Клонируется ОДИН раз, ref переиспользуется для всех роликов. 🔴 НЕ брать длинный референс: сама модель кидает warning на >20с («degraded voice cloning quality, slower, higher memory — recommend 3-10s»), проверено (40с дал хуже + медленнее, 9с = чистый клон за 7с). Готовый чистый референс автора: `~/.business/processes/omnivoice-test/ivan_ref9.wav` (+ `ivan_ref9.txt`), вырезан из «Бонус за подписку ТГ.mp4».
2. `model.create_voice_clone_prompt(ref_audio, ref_text)` — ref_text = дословная расшифровка ref_voice.
3. `model.generate(text=<адаптированный скрипт>, voice_clone_prompt=prompt, language='ru'|'en')` → audio 24kHz.

## Обёртка скилла

`scripts/omnivoice-tts.py "<текст>" <ref_voice.wav> <ref_text.txt> <out.wav>` — параметризованная обёртка над clone.py: грузит модель (MPS), клонирует из ref, генерит текст, пишет WAV. Первый прогон качает веса HF.

## Важно

- Это клон ГОЛОСА АВТОРА (по его записи), НЕ edge-tts (тот = чужой голос «Дмитрий», для talking-head личного бренда не годится).
- Язык передавать явно (`ru`/`en`) — модель мультиязычная.
- Для разговорной естественности: CAPS в тексте на акцентах (если поддерживается версией), короткие фразы, паузы.
- Голос потом подаётся в HeyGen Avatar V как audio-дорожка для lip-sync (Avatar V audio-driven — энергия голоса управляет мимикой).
## 🔴 Гейт озвучки (0.0, прецедент кривых ударений в готовом ролике)

Модель НЕ поддерживает метки лексического ударения (по коду пакета: `accent` = акцент голоса american/british, не ударение). Контроль качества = 3 шага, кредитные фазы (HeyGen) не стартуют без них:

1. **Текст-линт до генерации** — `scripts/tts-textlint.py --file <text>`: транслиты брендов кириллицей = FAIL (дубль-гард в `omnivoice-tts.py`), цифры/омографы = WARN.
2. **Round-trip после** — `scripts/tts-verify.py <wav> <text-file>`: whisper-сверка аудио с текстом, расхождения списком («вайб»→«вайп» — реальный улов).
3. **Прослушка автором до HeyGen** — ударения русских слов машина не верифицирует; MP3 на Рабочий стол, ждать «ок».

### Правила TTS-текста
- Бренды — по **реестру произношений** в SKILL.md Фаза 4 (НЕ слепо латиницей: Claude = «Клод» кириллицей, латиница даёт «Клоуд»; ChatGPT = латиницей).
- Числительные — прописью в нужном падеже («по десятибалльной», не «по 10-бальной»).
- «ё» проставлять везде («твоё», «отчёт») — без неё модель чаще мажет.
- Омографы (зАмок/замОк, дорОга/дорогА…) — переформулировать на однозначное слово.
- Спорное слово → тест-фраза 3-5 слов ДО полного трека, результат → в реестр.
