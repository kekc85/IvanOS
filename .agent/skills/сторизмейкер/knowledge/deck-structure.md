# Канон продающей сторис-деки (продающий highlight)

Скелет деки «мой путь» (15 кадров), принятый автором и провалидированный тройным ревью. Это дефолт для продающего highlight под холодный трафик; адаптировать под задачу, НЕ ломая драматургию (порядок блоков) без причины.

## Драматургия (каркас Блэра Уоррена: пруф → подозрение/вина → надежда → враги закрыты → мечта+шаг)

| # | Блок | Кадр | Формат | Задача |
|---|---|---|---|---|
| 1 | ХУК-ПРУФ | «Я отдал этот профиль Claude Code» + 2 скрина целиком | видео static-first | контринтуитивное заявление + визуальный пруф в первую секунду |
| 2 | ПРУФ-МЕХАНИКА | живые комменты с кодовыми словами | видео | показать механику живьём; заголовок с НОВОЙ инфо, не дубль хука |
| 3 | ПРУФ-ДЕНЬГИ | лента оплат 990 ₽ / 99 000 ₽ | видео | деньги реальные, с именами; эскалация подписчики → система → деньги |
| 4 | БОЛЬ 1 | «Нейросети освоил, а денег с них нет» | фото | точная идентификация + снятие вины («её тебе никто не показывал») |
| 5 | БОЛЬ 2 | «Год откладываешь первый продукт» | фото | вторая грань боли, без нового пруфа не затягивать |

## Правила блока «вечер» (11-14)

- Структура кадра: кадр эфира/пруф сверху → кикер «вечер N · тема» → заголовок → «зачем» → «что будет» → карточка «унесёшь» (2-3 пункта)
- Каждый пункт «унесёшь» - конкретный артефакт; названия скиллов с расшифровкой по-человечески
- VIP-вечер = дефицит: «мест мало, разбираю лично» + приоритет по времени регистрации

## Ссылка (link-стикер при заливке)

- Кадры 10 и 15; в тексте всегда «жми ссылку наверху» (слово «стикер» запрещено)
- Ведёт в Telegram-канал с регистрацией (вход трафика = закрытый канал, не бот напрямую)

## Прогноз-ориентир (ревью маркетолога по решению автора)

До оффера доживает 55-65% открывших, до финального CTA 30-40%, тап по ссылке 8-12% при правильной геометрии срочности. Если новая дека структурно хуже этих ориентиров по ревью - переделывать до отдачи.
