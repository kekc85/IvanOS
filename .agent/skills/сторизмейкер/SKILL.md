# Сторизмейкер - продающие сторис-деки под ключ

Собирает вечнозелёный продающий highlight (или сторис-серию запуска): холодный зритель с Reels → профиль → highlight → регистрация. Один прогон = готовые кадры 1080×1920 (PNG статика + MP4 анимация), проверенные тройным ревью, отданные декой с кэш-барьером.

## Когда применять

- «сделай сторис / сториз / актуальное / хайлайт про X»
- «сторис про мой путь / запуск / продукт»
- «дека сторис», «сторителлинг в актуальное»
- правки готовой деки: «переделай кадр N», «этот слайд говно - чини»
- `/сторизмейкер`

НЕ для: каруселей (→ carousel), лендингов (→ website), видео-рилз (→ replicate-viral / video), дек уроков (→ lesson-deck / prezentaciya-uroka).

## Обязательные чтения ДО работы (Mandatory Reads)

1. `knowledge/deck-structure.md` - канон драматургии продающей деки (15 кадров)
2. `knowledge/error-registry.md` - 37 анти-ошибок с прецедентами; прогон по нему перед КАЖДОЙ отдачей
3. `knowledge/pipeline.md` - технический конвейер (json → генераторы → ffmpeg → кэш-барьер)
4. `visual-anchors/manifest.md` + сами якоря - эталон качества, сверка side-by-side
5. `.business/voice-corpus/_voice-profile.md` - голос автора
6. Гейты `_shared/context-gap-gate.md` и `_shared/mastery-gate.md`

## Workflow

### Фаза 0 - Бриф и сырьё (context-gap gate)
Что продаём, куда ведёт ссылка, какие есть ЖИВЫЕ пруфы (скрины/видео/цифры), какие фото автора доступны (лицо видно, сцены разные), реестр прошлых правок автора по теме. Нет пруфов/цифр - СТОП, запросить списком (единственный разрешённый вопрос), не выдумывать. Рабочая папка `~/highlight-work/<slug>/render/` (вне iCloud).

### Фаза 1 - Структура (mastery gate)
Скелет по `knowledge/deck-structure.md`. Линза мастеров по `mastery/PROTOCOL.md`: offer-design (Хормози - ценность/усилия), persuasion-psychology (Чалдини - честный дефицит, пре-суазия; Уоррен - вина/враги/надежда), virality-attention (Кейн - хук). Evidence Report: метод → как применён в структуре.

### Фаза 2 - Тексты кадров
Все тексты в `slides-benchmark.json` (один источник истины). Правила: реестр A (связные предложения, термин+расшифровка, без мета-ярлыков, «Claude Code» именем, ₽ у цен, покрытие сегментов «не эксперт»/«не знаю что продавать»). Полный прогон humaniser (DETECTOR→REWRITER→CHECKER) + формат-тройка.

### Фаза 3 - Рендер
По `knowledge/pipeline.md`: статика (фото-кадры) через build-генератор, анимация через Playwright recordVideo → ffmpeg. Правила: реестр C (static-first на хуке и CTA, без shine-sweep, мягкие пульсы, сейф-зоны, скрины целиком, контраст-пилюли, типограф против висячих слов).

### Фаза 4 - Самопроверка стоп-кадрами
Каждый кадр: стоп-кадр с диска (видео - в содержательной фазе, `-ss 5..7`) → Read → глазами по реестру. Дефект → чинить КЛАССОМ (все кадры с той же болезнью), не точечно.

### Фаза 5 - Тройное ревью (новая дека / крупная ревизия)
3 параллельных агента по стоп-кадрам с диска: (1) сторис-маркетолог с mastery-линзой - конверсия, геометрия срочности, дубли смыслов; (2) визуальный дизайнер - типографика, контраст, сейф-зоны, артефакты; (3) холодный зритель-новичок (персона из ЦА, листает по 2 сек) - где скучно/непонятно/жаргон. Канон-ограничения в бриф каждому (решения автора не трогать). Фиксы классами → контрольные стоп-кадры. Точечная правка 1-2 кадров - без полного ревью, но с фазой 4.

### Фаза 6 - Паблиш с кэш-барьером
Новый префикс имён файлов на КАЖДУЮ ревизию (bNN-*), новая deck-bNN.html с маркером «если видишь этот заголовок, кэш сброшен», curl 200 на каждую ссылку. Сервер умер - перезапустить.

### Фаза 7 - Доставка
В чат: ссылка на деку + инлайн стоп-кадры изменённых кадров + список изменений по пунктам ударов автора. НЕ отправлять в Telegram-бота (<твой-бот> = карусели, сторис туда не льём) и никуда без явной просьбы. Порядок заливки и куда стикер - строкой в финале.

## Принципы

1. **Идеал до показа.** автор видит только версию, прошедшую реестр + стоп-кадры. Полусырое = разнос + сожжённое доверие
2. **Реестр правок автора = закон.** Каждый разнос → пункт в error-registry.md этого скилла (сессионные уроки поднимать сюда же)
3. **Пруфы живые.** Реальные скрины/видео/цифры; нет пруфа - нет кадра
4. **Смысл → форма.** Сначала структура и тексты, потом визуал
5. **Один источник истины** - slides-json; править источник, не рендер
6. **Каждая ревизия - новые имена файлов.** Кэш уже один раз стоил доверия («ты дал одну и ту же ссылку»)

## Anti-patterns (топ из реестра, полный список - error-registry.md)

- Телеграфные обрубки и жаргон без расшифровки («набор звуков»)
- Мета-ярлыки («ключевая история», «доказательство»)
- Нарратив, противоречащий фигуре автора («мне не пришлось быть маркетологом» - автор маркетолог)
- Смыслы, отрезающие сегмент ЦА («ты уже эксперт» - а кто себя им не считает?)
- Входные анимации на первом кадре и CTA; бегающие блики
- «Готово» без стоп-кадров с диска; та же ссылка/имена файлов на новую ревизию
- Отправка в бот каруселей или куда-либо без просьбы

## Memory cross-refs

- - результат показать в чат + объяснить
- - только открываемые форматы
- - в бот только по прямой команде
- - нет факта → спросить списком
- - линза мастеров с Evidence
- - полный прогон humaniser
- - дефект чинить классом
- - править источник, не рендер

## Параллельные скиллы

`carousel` (карусели IG - другой формат и доставка), `lesson-deck` / `prezentaciya-uroka` (обучающие деки), `video` / `replicate-viral` (рилзы), `website` (лендинги). Сторизмейкер = именно вертикальные сторис/highlight с продающей драматургией.

## MASTERY+CONTEXT GATES (shared, injected)

> Два обязательных гейта перед написанием публикуемого текста. Общие для всех writer-скиллов, источник истины в `_shared/`.

### Гейт 1 — Context-gap (нет реального контекста → СПРОСИ, не выдумывай) — HARD
`Read(~/.claude/skills/_shared/context-gap-gate.md)` и примени ДО draft. Если для текста нужны цифры / инфоповоды / новости / цены / даты / кейс / цитата, которых НЕТ в источниках (config / карта смыслов / story-bank / транскрипт / то, что дал автор) → **СТОП, не писать**, вывести в чат нумерованный список «нужно от тебя:» и ждать. Выдумывать, округлять, ставить плейсхолдер в финал — запрещено. Вывести секцию `Context-gap: нет / список вопросов`.

### Гейт 2 — Mastery (линза мастеров) — HARD
`Read(~/.claude/skills/_shared/mastery-gate.md)` (полный регламент — `mastery/PROTOCOL.md`). До draft: Inventory ВСЕХ авторов `mastery/copywriting/` + Select с обоснованием + bind. После draft, до humaniser: Evidence Report (метод→цитата) + независимый верификатор (субагент-скептик; нет цитаты→FAIL; верификатор запускается ВСЕГДА, без исключений — v4.2, `--fast`/облегчённый режим устранён).

**Порядок:** Context-gap → (если полно) Mastery Inventory+Select → write → Evidence+Verifier → Humaniser → output.
