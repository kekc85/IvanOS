## Общий вайб жанра
Энергичный premium-инфобиз на СВЕТЛОМ фоне, но БОЛЬШОЙ и СМЕЛЫЙ (не muted, не «тихий лакшери»). Контраст: крупная капс-типографика + живые РЕАЛЬНЫЕ ассеты (фото-cutout, GIF-мокапы телефонов, скрины профилей/чатов/денег) + повёрнутые стикеры-наклейки + 3D-пропсы (пачки денег, %-знак, счётная машинка). Вайб = «громкий результат и деньги», а не минимал.

- **Синий основной** ~#2B7FE0 / #2E8BE6 — заголовки, плашки-карточки модулей, кнопки-якоря, акценты в тексте.

- Белый фон карточек, тёмно-серый/чёрный текст для подзаголовков и тел.

## Типографика
- **Огромные UPPERCASE кириллические заголовки**, тяжёлый жирный гротеск. Секционные H2 капсом по центру с **выделением части фразы синим** («СОПРОВОЖДЕНИЕ ТОЧНО ДЛЯ ТЕБЯ, **ЕСЛИ ТЫ:**»).
- H1 в hero — гигантский, синий, капс. Акцент-фраза — в цветной плашке.
- Тела — обычный гротеск, ключевые слова **жирным**; буллиты с **синими/оранжевыми кружками-маркерами** (не чекбоксы, не `→`).

## 9 приёмов-сигнатур жанра (целевая планка — забрать в любой флагман)
1. **Реальное фото эксперта cutout** + летящие иконки соцсетей на пунктирных линиях.
2. **Анимированные GIF-мокапы** реальных телефонов/профилей (не статичные PNG, не абстрактные карточки).
3. **Повёрнутые стикеры-наклейки** с тенью: рукописные пометки, прайс, уведомления о зачислении/переводе — раскиданы по секциям.
4. **3D-пропсы денег** (пачки долларов, счётная машинка, %-гексагон, рука с купюрами) в денежных секциях.
5. **Гигантская капс-типографика** синим + цветные акцент-плашки (оранжевая).
6. **Соц.доказательство РЕАЛЬНЫМИ скринами** (рост подписчиков в hero, скрины профилей учеников в кейсах, скрины зачислений).
7. **Зебра-лейаут карточек модулей** (чередование лево/право) — ломает «секции стопкой».
8. **Тариф-таблица 4 колонки** с цвет-кодом + исключённые пункты серым перечёркнутым (апсейл наглядностью) + цена/мес крупно + рассрочка.
9. **Value-stack по Хормози** («стоимость отдельно: N / бесценно») перед ценой. Светлый «облачный» фон с изогнутыми лентами, НЕ плоский белый, НЕ тёмная неонка.
