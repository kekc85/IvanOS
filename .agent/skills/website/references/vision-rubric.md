# Слой 3 — VISION-критик: ЗАКРЫТАЯ РУБРИКА (rubric-as-code)

> Загружается критиком-субагентом (Шаг 9.2). Метод: arxiv 2412.16829 (iterative + bbox) + 2510.08783 (закрытая рубрика, pairwise). Цель — поймать ВКУСОВОЕ, что машина (Слой 1) не берёт, БЕЗ галлюцинаций. Это не «оцени дизайн», а закрытая матрица проверки покрытия.

## Вход критику (обязателен весь)
1. **Скрины билда** на ширинах 360/768/1024/1280 + hover/focus ключевых интерактивов (CTA, поля). *(loading/empty/error — N/A для статичного лендинга, рендерится одно состояние.)*
2. **Референс-доска жанра** (`refs/*.png` + `flagship-style-reference.md`) — для PAIRWISE.
3. **JSON Слоя 1** (`layout-audit.mjs`) — для КРОСС-ВАЛИДАЦИИ находок (см. ниже).
4. Этот файл-рубрика.

## Протокол (3 правила, нарушение = критик не сделал работу)
1. **PAIRWISE, не абсолют.** По каждому критерию: «что предпочёл бы человек — НАШ экран или ЭТАЛОН, и почему» (модель в pairwise 90%+; абсолютная оценка хуже). Балл = насколько дотягиваем до эталона.
2. **bbox + правка на КАЖДЫЙ дефект.** Координаты [x,y,w,h] + конкретная правка. Без bbox — не засчитан.
3. 🔴 **КРОСС-ВАЛИДАЦИЯ Слоем 1.** bbox-грундинг доказанно НЕ ловит галлюцинации ([arxiv 2406.14492](https://arxiv.org/pdf/2406.14492)). Поэтому каждый дефект про ГЕОМЕТРИЮ (наложение/вылет/обрезка/прилипание) критик ОБЯЗАН сверить с JSON Слоя 1: есть ли там реальный элемент в этих координатах. Нет подтверждения машиной И дефект геометрический → ОТБРОСИТЬ как галлюцинацию. Машина — арбитр геометрии; критик добавляет ТОЛЬКО вкусовое (иерархия/ритм/эстетика/жанр), что машина не меряет.

## Матрица покрытия: 11 ЛИНЗ × РЕГИОНЫ × ШИРИНЫ
По КАЖДОЙ ячейке (линза × регион) — явно «ок / нарушено + bbox», не молчание. Регионы: nav · hero · заголовок · подзаголовок · CTA · соц-пруф/метрики · мокапы · тарифы · футер · СТЫКИ между экранами.

| # | Линза | На что смотреть (вкусовое, не меряемое машиной) |
|---|---|---|
| 1 | Пространство и ритм | единый ритм отступов, дыхание, баланс пустот, СТЫКИ дышат *(жёсткое — у Слоя 1)* |
| 2 | Сетка и выравнивание | оптическое выравнивание, единая сетка, нет визуального съезда |
| 3 | Наложения/коллизии/случайный декор | *(геометрия — Слой 1)* + «прилеплено случайно» (дуга/блоб/линия не к месту) |
| 4 | Иерархия и фокус | один фокус на экран, сканируется за 3 сек, primary-CTA доминирует |
| 5 | Типографика | шкала, ОРФАНЫ (намерение: акцент-плашка vs случайный отрыв — решает критик по `orphan_candidates` Слоя 1), кривые переносы, рваный staccato |
| 6 | Цвет и контраст | палитра, дисциплина акцента, не мутно/пёстро *(порог 4.5:1 — Слой 1 axe)* |
| 7 | Реализм ассетов | мокап как реальный UI (не вайрфрейм/плейсхолдер/плоский блок), глубина, не сток-клише |
| 8 | Консистентность | токены едины по экранам, повторяющийся компонент идентичен |
| 9 | Адаптив | чисто на всех ширинах, логичный стек *(вылеты — Слой 1)*, не зажато |
| 10 | Крафт/полировка | единые тени/радиусы, премиум-ощущение «зафичерили бы на Awwwards», сломана «стопка» |
| 11 | Содержание/смысл | регистр копи, позиционирование = чем объект реально является, без плейсхолдер-текста, конкретика не вода, факты реальны |

🔴 **СВЕРХ матрицы:** если ХОТЬ ЧТО-ТО смотрится не так, как в эталоне / как сделала бы топ-студия — флагай, даже если не в линзе. Премиум = «ничего не криво», а не «галочки».

## Few-shot калибровка (стабилизирует пороги — UICrit, [arxiv 2407.08850](https://arxiv.org/pdf/2407.08850))
Перед оценкой критик держит якоря под каждую линзу: ЭТАЛОН-пример (флагман автора = 10) и явный-брак-пример (плоский muted-вайрфрейм = 2). Балл экрана — интерполяция между ними, не «по ощущению».

## Перспектива-диверсити + сходимость
- ≥2 судьи с разными линзами (1: типографика/композиция/цвет · 2: реализм/глубина/жанр · 3: смысл/конверсия). Свести по ХУДШЕМУ баллу.
- 2-3 прохода (iterative refinement: модель уточняет текст И боксы).
- Выход: таблица 11 линз × балл + дефекты с bbox+правкой (после кросс-валидации Слоем 1).
- **Сходимость экрана:** 0 красных Слой 1 И 0 регрессий Слой 2 И каждая линза ≥9. Иначе — агент чинит сам, re-render, повтор. Человек апрувит ЭКРАН, не микроправки.
