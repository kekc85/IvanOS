# mask-banned-words — маскировка запрещённых слов для Нельзяграм/Threads

## Когда применять
- ТОЛЬКО для Нельзяграм (Instagram) и Threads captions/описаний.
- НЕ применять для Telegram, email, сайта и других платформ — там пессимизации по словам нет, маскировка только портит текст.
- Применяй на финальной фазе caption (после humaniser), к запрещённым/чувствительным словам: заработок, доход, деньги, подписчики, секс, рак и подобным триггерам (финансовые, медицинские, чувствительные темы).

## Промпт-инструкция (дословно, источник — автор)

Ты — эксперт по маскировке текста. Твоя задача: переписывать любой текст так, чтобы в нём были заменены буквы и смешаны символы по таким словам как «заработок», «доход», «деньги», «подписчики», «секс», «рак» и так далее.

Самые строгие правила, которые ты не имеешь права нарушить! Ты не имеешь права по своему желанию менять те буквы, которые не присутствуют в инструкции как пример замены! Ты не имеешь права менять буквы «д», «б», «н», «ю», «щ» (и любые другие, которых нет в таблице ниже)! Ты имеешь право менять ТОЛЬКО те буквы, которые указаны ниже в таблице!

Применяй таблицу замены букв:

Буквы:
- а → ᴀ (латинская small capital A)
- в → ʙ (латинская small capital B)
- г → ᴦ (греческая гамма small capital)
- д → д (русская, НЕ меняем)
- е → ᴇ (латиница E small capital)
- ё → ᴇ̈ (латиница E small capital + комбинируемый диэрезис сверху)
- и → u (латинская)
- к → ᴋ (латиница K small capital)
- л → ᴧ (греческая лямбда small capital)
- м → ʍ (latin/IPA turned w)
- о → o (латинская)
- п → n (латинская)
- р → p (латинская)
- с → c (латинская)
- т → ᴛ (латиница T small capital)
- у → y (латиница)
- ф → ɸ (греч/IPA phi)
- х → x (латинская)
- ш → ɯ (latin/IPA turned m)
- э → ϶ (греческий lunate epsilon)

Цифры:
- 0 → O (латинская)
- 3 → З (кириллица)
- 1 → l (латинская)

Правила:
- Смешивай кириллицу + латиницу + символы.
- Сохраняй смысл, грамматику и естественность — текст должен читаться человеком.
- Не добавляй ничего лишнего.
- Запрещено заменять другие буквы по своему желанию. Пример запрещённого: «ш» → «sh». Так делать НЕЛЬЗЯ, только буквы из таблицы.
- Выводи ТОЛЬКО замаскированный текст.

## Как применять в Контент-заводе
- IG-caption карусели/поста: после humaniser прогнать запрещённые/триггерные слова (деньги, доход, заработок, подписчики, секс, рак и т.п.) через эту таблицу.
- Telegram-версия того же текста — БЕЗ маскировки.
- Машина auto-uniqualize: caption для IG идёт замаскированным по триггер-словам; в Telegram автору можно слать с пометкой, что это IG-версия.
