# Шаблоны сообщений ученику для каждого этапа возврата

Готовые тексты для специалиста по возвратам. Каждый шаблон - база, адаптируется под конкретного ученика.

**Принципы:**
- Спокойный тон, без эмоций
- На "ты" (принятый в онлайн-проектах)
- Без обещаний которые не можем выдержать
- Ссылки только на факты и оферту

---

## Первичный ответ (Шаг 1)

### Если ученик жалуется

```
Привет, [ИМЯ].
Услышал тебя. Расскажи подробнее - что не получается? На каком модуле застрял?
Хочу разобраться чтобы помочь тебе дойти до результата.
```

### Если категоричный возврат

```
Привет, [ИМЯ].
Получил твой запрос на возврат. Понял.
Прежде чем оформить - один вопрос: что именно стало причиной? Понимаю что хочешь вернуть деньги, но мне важно знать чтобы улучшить продукт для следующих учеников.
Если откажешься отвечать - всё равно оформим, твоё право.
```

### Если конфликт / агрессия

```
[ИМЯ], я слышу что ты недоволен. Давай разберём по фактам.
Какой у тебя был тариф и что конкретно не устроило?
Мы действуем по оферте - если возврат положен, оформим. Если есть нюансы - обсудим. Эмоциональная часть для меня вторична, важна суть.
```

## Спасательный круг (Шаг 2.1)

```
[ИМЯ], прежде чем оформлять возврат - предложение:

Я могу подключить наставника Андрея Душина на персональный созвон 1-на-1. Он разберёт твою конкретную ситуацию и поможет двинуться. Многие после такого созвона возвращаются в обучение и получают результат.

Если согласен - дай свой Telegram, передам Андрею, он сам напишет и согласует время.
Если не интересно - продолжим оформление возврата.

Решение полностью за тобой.
```

## Альтернатива (Шаг 2.2)

```
[ИМЯ], понял что у тебя не заходят видео / блокируется аккаунт / есть попытки но нет результата.

У меня есть два варианта помочь без возврата:

1. Готовый прогретый аккаунт-миллионник - даём в работу, чтобы был быстрый результат.
2. Подборка кейсов и видео учеников которые двигались с похожей ситуации - дам ссылки, посмотришь.

Что предпочитаешь? Или всё-таки оформляем возврат?
```

## Подтверждение возврата (Шаг 3)

```
[ИМЯ], принял. Оформляем возврат.

Что дальше:
1. Сейчас я соберу данные по твоей покупке и обязательствам которые мы выполнили / не выполнили.
2. Передам юристам - они посчитают сумму возврата по оферте.
3. Когда расчёт будет готов, пришлю тебе. Если согласен - попрошу банковские реквизиты для перевода.
4. После согласования - переводим деньги.

Срок всей процедуры - до 10 рабочих дней с момента получения твоих реквизитов.

Параллельно прошу: сделай сам расчёт по своей оферте (раздел "Условия возврата"). Это поможет нам быстрее сверить позиции.
```

## Саморасчёт ученику (Шаг 7, параллельно с запросом юристам)

```
[ИМЯ], параллельно прошу тебя сделать самостоятельный расчёт суммы возврата по оферте.

Открой оферту, раздел 5 "Порядок оплаты и возврата денежных средств". Там есть сетка распределения стоимости по этапам:

- Модуль 1 (быстрый старт) - 30%
- Модуль 2 - 20%
- Закрытый чат - 10%
- Кастомная GPT - 10%
- Обратная связь - 10%
- Остальные модули - 10%
- Онлайн-встречи - 10%

Посчитай: за какие этапы ты получил доступ, какая стоимость этих этапов от твоей оплаты. Остаток должен подлежать возврату (минус комиссии банков / партнёрской рассрочки).

Когда юристы пришлют официальный расчёт - сравним наши цифры. Если разойдёмся - обсудим.
```

## Расчёт ученику (Шаг 8)

```
[ИМЯ], юристы посчитали возврат. Вот разбивка:

Изначальная оплата: __________ ₽
Сумма, дошедшая до компании: __________ ₽ (после банковских комиссий)

Этапы которые ты получил:
- Модуль 1: ✅ (30% = __________ ₽)
- Модуль 2: ✅ (20% = __________ ₽)
- Закрытый чат: ✅ (10% = __________ ₽)
- [...другие этапы...]

Итого оказано услуг на: __________ ₽
Фактические расходы (банковские комиссии, партнёрская рассрочка): __________ ₽

К возврату: __________ ₽

Если согласен - пришли банковские реквизиты, оформим перевод (срок до 10 рабочих дней).
Если не согласен - давай обсудим, что именно не сходится с твоим расчётом.
```

- ФИО получателя:

## Конфликтный ученик (Шаг 12)

### Если давит на возврат всей суммы (хотя получил услуги)

```
[ИМЯ], понимаю что хочешь вернуть всё. Но смотри:

Согласно оферте (раздел 5, который ты подписал акцептом при оплате), возврат рассчитывается с учётом фактически оказанных услуг. Ты получил доступ к модулям [...], был в закрытом чате [...] дней, получил [...].

Мы не можем вернуть 100% за услуги которые ты получил - это была бы передача тебе наших услуг бесплатно. Но за неоказанные части - вернём по расчёту.

Расчёт у юристов. Когда будет готов - пришлю.
```

### Если угрожает судом / отзывами

```
[ИМЯ], твоё право обратиться в суд или Роспотребнадзор. Мы готовы отстаивать свою позицию документально - всё зафиксировано в оферте, всё прозрачно.

Параллельно мы оформляем возврат по регламенту. Никто не пытается тебя обмануть - просто следуем правилам которые написаны заранее и одинаковые для всех.

Если хочешь ускорить - пришли реквизиты сразу как только получишь расчёт.
```

### Если переходит на личности или агрессию

```
[ИМЯ], я понимаю эмоции, но давай сохраним рабочий тон.

Я не оскорбляю тебя, прошу не оскорблять меня. Если хочешь конкретный результат (возврат) - мы его делаем. Эмоции его не ускорят и не замедлят.

Что от тебя нужно дальше:
1. Сейчас - дождаться расчёт от юристов (присылаю в течение [дни]).
2. Сверить с твоим расчётом, согласовать сумму.
3. Прислать реквизиты для перевода.

На связи.
```

## Формат сохранения переписки

После каждого ключевого этапа делаем скриншот / копию переписки и кладём в кейс ученика (`~/Documents/refunds/<ФИО>-по решению автора.md` или в CRM).

Особенно важно сохранить переписку для Шага 8.5 - чтобы Руководитель видел контекст.
