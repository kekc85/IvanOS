# Аудит-чек-лист: 4 слоя нарушений

Адаптация blueprint `~/.business/processes/legal-attack-blueprint.md` для **самопроверки** (не для атаки на чужие сайты).

Используется в Режиме 2 «Аудит сайта». Прогоняешь сайт пользователя по этому чек-листу, выдаёшь отчёт с приоритетами.

## Слой 1: Персональные данные (152-ФЗ, штрафы РКН)

### Cookies и трекеры

- [ ] Cookie-баннер: есть / отсутствует / нерабочий
- [ ] Трекеры загружаются ДО согласия (через `document.cookie` + `<script src>`):
  - `_ym_*` - Яндекс.Метрика
  - `tmr_*`, `domain_sid` - Top.Mail.Ru
  - `_ga`, `_gid` - Google Analytics
  - `_fbp` - Facebook Pixel

**Штраф:** до 700 000 ₽ (ч.2 ст.13.11 КоАП)

**Рецепт починки:**
- Использовать cookie-баннер из `materials/legal-pack/_placement/cookie-banner.md` (если файл существует) или подобный код
- Аналитика грузится ТОЛЬКО после явного "Принять все"

### Политика конфиденциальности

- [ ] Размещена в свободном доступе (ст.18.1 ч.2)
- [ ] Ссылка в подвале каждой страницы
- [ ] regex по тексту политики:
  - `cookie|куки` → если 0 совпадений = нарушение
  - `яндекс.метрик|yandex` → если 0 совпадений = нарушение (если Метрика стоит)
  - `top.mail|mail\.ru\s+top` → если 0 совпадений = нарушение
  - `реклам[а-я]+\s+(коммуникац|рассылк|звонк)` → если 0 совпадений = нарушение
  - `трансгранич|иностранн|США|ОАЭ|Евросоюз` → если используется Telegram/Google/AWS

**Штраф:** до 60 000 ₽ (ч.3 ст.13.11)

### Реестр операторов ПДн

- [ ] ИП/юр.лицо в реестре `pd.rkn.gov.ru/operators-registry/operators-list/`

**Штраф:** до 300 000 ₽ (ч.10 ст.13.11)

### Формы сбора данных

- [ ] Предзаполненный чек-бокс согласия - нарушение
- [ ] Отсутствие отдельного чек-бокса согласия на рекламу (звонки/SMS) - нарушение
- [ ] Кнопка "Отправить" / "Оплатить" активна без отметки чек-бокса - нарушение

## Слой 2: Защита прав потребителей (Роспотребнадзор)

### Реквизиты и контакты

- [ ] Адрес места нахождения ИП/юр.лица в подвале (есть / нет)
- [ ] Email указан на каждой странице
- [ ] Режим работы прозрачен (или «круглосуточно» обманывает)
- [ ] ИНН и ОГРНИП в реквизитах оферты
- [ ] Сведения об образовании/квалификации специалистов (если рекламируется «опыт N лет»)

### Публичная оферта

Проверить полноту:
- [ ] Предмет договора (конкретный, не «оказание услуг»)
- [ ] Момент возникновения права на оплату/«гонорар успеха»
- [ ] Порядок расчётов
- [ ] Ответственность сторон
- [ ] Порядок расторжения (с механизмом возврата)
- [ ] Подсудность (одностороннее ограничение прав потребителя = ничтожно)
- [ ] Поэтапная приёмка услуг (защищает от возврата 100% за частично оказанную услугу)
- [ ] Сетка распределения стоимости по этапам

**Штрафы:** ч.1 ст.14.7, ч.1-2 ст.14.8 КоАП

## Слой 3: Реклама (ФАС)

### Запрещённые утверждения

- [ ] Гарантирующие утверждения о результате:
  - «90% выигрываем», «100% возврат», «гарантируем результат», «доведём до победы»
  - «зарабатывают 100К/мес», «уже на первой неделе»
  - Особенно жёстко для юр.услуг, медицины, эзотерики, образования
- [ ] Конкретные имущественные цифры без подтверждения («помогли вернуть N млн»)
- [ ] Сравнения с конкурентами (без оснований)
- [ ] Рассылки/звонки без согласия (форма «перезвоним в 10 минут» без отдельного чекбокса)
- [ ] Реклама услуг, требующих квалификации, без подтверждающих сведений

**Штрафы (КоАП ст.14.3):**
- Гарантия результата → 100-500К для юр.лиц, 4-20К для ИП
- Реклама без согласия → до 500К
- Без подтверждения квалификации → ч.1 ст.14.3

### Рассылки

- [ ] В каждом маркетинговом письме ссылка "Отписаться" одним кликом
- [ ] Согласие на рассылку - явный чек-бокс, не предустановленный
- [ ] Логи дачи согласий хранятся (рекомендуется 10 лет)

### Прескролл для lazy-load

Перед серией скриншотов:

```js
async () => {
  let h = 0;
  for (let i = 0; i < 40; i++) {
    window.scrollTo(0, document.body.scrollHeight);
    await new Promise(r => setTimeout(r, 800));
    if (document.body.scrollHeight === h) break;
    h = document.body.scrollHeight;
  }
  document.querySelectorAll('img[data-src], img[loading="lazy"]').forEach(img => {
    if (img.dataset.src) img.src = img.dataset.src;
    img.loading = 'eager';
  });
  window.scrollTo(0, 0);
  await new Promise(r => setTimeout(r, 3000));
}
```
