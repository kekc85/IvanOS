# Template: Story / news mega-thread

**Reference cluster:** Paips-story + Idea-drop (Bloom Named-Principle / Cole 7 templates / Cheung AI-news).
**Char zone:** Hook = B (200-280).
**Format:** Mega-thread 18-34 tweets.

## Skeleton - Bloom Named-Principle Visual Thread

```
1/ Hook: "Everyone needs to read this.

The [Principle Name] Principle.

(a visual thread)"

2-3/ Setup of named principle (origin / why matters)

4-15/ Beats with concrete examples + verbatim (1-2 examples per beat)

16-25/ Variations / counter-examples / edge cases

26-30/ Synthesis

31-34/ Closer:
- "Bookmark this for later"
- "Newsletter goes deeper: <link>"
- Recurrent CTA visual
```

**Recyclable quarterly** - Bloom reuses same template с обновлёнными examples.

## Skeleton - Cole's 7 templates (choose one)

1. **Framework** - "Here's a framework for [X]: [name + 5-7 steps]"
2. **Curation** - "Best [N] [items] I've ever consumed about [topic]"
3. **This Just Happened** - "[Surprising recent event]. Here's what it means..."
4. **If I Had To Do It Over Again** - "[N] things I'd do differently"
5. **Here's The Real Reason** - "Everyone says X. Real reason is Y..."
6. **Lessons Learned** - "[N] hard lessons from [experience]"
7. **Success Story** - "[Person] went from [start] to [end]. Here's how..."

## Skeleton - Cheung AI-NEWS thread

```
1/ Hook: "AI NEWS: [Vendor] just [delta]. Here's why it matters."

2-10/ Tool reveal (10 use cases с screenshots / 1-line examples)

11-12/ Implications

13/ Newsletter CTA: "Full breakdown in The Rundown - link below ↓"
```

автор adaptation: "ВАЙБ-РАЗБОР: [инструмент / запуск / событие]" + TG канал CTA.

## Voice rules

- Each beat = 1 sentence (Cole rule, partially)
- Specific numbers / names / verbatim quotes
- 1/3/1 ритм (короткая hook / длинные body / короткий closer)
- Closer = newsletter CTA OR community CTA OR bookmark directive

## Char rules

- Hook tweet ≤220 chars (room for "1/N" indicator)
- Each beat ≤280 (X) / ≤500 (Threads)
- Total = 18-34 tweets (compact 8-15 = use `numbered-list.md` instead)

## Verbatim Bloom example (Parent Time Principle, 18 tweets)

```
1/ Everyone needs to read this.

The Parent Time Principle.

(a visual thread)

2/ Concept: We get 18 summers with our kids before they leave the nest.

[continue с 16 more beats]

18/ Read the full essay в newsletter.
```

## Recyclable note

Mega-threads should be quarterly recyclable - Bloom reposts same skeleton с refreshed examples every 90 days.

## Anti-patterns

- Hook tweet >220 chars (no room для thread indicator)
- Beats без concrete examples
- "Just read it" closer (specific CTA лучше)
- Total <18 (use mini-thread instead)
- Total >34 (audience drops off)
- Generic principle name без origin / explanation
