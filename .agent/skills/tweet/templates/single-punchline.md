# Template: Single punchline

**Reference cluster:** Aphorism (Naval / Iman / Butcher) OR Spiky (Hormozi).
**Char zone:** A (40-100 chars) preferred.
**Format:** 1 tweet ≤280 X / ≤500 Threads.

## Skeleton

```
[Statement line, declarative, no question, no setup]
```

## Hook patterns applicable

1. Naked aphorism (Naval / Iman / Butcher) - identity bomb
2. Counter-intuitive opener (Hormozi / Levels)
3. Spiky one-liner (Hormozi)

## Voice rules

- Declarative, не interrogative
- No "I think" / "I believe" hedge
- Concrete если возможно (number / specific identity)
- No emoji
- No hashtag
- Max 1 sentence

## Verbatim examples из research

- **Naval:** "Earn with your mind, not your time."
- **Hormozi:** "You don't lack discipline. You lack clarity."
- **Iman:** "If 18-year-old me saw 28-year-old me, he'd be proud."
- **Butcher:** "Complexity happens by default. Simplicity happens by design."

## автор RU adaptation examples

- "Не курсы делают результат. Решения делают результат."
- "Контент-завод - это не про объём. Это про систему."

## Anti-patterns

- Questions в hook ("Why do most people...?")
- Long setup ("As I was thinking about...")
- Hedge ("It might be that...")
- Generic ("Hard work pays off" - без specifics)
- Self-quoting ("As I always say...")
