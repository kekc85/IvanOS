# Template: Contrarian take

**Reference cluster:** Spiky (Hormozi / Sanchez / Yacine / Levels).
**Char zone:** A (40-100) single OR B (200-280) hook для 3-tweet.
**Format:** Single tweet OR 3-tweet mini (hook + proof + lesson).

## Skeleton - Single

```
[Statement opposing consensus, declarative]
```

Example:
```
Most "marketing funnels" are just slow ways to lose customers.
```

## Skeleton - 3-tweet

```
1/ [Counter-intuitive thesis - what everyone says is wrong]

2/ [Proof point: data / example / personal experience]

3/ [What works instead - actionable lesson]
```

## Hook patterns applicable

1. Counter-intuitive opener (Levels / Hormozi)
8. Authority dunk (quote-tweet wrong claim)
11. Frustration-as-flex (Yacine / Ras Mic)

## Voice rules

- Statement against consensus (not just niche-contrarian)
- Without hedge ("I think")
- With proof (data / example / personal track record)
- No attack на person - attack на phenomenon (Common Enemy rule)

## Verbatim examples из research

- **Levels:** "Most indie hacking advice is wrong. Build for $1000/mo first, not $100K."
- **Hormozi:** "Most 'sales objections' are excuses you accept."
- **Yacine:** "Cursor isn't faster than nvim. You're just slow at nvim."

## автор RU adaptation examples

- "Не понимаю зачем платить 500К за курс по 'архитектуре ИИ-систем', если можно собрать первый продукт за неделю."
- "Большинство 'воронок' - это просто медленный отказ от собственного продукта."

## Common Enemy rule (HARD)

- Attack на **явление** ("курсомания" / "продюсерская модель" / "Cursor мифы")
- NOT attack на **имя** ("<конкурент> не прав" / "Палий обманывает")
- Memory: `[[feedback-no-attacking-competitors-by-name]]`

## Anti-patterns

- Personal attacks
- Pure provocation без proof / insight
- Hedge ("It might be that...")
- Niche-contrarian ("Cursor вместо VS Code" - too narrow)
- Without specific contrast ("X is bad" без "Y is better")
