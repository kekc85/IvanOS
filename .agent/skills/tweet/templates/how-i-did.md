# Template: How-I-did demo

**Reference cluster:** Build-in-public (Levels / Marc Lou / Friks / Alex Finn / Nate Herk).
**Char zone:** Hook = B (200-280) с specific outcome.
**Format:** Mini-thread 8-12 tweets build-in-public.

## Skeleton

```
1/ Hook: "$X in N days. Here's the workflow." (Zone B)

2/ Setup: starting point (date / state / what didn't work before)

3-7/ Steps with concrete numbers / time / tools

8/ Result + lesson

9-10/ Newsletter CTA / community link / "follow for more"

11-12/ Optional: counter-question / discussion prompt
```

## Hook patterns applicable

3. Specific outcome + mystery (Marc Lou / Levels)
9. Day-counter X/Y framing (Friks)
6. Greentext mystery (Cheung)

## Voice rules

- **Concrete numbers HARD** - $X, N days, specific tool versions
- **Verbatim screenshots** где возможно (Stripe / MRR / followers count) - НО screenshot uses → `single-image` type=dashboard-screenshot, не в `tweet`
- **Day-counter** для launches ("Day 47/90")
- **"Just shipped" / "Just hit"** opener
- No fake humility ("I'm just lucky")
- No grandiose ("Game-changing")

## Item format rule (steps 3-7)

Каждый step:
```
N/ [Step name]

[1-2 line concrete action + result]
```

Example:
```
3/ Newsletter setup → Beehiiv

Migrated 3K subs в 2 hours. First email to new list = 38% open rate.
```

## Cross-post note

Stripe screenshot → НЕ в этот template, идёт в `single-image` type=dashboard-screenshot (deprecated absorption).

## Anti-patterns

- Fake numbers (instant credibility kill если detected)
- Projections как fact ("on track to $X")
- Generic "Built X in N days" без proof
- Stock images instead of real screenshots - `single-image` handles screenshots
- Negative statistics ("only 20% reach goal")
- Student data без permission
