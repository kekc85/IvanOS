# Template: Spiky one-liner

**Reference cluster:** Spiky (Hormozi / Sanchez / Iman).
**Char zone:** A (40-140 chars) preferred (retweet-bait optimal).
**Format:** 1 tweet ≤280 X / ≤500 Threads.

## Skeleton

```
[Single 1-3 line punchline, declarative, contrarian]
```

## Hook patterns applicable

5 sub-patterns:

1. **Inversion of consensus** - "Everyone thinks X. Reality: Y."
2. **Hard truth** - blunt observation o industry / behavior
3. **Counter-cliché** - переворачивание popular advice
4. **Provocative claim** - bold statement без hedge
5. **Numbered list очень короткий** - "3 things that work in 2026: 1. X 2. Y 3. Z"

## Voice rules

- Quote-tweet bait (вызывает desire to discuss)
- Bookmark-worthy
- Memorable (recall test)
- Без hedge
- Без имён конкурентов в attack - Common Enemy = phenomenon

## Anti-patterns

- Fluffy generic ("Hard work pays off")
- Hedge / qualified statements ("It might be that...")
- Имена конкурентов в attack
- Pure provocation без insight
- Self-quoting ("As I always say")
