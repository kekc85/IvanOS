# Thread Structure (X / Threads)

> Bimodal length rule + 4 dominant skeletons.
> Sources: research/2026-05-28-tweet-skill-research/per-author/en-{welsh-x,bloom-x,cole-x}.md

## Length rule (HARD, Thread Length Gate)

| Length | Status | Use case |
|---|---|---|
| 1 tweet | Single | Aphorism / spiky |
| 2 tweets | Edge | Quote + reply self-pattern |
| 3-7 tweets | **Awkward middle - FAIL** | Avoid |
| 8-15 tweets | Compact | Weekly mini-thread |
| 16-17 tweets | **Awkward - FAIL** | Avoid (expand to 18+) |
| 18-34 tweets | Mega | Monthly recyclable |
| 35+ tweets | Too long | Use Cole atomic essay → screenshot single tweet instead |

## Hook tweet constraint (HARD)

- ≤220 chars (room для "1/N" thread indicator)
- Hook char zone: B (200-220) preferred для thread hooks
- Carries 80% of audience retention

## Skeleton 1 - Welsh PAIPS-thread (8-15 tweets)

```
1/ [Pain hook - concrete reality]
2/ [Agitate - consequences]
3/ [Intrigue - counter-intuitive turn]
4-N-1/ [Positive insights, numbered or named]
N/ [Soft CTA - newsletter / community]
```

## Skeleton 2 - Bloom Named-Principle Visual Thread (18-34 tweets)

```
1/ Hook: "Everyone needs to read this. The [Name] Principle. (a visual thread)"

2-3/ Setup (origin / why matters)

4-15/ Beats - examples + verbatim quotes (1 sentence per beat, Cole rule)

16-25/ Variations / counter-examples / edge cases

26-30/ Synthesis

31-34/ Closer:
- "Bookmark this for later"
- "Newsletter goes deeper: <link>"
- Recurring CTA visual
```

**Quarterly recyclable** - same skeleton, refreshed examples каждые 90 дней.

## Skeleton 3 - Cole's 7 thread templates

### 3.1 Framework
```
1/ [Hook: "Here's a framework for [outcome]"]
2/ [Framework name + 1-line definition]
3-N/ [Each step: name + verbatim example]
N+1/ [Closer]
```

### 3.2 Curation
```
1/ "Best [N] [items] I've ever consumed about [topic]"
2-N/ [Each item: name + 1-line why]
N+1/ [Closer]
```

### 3.3 This Just Happened
```
1/ "[Surprising recent event]"
2/ Setup: what happened
3-N/ Beats: implications
N+1/ Lesson + closer
```

### 3.4 If I Had To Do It Over Again
```
1/ "[N] things I'd do differently"
2-N/ Each item: what I did → what I'd do instead
N+1/ Closer
```

### 3.5 Here's The Real Reason
```
1/ "Everyone says X. Real reason is Y..."
2-N/ Beats: proof / examples
N+1/ Closer
```

### 3.6 Lessons Learned
```
1/ "[N] hard lessons from [experience]"
2-N/ Each lesson + concrete story
N+1/ Closer
```

### 3.7 Success Story
```
1/ "[Person] went from [start] to [end]. Here's how..."
2-N/ Story beats with numbers
N+1/ Lesson + closer
```

## Skeleton 4 - Cheung AI-NEWS thread

```
1/ "AI NEWS: [Vendor] just [delta]. Here's why it matters."

2-10/ Tool reveal (10 use cases с screenshots / 1-line examples)

11-12/ Implications

13/ Newsletter CTA: "Full breakdown in [newsletter]"
```

**автор RU adaptation:** "ВАЙБ-РАЗБОР: [инструмент / запуск / событие]" + TG канал CTA.

## Per-beat rules

- **1 sentence per beat** (Cole signature rule, applies к 80% beats)
- **Specific over abstract** - concrete number / name / verbatim quote
- **No "1." numbering в final beat** (distorts numbered promise)
- **No questions в hook** (statements only)
- **No links в hook** (move to closer)

## Closer patterns

| Pattern | When | Source |
|---|---|---|
| Newsletter sign-up | Have newsletter | Welsh / Bloom / Cole / Cheung |
| "Bookmark this" directive | Mega-thread | Bloom signature |
| Community link | Have paid community | Sanchez / Hormozi |
| Open question | Discussion thread | Yacine / Friks |
| Null (no CTA) | Aphorism / spiky | Naval / Iman |
| Meta-self-reference | Demonstration | "This hook is an example" - Acosta |

## Cross-post X → Threads adapt

- Same content base
- Expand 280 → 500 chars если есть room (Threads allows more)
- Chain length: max 10 posts на Threads (algorithm penalty при длинных chains)
- Same hook
- Same closer
