## Tier 1 — Auto-fail (риторические AI-фигуры)

### A. Triple-negation reveals
- "Не X. Не Y. Не Z. [W]." (parallel triple negation + final assertion)
- "Не курсы. Не воронки. Продукт."
- "Не аудитория. Не оффер. Сборка."
- "Не контент. Не команда. Решение."

Detection regex: `Не [А-Я].*\. Не [А-Я].*\. (Не [А-Я].*\. )?[А-Я]`

### F. Bare-imperative staccato pairs/triples (NEW v1.2)

Прецедент по решению автора: skill v1.1 пропустил "Сначала продукт. Потом контент." Это близкий родственник Tier 1A triple-negation - **bare-imperative parallel staccato** с обнулённой структурой.

**Pairs:**
- "Сначала X. Потом Y."
- "X сначала. Y потом."
- "X. Не Y." (binary негация)
- "X. И всё."
- "X. Точка."
- "X. Без вариантов."
- "X. Никак иначе."
- "X. Тогда Y."
- "Сначала делай X. Потом делай Y."

**Triples (imperative):**
- "Делай. Тестируй. Запускай."
- "Слушай. Делай. Запускай."
- "X. Y. Z." (3 короткие императивы без объяснения)

**Detection regex:**
- `^[А-Я][а-я]+ [а-я]+\. (Потом|И всё|Точка|Без вариантов|Никак иначе)\.?`
- `^Сначала .{1,20}\. Потом .{1,20}\.?`
- `^[А-Я][а-я]+\. [А-Я][а-я]+\. [А-Я][а-я]+\.$` (triple bare imperative)

**Почему AI любит:** короткие parallel императивы создают fake-gravitas. Никто из 21 EN автора research так не пишет.

**Real RU creator alternatives:**

| AI staccato (плохо) | Реальная альтернатива |
|---|---|
| "Сначала продукт. Потом контент." | "Самое неочевидное - продукт нужно собрать раньше чем учиться продавать." |
| "Делай. Тестируй. Запускай." | "Я не учу, я сразу собираю и тестирую через продажу." |
| "Продукт. Не контент." | "Курсы не дают результат. Первый клиент даёт." |
| "X. И всё." | (убрать "И всё", оставить утверждение) |
| "X. Точка." | (убрать "Точка", если нужна категоричность - переформулировать) |

## Tier 5 — Structure tells

- Tri-parallel (3 параллельных коротких предложения) когда не оправдан содержанием
- Перечисление-молчание ("Не X. Не Y. Не Z. ___.") - Tier 1
- Каждый абзац начинается с reveal markers
- Em-dash в reveals («главное - это X»)
- Numbered list где каждый item начинается с одного глагола
- Closing summary tweet repeating main points
- "Что в итоге" / "Итого" / "Подведём итог" в closer
- Excessive parallelism (3+ paragraphs одинаковой структуры)
- AI-rhythmic (короткое.короткое.короткое.длинное.) >2 раз

## Anti-AI rhythm rule

Главный AI tell - ритмическая параллельность:

Плохо (AI):
```
Не курсы делают результат.
Не воронки делают результат.
Не команда делает результат.
Продукт делает результат.
```

Хорошо (живой голос):
```
В 2024 году я слил ₽2М на курсах по запускам.
В 2025 первый продукт за неделю принёс ₽50К.
Разница не в обучении, а в том что я наконец сделал что-то для клиента.
```

Живой голос ломает ритм. AI выравнивает.
