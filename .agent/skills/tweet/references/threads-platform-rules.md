# Threads (Meta) Platform Rules 2026

> Meta Threads algorithm + cross-post rules.
> Sources: 21-author research (Cheung / Marc Lou / Cole cross-post observations) + public knowledge state May 2026.

## Char limits

| Tier | Limit |
|---|---|
| Standard post | 500 chars |
| Chain (one author) | unlimited posts, но algorithm penalty при >10 |
| Bio | 150 chars |

## Algorithm signals 2026

### Positive (boost)

- **Cross-post identical from X** (Cheung pattern - Meta boosts cross-posts с Instagram pipeline)
- **Native video / image** в posts
- **Threading с completion** (similar к X)
- **Reply rate на own posts** (engagement signal)
- **Instagram cross-traffic** (Threads connected к Insta account boosts)

### Negative (penalty)

- **External links** (heavy penalty - алгоритм keeps users in app)
- **Hashtags** (mild penalty, не как X)
- **Chains >10 posts** (algorithm cuts distribution)
- **Re-posted content без adapt** (some adapt helps)
- **Engagement bait** ("comment if you agree")

## Format rules

### Standard post

- ≤500 chars (more than X 280)
- Allows emoji более freely than X (Meta UI encourages)
- Links → discouraged, но можно в comments

### Chain

- Max 10 posts (algorithm sweet spot)
- Hook post ≤350 chars (room для chain indicator)
- Same skeleton как X mini-thread

## Cross-post X ↔ Threads

### X → Threads (Cheung pattern)

- **Identical drop** by default (same content, same time)
- **Optional expansion** 280 → 500 chars если есть room для richer narrative
- **Chain shortening** - X mega-thread 18-34 tweets → Threads chain ≤10 posts (compress beats)
- **Same hook** (text identical)
- **Same closer** (но links discouraged - newsletter CTA → community CTA или null)

### Threads → X

- **Shorten 500 → 280** если post длинный
- **Keep newsletter / external links** (X allows better)
- **Threading** - Threads post → может стать single X tweet or thread депенды на content

## Voice adjustments

- **Slightly more casual** than X (Meta UI encourages - ratio "I" vs "we" similar)
- **Emoji more allowed** в body (НЕ в hook still)
- **Less hashtag penalty** but still avoid (no organic benefit)

## Posting cadence

- **Cheung** - 3-7 X posts/day, identical Threads cross-posts (same volume)
- **Marc Lou** - Threads mirror к X (every drop)
- **Welsh** - X primary, Threads cross-post via Hypefury automation

**авторская recommendation:** Same cadence как X. Cross-post automation предпочтительна (less cognitive load).

## What NOT to do

- Post Threads-only content без X mirror (wastes content asset)
- Treat Threads как LinkedIn (это не professional network)
- Use Instagram-style hashtag spam
- Long Premium-like essays (≤500 chars hard, нет X Premium long equivalent)

## Threads-specific features

- **Repost** (similar к RT)
- **Quote post** (similar к Quote-Tweet)
- **Reply** (one-tap)
- **Fediverse cross-post** (ActivityPub, opt-in) - interesting для long-term EN audience
