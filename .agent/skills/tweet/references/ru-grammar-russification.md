# RU Grammar Russification (v1.1, 2026-05-28)

> Правила перевода EN → RU без грамматической кальки.
> Применяется в `03-write.md` Pass 2.5 после Voice injection.
> Прецедент по решению автора: Hormozi "X don't make Y" → "X не делают результат" (калька). Правильно: "X не даёт результат".

## Принцип

Дословный перевод EN глагола в RU = калька. AI делает её по умолчанию.
Живая RU замена = другой глагол / другая конструкция / переформулирование.

## Часть 1 - Глаголы (replacements)

### `make` (английское "делать как универсал")

| EN | RU калька (плохо) | RU нормально |
|---|---|---|
| make result | делать результат | давать результат / приносить результат |
| make progress | делать прогресс | продвигаться / идти вперёд / расти |
| make money | делать деньги | зарабатывать |
| make sense | делать смысл | иметь смысл / логично / понятно |
| make decision | делать решение | принимать решение |
| make sale | сделать продажу | продать |
| make customer | сделать клиента | привлечь клиента / получить клиента |
| make difference | делать разницу | менять / отличаться |
| make impact | делать impact | влиять / производить эффект |

### `have`

| EN | RU калька (плохо) | RU нормально |
|---|---|---|
| have result | иметь результат | получить результат / выйти на результат |
| have conversion | иметь конверсию | конвертить / конверсия идёт |
| have audience | иметь аудиторию | у меня аудитория / есть аудитория |
| have followers | иметь followers | у меня подписчики |
| have problem | иметь проблему | у меня проблема / столкнулся с |
| have time | иметь время | есть время / у меня время |

### `take`

| EN | RU калька (плохо) | RU нормально |
|---|---|---|
| take control | взять контроль | взять под контроль / контролировать |
| take action | взять action | действовать / делать |
| take risk | взять риск | рискнуть / пойти на риск |
| take opportunity | взять возможность | воспользоваться / поймать момент |
| take ownership | взять ownership | взять ответственность / отвечать |
| take onboard | взять на борт | взять в команду / нанять |

### `give`

| EN | RU калька (плохо) | RU нормально |
|---|---|---|
| give value | дать ценность | принести пользу / дать выгоду |
| give attention | дать внимание | уделить внимание |
| give feedback | дать feedback | дать обратную связь / прокомментировать |

### `build`

| EN | RU калька (плохо) | RU нормально |
|---|---|---|
| build audience | построить аудиторию | собрать аудиторию / нарастить |
| build product | построить продукт | собрать продукт / сделать продукт |
| build business | построить бизнес | сделать бизнес / запустить бизнес |
| build ecosystem | построить экосистему | (banned - Tier 4 AI-tells) |
| build community | построить community | собрать клуб / сделать клуб |

### `drive`

| EN | RU калька (плохо) | RU нормально |
|---|---|---|
| drive traffic | гнать трафик | (OK, living language) |
| drive sales | гнать продажи | продавать |
| drive growth | гнать рост | расти |

### `create`

| EN | RU калька (плохо) | RU нормально |
|---|---|---|
| create content | создавать контент | делать контент / писать контент |
| create value | ~~создавать ценность~~ → создавай(те) ценность (безадресный императив без объекта) | давать выгоду / приносить пользу |
| create opportunity | создавать возможность | открыть возможность |
| create system | создавать систему | сделать систему / собрать систему |

> **«create value» СУЖЕНО по решению автора** вслед за humaniser кат.13 (замер: владелец пишет так сам - VOICE-015 «Чем больше ты создаешь ценности, тем устойчивее сможешь расти», ivan-final-0 «отвечает в минуту интереса и сразу отдает ценность»). Калька = брак ТОЛЬКО как безадресный императив без объекта («Создавай(те) ценность» как самостоятельный совет). Форма от 1-го лица с объектом/фактом рядом - живой оборот, не калька, переписывать не надо.

## Часть 2 - Конструкции (sentence structures)

### Triple-parallel (AI любит)

Плохо:
```
Не курсы делают результат.
Не воронки делают результат.
Не команда делает результат.
Продукт делает результат.
```

Хорошо (ломаем ритм):
```
В 2024 году я слил ₽2М на курсах.
В 2025 первый продукт за неделю принёс ₽50К.
Разница не в обучении, а в том что я наконец сделал что-то для клиента.
```

### Reveal openers (AI любит "drama")

Плохо: "Главное открытие месяца..."
Хорошо: "Понял что..."

Плохо: "Что важно сделать первым..."
Хорошо: "Сначала продукт. Потом контент."

Плохо: "В этом и заключается секрет..."
Хорошо: (просто утверждать)

### Gerund / infinitive opening

EN: "Building audience is hard."
RU калька (плохо): "Построение аудитории - это сложно."
RU живо: "Собрать аудиторию сложно." / "Аудитория собирается долго."

EN: "Selling is the skill."
RU калька: "Продажа - это навык."
RU живо: "Главный навык - продать первого." / "Продать - вот навык."

## Часть 3 - Регистры

### "Ты" vs "Вы" (автор primary "ты")

EN "you" → RU "ты" в автора voice.
НЕ "Вы". НЕ "вы".

Плохо: "Если ты хочешь зарабатывать, тебе нужно..."
Хорошо: "Хочешь зарабатывать - сделай первый продукт."

### Безличные конструкции

EN: "It's important to ship."
RU калька: "Это важно - запустить."
RU лучше: "Запускай. Дорабатывай в продакшене."

## Часть 4 - Англицизмы (когда допустимо)

### Voice corpus автора - допустимо

- Нельзяграм
- вайбкодинг / вайбмаркетинг
- контент-завод
- Дубайск
- перегнать (видео)
- пдп

### Tech jargon - допустимо в narrow context

- "промпт"
- "лидмагнит"
- "конверсия"
- "трафик"
- "оффер"

### Banned - никогда

- shipped (используй "запущенный" / "выпущенный")
- real (используй "настоящий" / "реальный")
- mode (используй "режим")
- platform (используй "платформа")
- product (используй "продукт")
- feature (используй "функция")
- update (используй "обновление")
- release (используй "выпуск")
