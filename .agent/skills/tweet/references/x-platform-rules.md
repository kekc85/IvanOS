## Algorithm signals 2026

### Positive (boost)

- **Bookmark > Like > RT > Reply** (priority order for distribution)
- **Engagement в первые 30 минут** (algorithm peak window)
- **Threads с completion rate >40%** (read-to-end signal)
- **Native video / native image** (vs external links)
- **Profile clicks → follows** (most valuable signal)

### Negative (penalty)

- **Hashtags** (universal penalty 2026 - research confirmed across 21 authors)
- **Multiple external links per tweet**
- **Engagement bait** ("RT if you agree" / "Like if you")
- **Quote-tweet without commentary**
- **Mass tagging** (>2 @ mentions без conversation)
- **Re-posted screenshot из другого аккаунта без credit**

## Format rules

### Single tweet

- ≤280 chars (standard) или ≤25K (Premium long)
- First line carries 80% - hook gate
- Links → move to first reply (если хочется)
- No emoji в hook (Tier 1 rule)

### Thread

- Hook tweet ≤220 chars (room для "1/N" indicator)
- Each subsequent tweet ≤280 chars
- 8-15 compact OR 18-34 mega (Thread Length Gate)
- Closer = newsletter CTA / bookmark directive / community link

### X Premium long (≤25K)

- Use rare, для essay-style only
- Examples: Marc Lou monthly MRR ritual, Naval long aphorism string
- Treat как single block с paragraph breaks
- No artificial threading

## Posting cadence (research-confirmed)

- Welsh formula: "2 Tweets every day + 1 Thread every week"
- Levels: 40 tweets/day (extreme prolific)
- Naval: 3-8 posts/week (low cadence but high signal)
- Bloom: 1 thread/week (consistent)

**авторская recommendation:** Welsh formula initially (lower friction для new account).

## Engagement etiquette

- **Reply rate > 50%** на own thread comments (Welsh / Bloom rule)
- **Quote-tweet с context** > raw quote
- **Reply guys strategy** - engage в top creators replies (early growth)

## Recovery from algorithm dip

Если engagement падает:
1. Post 3 dunk replies на trending topics (immediate engagement)
2. Wait 2-3 days
3. Post mega-thread (high completion signal)
4. Cross-post на Threads (Meta может boost)

## Algorithm myths (NOT true 2026)

- "Tweets с фото получают больше engagement" - NEUTRAL (depends на content, не на media presence)
- "Posting в peak hours = больше views" - slight effect, не critical
- "Verified blue checkmark boost" - minimal effect
- "Long threads always perform better" - only если completion rate >40%
