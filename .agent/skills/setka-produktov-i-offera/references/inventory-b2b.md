# Фаза 2.B2B. Глубокое описание каждого продукта (B2B-ветка)

Применяется при `b2b: true`. B2B-форматы разнообразнее B2C: партнёрство, товарная поставка, корпоративный договор, лицензирование, тендер. Внутри каждого формата свои нюансы — структура полей адаптируется.

## A'. Базовые атрибуты

- **Название продукта / соглашения** (название товарной линейки / название партнёрской программы / название контракта)
- **Тип B2B-формата:**
  - Партнёрство/посредничество (дилер/дистрибьютор/реселлер/реферал)
  - Товарная поставка (физический товар через дистрибьютора или напрямую B2B-покупателю)
  - Корпоративный договор / рамочное соглашение (сервис/услуга для юрлица)
  - Тендер / госконтракт
  - Лицензирование / франшиза
  - Подряд / субподряд
- **Состав предложения** — что эксперт даёт партнёру/B2B-клиенту:
  - Для партнёрства: товар/услуга, маркетинговая поддержка, обучение, эксклюзивность территории/ниши
  - Для товарной поставки: товарная линейка (список SKU), упаковка, сроки доставки, минимальная партия
  - Для договора: предмет договора, сроки, ответственность, состав работ
- **Условия (заменяет «цена»):**
  - Для партнёрства: размер комиссии/скидки/бонуса от конечной сделки или фиксированной выплаты
  - Для товарной поставки: оптовая цена, минимальная партия, рекомендованная розничная цена (РРЦ), маржа партнёра
  - Для договора: стоимость работ, схема оплаты (предоплата/постоплата/этапы), формула расчёта при тендере
- **Длительность / срок действия** (бессрочно / 1 год с автопролонгацией / разовая поставка / др.)
- **Статус** (активный / в разработке / приостановлен)
- **Документы партнёрства** — где лежат образцы (рамочный договор, спецификация, прайс, презентация-питч); ссылки или путь к файлам

## B'. Целевой сегмент партнёров и коммерческая ценность

- **Целевой сегмент партнёров из `.business/Профиль ЦА.md`** — какой тип партнёра (дизайнер интерьера / магазин / агентство / корпоративный закупщик). Не путать с конечным клиентом партнёра — это другой контур, в этой инвентаризации не описывается.
- **Коммерческая трансформация партнёра (точка A → точка B)** — что меняется в бизнесе партнёра: «приходит [текущая ситуация в бизнесе], получает [новый поставщик / новый источник дохода / решение операционной задачи]». Для B2B это не личностная трансформация, а **деловая выгода**: выручка, удобство, операционные показатели, расширение ассортимента, надёжность поставок.
- **Ключевая ценность для партнёра** — за что партнёр выбирает именно это предложение (стабильность поставок / эксклюзивность территории / уровень комиссии / маркетинговая поддержка / репутация бренда / качество товара / гибкие условия).

## C'. Офферы и месседжи (B2B)

- **Главный оффер для партнёра** — как эксперт обычно зовёт к сотрудничеству в B2B-постах / на лендинге для дилеров / в холодных письмах / на презентации-питче. Дословно с меткой источника.
- **Альтернативные формулировки — только если есть 3+ существующих образцов** (то же правило, что в B2C).
- **Главные доказательства**: количество действующих партнёров, оборот через партнёров, средний чек партнёра, кейсы успешных партнёров (1–3 примера в одну строку).

## D'. Дисклеймеры и табу (B2B)

B2B-табу отличаются от B2C — спроси эксперта:

> Перечисли что ты **НЕ обещаешь** партнёру:
> - Гарантированный объём продаж («не обещаю N продаж в месяц» — это зависит от партнёра)
> - Эксклюзивность территории если её нет («не закрываем регион под одного дилера»)
> - Гарантированные сроки доставки если есть зависимости от логистики
> - Прямую работу с конечным клиентом партнёра («мы не вмешиваемся в продажу партнёра»)
> - Маркетинговый бюджет («не финансируем рекламу партнёра»)
> - Возврат непроданного товара (для товарной поставки)
> - Защиту от ценовой конкуренции (если несколько дилеров)
> - Любые другие границы.
