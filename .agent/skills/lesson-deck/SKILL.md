# lesson-deck — презентации прогревочных уроков

Сквозной процесс сборки blueprint-деки урока (прогрев к воркшопу/марафону). Выстрадан на уроках 1-3 (июнь 2026). Принцип: **форма после смысла**. Сначала смыслы и текст, к визуалу НЕ переходим, пока смысл и текст не согласованы.

Эталоны (читать перед стартом, копировать бренд/компоненты/моушен): `~/.business/запуски/<твоя-папка-запуска>/прогрев-уроки/слайды-урок1|2|3/index.html`.

## Когда применять
- «сделай урок-презентацию» / «дека урока N» / «слайды для воркшопа» / «следующий подготовительный урок»
- любая прогревочная презентация-слайды к платному событию

НЕ для: постов (`post`), каруселей (`carousel`), лендингов (`website`), видео-рилзов (`replicate-viral`).

## 🔴 15 ЖЁСТКИХ ГЕЙТОВ (каждый выстрадан правкой автора — нарушение = переделка)

1. **АУДИТ ДУБЛЕЙ перед показом.** Каждый урок несёт СВОЁ. Перед сборкой и перед показом — прогнать новую деку против ВСЕХ прошлых уроков (смыслы, заголовки, визуальные форматы, кейсы, цифры). Любой дубль смысла/визуала прошлого урока = выкинуть/переписать. Запускать независимым агентом-аудитором (не собой — необъективен). Прецедент: слайд 2/3/4/10/12/13 урока 3 дублировали урок 1/2, автор поймал → «подход некомпрехенсив».
2. **HUMANISER обязателен для ЛЮБОГО текста, включая текст на слайдах.** Прогон через `Skill('humaniser')` + канон голоса `_voice-profile.md`. Не «для постов» — для ВСЕГО, что прочитает человек.,.
3. **Контент ТОЛЬКО из мира ЦА.** Без «яхта», «доход на автопилоте», макро-страшилок («через год AI за $20 заменит», «окно рынка схлопнется»). Новичок думает «хоть 3к в день / не знаю что продавать». Чужие образы = инфоцыганщина..
4. **Всегда выгодный свет эксперта.** Факап как слабость («обжёгся, ушёл от метода») запрещён. Уязвимость — только если играет НА него.
5. **Без ложных привязок старого к новому.** Старое достижение (<число> млн год назад) ≠ пруф нового метода (вайбкодинг внедрён сейчас) — видно насквозь. Пруф = релевантный + текущий + честный (live-система сейчас).
6. **Визуал на КАЖДОМ слайде, не голый текст.** Мокап / чарт / схема / дашборд / рендер интерфейса. Голый текст = брак (автор: «это просто текст, никто смотреть не будет»). Компоненты — см. Технический референс.
7. **Показывать только чистый режим + живую ссылку/видео.** Мета сверки (СЛОТ/Хант) выключены (`body.clean`). На статичном JPEG анимации НЕ видно → показывать живую ссылку (FTP-деплой) или видео. автор: «дизайна нет, статика» — потому что смотрел JPEG.
8. **НЕТ scroll-snap.** `scroll-snap-type/align` дёргают/телепортируют при листании. Убрать везде (`html{scroll-behavior:auto}`, у `.slide` без `scroll-snap-align`).
9. **Орфаны.** Ни одно слово не висит на отдельной строке (особенно последнее, «воркшоп»). `text-wrap:pretty` на абзацы, `text-wrap:balance` на заголовки.
10. **Overflow-чек на ПК (1280) и мобиле (390).** Программно: вылет за viewport И за рамки родителей (длинные слова обрезаются карточками). `overflow-wrap:break-word;word-break:break-word;hyphens:auto` на заголовки/текст блоков. Прецедент: «Самопродающая» вылезла за карточку.
11. **Не fake-done.** Не помечать готовым/✅ то, что не сделано. Текст в каркасе ≠ «дизайн собран».
12. **Не переобещать инструмент.** Скилл-распаковщик «достаёт твой актив», а не «решит рынок/гарантированно скажет что продавать».
13. **Единственное действие читателя = регистрация.** Если аудитория УЖЕ зарегистрирована (прошли прошлые уроки) — личка-касание (deep-link `t.me/...?text=`), не повторная рега. Никаких других домашек.
14. **Стена.** Не палить: цену курса / Stack / гарантию / «марафон» (только «воркшоп») / VIP / trip-wire механику. Статус Стены сверять с `<решения-запуска>.md`.
15. **Бренд серии держать.** Терракота/кремовый/золото + Unbounded/Manrope/JetBrains + boot-таймлайн как у уроков 1-2. Узнаваемость серии. Не «свежий дизайн» (выпадет из серии).

## 7 ФАЗ (гейт апрува автора на отмеченных)

**Ф0 — Цель + работа в воронке.** Одной строкой: какой урок, его место в серии, что двигает (доходимость/рега), потолок awareness, Стена. Сверить с картой смыслов запуска.

**Ф1 — Костяк.** Структура (легендарный продукт + трипваер). Слоты: приветствие/мост из прошлого урока · боль · актуализация · желание · идея/механика · техника · закрыв · CTA. ← внутренний.

**Ф2 — Ресёрч смыслов (банк с RAC).** ИЗВЛЕКАТЬ, не синтезировать. Параллельные агенты-экстракторы по доменам (`4.1-Профиль-базы`, `5.1-Belief-Map`, `5.0-формулировки`, `5.2-Карта-смыслов`, `1-Аудитория`, `objections`, `Распаковка бренда`, банки конкурентов, Реестр-инструментов). Каждый смысл = дословная улика + путь:строка. → независимый скептик-верификатор (цитата реальна? атрибуция боль ЦА≠кейс автора? выдумка→FAIL) → completeness-критик (что упущено). Сохранить банк-смыслов-RAC.md. **Метод: всё, что машина может проверить — проверяет; глубина из ВСЕХ доменов, не 1-2 файла.**

**Ф3 — Структура урока ← АПРУВ смыслов.** Слот→смысл(улика)→что качает(Hormozi)→awareness. >50% блоков = прогрев/маркетинг, техника = малая часть. Аудит дублей с прошлыми уроками (гейт 1). Показать автору на сверку.

**Ф4 — Текст ← АПРУВ текста.** Текст блоков на реальных смыслах/языке ЦА (дословные цитаты опроса). → **бенчмарк против целей** (независимый адверсар-критик 3 линзы: маркетолог-доходимость / холодный клиент / стратег воронки → балл + дыры + правки) → внести правки → **humaniser** (гейт 2) → канон голоса (нет концевых точек, нет em-dash внутри строк, лексика «автооплаты» не «продажи»). Показать ТЕКСТ автору ДО формы.

**Ф5 — Дизайн/форма ← АПРУВ поэкранно.** HTML-дека: бренд серии (гейт 15) + boot-таймлайн + GSAP motion + визуальный блок на каждом слайде (гейт 6) + мокапы. Подфазы: 5.1 ритм · 5.2 копи (уже из Ф4) · 5.3 визуал-направление на пик-слайде → апрув → размножение · 5.4 ассеты · 5.5 анимация (motion под смысл, не косметика) · 5.6 финал-ревью кадров (адверсар) + overflow-чек ПК+мобила (гейт 10) + орфаны (гейт 9) + чистый режим (гейт 7). Показывать живой ссылкой/видео, не JPEG.

**Ф6 — Публикация.** FTP-деплой на сайт (Timeweb, см. референс) → живая ссылка `<твой-домен>/urok-N/`. Перед деплоем — overflow-чек + орфаны. Дать кликабельную ссылку в чат.

## Технический референс

**Бренд (CSS :root):** `--terra:#BE4A24; --terra-h:#A83F1E; --cream:#FAF6EF; --cream2:#F3ECE0; --line:#E4DACB; --gold:#C98A3C; --kick:#875420; --ink:#1C1815`. Шрифты: Unbounded (заголовки 800-900), Manrope (тело), JetBrains Mono (моно/мета), Playfair Display (цитаты). Копировать `<style>` целиком из урока 2 или 3.

**Слайд:** `.slide{min-height:100vh;...overflow:hidden}` (БЕЗ scroll-snap-align). ghost-номер `::before`, золотой корешок `::after`. Варианты: `.center`, `.right`, `.dark` (тёмный = эмоц-пик).

**Готовые визуальные компоненты** (копировать из урока 3 CSS):
- `.vsc` — рендер интерфейса Claude/VS Code (чат, печать typing через SLIDEFX)
- `.phone`+`.scr`+`.toast`+`.ofr` — телефон-мокап с оплатами (НЕ дублировать между уроками — флагман-визуал)
- `.bars`/`.barrow`/`.fill` — бар-чарт с % (анимация заполнения)
- `.cards` — карточки; `.scheme`+`.sb`+`.sar` — схема-цепочка; `.flow` — flow-цепочка
- `.tline`+`.tp`+`.tar` — timeline (для dark); `.dash` — дашборд цифр/оплат (count-up)
- `.arsenal`+`.agrp`+`.sk` — доска множества скиллов по группам
- `.copyrow`+`code`+`.cp` — копируемая команда с кнопкой «Копировать»
- `.regbtn`/`.lichka` — CTA deep-link в личку

**Motion:** GSAP + ScrollTrigger. boot-таймлайн (космос→bloom). `window.__SLIDEFX[N]=s=>{...}` под каждый слайд (reveal/typing/count-up/цепочки). Постоянная динамика стрелок: `@keyframes arrowpulse`. `prefers-reduced-motion` уважать.

**Переносы/орфаны (обязательно):** `h1,h2,.lead,.take,.card h3,...{overflow-wrap:break-word;word-break:break-word;hyphens:auto}` + `.lead,.take,...{text-wrap:pretty}` + `h1,h2{text-wrap:balance}`.

**Overflow-чек (Playwright, ПК 1280 + мобила 390):** погасить boot, сбросить inline opacity/transform, проверить для каждого `.slide *`: `r.right>vw` (за viewport) И `r.right>parent.right при overflow!=hidden` (за рамку родителя). badCount должен быть 0 на обоих.

**Деплой (FTP Timeweb):** `curl -s --ftp-create-dirs -T index.html "ftp://$FTP_USER:$FTP_PASS@<твой-ftp-host>/public_html/urok-N/index.html"` (креды читать из переменных окружения /, НЕ хардкодить пароль в файл). Проверить `curl -o /dev/null -w '%{http_code}'` = 200.

**Локальный рендер для ревью:** `python3 -m http.server PORT` из папки слайдов (НЕ из website-проекта — хук блокирует) → Playwright navigate localhost.

## Anti-patterns (реальные ошибки сессии уроков 1-3)
- Реактивные точечные правки вместо системного аудита → дубли проскакивают. Гони аудит против всех уроков СРАЗУ.
- Показ статичного JPEG как «дизайн» → анимации не видно, автор видит «статику». Только живая ссылка/видео.
- Текст в каркасе урока 2 + ✅ «дека собрана» = обман. Дизайн ≠ залитый текст.
- Голый текст на слайде «потому что смысл важнее» → автор: «никто смотреть не будет». Визуал везде.
- Боль/визуал/механика из прошлого урока → дубль. Каждый урок СВОЁ.
- «Скилл скажет что продавать» → переобещание. Честно: распаковщик достаёт актив.
- Забыл humaniser на слайдах («это же слайды, не пост») → нейрослэнг/орфаны. Humaniser ВСЕГДА.
- scroll-snap «для красоты» → дёрганье. Убрать.
