# Фаза 1: забор видео + плотная нарезка

Цель: получить локальное видео, метаданные, кадры, и КРУПНЫЕ секционные контактные листы.

## Вход
URL виральнго ролика (IG Reels / TikTok / Shorts) или путь к локальному видеофайлу.

## Шаги

1. **Базовый забор через ingest-reel** (не переписывать скачивание, переиспользовать).
   ```bash
   ~/.claude/skills/ingest-reel/scripts/ingest.sh "<URL>"
   ```
   Даёт `~/.business/growth/ingest/{date}-{video_id}/` с `{video_id}.mp4`, `info.json`,
   `{video_id}.description`, `transcript.txt`, `frames/`, `grid.jpg`.
   - Приватный/упал на login → проверить куки `~/.config/yt-dlp/instagram-cookies.txt`, повторить.
   - Если на вход дали локальный файл (не URL) - пропустить ingest, работать с файлом.

2. **Плотная нарезка + секционные листы** (главная защита от пропуска вау-триггера):
   ```bash
   ~/.claude/skills/reel-to-script/scripts/dense-frames.sh "<...>/{video_id}.mp4"
   ```
   Даёт `dense-{video_id}/` с `frames/`, `sheet_NN_<a>-<b>s.jpg` (по ~6с, крупные), `overview.jpg`.

3. **Прочитать листы в правильном порядке** (см. `knowledge/dense-frame-analysis.md`):
   - сначала КАЖДЫЙ `sheet_NN` по порядку (Read), фиксируя быстрые события и резы;
   - потом `overview.jpg` для глобальной дуги.
   Не писать разбор «по одному grid» - так теряется sub-second триггер.

## Выход
Пути к видео, info.json/description, секционным листам. Черновые наблюдения по каждому листу
(быстрые события, резы, планы) - вход для Фазы 3.

## Гейт
Не переходить к Фазе 3, пока не прочитаны ВСЕ секционные листы. Если ролик длиннее 20с и
листов много - прочитать все, не выборку (быстрый beat может быть в любом окне).
