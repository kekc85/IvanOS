# Фаза 3: пошотовая реконструкция

Цель: превратить плотные наблюдения (Фаза 1) + сигналы (Фаза 2) в покадровый разбор с
причинностью и сменой планов. Это ядро скилла. Здесь рождается точность или выдумка.

## Вход
Секционные листы + наблюдения (Фаза 1), cue из подписи/эмодзи (Фаза 2).

## Шаги

1. **Логлайн** - 1-2 строки: что происходит и в чём вау/крючок. Назвать контраст явно.

2. **Вау-триггер и причинность** - найти момент-триггер (часто sub-second: метеор, вспышка, beat)
   и выстроить цепочку «A вызывает B вызывает C» до финала. Пример эталона:
   «звезда падает в точку моря (sheet_01, ~2с) → ИЗ ЭТОЙ точки встаёт волна (sheet_02) →
   накрывает (sheet_03)». Без причинности скрипт = список картинок, регенерация развалится.

3. **Раскадровка по шотам** - пройти по таймкодам, для КАЖДОГО шота заполнить:
   - `t` (секунды от-до),
   - `план` (крупный / средний / сверхширокий / макро / POV),
   - `камера` (статичная / наезд / отъезд / орбита / FPV-тряска / дрон),
   - `субъект/действие` (поза, что в руках, реагирует или нет, спина/лицо),
   - `среда/событие` (что растёт/приближается/происходит),
   - `свет/цвет` (время суток, источник, тёплый-холодный контраст, грейдинг),
   - `звук` (ветер/гул/SFX/музыка/тишина).
   Явно отмечать РЕЗЫ и смену плана (крупный↔сверхширокий↔средний) - это и есть «киношность».

4. **Глобальный стиль** - эстетика, палитра, соотношение сторон, длительность, темп монтажа,
   речь/музыка/субтитры есть или нет.

## Правило no-invention (критично)
Каждый пункт либо виден на кадрах / подтверждён сигналом, либо помечается `[не подтверждено]`.
Запрещено дописывать детали «для красоты». Это была главная причина прошлого провала.
Сомнение по конкретной секунде → открыть `frames/f_XXXX.jpg` вокруг неё, а не догадаться.
