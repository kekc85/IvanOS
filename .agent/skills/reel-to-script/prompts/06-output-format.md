# Фаза 6: сборка и выдача артефакта

## Шаги

1. **Собрать файл** по схеме `knowledge/script-schema.md` (frontmatter + разделы 1-9).
   Сохранить в:
   ```
   ~/.business/growth/reel-scripts/{YYYY-MM-DD}-{video_id}.md
   ```
   Создать папку, если её нет.

2. **Проверка полноты** (мини-L1 перед выдачей):
   - frontmatter содержит `source_url`, `metrics`, `tools_named_by_author`, `verified_against_original`;
   - есть разделы 1-8; раздел 6 (keyframe-промпты) непустой; раздел 9 есть, если есть `[не подтверждено]`;
   - в раскадровке (3) больше одного шота, если ролик содержит резы;
   - 🔴 в разделе 6 `Total: Ns` имеет N ≤ 15 и максимальный таймкод ≤ 15с (потолок Seedance на
     одну генерацию). N > 15 = брак, пересжать драматургию в 15с перед выдачей.

3. **Отчёт в чат** (автор читает с телефона и файлы НЕ открывает - см.
  ):
   - 🔴 САМ финальный ОДИН видео-промпт (раздел 6) - целиком в код-блоке прямо в чат, чтобы
     скопировать и вставить. Не прятать в файл, не давать локальную ссылку на него.
   - логлайн + вау-триггер/причинность (1-2 строки),
   - число шотов и смена планов, пайплайн одной строкой (инструмент анимации - факт автора),
   - статус keyframe-гейта (прошёл / ждёт проверки опорного кадра).
   Затем предложить следующий шаг (сгенерить опорный кадр и сверить, либо гнать один промпт).

## Принцип доставки
Файл - для машины и для повторного использования (вход в `[[replicate-viral]]` /
`[[higgsfield-generate]]`). Чат - для человека: коротко, по делу, с одним следующим действием.
Если результат показывается автору - соблюдать правила доставки проекта (открываемый формат,
без локальных markdown-ссылок на картинки в чат).

## Готово
Скрипт сохранён, отчёт выдан, следующий шаг назван. Конвейер reel-to-script завершён.
