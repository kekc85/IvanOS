# Фаза 4: разбор production-пайплайна + keyframe/анимация-промпты

Уровень оригинала делает цепочка инструментов, не один промпт. Эта фаза определяет слои и пишет
конкретные промпты под слой 1 (keyframe) и слой 2 (анимация). База: `knowledge/production-pipeline.md`.

## Вход
Названные автором инструменты (Фаза 2), раскадровка и стиль (Фаза 3).

## Шаги

1. **Read `knowledge/production-pipeline.md`** - канонический пайплайн (6 слоёв) и таблица
   «слой → инструмент».

2. **Определить нужные слои именно этому ролику** (не все всегда нужны):
   - keyframe (опорный кадр), анимация, склейка/extend, апскейл, монтаж, звук.
   - Для каждого слоя - инструмент. Приоритет: **названный автором** (факт) → иначе из таблицы
     с пометкой `[инференс, не подтверждено автором]`.
   - Признаки наличия слоя: чистый 4k60 → апскейл (Topaz); смена планов → склейка/монтаж;
     честная сложная вода → вероятно Runway; мульти-shot + звук → Seedance полная.

3. **🔴 Написать ОДИН финальный видео-промпт (мульти-shot)** - весь ролик одним промптом
   (раздел 6 схемы): общее описание стиля+субъекта → шоты по таймкодам (`0-2s:` … `13-15s:`, потолок
   15с) с
   резами `hard cut` и сменой планов → строка звука → `Total: Ns / N shots / 9:16`. Это ГЛАВНЫЙ
   выход, его автор копирует и вставляет. НЕ дробить на отдельные keyframe/анимация-промпты.
   Seedance 2.0 полная держит мульти-shot; для воды/сложной физики рассмотреть Runway.

4. **Написать опорный кадр-промпт (опционально, для гейта)** - один короткий картиночный промпт
   ключевого кадра (раздел 7) под дешёвую проверку уровня в Фазе 5. Это не финал, финал = шаг 3.

5. **Если у автора есть код-слово** (Фаза 2) - отметить, что точный авторский промпт закрыт, наш
   реконструирован, и сверка в Фазе 5 это учитывает.

## Выход
Раздел 5 (пайплайн: слои→инструменты), раздел 6 (keyframe-промпты), раздел 7 (анимация-промпты)
схемы `knowledge/script-schema.md`.

## Анти-паттерн
Не выдавать один text-prompt без слоёв keyframe/апскейл/монтаж и не называть это «как у оригинала» -
это ровно то, что дало результат «в разы хуже».
