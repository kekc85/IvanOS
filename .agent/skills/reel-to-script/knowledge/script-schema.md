# Script schema: структура супер-детального production-скрипта

Финальный артефакт скилла. Это не маркетинговое описание и не один абзац-промпт, а полный
воспроизводимый разбор. Сохраняется в `~/.business/growth/reel-scripts/{date}-{video_id}.md`.

Каждое поле либо подтверждено кадрами/сигналами, либо помечено `[не подтверждено]`. Выдумок нет.

```markdown
---
source_url: <URL>
author: <handle>
metrics: { likes: N, views: N|NA, comments: N, date: YYYY-MM-DD, duration: Ns }
platform_of_virality: <IG Reels | TikTok | Shorts>   # где замерена виральность (площадка публикации)
tools_named_by_author: [<из reel-meta TOOLS, дословно>]   # факт; [] если не назвал
codeword_gate: <код-слово или none>   # если полный промпт автор отдаёт по комменту/DM
verified_against_original: <yes | partial>   # Фаза 5
---

# Reel-to-Script: <короткое имя формата>

## 1. Логлайн (1-2 строки)
Что происходит и в чём вау. Пример: «человек спиной у моря спокойно пьёт; падает звезда,
из точки падения встаёт цунами; он не реагирует». Контраст/крючок назвать явно.

## 2. Вау-триггер и причинность
- Триггер: <что именно, на какой секунде, на каком sheet виден>
- Причинность: <A вызывает B>, цепочка до финала. Это то, что нельзя пропустить.

## 3. Раскадровка по шотам (таймкоды)
Таблица или список. Для КАЖДОГО шота:
| t (с) | план | камера | субъект/действие | среда/событие | свет/цвет | звук |
Планы: крупный / средний / сверхширокий / макро / POV. Отмечать резы и смену плана.

## 4. Глобальный стиль
Эстетика (35mm/анаморф/film grain/ARRI), палитра, грейдинг, соотношение сторон, длительность,
темп монтажа, наличие/отсутствие речи, музыки, субтитров.

## 5. Production-пайплайн (слои → инструменты)
Из knowledge/production-pipeline.md. Только нужные этому ролику слои:
- keyframe: <инструмент> - <зачем>
- анимация: <инструмент> - <зачем>
- склейка/extend: <да/нет, как>
- апскейл: <да/нет, инструмент> - пометить если виден 4k60
- монтаж: <да/нет, инструмент>
- звук: <нативный/ElevenLabs/нет>
Каждый инструмент: факт (назван автором) или `[инференс]`.

## 6. 🔴 ФИНАЛЬНЫЙ ВИДЕО-ПРОМПТ (ОДИН мульти-shot, ГЛАВНЫЙ выход)
ВСЕГДА один промпт на весь ролик, не россыпь. Структура:
- общая строка: эстетика (35mm/анаморф/grain/ARRI) + СУБЪЕКТ + свет/палитра.
  🔴 СУБЪЕКТ: если пользователь ставит свой персонаж по референсу (Elements/фото/Soul ID) -
  НЕ описывать внешность (волосы/лицо/тело/одежду), писать `use the exact person from the reference
  image, keep their face, hair, body and clothing unchanged, do not invent or alter the person`,
  внешность донора-оригинала НЕ копировать (принцип 10). Описывать только действие/сцену/камеру;
- шоты по таймкодам: `0-2s: …`, `2-3s: …`, … каждый с планом, камерой, действием, событием,
  звуком; резы помечать `hard cut`; смена планов крупный↔сверхширокий↔средний обязательна;
- строка звука: что слышно (ветер/гул/SFX), есть ли речь/музыка;
- финальная строка: `Total: Ns / N shots / 9:16`, где Ns ≤ 15 (потолок Seedance 2.0 на одну
  генерацию, диапазон 4-15с). Таймкоды НЕ выходят за 15с, даже если оригинал длиннее: драматургию
  сжать в потолок. Длиннее 15с = это уже не один промпт (extend отдельными кусками).
Один промпт держит Seedance 2.0 (полная) и Runway. Это то, что автор копирует и вставляет.

## 7. Опорный кадр-промпт (опционально, ТОЛЬКО для keyframe-гейта)
Один короткий картиночный промпт первого/ключевого кадра (субъект, ракурс, свет, стиль) -
чтобы дёшево проверить уровень ДО видео (Фаза 5). Не финал, а проверочный кадр. Финал = раздел 6.

## 8. План воспроизведения (порядок + гейт)
1. Сгенерить опорный кадр (раздел 7) → сверить с оригиналом (дёшево, Фаза 5 keyframe-гейт).
2. Совпал по уровню → запустить ОДИН видео-промпт (раздел 6) в Seedance полную / Runway.
3. При нужде: апскейл (Topaz) → монтаж/звук. Длиннее 15с → extend тем же стилем.
С пометкой, где тратятся дорогие кредиты и что проверяется до этого.

## 9. Чего НЕ видно / риски
`[не подтверждено]`-пункты, что автор спрятал (код-слово), где реконструкция гадательна.
```

## Минимальный набор обязательных полей (для L1/E2E проверки)

Скрипт считается полным, только если есть: frontmatter с `source_url` + `metrics` +
`tools_named_by_author`, разделы 1-8. Раздел 9 обязателен, если хоть что-то `[не подтверждено]`.
Раздел 6 (keyframe-промпты) обязателен всегда - это вход в гейт «дешёвое до дорогого».

## Что отдавать в чат (vs в файл)

В файл - полный скрипт по схеме. В чат пользователю - компактно: логлайн, вау-триггер+причинность,
число шотов, пайплайн одной строкой, и предложение прогнать keyframe-гейт. Не дублировать весь
файл в чат.
