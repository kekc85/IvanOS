# Production pipeline: чем топ-авторы реально делают виралки

Уровень оригинала делает НЕ один text-to-video промпт, а ЦЕПОЧКА инструментов. Это доказано
подписями самих авторов (собрано 2026-06-21 через `reel-meta.sh` по реальным IG-виралкам).
Каждый слой отвечает за свою часть качества. Скрипт обязан назвать слои, иначе на выходе сырьё.

## Доказательства (цитаты из подписей, метрики на площадке публикации)

| Автор | Лайки | Цитата из подписи | Что вскрывает |
|---|---|---|---|
| @freestayler | 580K | «I made it with **Runway**… similar prompts inside the platform» | топ-реплика wave-формата сделана в Runway, не Seedance |
| @StevieMac03 | 239K | «extended and **joined with keyframe**… **Upscale 4k 60fps @topazlabs Starlight 2.5 / Astra**» | склейка через keyframe + апскейл Topaz = «ультра-реализм» |
| @AswinAjiRaj | 100K | «**Seedance 2.0 + Seedream 5.0**… directing scenes, most people are still generating clips» | кадр (Seedream) + анимация (Seedance), режиссура сцен |
| @CGEYE | 159K | «Tools: **Kling + Higgsfield + DaVinci Resolve + ElevenLabs + Claude**» | полный пайплайн: видео+монтаж+звук+сценарий |

Вывод: «вставил промпт в Seedance» даёт средний уровень. Разрыв с оригиналом закрывают
keyframe-слой, апскейл и монтаж, которых при одной сырой генерации нет.

## Канонический пайплайн (6 слоёв)

```
1. KEYFRAME      идеальный первый/опорный кадр генерится ОТДЕЛЬНО в картиночной модели
                 → Seedream 5.0 / Midjourney / GPT Image 2 / Nano Banana
                 → отсюда реализм текстур, композиция, свет. НЕ из видео-модели.
2. АНИМАЦИЯ      keyframe анимируется (image-to-video)
                 → Runway (честная вода/физика) / Seedance 2.0 / Kling 3.0
                 → часто несколько отдельных шотов, не один клип
3. СКЛЕЙКА/EXTEND смена планов и длина >15с через keyframe-join + extend
                 → крупный ↔ сверхширокий ↔ средний, продление концовки
4. АПСКЕЙЛ       до 4k 60fps → Topaz Starlight / Astra
                 → вот откуда «ультра-реализм», которого у сырого Seedance нет
5. МОНТАЖ        склейка шотов, цвет, ритм, тайминг → DaVinci Resolve / CapCut
6. ЗВУК          нативный звук модели ИЛИ ElevenLabs (эффекты/голос/музыка)
```

## За какой слой какой инструмент отвечает (для рекомендации в скрипте)

| Нужно | Инструмент(ы) | Почему |
|---|---|---|
| Фотореалистичный опорный кадр | Seedream 5.0, Midjourney, GPT Image 2 | детализация и свет картиночных моделей > видео-моделей |
| Анимация воды / сложной физики | Runway | в данных топ-wave-реплика (580K) сделана в Runway |
| Мульти-шот из одного промпта, нативный звук | Seedance 2.0 (полная, не Fast) | держит мульти-shot + синхронный звук |
| Персонаж-консистентность по референсу | Seedance + Soul ID, Kling | identity по кадрам |
| Апскейл до 4k60, «киношность» | Topaz Starlight / Astra | поднимает сырой рендер до ультра-реализма |
| Склейка планов, цвет, ритм | DaVinci Resolve | смена планов = монтаж, не одна генерация |

## Правило выбора Seedance 2.0 vs Seedance Fast

- **Полная 2.0** - финальный публикуемый дубль, особенно вода/сложная физика/мелкая детализация.
  Fast ускоряется за счёт детализации и просчёта движения → воду и масштаб смазывает.
- **Fast** - черновики, перебор композиции и тайминга (в Seedance Unlimited без списания кредитов).
- Схема: тестируешь на Fast → финал на полной.

## Как это попадает в выходной скрипт

В финальном артефакте (`script-schema.md`) обязан быть блок `pipeline`:
- какие слои нужны именно этому ролику (не все всегда),
- конкретный инструмент на каждый слой (из названных автором, иначе из таблицы выше),
- отдельные keyframe-промпты (для слоя 1) и анимация-промпты (для слоя 2),
- пометка где у автора стоял апскейл/монтаж (если виден по качеству 4k60 / по смене планов).

Если автор назвал инструменты в подписи (`reel-meta.sh` секция TOOLS) - брать ИХ, это факт.
Если не назвал - инферить по таблице и пометить `[инференс, не подтверждено автором]`.

## Обновление

Видео-модели и апскейлеры меняются быстро. При расхождении (новая модель, автор называет
незнакомый инструмент) - дополнить таблицы и детектор в `scripts/reel-meta.sh`. Дата ревизии
последняя в шапке SKILL.md.
