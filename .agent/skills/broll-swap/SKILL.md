# broll-swap — замена нижнего B-roll в сплит-скрин рилзах

Сплит-скрин рилз = два видео в одном кадре 9:16: сверху смысловой контент (речь, демо, разбор), снизу generic B-roll для удержания (subway surfers, satisfying-нарезка, gameplay). Этот скилл **сохраняет верх**, **выкидывает низ** и **подставляет свежий бесплатный сток**, чтобы получить уникальный по нижней дорожке ролик. На выходе — готовый MP4.

**Скилл НЕ ищет рилзы.** Пользователь сам скидывает URL или локальный файл.

## Когда триггерить

- `/broll-swap <URL-или-файл>`
- «замени низ в этом сплите», «вырежи нижнюю часть и подставь сток»
- «перегони этот сплит-рилз со свежим B-roll»
- Пользователь скинул split-screen рилз и хочет поменять нижнюю дорожку

## Когда НЕ триггерить

- Рилз НЕ сплит-скрин (одно полнокадровое видео) — нечего разделять
- Нужно заменить ВЕРХ (смысл), а не низ — это другая задача
- Нужен B-roll с лицом/аватаром автора — нижняя часть тут чистый сток без лица (по решению автора). Лицо — через `higgsfield-generate` отдельно
- Нужна полная пересборка ролика в стиле автора — это `produce-reel`

## Принципы (решения автора)

1. **FIDELITY: низ повторяет B-roll автора один-в-один, с небольшими отличиями.** Это ядро скилла. Новый нижний клип должен совпадать с тем, что было снизу У АВТОРА: тот же тип (gameplay / satisfying / nature / cooking / parkour и т.д.), тот же субъект, похожее движение и кадрирование. НЕ произвольный клип, НЕ «выбрать самый красивый», НЕ «по вайбу». Поисковый запрос строится из того, что РЕАЛЬНО видно на сэмплах низа автора, максимально точно — а не из фантазии. Цель: ролик неотличим от оригинала по нижней дорожке, кроме того что это другой источник (уникализация).
   - Ниша автора (личный бренд / вайбкодинг / ИИ) живёт в ВЕРХНЕЙ части, которую мы сохраняем. Низ в сплит-формате — generic-наполнитель для удержания, как у автора.
   - Альтернативный режим «тематический низ под нишу автора вместо как-у-автора» — только если автор явно попросит. По умолчанию — fidelity к автору.
2. **Низ = чистый B-roll без лица.** Верх несёт контент, низ — план без лица/аватара.
3. **Выход = готовое видео.** Скилл сам собирает финальный MP4, не полуфабрикат.
4. **Бесплатный сток сначала.** Pexels public ($0, без ключа, без регистрации, Pexels License). Higgsfield — только по явному флагу `--higgsfield`, по правилу free-tools-first.

## Workflow (3 стадии, между ними решает Claude)

### Стадия 1 — analyze: скачать, замерить, найти линию раздела

```bash
python3 ~/.claude/skills/broll-swap/scripts/swap.py analyze "<URL-или-файл>"
# нестандартный сплит (не 50/50): python3 .../swap.py analyze "<...>" --split 0.55
```

Скрипт: качает (yt-dlp) или берёт локальный файл → ffprobe размеры/длительность → **автодетект горизонтальной линии раздела** (строка, которая остаётся сильным краем во ВСЕХ кадрах; при слабом сигнале fallback 0.5) → рисует контрольный кадр `control-split.jpg` с красной линией → вырезает 4 сэмпла нижней зоны. Печатает `MANIFEST=`, `CONTROL_FRAME=`, `BOTTOM_FRAMES=`, `SPLIT_METHOD/CONFIDENCE`.

**Claude обязан:**
1. `Read` контрольный кадр `CONTROL_FRAME` — убедиться, что красная линия лежит точно на границе верх/низ. Если линия мимо — перезапустить `analyze --split <ratio>` с правильной долей (доля = высота верха / полная высота).
2. `Read` `BOTTOM_FRAMES` — точно определить, что за B-roll снизу У АВТОРА, и собрать **2-3 EN-ключа, описывающих ИМЕННО это** (субъект + действие + ракурс), чтобы найти такой же план. Цель — совпадение один-в-один, не «похожая тема». Примеры: автор показал `subway surfers gameplay` → ищем `subway surfers gameplay`, а не абстракцию; `hydraulic press crushing` → так и ищем; `kinetic sand cutting top view` → так и ищем. Запрос = то что на сэмплах, не выдуманное.

### Стадия 2 — stock: подобрать бесплатные кандидаты

```bash
python3 ~/.claude/skills/broll-swap/scripts/swap.py stock --query "EN keywords" --n 3
```

Скрейпит Pexels публично, качает 3 кандидата + превью-кадр каждого. Печатает `CAND_N_VIDEO/THUMB/SIZE/SOURCE`.

**Claude обязан:** `Read` все `CAND_N_THUMB`, выбрать **максимально похожий на нижний план автора** (тот же тип/субъект/движение/кадрирование) — критерий «один-в-один с оригиналом», а НЕ «самый красивый» и НЕ «по вайбу». Если ни один не повторяет оригинал — повторить `stock` с уточнённым запросом, пока не найдётся совпадающий.

Higgsfield-путь (только при `--higgsfield` от пользователя): вызвать skill `higgsfield-generate` с описанием низа как промптом (Seedance, мало кредитов), получить mp4 — он станет `--bottom` на стадии 3.

### Стадия 3 — build: собрать готовый MP4

```bash
python3 ~/.claude/skills/broll-swap/scripts/swap.py build \
  --manifest <MANIFEST> \
  --bottom <выбранный-кандидат.mp4> \
  --bottom-desc "что за B-roll" \
  --bottom-source-url "<Pexels URL>"
```

Скрипт: кропает верх по манифесту → масштабирует+кропает нижний клип точно под нижнюю зону → зацикливает до длительности оригинала → `vstack` → накладывает оригинальное аудио → рендерит H.264/yuv420p/+faststart. Печатает `FINAL=` и `SIDECAR=`.

**Claude обязан после build:**
1. Открыть готовый ролик командой ОС: `open "<FINAL>"` на macOS, `start "" "<FINAL>"` на Windows, `xdg-open "<FINAL>"` на Linux (или универсально `~/.claude/skills/_shared/bin/open-file "<FINAL>"`).
2. Выдать в чат: путь к MP4, что было снизу → что стало, источник + лицензия.

## Output

Плоско, без подпапок:
- `~/.business/growth/broll-swap/{date}-{slug}-swapped.mp4` — готовый ролик
- `~/.business/growth/broll-swap/{date}-{slug}-swapped.txt` — sidecar: источник, split, размеры, описание низа, лицензия

Рабочие файлы (манифест, сэмплы, контрольный кадр) — в `{date}-{slug}-work/`.

## Что НЕ делает

- Не транскрибирует и не переозвучивает — верхнее аудио сохраняется как есть
- Не добавляет лицо/аватар в низ (v1.0) — низ чистый сток
- Не правит верхнюю часть — она сохраняется пиксель-в-пиксель
- **Humaniser не нужен** — это media/data-processing скилл, аудиторного текста не производит (описание низа служебное, для сорсинга)

## Зависимости

- `ffmpeg` / `ffprobe` / `yt-dlp` (homebrew), Python 3 + Pillow
- Pexels — публичный скрейп, **ключ не нужен**. Если Pexels заблокирует — повторить с более простым EN-запросом
- Higgsfield-путь — через skill [[higgsfield-generate]] (только по флагу)

## Риски и митигации

- Линия раздела не 50/50 / нестандартная → контрольный кадр + флаг `--split`
- Captions/текст на стыке верх-низ → весь низ заменяется, baked-низ исчезает; обрывки на самой границе верха остаются (минор v1.0)
- Сток не совпал по вайбу → 3 кандидата + повтор `stock` с другим запросом
- Оригинальное аудио шло поверх всего кадра (обычно так) → сохраняется; если у нижней дорожки было своё аудио — теряется (приемлемо)
