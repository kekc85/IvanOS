# Visual types (5 типов v1.0)

Подробный каталог 5 типов одиночной картинки-поста с критериями выбора, структурой и common mistakes.

---

## Type 1: concept-diagram

**Когда применять:**
- Тема выражается как mental model / framework / relationship между концептами
- Нужно показать как X относится к Y (spectrum / 2x2 / iceberg / pyramid / funnel / equation)
- Цель: bookmark / share как «карманная» mental model
- Reference: Jack Butcher (Visualize Value), Sahil Bloom diagrams, Codie Sanchez frameworks

**Под-типы (geometry):**
1. **Spectrum / scale** - линия с 2-5 точками на оси (X vs Y)
2. **2x2 matrix** - 4 квадранта с labels
3. **Iceberg** - visible часть vs hidden часть
4. **Funnel** - стадии фильтрации с цифрами или labels
5. **Pyramid** - hierarchy (Maslow-style)
6. **Equation / formula** - «Outcome = Input × Multiplier / Friction»
7. **Framework boxes + arrows** - 3-5 boxes connected (process flow)
8. **Venn 2-3 круга** - пересечение концептов
9. **Tree branches** - root → leaves decomposition
10. **Cycle** - X → Y → Z → X (loop)

**Структура brief:**
- Geometry: какой из 10 выше
- Labels: дословный текст всех elements
- Hierarchy: что primary, что secondary
- Palette: 1-2 цвета max
- Negative space: 30-50% canvas

**Common mistakes:**
- 8+ elements (overwhelmed)
- Decorative icons без смысла
- Gradient fills вместо flat
- Multiple typefaces
- Text-heavy labels (>3 слов на label)

**Tool:**
- Primary: Figma (clean shapes) или Photopea
- AI-assisted: DALL-E 3 для text accuracy, Midjourney для general aesthetic, Higgsfield для batch

**Aspect default:** 1:1 (1080x1080) для X / IG / TG. 1.91:1 для LinkedIn feed.

## Type 2: dashboard-screenshot

**Когда применять:**
- Есть real verified metric: Stripe MRR / Skool members / newsletter subs / Нельзяграм reach / cash event total
- Цель: pure proof = bookmarks + retweets
- Reference: Pieter Levels (Photo AI screenshots), Marc Lou (MRR recaps), Pat Walls (Starter Story revenue interviews)

**Под-типы:**
1. **Single metric reveal** - 1 цифра огромная (Stripe / Analytics screenshot cropped)
2. **Time-series chart** - график за период с annotated milestones
3. **Comparison split** - до vs после в одном dashboard
4. **Multi-metric grid** - 4-6 ключевых KPI tiles
5. **Notification screenshot** - «$X received» уведомление (Stripe / PayPal)

**Структура brief:**
- Real metric: какое (verified через .business/ или user-provided)
- Crop: что в кадре, что отрезано
- Highlight: yellow box / arrow на key number
- Privacy: blur customer names / emails / sensitive IDs
- Caption hint в image: 0-1 слово max (image speaks)

**Common mistakes:**
- Выдуманные numbers (instant credibility kill при detection)
- Projections как fact («on track to $X»)
- Negative статистики
- Misleading crops (вырезан контекст что искажает)
- Stock dashboard images вместо реального
- Customer data без permission

**Tool:**
- Native screenshot tool: CleanShot X (macOS) / ShareX (Windows)
- Polish: Photopea / Figma для annotations
- Highlight: 1 yellow box или 1 arrow max
- AI generation запрещена (real screenshot only)

**Aspect default:** 1:1 (1080x1080). LinkedIn Multi-Image: 4 images 1:1.

## Type 3: meme

**Когда применять:**
- Cultural reference уже известный аудитории (Drake meme / Distracted Boyfriend / Galaxy Brain / etc)
- Topic твист на знакомый формат через recognition
- Цель: share через «о, это про меня»
- Reference: Distillery (general meme culture), Saagar Enjeti meme posts, finance Twitter memes

**Под-типы:**
1. **Drake format** - rejecting / approving 2 options
2. **Distracted Boyfriend** - choice between 3 entities
3. **Galaxy Brain** - escalating sophistication
4. **Two buttons** - dilemma
5. **Expanding brain** - levels of understanding
6. **This is fine** - dissonance situation
7. **Stonks / Not Stonks** - metric reaction
8. **Pointing Spider-Men** - similarity / hypocrisy
9. **Original meme** - skill-driven, не template

**Структура brief:**
- Format: какой template выше
- Text overlay: дословный текст top / bottom / labels per element
- Topic connection: какая связь meme template ↔ topic
- Recognition test: пройдёт ли это для аудитории 25-45 RU/EN

**Common mistakes:**
- Outdated meme (>12 мес для fast-moving formats)
- Force connection (template не подходит topic, audience не считает)
- Too text-heavy (more than 1 line per overlay)
- Inside joke только для узкой ниши без universality
- Mean-spirited / attacking specific people

**Tool:**
- Primary: Photopea (free) или Canva meme generator
- Templates: imgflip.com / kapwing.com
- Hand-drawn meme: Procreate / Photoshop

**Aspect default:** 1:1 для большинства, 4:5 для IG feed reach max.

## Type 4: quote-card

**Когда применять:**
- Есть quote-worthy фраза (своя или другого автора с attribution)
- Цель: bookmark + share как «pocket wisdom»
- Reference: Naval quote cards (plain text on neutral bg), Hormozi (bold sans on black), James Clear

**Под-типы:**
1. **Plain text card** - text + small attribution (Naval style)
2. **Bold sans on black** - high-impact (Hormozi style)
3. **Serif on cream paper** - editorial / book-feel (Maria Popova)
4. **Handwritten / hand-lettered** - personal feel
5. **Photo backdrop + quote overlay** - cinematic (использовать с осторожностью)

**Структура brief:**
- Quote text: дословно (<140 chars для тогда вписалось в 1 frame легко)
- Attribution: имя + role или «- Автор»
- Background: solid color hex или neutral texture
- Typography: serif vs sans + размер hierarchy
- Quote source: своя / chuжая (с verified attribution)

**Common mistakes:**
- Misattributed quotes (verify before publishing)
- Своя quote выдаваемая за чужую
- Quote >25 слов (не вписывается в 1 frame визуально)
- Decorative fonts которые читаемость убивают
- Stock background photos
- Цитата без identity автора (генерик)

**Tool:**
- Primary: Figma (clean typography control)
- Quick: Canva quote template
- Verify quote: web search для attribution
- Naval-style minimal: даже text editor screenshot с rendered text

**Aspect default:** 1:1. 4:5 для IG feed reach.

## Type 5: before-after (статичный, не video)

**Когда применять:**
- Transformation visual: было X → стало Y в одном кадре
- Цель: proof через визуальный contrast
- Reference: Pat Walls (Starter Story transformations), redesign showcases, fitness before/after culture
- ВАЖНО: video before-after - отдельный skill `before-after` (video sub-format #5)

**Под-типы:**
1. **Split vertical** - left half = before, right half = after
2. **Split horizontal** - top = before, bottom = after
3. **Slider visualization** - draw of slider между двумя states
4. **Annotated comparison** - before + after side by side с arrows / labels
5. **Stack** - две картинки одна над другой с stark visual difference

**Структура brief:**
- Split direction: vertical / horizontal / stack
- Before label: дословный текст в before frame
- After label: дословный текст в after frame
- Visual delta: что конкретно отличается (концепт-уровень)
- Caption hint: 0-1 слово max в image

**Common mistakes:**
- Преувеличенные visuals («чудо-преобразование»)
- Faked screenshots в after
- Длинный текст overlay (картинка должна сама говорить)
- Misleading proportions (different scales для before vs after)
- Без consent если показываешь чужой before-after

**Tool:**
- Figma split layouts
- Photopea для photo composites
- Screen split macOS tools (Rectangle / Magnet)

**Aspect default:** 1:1 (vertical split visual), 4:5 для feed reach.

## Type selection decision tree

```
Что primary intent?
├── Mental model / framework → concept-diagram
├── Real metric proof → dashboard-screenshot
├── Cultural recognition + topic twist → meme
├── Pocket-wisdom phrase → quote-card
└── Transformation evidence → before-after

Не подходит ни один?
└── Возможно нужен другой skill:
    ├── Текст без картинки → post / paips-post / spiky-one-liner / longform
    ├── 2+ кадров → future carousel skill
    ├── Видео → replicate-reel / video / produce-reel
    ├── Brand product visual → higgsfield-product-photoshoot
    └── Marketplace listing → higgsfield-marketplace-cards
```
