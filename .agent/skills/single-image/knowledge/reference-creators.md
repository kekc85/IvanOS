## Универсальные принципы reference usage

1. **Reference - structure, не content.** Копируем формат / композицию / typography choices. Не копируем дословные тексты / specific mental models / branded elements.

2. **Не один creator.** Гибрид нескольких references безопаснее чем close-clone одного (избегаешь plagiarism perception).

3. **Audience fit.** Reference creator должен иметь overlap audience с твоим (или явно transferrable aesthetic).

4. **Recency check.** Aesthetic стандарты меняются. Reference of >2 years - проверь актуальность.

5. **Attribute mentally.** Если влияние >40%, упомяни в production notes («inspired by X visual language»). Не публикуй как unique invention если это явный clone.

6. **Anti-creator: generic AI image generators output без identity.** Каждый brief должен иметь visible identity якорь, иначе это generic.
