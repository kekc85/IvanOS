# Template: voronka-push

> Тип №1. Вовлечение подписчика в следующий шаг воронки. Daily-формат, основной push контент-фабрики.

## Параметры

| Параметр | Значение |
|---|---|
| Длина | 100-200 знаков (target: medium) |
| Кнопок | 1-2 |
| Hook framework | Curiosity-Gap / Results-First / Numbered / Vulnerable работают лучше |
| Tone | Имperative + direct address «ты» |
| Эмоджи | 0-1, не в первых 50 знаках |

## Когда использовать

- Регулярный daily push в основной воронке
- Шаг между lead magnet и trip-wire / клубом / cash event
- Когда есть конкретный артефакт (пост / видео / разбор) и хочется привести трафик
- В рамках Carved-out серии (drip-segment может быть альтернативой)

## Когда НЕ использовать

- Время-критичный анонс (вебинар через час) → `reminder`
- Анонс нового материала без CTA-конверсии → `content-tease`
- Winback холодных → `re-engagement`

## Anti-patterns specific to voronka-push

- **Не делать push без конкретного next step**. Если CTA = «думай», это не push.
- **Не использовать двусмысленные кнопки**. «Узнать» (об чём?) или «Подробнее» (где?) failят review.
- **Не подавать как новость без CTA**. Push без кнопки = пост в канал, не push. Минимум 1 кнопка обязательна.
- **Не мешать сегменты**. Если push нацелен на cold - не упоминать «вы знаете эту тему», это для hot.

## CTA-bridge - когда стоит, когда нет

Стоит:
- Если кнопка одна и она не очевидна из контекста («Получить») → добавить «↓»
- Если есть две кнопки и нужно подсказать иерархию

НЕ стоит:
- «Жми кнопку» / «нажми сюда» - дублирование affordance
- «Кстати, у нас есть…» - лишний слой
- Если CTA-bridge >30 знаков - это уже не bridge, это новое предложение body
