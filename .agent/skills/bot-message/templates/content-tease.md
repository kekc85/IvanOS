# Template: content-tease

> Тип №3. Анонс нового материала (поста / видео / эссе / разбора). Цель - клик на материал. 2-3 раза в неделю.

## Параметры

| Параметр | Значение |
|---|---|
| Длина | 300-700 знаков, 2-3 абзаца (target: tease). Один абзац = брак (fix 2026-05-29) |
| Кнопок | 1 |
| Hook framework | Curiosity-Gap / Results-First / Vulnerable / Numbered |
| Tone | Любопытство + намёк на ценность |
| Эмоджи | 0-1, не в первых 50 знаках |

## Scaffold (2-3 абзаца)

```
АБЗАЦ 1 — HOOK (40-80 знаков):
<намёк / результат / интрига - стопит скролл в notification preview, читается без контекста>

АБЗАЦ 2 — РАЗВОРОТ (100-300 знаков):
<коротко суть: что за материал, какую ситуацию закрывает, 1-2 конкретные детали-зацепки. Цельные предложения, без рубки точками>

АБЗАЦ 3 — МОСТ К КЛИКУ (60-150 знаков):
<что именно ждёт в материале + почему стоит открыть. Подводит к кнопке>

КНОПКА (одна):
- Текст: глагол потребления + объект («Читать пост», «Смотреть видео», «Открыть разбор»)
- Тип: URL (на пост в канале / видео в Нельзяграм / статья в блоге)
- Назначение: <прямая ссылка на материал>
```

## Примеры формата (заглушки)

### Пример A: Results-First + URL на пост

```
Один комментарий под видео принёс 12 покупок Skool.
Без рекламы, без воронки. Только правильная мысль в правильное время.

В новом посте разобрал что именно работает в комментариях и почему 95% делают это неправильно.

[Читать пост]  → URL
```

### Пример B: Curiosity-Gap + URL на видео

```
Бот без воронки и без рекламы - за месяц 200 покупок.
Парадокс: чем меньше шагов, тем выше CTR.

Снял подробное видео - показываю как устроена антиворонка и почему классическая лестница не работает.

[Смотреть видео]  → URL
```

### Пример C: Numbered + URL на эссе

```
5 элементов которые отличают рабочий push от шума.
Чек-лист по своему боту займёт 10 минут.

В свежем эссе разобрал каждый элемент с примерами из своей базы за май.

[Открыть эссе]  → URL
```

## Когда использовать

- Новый пост в основном канале
- Новое видео (Reels / Shorts / TikTok / YouTube long-form)
- Новое эссе (Newsletter / blog / LinkedIn article)
- Новый разбор (открытый разбор воронки / кейс)
- Открытие нового материала в клубе (для членов клуба)

## Когда НЕ использовать

- Анонс продукта / запуска → `broadcast-news`
- Напоминание о событии → `reminder`
- Push в основной воронке без content-объекта → `voronka-push`

## Anti-patterns specific to content-tease

- **Не раскрывать всю суть в push'е**. Tease = намёк, не пересказ. Если push даёт всю ценность - кнопка не нужна, аудитория не кликает.
- **Не использовать generic кнопки**. «Открыть» (что?) failит. «Открыть разбор» / «Читать пост» - конкретно.
- **Не делать push длиннее самого материала**. Если статья 1000 слов, push 250 знаков - норм. Если push 300 знаков для видео 30 секунд - переcложно.
- **Не использовать negative hook'и из материала**. Если в материале «20% доходят» - не выносить в push (см. `feedback_no_negative_stats_in_public_offer`). В push - позитив или нейтрал.

## Hook patterns под content-tease

### Pattern: «Один X = Y результат»

«Один пост в боте принёс 47 покупок» / «Один комментарий = 12 продаж»

Работает потому что:
- Конкретика (один X)
- Результат (Y)
- Парадокс (если Y большой при X = 1)

### Pattern: «N элементов / ошибок / шагов»

«5 элементов рабочего push» / «3 ошибки воронки»

Работает потому что:
- Структурированность (N конкретных)
- Применимость (можно проверить себя)
- Промежуточная ценность (даже без клика дал thought)

### Pattern: Парадокс / Противоречие

«Бот без воронки приносит больше чем с воронкой» / «Меньше шагов = выше CTR»

Работает потому что:
- Нарушает ожидание
- Требует объяснения (создаёт gap)
- Запоминается

## Связь с другими skills

- Новый пост → ссылка из `post` output
- Новое видео → ссылка из `produce-reel` output
- Новое эссе → ссылка из `longform` output
- Новая статья / разбор → ссылка из `post` + manual
