# Template: reminder

> Тип №2. Напоминание о действии. Время-критичный формат - окно вебинара, дедлайн запуска, время открытия чего-то.

## Параметры

| Параметр | Значение |
|---|---|
| Длина | 80-150 знаков (target: short) |
| Кнопок | 1 |
| Hook framework | Time-Trigger / Curiosity-Gap |
| Tone | Утилитарный, безэмоциональный |
| Эмоджи | 0 |

## Scaffold

```
HOOK (30-50 знаков):
<время + действие - должно ясно считываться в notification preview>

BODY (30-100 знаков):
<что именно произойдёт / что подписчик получит, если придёт>

КНОПКА (одна):
- Текст: «Иду» / «Напомнить» / «К материалу»
- Тип: callback_data или URL
- Назначение: <подтвердить присутствие / получить ссылку>
```

## Примеры формата (заглушки)

### Пример A: Time-Trigger + Single callback

```
Через 1 час старт вебинара по контент-фабрике.
Покажу как один бот за неделю принёс 47 покупок Skool.

[Иду]  → callback
```

### Пример B: Дедлайн запуска + Single URL

```
Окно регистрации в марафон закроется в 23:59.
После - следующее окно только через 6 недель.

[Войти в марафон]  → URL
```

### Пример C: Анонс открытия + Single callback

```
Через 15 минут открою доступ к новой статье в клубе.
Покажу полный разбор воронки на 1000 подписчиков.

[Получить ссылку]  → callback
```

## Когда использовать

- За 24 часа / 1 час / 15 минут до события (вебинар / открытие окна / запуск)
- За 24 часа до закрытия окна продажи
- За 1 час до открытия доступа к новому материалу
- За день до конца bonus-окна

## Когда НЕ использовать

- Нет конкретного времени (просто «скоро» / «вот-вот») → `voronka-push`
- Анонс нового материала без дедлайна → `content-tease`
- Регулярная серия → `drip-segment`

## Anti-patterns specific to reminder

- **Не делать decoration**. Reminder = чистая утилитарная информация. Эмоджи, шутки, лирика - ослабляют urgency.
- **Не использовать «срочно»/«внимание»**. Hook уже несёт urgency через время. «Срочно!!! Внимание!!!» - это spam-сигнатуры.
- **Не предлагать выбор**. Reminder = одна кнопка. «Иду / Не сейчас» - это сегментация, не reminder.
- **Не повторять reminder больше 2 раз подряд**. После 2 reminder'ов одного события - следующий уже spam.

## Тайминг - best practices

| До события | Что в reminder |
|---|---|
| 24 часа | Полная информация: что, когда, зачем |
| 1 час | Короткое напоминание + кнопка подтверждения |
| 15 минут | Максимально лаконично: «через 15 минут старт» + URL |

## CTA-кнопка - особенности

Кнопка reminder должна быть **немедленным действием**:
- «Иду» - подтвердить присутствие (callback)
- «К материалу» / «Открыть» - получить ссылку (URL)
- «Напомнить за 15 минут» - отложить (callback) - используется редко

Запрет:
- «Узнать больше» (нет времени, событие началось)
- «Изучить вопрос» (не utility, событие)
- «Решить» (push не для размышления)
