# Template: Framework Breakdown

**Когда применять:** методология / N шагов / system / playbook.
**Reference creator:** Justin Welsh («I cracked LinkedIn's code in 8 moves»), Sahil Bloom.
**Slide count:** 8-12.

---

## Structure

```
[Slide 1 - Hook]
"<Number> moves/steps/keys to <outcome>. <Timeframe>. <Credibility>:"
Example: "8 ходов вайбмаркетинга. <твоя выручка> позже. Вот:"

[Slide 2 - Context / Why this matters]
"Эта методология применима к <segment>. Почему сейчас: <why_now>."

[Slides 3 to N-2 - Numbered Steps]
"01 - <Action verb> <thing>"
"<Body: 15-25 слов раскрывая шаг + REAL example>"

[Slide N-1 - Synthesis]
"Pattern: всё это вместе работает потому что <insight>."

[Slide N - CTA]
"Comment '<keyword>' → DM полную методологию"
ИЛИ
"Сохрани этот carousel - методология не для одной сессии"
```

## Hook formulas (3 варианта для A/B)

1. **Number + outcome + timeframe + credibility:** «8 ходов вайбмаркетинга. <твоя выручка>. <число учеников> позже:»
2. **Counter-intuitive promise:** «Методология которую я не показывал. Внутри 8 шагов:»
3. **Identity-driven:** «Если ты эксперт без аудитории - этот carousel для тебя. 8 шагов:»

## Real elements requirements

≥40% slides должны содержать:
- Real product names by name (Cursor / Claude Code / Lovable / Stripe)
- Real numbers (₽ / $ / followers / time savings)
- Real screenshots (Stripe dashboard / Cursor IDE / Skool community)
- Author face photo (1-2 slides)

## Pacing

- Slide 1: promise + curiosity gap
- Slide 2: context (tease numbered structure)
- Slide 3..N-2: open loop (каждый шаг tease'ит следующий)
- Slide N-1: loop close (synthesis)
- Slide N: action trigger

## Visual style

- **Typography:** sans-serif bold для headlines (60pt+), regular для body (36pt+)
- **Numbering:** «01 / 02 / 03» - крупно
- **Color:** brand accent (Ivan red) + minimal palette (max 3 colors)
- **Layout:** consistent template per slide - odd=text-heavy / even=screenshot где возможно
- **No-go:** generic gradient backgrounds / AI-illustrated humans / stock photos
