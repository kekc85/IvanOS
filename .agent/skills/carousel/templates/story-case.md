# Template: Story / Case

**Когда применять:** мой кейс / история ученика / before-after с числом / personal experience.
**Reference creator:** Lara Acosta (SLAY framework), Pieter Levels (Stripe-revenue story).
**Slide count:** 10-12.

---

## Structure (Acosta SLAY adapted + Pieter Levels real-numbers)

```
[Slide 1 - Hook]
"<Name>. <Number outcome>. <Timeframe>. <Tease lesson>:"
Example: "Лиза. 940 000 ₽. 6 недель. С нуля. История:"

[Slide 2 - Context / Before state]
"<Background - кто человек, где был до>"

[Slide 3 - Problem / Trigger]
"<Что было сломано / что заставило начать>"

[Slides 4-6 - Action / Journey]
"Шаг 1: <action>" + screenshot/proof
"Шаг 2: <action>" + screenshot/proof
"Шаг 3: <action>" + screenshot/proof

[Slides 7-8 - Outcome with NUMBERS]
"<Result 1 - конкретное число>"
"<Result 2 - конкретное число + proof screenshot>"

[Slides 9-10 - Lesson / Generalizable]
"Что я (или Лиза) поняла из этого:"
"<Lesson 1>"
"<Lesson 2>"

[Slide N - CTA]
"Comment 'история' → DM полный кейс с разбором каждого шага"
```

## Hook formulas (3 варианта)

1. **Name + Outcome + Timeframe:** «Лиза. 940К ₽. 6 недель. С нуля. Вот как:»
2. **Identity-flip:** «Эксперт без аудитории → 940К ₽ за 6 недель. История:»
3. **Counter-intuitive:** «Сделала запуск без рекламы, без сайта, без команды. 940К ₽. Шаги:»

## Real elements requirements

≥50% slides должны содержать:
- Real name автора кейса (с согласия)
- Real numbers с конкретикой (₽ / $ / users / time)
- Real screenshots (Stripe / DM / dashboard / контракт без личных данных)
- Author face / face of case subject (если согласие)
- Real timeframes (6 недель / 90 дней / etc.)

**FAIL:** «один эксперт сделал X» (без имени) / «900К+ рублей» (без точности) / generic «один из учеников».

## Pacing

- Slide 1: promise (number + name + timeframe - все 3 detail)
- Slide 2-3: context + problem (curiosity gap)
- Slide 4-6: action steps (proof через screenshots)
- Slide 7-8: payoff (NUMBER reveal)
- Slide 9-10: lesson (loop close - что это значит для reader)
- Slide N: CTA (action specific)

## Visual style

- **Hook slide:** name + number max large, минимум остальных elements
- **Action slides:** split (left = step text, right = screenshot proof)
- **Outcome slides:** number-bomber style (huge font), Pieter Levels style
- **Lesson slides:** typography-led, low color
- **Selfie / face:** 1-2 slides с фото (по Acosta - bottom-right corner)
- **No-go:** generic «happy student» illustration / stock photo

## Banned для story-case

- Кейсы без имени и числа (vague proof) - auto-fail
- Negative статистики типа «20% не доходят» - нельзя в public
- Public outing неуспешного кейса - нельзя
- Confidential информация (точные продажи если автор просил не публиковать) - нельзя
