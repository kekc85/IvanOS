## TL;DR (паттерны которые нужно реплицировать в templates)

| Pattern | IG creator carousels | LinkedIn doc carousels |
|---|---|---|
| Hero area | **55-70%** of canvas | **10-25%** (typography-led) |
| Typography role | overlay (bottom-third / corner / upper-quarter) | hero itself (large H1) + body framework |
| Real elements | physical UI screenshots / numbers с context / hands-in-frame / brand logos | inline numbers ("$10.8M") / data dashboards / metrics |
| Slide count | 6-12 | 8-12 (Welsh 10 / Donnelly 8-10 / Codie 12) |
| CTA strategy | comment keyword → DM | lead-magnet / program / newsletter |
| Brand consistency | per-creator palette + filter cohesion | per-creator color (Donnelly green / Codie black+gold) |
| Anti-AI moat | tactile imperfections / practical light / real artifacts | own-numbers proof + verified outcomes |

| Параметр | RU pattern | EN pattern |

| Platform | TG (album 2-5 images / single + heavy caption) | IG carousel 10 slides / LinkedIn doc 8-12 |
| Hero | реальный скриншот / график / ₽-цифра | polished custom-design slide |

| Design philosophy | zero-design / "доказательство важнее эстетики" | polished consistency / brand recognition |

1. **Two distinct paths** RU vs EN - не один template family

3. **EN path = IG/LinkedIn:** 10-slide hero-photo-overlay / typography-framework
4. **Ivan может cross-post** - через `subject.market: both` config

- ✅ v2.0 = EN IG/LinkedIn templates (P1-P7) - foundation

- Canonical: C1 halfbakedharvest / C2 brandonwoelfel / A1 growwithjo

- Real elements: visible UI chrome (window borders / timestamps / usernames / metric numbers)

- Canonical: C3 divyannshisharma / C4 Marc Lou

- Typography: caption text 40-50% with bold equation/sum
- Real elements: brand-recognizable product UI fragments

- Hero: 2-up photo grid 80-85%
- Typography: minimal - checkmark/X/category labels
- Real elements: paired real-life photos demonstrating contrast
- Canonical: A2 thebirdspapaya
