# Движок автопостинга

Ставишь публикацию в очередь одной командой, движок отправляет её сам в нужную
минуту в Telegram, Instagram и VK. Только официальные API площадок: никакой
работы под твоей живой сессией в браузере, потому что именно она приводит к
блокировкам аккаунта

## Быстрый старт

```
bash setup.sh                  # macOS и Linux
powershell -NoProfile -ExecutionPolicy Bypass -File setup.ps1   # Windows
```

Дальше впиши ключи в `.env` и спроси доктора:

```
python3 cli.py doctor
```

Доктор по каждой площадке скажет одну из трёх вещей: работает, не настроено
(и что именно вписать), не отвечает (и что с этим делать)

## Команды

| Команда | Что делает |
|---|---|
| `python3 cli.py doctor` | диагноз по площадкам и по сети |
| `python3 cli.py add --platform telegram --text "..."` | поставить публикацию в очередь |
| `python3 cli.py add ... --at "+2h"` | отложить на два часа |
| `python3 cli.py add ... --at "2026-09-01 09:00"` | назначить на дату и время |
| `python3 cli.py run` | отправить всё, чему пришло время |
| `python3 cli.py run --loop` | крутиться и просыпаться раз в минуту |
| `python3 cli.py status` | что в очереди и чем закончилось |
| `python3 cli.py retry` | вернуть упавшее обратно в очередь |
| `python3 cli.py media put kartinka.jpg` | положить файл в веб и получить адрес |
| `python3 cli.py media check <адрес>` | проверить, что адрес живой и отдаёт медиа |

## Примеры

Текст в канал прямо сейчас:

```
python3 cli.py add --platform telegram --text "первый пост движка"
python3 cli.py run
```

Картинка в Instagram завтра в девять утра:

```
python3 cli.py add --platform instagram --kind photo \
  --media https://tvoy-sait.example/kartinka.jpg \
  --text "подпись поста" --at "2026-09-01 09:00"
```

Карусель из трёх картинок, лежащих на диске (сначала уедут в веб):

```
python3 cli.py add --platform instagram --kind carousel --upload \
  --media a.jpg b.jpg c.jpg --text "подпись"
```

## Что должно быть готово до первой публикации

- Telegram: бот у BotFather, бот администратор твоего канала
- Instagram: профессиональный аккаунт, приложение в кабинете разработчика,
  токен со скоупом публикации, публичный адрес для картинок
- VK: сообщество, где ты администратор, и токен с правом публикации

Полная проводка по шагам лежит в `RASPAKOVKA.md` рядом с движком. Частые затыки
и что с ними делать - в `GRABLI.md`
