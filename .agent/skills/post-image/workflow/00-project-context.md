# Workflow 00 — Project Context (репликуемость)

**Когда:** первым делом при вызове скилла.
**Цель:** развязать движок от конкретного проекта. Движок общий, image-DNA проекта — снаружи.

## Шаг 1 — активный проект
- `--project <name>` → активный проект = `<name>`.
- нет флага → `default` (общий профиль из `knowledge/anti-slop-method.md`).

## Шаг 2 — загрузить image-DNA проекта
- `default` → `knowledge/anti-slop-method.md` (общий стиль-ДНК).
- `<name>` → `.business/проекты/<name>/post-pack/image-dna.md`. Не найден → fail с подсказкой «нет image-dna.md для проекта <name>».

## Шаг 3 — связать `{active.*}`
```yaml
active:
  project: default | <name>
  palette:        # палитра проекта (перекрывает дефолт)
  hero_typage:    # типаж/возраст/пол героя
  theme_moment_map: # карта «тема поста → момент кадра»
  aspect_ratio:   # дефолт 4:5
  anchors_note:   # что повторять/не повторять из visual-anchors
```
Если поле отсутствует в image-DNA проекта → брать дефолт движка.

## Шаг 4 — сверить с эталонами
Прочитать `visual-anchors/manifest.md` — что повторять / что НЕ повторять. Промпт собирается с оглядкой на эталоны (фаза 2).

**Дальше:** фаза 1 (brief).

> NB (картинки тоже ротировать): не повторять один и тот же кадр-момент/композицию для соседних постов. Сверяться с темой по `image-dna.md` (карта тема→момент) — разные темы = разные сцены.
