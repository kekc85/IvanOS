# post-image - фотореалистичная картинка к посту (анти-AI-слоп)

> Берёт готовый пост (или тему) → одна editorial-фотография через GPT Image, без текста на картинке. Главная задача - НЕ выглядеть как генерик AI-хрень. Картинку автор прикладывает к посту, текст несёт сам пост.

## Когда применять
- `/post-image`, «картинку к посту», «фото под пост», «визуал к посту»
- авто-вызов из `post` на финальной фазе (опционально)
- НЕ для: каруселей (→ `carousel`), целых роликов (→ `produce-reel`), картинок с текстом-на-картинке (→ `single-image`)

## Принцип: почему не-генерик
1. **Фото-эталоны.** До генерации сверяемся с реальными editorial-снимками в `visual-anchors/` (+ `manifest.md`: что повторять / что нет). Без якоря промпт съезжает в сток-AI.
2. **Editorial-документалка, не иллюстрация.** Живая кожа с порами, естественный свет, плёночная камера, приглушённая палитра, кадр-репортаж.
3. **Жёсткий негатив-лист** в каждом промпте (no plastic skin / CGI / stock smile / text / extra fingers).
4. **QA каждой картинки** перед выдачей (фаза 4). Ни один кадр не уходит без просмотра.

Метод детально - `knowledge/anti-slop-method.md`. Интеграция движка генерации - `knowledge/gpt-image-integration.md`.

## Реплицируемость (как у `post`)
Движок (этот скилл) общий. Проект-специфичный **image-DNA** (палитра, типаж героя, карта тема→момент) лежит СНАРУЖИ: `.business/проекты/<project>/post-pack/image-dna.md`, подключается `--project <name>`. Дефолт без флага = общий профиль. Резолв - `workflow/00-project-context.md`. Первый инстанс: `health` (Анти-Кортизол).

## Workflow (5 фаз)

### Фаза 0 - Project context (`workflow/00-project-context.md`)
Резолв `--project <name>` → загрузить image-DNA проекта (палитра / типаж / тема→момент / формат). Дефолт = общий профиль из `knowledge/anti-slop-method.md`. Сверить с `visual-anchors/manifest.md`.

### Фаза 1 - Brief
Прочитать пост (или тему). Определить: главная эмоция/тема → подобрать МОМЕНТ по карте «тема→момент» из image-DNA проекта (не буквальная иллюстрация, а честная атмосфера). Зафиксировать: герой, момент, интерьер, свет, настроение.

### Фаза 2 - Prompt (ULTRA, self-contained)
Собрать промпт по шаблону `knowledge/anti-slop-method.md`: [editorial documentary photo] + [герой+живая кожа] + [момент] + [реальный интерьер] + [естественный свет] + [Portra 400 / 50mm / зерно] + [палитра проекта] + [композиция/воздух] + [реализм-бустеры] + [aspect ratio] + Negative: [анти-слоп лист]. Без текста на картинке.

### Фаза 3 - Generate (`knowledge/gpt-image-integration.md`)
ОСНОВНОЙ путь - ТИХИЙ канал: `scripts/gen-chatgpt-image-cdp.py` без флагов (движок `codex_image`, тот же логин ChatGPT, только через Codex CLI). Окно браузера НЕ открывается, ждать и смотреть на экран не нужно, за компьютером можно спокойно работать параллельно. Поднимать заранее тоже ничего не надо.

Запасной путь (включаю, только если тихий канал отказал и назвал причину) - прежний браузерный тракт тем же скриптом с флагом `--engine browser`: живой ChatGPT в рендер-Chrome по CDP :9222, вот он окно откроет. Дальше по лестнице - higgsfield GPT Image 2 при наличии кредитов (🔴 только по явному «да» автора, само не запускается), либо paste-ready промпт автору в руки.

Выход - PNG ПРЯМО на рабочий стол: `~/Desktop/post-<slug>.png` (плоско, без подпапок - `feedback_flat_output_no_subfolders`, автор перетаскивает сразу со стола).

### Фаза 4 - QA-гейт (HARD, смотреть КАЖДУЮ)
Открыть каждую сгенерённую картинку (Read image) и проверить:
1. Кожа живая (поры/текстура), не пластик/воск
2. Руки/пальцы целые, без артефактов
3. Нет текста / букв / вотермарок
4. Палитра в image-DNA проекта
5. Момент бьётся с темой поста
6. Не похоже на сток / типичный AI-генерик
7. Не чужой/подменённый кадр (память `feedback_review_every_slide_before_deliver`)
Провал любого → переписать промпт (усилить негатив / уточнить момент) и перегенерить. Не выдавать брак.

### Фаза 5 - Deliver
Показать картинку автору + 1 строка «что на ней и почему под тему». Путь к файлу. Плоская папка, без подпапок (`feedback_flat_output_no_subfolders`).

## Anti-patterns
- Генерить без сверки с `visual-anchors` → съезд в генерик.
- Текст/буквы на картинке (GPT-image врёт буквы; текст несёт пост).
- Выдать кадр не посмотрев (фаза 4 обязательна).
- Палитра/типаж мимо image-DNA проекта → лента разваливается.
- Сток-улыбка, постановочная «модель», HDR-глянец, CGI-пластик.

## Mastery
Визуальной mastery-области в `mastery/` нет (отмечено в `tasks/inbox.md`). Якорь качества - реальные `visual-anchors/` + анти-слоп метод. При появлении `mastery/photography/` подключить по `mastery/PROTOCOL.md`.
