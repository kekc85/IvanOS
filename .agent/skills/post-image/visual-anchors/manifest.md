# Visual Anchors Manifest

> Эталоны стиля для сверки промпта (анти-генерик). Цель — НЕ wellness-сток, а живая editorial-документалка.
> ⚠️ Статус: эталон задан вербально-точно (ниже). Реальные PNG-якоря добавлять по мере набора: класть в эту папку как `reference-<источник>-по решению автора.png` и дописывать блок. До этого промпт + QA опираются на вербальный эталон.

## Эталонная эстетика (что повторять)
- **Плёночная документалка:** Kodak Portra 400 / 35mm, мягкое зерно, неидеальный естественный свет, правдивый приглушённый цвет.
- **Живой человек:** реальная кожа (поры, текстура, лёгкая асимметрия), естественная непостановочная мимика, без ретуши-глянца.
- **Свет от окна / раннее утро / пасмурно:** мягкие направленные тени, без студийной вспышки.
- **Кадр-репортаж:** чуть несимметрично, есть воздух, реальный бытовой интерьер.
- Референс-режиссёры стиля (как ориентир тона, НЕ копировать буквально): редакционный документальный портрет, «тихая» бытовая сцена.

## Что НЕ повторять (анти-слоп)
- Глянцевый wellness-сток (идеальная улыбающаяся «модель», белая студия, переэкспонированный HDR).
- Пластиковая/восковая кожа, beauty-ретушь, гипер-насыщенность.
- CGI/3D-рендер, сюрреализм, симметричное «идеальное» лицо.
- Текст/буквы/вотермарки, лишние пальцы, артефакты рук.
- Постановочные «иллюстрации заголовка» с реквизитом-капитаном.

## QA-сверка
Каждая сгенерённая картинка сверяется с этим эталоном (фаза 4). Похоже на «что НЕ повторять» → перегенер.
