# ОСИРОТЕВШИЕ ПУТИ СЛОЯ СКИЛЛОВ (1.5.2 круг 2, F39 вердикта)
#
# Что это. Пути, которые мы ВЫВЕЛИ из поставки. У новичка их нет по построению,
# а у обновляющегося они остаются жить: обновление кладёт новое и обновляет
# существующее, но ничего не уносит. Установщик по этому списку ПЕРЕНОСИТ такой
# путь в датированную папку `.ivanos-retired-<штамп>` рядом со слоем скиллов.
#
# Ничего не удаляется (правило №0 владельца): перенос обратим, ученик видит папку
# и может вернуть содержимое обратно, если оно ему зачем-то нужно.
#
# Формат: один путь на строку, ОТНОСИТЕЛЬНО каталога скиллов, слэш прямой.
# Строки с `#` и пустые игнорируются. Путь с `..` или ведущим слэшем отвергается
# установщиком как подозрительный.
#
# Установщик переносит путь ТОЛЬКО когда его нет в свежем payload: строка,
# случайно оставшаяся здесь после возврата каталога в поставку, ничего не сломает.
