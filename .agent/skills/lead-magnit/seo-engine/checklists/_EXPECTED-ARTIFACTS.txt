# _EXPECTED-ARTIFACTS.txt - эталонный список артефактов-доказательств по этапам.

> Генераторы картинок и сборщики запросов в пакет НЕ входят: ниже описан их интерфейс,
> по которому Клод соберёт такой же инструмент на твоём проекте. Команды даны как описание
> интерфейса, а не как готовый запуск
#
# ПЯТЬ СЕКЦИЙ (калибровка по решению автора: фикс-волна 1 - дефекты Б2/Б3 скептика-1,
# фикс-волна 5 - дефект Б10 скептика-5, секция MIN-REVISION).
# Раньше уровень был один - полный 16-этапный список, и он же стоял на входе
# публикации. Гейт, который роняет весь корпус, никого не останавливает: его просто
# перестают звать. Замер: MIN одним списком ронял 33 каталога из 38.
#
#   MIN        - ОБЯЗАТЕЛЬНЫЙ МИНИМУМ статьи НОВОГО маршрута. Блокирует деплой:
#                без этих файлов публиковать нечего и нечем доказать, что статья
#                прошла конвейер. Гейт: `artifacts_gate.py <slug>` (режим по умолчанию).
#   MIN-LEGACY - минимум статьи СТАРОГО маршрута (опубликована ДО 2026-08-12).
#                Её каталог часто содержит только скачанную с прода страницу:
#                требовать от неё следов конвейера, которых не было в природе, -
#                это и есть «гейт, роняющий корпус». С неё спрашивается ровно то,
#                без чего нельзя заливать: сама страница и источник её текста.
#   MIN-REVISION - минимум РЕВИЗИОННОЙ ПЕСОЧНИЦЫ (каталог патча ВНЕ $WORK:
#                `_rebuild/*/interlink-pilot/<slug>/`, `_rebuild/*/refresh-out/<slug>/`).
#                Там по контракту лежит ровно index.html, а у страницы, выпущенной
#                до порога, источника в $WORK нет вообще - она сама себе источник.
#                Спрашивается страница + СВИДЕТЕЛЬСТВО РЕВИЗИИ (что и от какой базы
#                патчится). Подробности и признак профиля - в самой секции ниже.
#   POST       - следы, которые физически появляются ТОЛЬКО ПОСЛЕ публикации.
#                В pre-deploy MIN их держать нельзя - это дедлок: чтобы залить,
#                нужен артефакт, который делается после заливки. Спрашиваются
#                на выдаче: `artifacts_gate.py <slug> --post` (его зовут
#                `article_gates.py --stage publish` и `rost.py готово`).
#   FULL       - ПОЛНЫЙ 16-этапный след. Это ЗАМЕР ДОЛГА, а не замок: прогон
#                `artifacts_gate.py <slug> --full` показывает, сколько следов
#                конвейера статья реально оставила, и НИКОГДА не роняет (exit 0).
#
# КАК ВЫБИРАЕТСЯ ПРОФИЛЬ КАТАЛОГА (Б10, до выбора маршрута). Внутри $WORK - СТАТЬЯ,
# что бы в каталоге ни лежало; вне $WORK с draft.md|spec.json|make_spec.py - тоже
# статья; вне $WORK и без источника сборки - РЕВИЗИЯ, дальше секция MIN-REVISION,
# и реестр публикаций тут ни при чём.
#
# КАК ВЫБИРАЕТСЯ МАРШРУТ СТАТЬИ (детерминированно, признак вне каталога статьи -
# подделать отсутствием файла нельзя). Ключ = адрес статьи в `content-sha-registry.json`
# (slug → /<page_prefix><slug>/, плюс плоский .html и список `redirected`):
#   есть в реестре, datePublished >= 2026-08-12   → НОВЫЙ маршрут  → MIN
#   есть в реестре, datePublished < 2026-08-12    → LEGACY         → MIN-LEGACY
#   есть в реестре, datePublished нет вовсе       → LEGACY         → MIN-LEGACY
#   в реестре нет (не публиковалась)              → НОВЫЙ маршрут  → MIN  (fail-closed)
# Порог задаётся ключом `new_route_since` в ~/.config/seo-publish.json.
#
# Уровни складываются: --min = MIN|MIN-LEGACY|MIN-REVISION (по профилю и маршруту) ·
# --post = --min + POST · --full = MIN + MIN-LEGACY + POST + FULL. MIN-REVISION в
# --full НЕ входит намеренно: свидетельство ревизии - след песочницы патча, а не
# след 16-этапного конвейера, и в замере долга статьи ему делать нечего.
# ГЛАЗАМИ файл читается по-прежнему (маркеры секций - обычные комментарии), но
# КАНОН вердикта - код: `artifacts_gate.py`. Ручной `diff` ниже профиля и маршрута
# НЕ знает, он сравнивает каталог со ВСЕМ файлом разом - значит у статьи он всегда
# покажет лишними строки чужих секций (MIN-REVISION, POST, FULL), и строку с
# префиксом `@witness:` в том числе. Это не долг статьи, это разные адресаты:
#   ls work/<slug>/ | sort > work/<slug>/_actual-artifacts.txt
#   grep -v '^#' checklists/_EXPECTED-ARTIFACTS.txt | grep -v '^$' | sort > /tmp/expected.txt
#   diff /tmp/expected.txt work/<slug>/_actual-artifacts.txt
#
# СИНТАКСИС СТРОКИ (понимает artifacts_gate.py, глазами читается так же):
#   имя.md          обязателен ровно этот файл/каталог
#   a.md|b.md       засчитывается любой из перечисленных (историческое имя ИЛИ новое)
#   etap-11-*.png   маска fnmatch: засчитывается любой подходящий файл каталога
#   имя.md?         УСЛОВНЫЙ: канон разрешает законный SKIP (см. комментарий рядом).
#                   Отсутствие показывается строкой «условно нет» и не роняет гейт.
#   @witness:a|b    СВИДЕТЕЛЬСТВО ПАЧКИ: ищется в каталоге И в его РОДИТЕЛЕ (ровно
#                   один уровень вверх). Нужен потому, что план патча выписывается
#                   ОДИН на всю пачку каталогов, а не копируется в каждый.
#   имя-DOLG.md     РАСПИСКА ПРИЗНАННОГО ДОЛГА вместо артефакта, которого физически
# не существует (пример: ресёрч пачки в даты запуска вёлся живьём, файла
#                   не осталось - конвейер шёл деградированным).
#
# 🔴 УСЛОВИЕ РАСПИСКИ ДОЛГА `*-DOLG.md` (иначе это дыра в замке, а не честность).
# Расписка засчитывается ТОЛЬКО статье с ПРИЗНАННЫМ долгом и ТОЛЬКО с датой ревизии
# внутри. Право даёт та же улика вне каталога, что и маршрут - дата выпуска в
# `content-sha-registry.json`:
# datePublished <= new_route_since (в т.ч. РАВНО порогу - пачка по решению автора) → годится
#   datePublished СТРОГО позже порога                                     → НЕ годится
#   статьи в реестре нет (не публиковалась) = новая                       → НЕ годится
# То есть НОВАЯ СТАТЬЯ С РАСПИСКОЙ НЕ СОБИРАЕТСЯ: ей положен настоящий ресёрч.
# Содержимое расписки: чем ресёрч вёлся, где улики (файл:строки журнала), какие
# конкретные факты верифицированы и ДАТА РЕВИЗИИ ИСТОЧНИКОВ (cadence).
#
# 🔴 АРТЕФАКТ ЗАСЧИТЫВАЕТСЯ ПО СОДЕРЖИМОМУ, А НЕ ПО ИМЕНИ (В8). `gates.json` с
# красным вердиктом внутри строку эталона НЕ закрывает: блокирует стадия `page`
# (verdict != PASS или стадии нет → «gates.json есть, но page=FAIL»), стадии
# `draft`/`publish` у опубликованной статьи информационные.
#
# 🔴 ТОТ ЖЕ ЗАКОН НА ВСЮ СЕКЦИЮ POST (П1, по решению автора - дыра приёмки). Три
# пост-отчёта закрывались ИМЕНАМИ ФАЙЛОВ, хотя правило выше действует с этой редакции.
# Улика: у `guide-ii-prilozhenie` внутри `etap-13-geo.md` стоит «Вердикт 13.4a:
# FAIL», а `artifacts_gate --post` печатал «вердикт: PASS» и пускал статью на
# выдачу. Теперь читается содержимое (детали и формулировки - в самой секции).
#
# 🔴 Имена приведены к ФАКТИЧЕСКИМ именам конвейера (сверка по 48 каталогам
# work/<slug>/, улика - счётчики в комментариях). Где канон и практика разошлись,
# стоит альтернатива `канон|факт`: эталон, который врёт про имя файла, отключает сам
# себя - diff краснеет всегда и его перестают читать.
#
# Строки, начинающиеся с #, - комментарии. Пустые строки игнорируются.
