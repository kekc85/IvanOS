## Шаги

1. **Подтвердить место в лестнице.** Лид-магнит = бесплатная ступень, ведёт на ТРИПВАЕР
   (платный продукт, `config.md` → target_*). 🔴 Статья ОТДАЁТ реальную пользу ЦЕЛИКОМ: половин у
   неё нет (закон владельца 29.08.2026), она вся ведёт человека к результату настоящими командами,
   кликами и промптами, объяснёнными простым языком новичка. На трипваере остаётся ГЛУБИНА
   (настройка под себя, сборка продукта, система), а не базовая инструкция. Прятать базу = вода,
   это разнесённый канон v2.0.

2. **Зафиксировать вход.** Кодослово → DM-автосценарий → ссылка на эту статью. Серия про Claude
   = кодослово «СЛОВО».

3. **Зафиксировать единственную цель.** Главный CTA = адрес из движка: при заданной
   `cta.invites_map` - именная ссылка канала по слагу статьи, иначе `target_url` с UTM. В
   черновике всегда токен `{{cta_url}}`, руками адрес не вписывать. Сформулировать **мостик** из
   результата статьи в обещание трипваера: «база у тебя работает; как настроить под свою задачу и
   собрать этим реальный продукт - на трипваере». Мостик опирается на то, что читатель ТОЛЬКО ЧТО
   сделал руками, релевантен теме, не generic. 🔴 Мостик живёт ВНУТРИ блока приглашения
   (CTA-канон движка статей), а не россыпью по телу: половины-прогрева больше нет.

4. **Зафиксировать prereq-вход.** Среда, которую читатель обязан иметь (по `config.md` → stack),
   ставится в Шаге 0 статьи со ссылкой на гайд установки (`config.md` → install_guide_url).
   Просить «открой в Claude Code» без шага установки = дыра в инструкции (принцип пререквизита
   в SKILL.md). 🔴 Формулировка prereq - на языке новичка: «окно, где ты словами пишешь ИИ задачу»,
   а не «терминал» (`knowledge/novice-standard.md` §6).

5. **Зафиксировать ИНТЕНТ и целевую длину.** Тип статьи задаёт объём тела (пороги -
   `seo-config-reference.yaml` → `tools.length`):

   | Интент | Целевая длина тела | Когда |
   |---|---|---|
   | Хвостовая единица | **900-1200 слов** | узкий задачный или сравнительный запрос, страница-термин: интент закрывается целиком, дальше вода |
   | Разбор / новость / обзор | **1200-2000 слов** | вышел инструмент, разбор кейса, сравнение |
   | Инструкция «как сделать» | **2000-3500 слов** | основной тип лид-магнита: поставить и запустить инструмент |
   | Опорная статья кластера | **от 4000 слов** | тема-зонтик, на которую ссылаются остальные статьи |

   Ниже нижней границы = тема не раскрыта, поиск такую не держит. Выше верхней (кроме опорной,
   у которой верхней границы нет) = дробим на две статьи под разные ключи (одно слово = одна тема
   = один URL). Хвостовая единица держит нижний край разделов - ровно 8 H2 по 120-150 слов
   (`config.md` → `depth_by_intent.tail`).

## Выход (зафиксировать)

```
ЛЕСТНИЦА: лид-магнит → трипваер (config target_product)
ВХОД: кодослово «СЛОВО» → DM → эта статья
ГЛАВНЫЙ CTA: адрес из движка (invites_map по слагу статьи, иначе target_url с UTM) → в черновике токен {{cta_url}}
МОСТИК (результат статьи → трипваер, живёт в блоке приглашения): «<готовая формулировка>»
PREREQ-ВХОД: гайд установки Claude <install_guide_url> (в Шаге 0 статьи)
ИНТЕНТ: <хвостовая | разбор | инструкция | опорная> → целевая длина тела <900-1200 | 1200-2000 | 2000-3500 | 4000+> слов
```
