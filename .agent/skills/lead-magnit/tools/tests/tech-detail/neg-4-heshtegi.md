# Что писать под роликом

Внизу увидишь там хештеги и настройку видимости поста. Хештеги ставь по теме ролика, двух-трёх хватает: это обычная подпись, а не какая-то настройка для своих.

Хэштеги другой раскладкой пишутся так же, разницы для площадки нет. Один хеш-тег с названием темы, один с городом - и достаточно, дальше площадка сама разберётся, кому показать.

Ничего сложного тут нет: подписал ролик словами, которыми его будут искать люди, и пошёл дальше снимать следующий.
