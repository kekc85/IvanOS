# Проверка адресов из России

Я прогнал десять адресов подряд и записал, что вышло. Первый же адрес отдался кодом 200, второй молчал почти минуту, третий выдал заглушку на своём языке. Дальше я повторил всё это ещё дважды, чтобы случайность не выдавала себя за правило.

Смысл прогона простой: понять, откуда человек из России попадёт внутрь без плясок, а где его развернут на входе. Ниже я разложил результат по строкам и коротко подписал каждую, чтобы читать можно было сверху вниз и не возвращаться.
