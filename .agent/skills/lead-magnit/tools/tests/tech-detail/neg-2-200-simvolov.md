# Как писать описание

Держи описание в пределах 200 символов и не пытайся впихнуть туда всё сразу. Одна мысль, одно обещание, одно понятное слово о том, что человек получит.

Длинное описание читают до середины и бросают, короткое дочитывают целиком. Поэтому первые пять слов решают больше, чем весь остальной текст. Напиши их так, будто объясняешь другу в очереди за кофе: без красивостей, зато понятно с первого раза.

Проверить просто: прочитай вслух. Споткнулся - переписывай.
