# prezentaciya-uroka - обучающая презентация урока

Сквозной процесс сборки обучающего урока-деки уровня флагмана: ученик открывает и САМ всё понимает, без преподавателя в кадре. Это продукт без лица (faceless-first). Захочешь - озвучишь синтезом голоса или запишешь себя поверх, но дека самодостаточна и так.

**Главный принцип: форма после смысла.** Сначала смыслы, исследование и текст. К визуалу не переходим, пока структура и содержание не готовы. Красивые пустые слайды = провал.

**Источник качества:** методология в `knowledge/methodology.md` (5 законов качества + 9-частная структура урока + микро-цикл лепестка + кластеры проблем + каталог артефактов). Дизайн-система деки в `knowledge/design-system.md`. Читать ОБА перед стартом.

## Когда применять
- «сделай презентацию урока / обучающий урок / слайды для курса / дека урока про X»
- «презентация урока без лица», «урок как в модуле», «обучающая презентация по моей теме»

НЕ для: прогрев-уроков к платному событию (`lesson-deck`), постов (`post`), каруселей (`carousel`), лендингов (`website`), рилзов (`replicate-viral`).

## 5 законов качества (гейт на каждом слайде и каждом уроке)

1. **Законченность смысла (главный).** Каждый блок доходит до вывода: что это -> почему важно для ТЕБЯ (ученика) -> что конкретно делать. Тест: закрой следующий слайд - предыдущий уже самодостаточен. «Написал вещь, непонятно зачем» = брак.
2. **Бабушка-тест.** Любой термин объясняется простым словом или бытовой аналогией при первом появлении. Инструкции супер-пошаговые: один шаг = одно действие + куда нажать + что вставить + что увидишь.
3. **Артефакт-инструмент на месте применения.** Где есть действие - там реальный инструмент, который можно забрать: дословный промпт в копи-блоке, команда, чек-лист, шаблон, дерево решений. Не «расскажи про», а «вот, копируй и делай».
4. **Ультра-реальная визуализация.** На каждом смысле реалистичный мокап/схема, по которому понятно что к чему. Не абстрактная метафора-фотосток. Тест: закрой текст - картинка всё ещё объясняет.
5. **Доходимость (шапка продуктолога+маркетолога).** Урок спроектирован чтобы его ДОСМОТРЕЛИ и ВНЕДРИЛИ: big idea цепляет, обещание ясное, доказательство на боли, вау держит, мясо даёт результат, домашка фиксирует. Один урок = один большой концепт, доведённый до вау-результата.

## Сквозной конвейер (11 фаз, форма после смысла)

Каждая фаза = свой промпт в `prompts/`. Оркеструет существующие скиллы - это и есть «партнёрства», без которых фаза не выполнится.

| Фаза | Что делаем | Какие скиллы тянем (партнёрства) | Гейт перехода |
|---|---|---|---|
| **0. Бриф урока** | один большой концепт урока · аудитория · осязаемый результат «к концу будет в руках» · faceless или под запись | `raspakovka-ekspertnosti` (твой метод), `.business/` | концепт и результат сформулированы одной строкой |
| **1. Дизайн серии** | бренд деки: палитра/шрифты/настроение/мокап-стиль; reference RU+зарубеж; есть прошлый урок -> держим серию | `website` (дизайн-фаза), `frontend-design`, `stitch-design-taste`, `gpt-taste` | бренд-токены зафиксированы (`design-system.md`) |
| **2. Ресёрч темы** | факты, данные, свежие источники, реальные команды/скрины по теме | `resyorch-nishi`, `youtube-transcript` | собран фактический бэкграунд, ничего не выдумано |
| **3. Смыслы по рынку** | что несут по этой теме сильные авторы/конкуренты, чего не хватает, чем отличишься | `analitika-arhiva`, `svertka-istochnika` | список рыночных смыслов + точка дифференциации |
| **4. Смыслы по своей базе** | твои кейсы, метод, цифры, истории, голос - из `.business` | `.business/` (распаковка, voice-corpus, кейсы), `stil-golosa-po-postam` | список своих смыслов с реальными якорями (не выдуманными) |
| **5. Обогащение если мало** | где смысла тонко - подтянуть контекст из внешних источников до глубины и законченности | `resyorch-nishi`, `svertka-istochnika` | тест глубины пройден: каждый лепесток имеет теорию+пример+вывод |
| **6. Структура урока** | разложить концепт по 9-частной дуге; мясо = лепестки (микро-цикл); кластер проблем; артефакты | `knowledge/methodology.md` | дуга собрана, лепестки расписаны, дублей с прошлыми уроками нет |
| **7. Текст слайдов** | написать текст в ТВОЁМ голосе; бабушка-тест; законченность; обязательный humaniser | `post`/`longform` (черновики), `humaniser` (ОБЯЗАТЕЛЬНО), `.business/voice-corpus` | текст согласован, humaniser пройден, ноль воды |
| **8. Сборка дека** | HTML-слайды: бренд-токены + анимации SLIDEFX + реальные мокап-компоненты; перф; overflow ПК+мобайл | `frontend-design`, `motion`, `gsap`, `design-system.md` | визуал на каждом слайде, overflow 0, без scroll-snap, чистый режим |
| **9. Запись (опц.)** | faceless: TTS-озвучка синхронно слайдам. on-camera: скрипт + аватар/своя запись | `hyperframes-media` (tts), `video` (скрипт), `avatar-generate`/`voice-generate` | дека озвучена/записана ИЛИ сознательно оставлена faceless |
| **10. Экспорт+публикация** | PDF (playwright, каждый слайд = страница) + live-ссылка по `connections.md` (дефолт - локальная выдача) | playwright, `connections.md` | PDF собран, ссылка/файл отдан, проверен на телефоне |

## Ветка faceless / запись
- **Faceless (дефолт).** Дека учит сама: визуал + текст + мокапы несут всё. Ничего записывать не нужно. Подходит продуктам без лица. На Фазе 9 - пропуск.
- **Озвучка без лица.** На Фазе 9 синтез голоса (`hyperframes-media tts` твоим `voice_id` из `connections.md`) кладётся дорожкой к слайдам - получается видео-урок без камеры.
- **На камеру.** Фаза 9 даёт скрипт диктора (`video`), дальше либо записываешь себя, либо ставишь своего аватара (`avatar-generate` на твоём HeyGen). Дека идёт фоном-слайдами.

Заучивание: faceless-дека + сгенерированный скрипт диктора = можно отрепетировать и записать с листа.

## 🔴 Жёсткие гейты (нарушение = переделка)
1. **Форма после смысла.** Не открывать Фазу 8 (визуал), пока Фазы 0-7 (смыслы+текст) не готовы и не согласованы.
2. **Humaniser для ЛЮБОГО текста**, включая текст на слайдах. Прогон через `Skill('humaniser')` + `.business/voice-corpus/_voice-profile.md`. Без неклише, без длинных тире, без точки в конце абзаца.
3. **Законченность каждого смысла.** Ни одного «предпосылка без вывода». Независимый агент-аудитор проходит деку на незаконченные смыслы перед показом.
4. **Визуал на КАЖДОМ слайде.** Мокап/чарт/схема/дашборд/рендер. Голый текст = брак.
5. **Артефакт-инструмент**, где есть действие: копи-блок с дословным промптом/командой/чек-листом, а не пересказ.
6. **Аудит дублей** перед показом: новый урок против всех прошлых (смыслы/заголовки/визуалы/кейсы). Дубль = переписать. Запускать НЕЗАВИСИМЫМ агентом-аудитором.
7. **Overflow-чек на ПК (1280) и мобиле (390)** программно. Без `scroll-snap`. Орфаны убраны (`text-wrap:balance/pretty`).
8. **Кластер проблем перед домашкой**: 2-4 типовые проблемы этого урока + готовое решение + профилактика.
9. **Не fake-done.** Текст в каркасе != «дизайн собран». Не помечать готовым непроверенное.
10. **Показывать живую ссылку/видео или инлайн-картинку**, не статичный JPEG (на нём анимаций не видно) и не локальный путь.

## Definition of done (урок готов)
- 9-частная дуга на месте, мясо разложено на лепестки с микро-циклом (теория+хорошо/плохо+ошибки+пример+вывод)
- Каждый смысл доведён до вывода, бабушка-тест пройден, ноль воды (humaniser ок)
- Визуал-мокап на каждом слайде, overflow 0 на ПК и мобиле, без scroll-snap
- Кластер проблем + артефакты-инструменты вшиты, домашка с точкой сдачи
- PDF собран + live/инлайн-доставка, проверено на телефоне
- Дубль-аудит пройден независимым агентом
