# Screen-Record + Face-Cam (Video Sub-format #1)

## Когда использовать

**автора альфа sub-format**. Демонстрация vibemarketing / вайбкодинг в Claude / Lovable / Bolt с своим лицом в углу.

Reference creator: Riley Brown @rileybrown.ai (635K TikTok). 1M+ cross-platform.

Использовать daily 1-2 видео из 5 daily. Самый authentic format автора = доказательство экспертизы через actually doing.

## Структура

```
Full-screen view:
- 80% area: Claude / Lovable / Bolt / Cursor / Tella interface  
- 20% bottom-right: face-cam webcam circle/square
- Captions: Hormozi-style word-by-word bold

Length: 30-60 sec optimal (peak engagement)
Aspect: 9:16 vertical
```

## Стек tools

| Этап | Tool | Cost |
|---|---|---|
| Recording | **Tella** или **Screen Studio** | $20-25/мес |
| Webcam capture | iPhone front camera или dedicated USB cam | $0-150 hardware |
| Audio | $100 wireless mic (Riley's setup) | hardware |
| Captions | **CapCut** или **Submagic** integration | бесплатно / $16/мес |
| Final assembly | CapCut на телефоне или Mac | бесплатно |

## Workflow

### Шаг 1: Pick demo idea
- Из feed monitoring / Virale: что у растущих залетает
- Apply virality + deficiency filters
- Topic should be **demonstrable за 30-60 sec**

### Шаг 2: Pre-recording prep (5-10 мин)
- Browser tabs закрыть (no notifications)
- Demo prep: какой prompt / какие steps будут показаны
- Hook script first 3 sec (use F.5 hook-generator if нужно)
- Audio level test

### Шаг 3: Recording (Tella) — 5-15 мин
- Open Tella session
- **Recording first hooks after main content** (Riley's pattern - main content first, hook re-shoot after)
- Multi-take ОК - Tella in-recording editing
- Face-cam corner: angle towards screen content
- Speak conversationally - explain что делаем
- Show actual results на screen

### Шаг 4: Trim + edit
- Cut dead air
- Hook punch first 1.5-3 sec
- Bold captions Hormozi-style
- 9:16 reformat for vertical
- Total length 30-60 sec

### Шаг 5: Distribution
- Нельзяграм Reel + Stories
- YouTube Shorts (cross-post)
- TikTok (cross-post)
- (опционально) Through uniqualizer для multi-account Нельзяграм
- (опционально) RU dub через C.3 multi-language-localization

## Гвардрейлы

- Voice автора (authentic talking, не scripted reading)
- Real demo (не simulated / fake results)
- Show ACTUAL results на screen
- Hook в first 1.5-3 sec
- БЕЗ em-dash в captions
- БЕЗ generic "subscribe для more" CTA
- Lexicon: Нельзяграм / Дубайск / контент-завод
- Categorically вайбмаркетинг angle

## Что НЕ делаем

- Scripted reading (не authentic)
- Fake / simulated demo results
- Long intros / channel logos
- Generic "what is X" explanations - show, not tell
- Captions с em-dash
- Multi-CTA финал

## Финальная фаза — Humaniser (HARD GATE для всех text-skills)

**ОБЯЗАТЕЛЬНО перед output:**

Вызови Skill tool: `Skill('humaniser', args=<финальный текст>)` ПЕРЕД любым output. НЕ читай humaniser/prompt.md inline и НЕ применяй mentally — это shallow execution которое пропускает AI-tics. Только полный pass через Skill tool invocation документированный в чате.

Humaniser v2 ловит 11 категорий AI-паттернов:
1. Ложная глубина
2. Фальшивая близость
3. Пустые связки
4. Канцелярит
5. Fake-энергия
6. Шаблонные призывы
7. Рубленые фразы (3+ из 1-2 слов подряд)
8. Кинематограф
9. Структурные клише
10. Интонационные клише
11. **Slap-эмфаза (длинное + 1-3-словное короткое для эмфазы) — главный AI-tic социалок 2025-2026**

**HARD GATE:** Output финального текста ТОЛЬКО после green CHECKER (все 5/5 в «Клише удалены»). Если CHECKER не green — REWRITER ещё раз. Без этого = брак.

**Прецеденты:**
- 2026-05-28: post v3.0 выдал «Zero ads. Zero funnels. Zero sales calls.» (triple-negation AI tic)
- 2026-05-29: caption выдал «Бесплатно. 30 минут работы и ожидание ответа.» (slap-эмфаза, новая категория 11)

Оба = провал shallow inline pass. HARD GATE через Skill tool решает.

### Humaniser Inline Reminder (fallback если Skill tool недоступен)

Перед output финального текста — проверь по 11 категориям AI-tics:

1. Ложная глубина («Это не X, это Y», «Секрет в том»)
2. Фальшивая близость («Знакомо?», «Представьте»)
3. Пустые связки («Давайте разберёмся», «Важно понимать»)
4. Канцелярит («В современном мире», «Является неотъемлемой»)
5. Fake-энергия («Спойлер», «Бонус», «Лайфхак»)
6. Шаблонные призывы («Хватит X», «Перестаньте X начните Y»)
7. Рубленые фразы (3+ предложения подряд из 1-2 слов: «Просто. Быстро. Эффективно.»)
8. Кинематограф («Воскресенье, 10 вечера», «Понедельник, 9 утра»)
9. Структурные клише (параллелизм X/Y/Z, всегда 3 пункта)
10. Интонационные клише («невероятно простой!», «истина в том»)
11. **Slap-эмфаза**: короткое standalone (1-3 слова) после длинного для эмфазы. SMELL TEST: «можно ли слить через запятую?». YES → SLAP, слить. Исключения: structural separator перед list / hook / punchline finale.

Прецеденты провала которые этот block ловит:
- post v3.0 2026-05-28: «Zero ads. Zero funnels. Zero sales calls.» (triple-negation, cat 7+9)
- caption 2026-05-29: «Бесплатно. 30 минут работы и ожидание ответа.» (slap-эмфаза, cat 11)

При нахождении любого pattern → REWRITER (переписать) → re-CHECKER → если clean → output.
