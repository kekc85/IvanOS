### Заголовок H3 → heading size 3

> Сначала боялся пылесоса. А потом ничего, втянулся.  
> — Джейсон Стетхем

1. Первый шаг
2. Второй шаг

- Пункт раз
- Пункт два

- [ ] Купить курицу
