# Workflow 01a - Mode A: Plan (из Карты смыслов)

**Назначение:** взять смысл + подсмысл на конкретную дату из Карты смыслов запуска и превратить в стартовый brief для поста.
**Входы:** `brief.mode = "plan"` + дата (по умолчанию - сегодня)
**Выходы:** `brief.topic`, `brief.angle`, `brief.source = "content-map"`
**Следующая стадия:** `workflow/01-finalize.md`

**Когда применять:** активный запуск идёт, Карта смыслов заполнена, есть запись на нужную дату. Это **power mode для контент-завода с дисциплиной**.

---

## Шаг 1 - Определить дату

По умолчанию: сегодня (значение из системного контекста).

Если в input указана другая дата («на 28 мая», «завтра», «послезавтра») - использовать её.

Записать `brief.target_date = "YYYY-MM-DD"`.

---

## Шаг 2 - Открыть Карту смыслов

Прочитать файл по пути `config.paths.content_map` с подстановкой `<active-launch>` из `config.active_launch.<lang>`.

Пример пути: `.business/запуски/<твоя-папка-запуска>/karta-smyslov.md`.

**Если файл не существует:**
→ Сообщить: «Карта смыслов запуска не найдена по пути `<path>`. Перехожу в Mode B2 (генерация идей под JTBD)».
→ Переход в `01b-spark.md` sub-flow B2. Stop.

**Если файл существует:**
→ Извлечь запись на `brief.target_date`.

---

## Шаг 3 - Найти запись на дату

Карта смыслов поддерживает три формата (определяется `config.paths.content_map_format`):

### Формат `calendar` (по умолчанию)

```markdown
## 2026-05-28
**Смысл:** вайбмаркетинг закрывает 90% работы соло-эксперта
**Подсмысл:** ученик из строительства зарабатывает 500К/мес на телеграм-боте
**Тип контента:** long-educational
**Архетип (если зафиксирован):** Magician
**Hook angle:** Results-first
```

### Формат `thematic` (без жёстких дат)

```markdown
## Неделя 21 (26.в даты запуска)
- **Сюжет:** «Контент-завод vs ручной контент»
- **Смыслы:**
  1. Один человек = один завод
  2. Дефицитность смыслов > виральность форматов
  3. Системное закрытие 30 постов в день
```

Если формат `thematic` - скилл выбирает один из смыслов недели, который ещё не использовался (проверка по `recent_posts`).

⛔ **ИСКЛЮЧЕНИЕ - активный запуск (`brief.launch_window = true`): формат `thematic` НЕ применяется.** У дня запуска 10 РАЗНЫХ несущих смыслов на 10 носителей (ОСН · ЗАКР · ИНФОРМЕРЫ · ММ · СТАРЫЕ · Б.1 · Б.2 · Б.3 · Р · EMAIL). Свободный выбор из общего пула = взять смысл чужого носителя или чужого дня и сжечь его - брак. Ячейка дня перебивает выбор, идти в Шаг 2.5.

---

## Шаг 2.5 - НОСИТЕЛЬ (обязателен при `brief.launch_window = true`)

У дня запуска смысл назначен НЕ дню, а носителю. Без этого шага скилл берёт произвольный смысл, и апрув-таблица Слоя 0 строится до того, как подтянется правильная ячейка.

1. `Read(config.content_plan)` - найти секцию `## ДN · по решению автора` на `brief.target_date`
2. Показать автору строку НОСИТЕЛИ ячейки (все 10 слотов дня одной таблицей: носитель · несущий смысл-код · CTA)
3. Взять носитель, указанный автором. **По умолчанию (автор не назвал) - ОСН**
4. Записать в brief:
   - `brief.carrier` ∈ {`osn`, `zakr`, `inf`, `mm`, `star`, `bot`, `bot_reg`, `email`}
   - `brief.smysl_codes` ← коды смыслов ИМЕННО этого носителя (не общего «Смысла дня»)
   - `brief.cell_path` ← путь к полной клетке: `.business/запуски/<active-launch>/_rebuild-v4/day-NN-DDMM.md` (мост уже проставлен в `<карта-смыслов>.html` строкой «ПОЛНАЯ КЛЕТКА: _rebuild-v4/day-NN-DDMM.md»)
5. `Read(brief.cell_path)` - секция своего носителя (`### 🔵 ОСН` / `### 🟣 ЗАКР` / `### 🤖 БN.M` / `### 📧 EMAIL` и т.д.). ИМЕННО ОТТУДА берутся угол, драматургия, фактура с якорями, анти-чеклист, варианты CTA и ссылка с UTM

🔴 `brief.cell_path` обязан доехать до `02b-research-summary.md` и `04-review.md`: без него скилл пишет по общему смыслу дня и теряет и запреты носителя, и его дверь

### Формат `hybrid`

Календарный костяк + thematic дуги. Скилл сначала смотрит точную дату, потом fallback на смысл недели.

---

## Шаг 4 - Извлечь поля

Из найденной записи извлечь.

**При активном запуске** (`brief.launch_window = true`) поля берутся из СТРОКИ НОСИТЕЛЯ (Шаг 2.5), а не из общего «Смысла дня»:
- `brief.topic` ← несущий смысл носителя `brief.carrier`
- `brief.angle` ← угол этого носителя из клетки `brief.cell_path`

**Вне запуска** - как раньше:
- `brief.topic` ← `Смысл`
- `brief.angle` ← `Подсмысл` (или сам Смысл если Подсмысла нет)
- `brief.type` ← `Тип контента` (если указан)
- `brief.archetype` ← `Архетип` (если указан)
- `brief.hook_type` ← `Hook angle` (если указан)

Поля, которых нет в карте - оставить пустыми, они заполнятся в `01-finalize.md`.

---

## Шаг 5 - Если запись на дату пустая

Если на `brief.target_date` ничего нет - НЕ выдумывать смысл. Действия:

1. Сообщить: «На дату <date> в Карте смыслов нет записи».
2. **Прочитать очередь** `~/.claude/skills/post/queue.md` УСЛОВНО (`[ -f ]`, файла может не быть - это законно, значит очередь пуста). Пишет её `01c-transcript.md` Шаг «Вариант B» - это незакрытые смыслы прошлых надиктовок. Есть непомеченные строки `- [ ]` → предложить их первым вариантом в вопросе ниже; взятый смысл отметить `- [x]` в том же файле.
3. Спросить **ровно один** вопрос: «Хочешь (а) взять смысл из очереди `queue.md` <первая строка>, (б) дополнить Карту прямо сейчас, (в) взять смысл из ближайшей даты, (г) перейти в Mode B2 (генерация идей)?» Очередь пуста → вариант (а) не показывать.
4. После ответа - действовать соответственно.

## Шаг 5.5 - 💰 Боевая карточка Слоя 0 (launch_window, NEW v5.0)

Если `brief.launch_window = true` (выставлен router Шаг 0.48) — построить боевую карточку по `references/launch-money-layer.md`:

1. Прочитать `<launch>/<решения-запуска>.md` ПЕРВЫМ (канон решений, перебивает остальные файлы).
2. Определить день запуска и температуру по шкале (`Воронка.md` даты + шкала в launch-money-layer).
3. Из ЖИВОЙ ячейки дня (`<карта-смыслов>.html` - именно он, НЕ «свежий по mtime»: в корне лежат ещё два архива v3 с отменёнными смыслами, они переименованы в `_archive-v3-*.html` и помечены баннером) перенести: шаг денежной цепи, слом убеждения (если заложен — перенос, НЕ выбор из objections.md), демо-артефакт.
4. «Почему сегодня» — только реальный факт. Нет факта → context-gap, спросить. 🔴 Это обоснование ДЛЯ КАРТОЧКИ, а не текст в пост: число оставшихся мест и перечень дат по умолчанию в тело поста НЕ переносятся (см. `_phases-state.md`, блок «СЧЁТЧИК МЕСТ / ДАТЫ СОБЫТИЯ»). В посте «почему сегодня» доносится смыслом, цифрой-дефицитом — только когда ячейка дня прямо требует дедлайн как несущую механику.
5. Записать `brief.money_card` + при показе фазы «смысл» вывести карточку ВМЕСТЕ с таблицей происхождения смыслов (один ✋-апрув), улика → state `L1.money`.

Вне окна запуска — шаг пропустить молча.

---

## Принципы Mode A

1. **Карта - единственный источник смысла.** Не дополнять своими идеями.
2. **Дисциплина даты.** Не «прыгать» по карте если на сегодня пусто - спросить пользователя.
3. **Пустая запись = stop, не вымысел.** Лучше fallback на Spark чем выдумать смысл.
4. **Карта обновляется отдельно.** Если её надо дополнить - это отдельный workflow в фазах запуска, не задача скилла.
