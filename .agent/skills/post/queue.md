# Queue (очередь смыслов скилла post)

Файл рабочий и живёт между сессиями. Пишет `workflow/01c-transcript.md`
(«Вариант B - пользователь сказал все три»): первый смысл надиктовки уходит в
текущий run, остальные ложатся сюда строками `- [ ]`. Читает
`workflow/01a-plan.md` Шаг 5 пункт 2 - условно (`[ -f ]`), предлагает первую
непомеченную строку вариантом (а) и помечает взятый смысл `- [x]` здесь же.

Формат строки:

    - [ ] Смысл N: <essence> | quote: «...»

Пустой файл = очередь пуста, вариант (а) в вопросе не показывается. Пустые
строки и этот заголовок потребитель игнорирует - он ищет только `- [ ]`.
