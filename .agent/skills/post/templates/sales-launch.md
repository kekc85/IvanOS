# Template 8 — Sales/Launch пост (1500-2500 chars) — v1.0, 2026-06-11

> **Грунд (не теория):** структура-афиша автора из реальных постов открытия реги по решению автора (`<launch>/Посты-по решению автора-открытие-реги.md`) + правки автора к лонч-посту по решению автора + gold-standard Пост 11. Брансон/generic sales-формулы — НЕ драйверы.
> **Обязательная пара:** строится ТОЛЬКО поверх боевой карточки Слоя 0 (`references/launch-money-layer.md`). Без карточки тип 8 не собирается.

## Когда применять

`brief.launch_window = true`. Три под-типа по фазе из температурной шкалы:

| Под-тип | Фаза | Структура |
|---|---|---|
| **8a Афиша** (открытие/дожим реги) | открытие реги, дни эфиров | Структура-афиша автора (ниже) |
| **8b Прогрев-носитель** (смысл дня → рега) | прогрев в даты запуска | Нарративный HSO по канону + лонч-обвязка (ниже) |
| **8c Продажа программы** | sales window (после открытия цены в день запуска) | 8b + оффер из <твой состав тарифов> |

## 8a — Структура-афиша (из реального поста автора)

1. ‼️ + событие («Открыта регистрация на…» / «Осталось N мест на…»)
2. Выгода одной фразой: что соберёт человек + снятие порога («даже если нет ниши, не маркетолог, не технарь»)
3. Даты/формат конкретно
4. 👉 CTA-кнопка №1 (рано, до раскрытия)
5. Анти-усилия строкой («без кода, без иностранной карты, без продюсера»)
6. Раскрытие по дням 1️⃣2️⃣3️⃣ — каждый день = глагол результата («поставишь», «соберёшь», «запустишь»)
7. «Что открывается сразу после регистрации» — список
8. Бонусы-скиллы — список
9. Анти-усилия + дефицит (цифра ТОЛЬКО с живого счётчика)
10. 👉 CTA-кнопка №2 + практ-ремарка курсивом

## 8b — Прогрев-носитель (дефолт окна прогрева)

Тело = обычный канон (примеры/истории 60-70%, ценность 24ч, смыслы дня с инлайн-разметкой) + лонч-обвязка:

1. **Несущий смысл дня из живой ячейки** (как обычно, Слой 1) — пост остаётся постом-историей, НЕ афишей.
2. **Мясо инструмента/результата — СПИСКОМ** (что сделал инструмент по пунктам), не прозой — правка автора.
3. **Демо-пруф из ячейки** (скрин/артефакт) — предложить визуал.
4. **Мост в регу** = продолжение смысла, не пришитый хвост: «на воркшопе соберёшь это себе» через конкретику дня программы (День 1 продукт / День 2 деньги / День 3 контент-завод).
5. **CTA-кнопка + практ-ремарка**, причина «сегодня» из карточки (строка 5).

## Жёсткие правила (все под-типы; проверяет Sales Gate 4.S)

- Единственное действие читателя = регистрация (8c: оплата). Микро-да В регу — можно. Reader-homework — брак.
- Без коммент-вопросов («а ты на чём застрял?») на лончевом.
- Жирным — ключевые сдвиги-фразы (скелет смысла при скролле), не отдельные слова.
- Все факты программы/механизма — из канона (`workshop.html`, <решения-запуска>, правда по механизму из `_phases-state.md` п.0). Заголовки дней не сочинять — диктует автор.
- Цены — только в 8c и только из <твой состав тарифов>.
- Негативных статистик и «цена в личке» нет.
- ЦА = новички без ниши/продукта: НЕ писать «твоя экспертиза/твой навык» как данность — снимать возражение «у меня нет ниши» («определишь на Дне 1»).

## Чем НЕ является

- НЕ замена канона: 8b проходит ВСЕ слои 1-5 как обычный пост. Лонч-обвязка — поверх, не вместо.
- НЕ hard-sell каждый день: баланс задаёт температурная шкала (прогрев продаёт мягко, через желание и демо).
