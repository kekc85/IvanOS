# Template: Long Educational (≤2500 chars)

> **Назначение:** длинный обучающий пост автора. Pillar контент канала <твой-хэндл>. ~1/неделя.
>
> **Target:** 1500-2500 chars (~300-500 RU слов). Sweet spot: 1800-2300.
>
> **Архетип:** Sage (primary) / Magician. Banned: Caregiver / Lover / Innocent.
>
> **Когда применять:** разбор кейса, framework, метод, market research, step-by-step. Когда читателю нужно «учиться от автора».

---

## Slot 1 - Hook (первая строка, 6-12 RU слов)

Длинному посту особенно важен сильный hook - иначе развернутая структура не дочитается.

Выбрать ОДИН из 4 типов hooks применимых к длинному:

### Type A - Listicle headline с цифрой
- «❗️5 сдвигов на рынке ИИ в 2026» (пост 7)
- «3 способа выйти из шадоу-бана за 24 часа»
- «4 формулы оффера, которые работают в 2026»

### Type B - Money/Result claim
Конкретная сумма / метрика в заголовке.
- «Разбор монетизации на [твоя цифра] в месяц на ИИ-блогере» (пост 8)
- «💰Ученик ищет сотрудников в свой ИИ контент-завод с оплатой до [твоя цифра]/мес» (пост 5)

### Type C - Alarm / Crisis frame
Тревога рынка + риторический вопрос.
- «🆘 Завтра Telegрам может быть заблокирован! Что нужно сделать прямо сейчас?» (пост 1)
- «❗️крупный игрок ушёл с рынка. Что это значит для рынка инфопродуктов»

### Type D - Personal moment-anchor → framework тизер
- «Меня уволили со СВОЕГО контент-завода…» (пост 4 - paradox + reveal в посте)
- «Только что закрыл клиента на 500К через ИИ-блогера - разбираю механику»

**Universal trick:** добавить emoji-маркер начала (❗️ 💰 🆘 📍 🔥 🫠) - это **системный приём автора**, встречается в 6 из 10 топ-постов.

## Slot 2 - Personal opening (1-2 абзаца, 100-200 chars)

Зачем нужен: хук сам по себе обещает много, но если не привязать к личной ситуации автора - пост читается как «инфопродукт-документация». Personal opening = trust-anchor.

Что входит:
- Откуда тема пришла (закрытый Мастермайнд / переписка с учеником / собственная задача)
- Личный момент / контекст жизни в момент написания
- Time-anchor («за последнюю неделю», «вчера», «3 дня назад»)

**Verbatim:**
- «Я сделал глубокий аналитический ресеч за последнюю неделю и разобрал 5 главных "сдвигов"» (пост 7)
- «*ученик по зарубежке не разрешил показывать полный никнейм аккаунта, но рассказал о внутрянке проекта» (пост 8 - mystery-anchor!)
- «Я решил пойти против правил и паники и УДВАИВАЮ свои мощности» (пост 1)
- «Вот такое сообщение увидел сегодня в своем закрытом Мастермайнде» (пост 5)

## Slot 3 - Framework / Method разворот (3-5 абзацев, 800-1500 chars)

Сердце поста. Что входит:
- 3-5 шаговая система ИЛИ
- 5 пунктов framework ИЛИ
- 3-актная хронология (раньше / переход / сейчас) ИЛИ
- Бинарный fork (или X, или Y, третьего не дано)

**Правила:**
- НЕ техническая инструкция (≠ documentation)
- Метафоры / аналогии / конкретные цифры
- Каждый пункт = собственный мини-абзац с emoji-маркером начала
- Цифры пронумерованы (1. 2. 3. ...)
- Объясняй через «почему» а не «что»
- 2-3 канонических термина автора (контент-завод, вайбкодинг, нейро-воронка, денежный треугольник, цифровой двойник)

**Структуры-готовые из gold-standard:**

### Structure A - 3-актная хронология (Past → Transition → Now)
Пост 4:
- «1. В 2025 я выкладывался по 5 раз в день руками»
- «2. В начале 2026 ИИ помогал, но я модерировал»
- «3. Сейчас Claude Code сам зашёл в Хигсфилд и сам кликает мышкой»

### Structure B - 5-step pipeline
Пост 2:
- «1. запускает сотни ИИ-агентов»
- «2. выбирает золотой сегмент»
- «3. через Claude и Lovable создаются готовые продукты»
- «4. вайбкодится нейро-воронка»
- «5. Claude Code сам заходит в Хигсфилд»

### Structure C - 3-блочный case разбор
Пост 8:
- «1. Он завайбкодил цифрового двойника бабушки в нише здоровья»
- «2. Запустил контент-ферму на 10 аккаунтов»
- «3. Монетизация - БАДы + партнёрка + приложение»

### Structure D - 5-bullet teaser через «-»
Пост 7:
- «- Что с рынком инфопродуктов после громких событий на рынке»
- «- Кто заработает в этом году, а кто проспит»
- «- Какие ниши умрут, какие выстрелят»
- «- Что делать новичкам с нуля»
- «- Куда мигрируют деньги аудитории»

### Structure E - Бинарный framework
Пост 8:
- «Если застрял где-то и не получается, значит не понимаешь на какой из 2 фаз ты находишься»
- «или поиск модели, или масштаб - третьего не дано»

## Slot 4 - Personal application (1-2 абзаца, 200-400 chars)

Зачем нужен: framework сам по себе sterile. Personal application показывает «вот как Я САМ это сейчас применяю» - это build-in-public momentum.

Что входит:
- Конкретный текущий действия автора
- Цифра / метрика (200к/мес токенов, +25к подписчиков, $3,228 доход)
- Может быть прогноз («к лету», «через месяц», «в этом году»)

**Verbatim:**
- «Сейчас я для своей фермы делаю вайбкодинг от А до Я: 1-2-3-4-5» (пост 2)
- «моя контент-ферма приросла на [твой результат] новых подписчиков… [твой пример] работает на нескольких аккаунтах по РФ» (пост 6)
- «Я решил пойти против правил и паники и УДВАИВАЮ свои мощности» (пост 1)
- «к лету появится новый мини-рынок - покупка готовых аккаунтов» (пост 5 - прогноз)

---

## Slot 5 - CTA (последний абзац)

Длинный обучающий = обычно sales-pivot или lead-magnet gating.

### Type A - Lead-magnet trade
- «заполни анкету на 2 минуты → статья откроется автоматически» (пост 7)
- «👉🏻 разбор внутри Сопровождения, узнать детали можно здесь» (пост 5)

### Type B - Dual-reaction vote (poll-механика)
Разделяет аудиторию на 2 сегмента для следующего поста.
- «🔥 если ИИ-блог в реалиях банов / ⚡️ если вайбмаркетинг» (пост 8)

### Type C - Sales link + urgency
- «👉🏻 Успеть забрать место и окунуться в вайбкодинг» + дедлайн «21-23 апреля в 19:00» (пост 2)
- «👉🏻 Успеть забрать место и автоматизировать весь контент-завод с нуля» (пост 4)

### Type D - Reaction + soft-link
- «Ставьте 🔥 если хотите следующий пост про X»
- «📱 Вся внутрянка в Мах»

**Close-formula (последняя строка):**
- «Берегите себя на этом рынке» (пост 7)
- «Никогда еще вход в мир ИИ не был настолько доступен» (пост 4)
- «третьего не дано» (пост 8)

## Constraints (hard rules)

- [ ] Total ≤2500 chars (target 1800-2300)
- [ ] Single main idea (метод / система - не 2 разные темы в одном посте)
- [ ] 1 архетип (Sage / Magician primary)
- [ ] ≤1 восклицательный знак
- [ ] 1 список / framework (длинному посту список разрешён, но ровно один)
- [ ] 2-3 уникальных термина автора
- [ ] Drama type: contrast / reveal / twist (НЕ linear прямолинейный)
- [ ] Em-dash «-» внутри строк ЗАПРЕЩЁН
- [ ] НЕТ «Instagram» - только «Нельзяграм»
- [ ] НЕТ negative stats про учеников в public
- [ ] Конкретные числа / метрики (минимум 2)
- [ ] Visual breathing: emoji-маркеры начала абзацев или brail-spacers (⠀)
- [ ] НЕ markdown-bold - разделение через пустые строки и emoji
- [ ] Тон - на «ты» в action-блоке, «мы» для со-причастности

### Пример 3 - Пост 1 (crisis + 3-step plan + reversal)
**URL:** https://<твой-tg-канал>/2195
**Length:** 2 384 chars
**Hook type:** C - alarm / crisis frame

```
🆘 Завтра Telegрам может быть заблокирован! Что нужно сделать прямо сейчас?

Информация о возможной полной блокировке активно распространяется в СМИ, ссылающихся на источники в ведомствах и Кремле

[твоя подпись] ❤️

Ставьте 🔥 - если в челлендж

📱 Вся внутрянка челленджа в моем Мах
```

**Параметры:**
- Hook: 🆘 alarm-emoji + direct threat + риторический вопрос
- Archetype: **Magician** (трансмутирует кризис в возможность)
- Drama type: contrast + reveal (тревога → разворот «99% замедляют, я УДВАИВАЮ»)
