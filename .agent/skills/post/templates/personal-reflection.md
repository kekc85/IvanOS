# Template: Personal Reflection (1500-2500 chars)

> **Назначение:** личностный прогрев / рефлексия / эмоции / «живой человек, не expert».
>
> **Target:** 800-2000 chars (~150-400 RU слов). Sweet spot: 1000-1600.
>
> **Архетип:** Magician / Sage / Outlaw / Hero (значения). Banned: Caregiver / Lover / Innocent / Jester (исключение: лёгкий Jester в самоиронии типа «🫠 меня уволили»).
>
> **Когда применять:** базовый прогрев к личности (NOT к продукту), рефлексия события, переосмысление, ценности, момент жизни → инсайт. 1-2/неделя.

---

## Slot 1 - Hook (личная ситуация / время-место / провокация)

Personal-reflection требует эмоционально-сильного hook. Никаких abstract framework заходов.

Выбрать ОДИН из 5 типов:

### Type A - Голый personal-statement (без emoji, без украшений)
Самый сильный для serious values.
- «У меня все деды воевали» (пост 9)
- «Только что закончил эфир с учениками. Сижу и не могу заснуть»

### Type B - Личная ситуация + сенсорные глаголы
Описание сцены через действия.
- «Отдыхал, гулял, стрелял, кайфовал и много ел на природе» (пост 6)
- «Убирался дома и неожиданно понял»

### Type C - Время-место («вчера/сегодня я + действие»)
- «Сидел вчера 4 часа в Claude Code до 3 ночи»
- «Сегодня утром залип на одной мысли»

### Type D - Paradox / self-deprecation hook
- «🫠 Меня уволили со СВОЕГО контент-завода…» (пост 4 - самоирония)
- «Я честно облажался»
- «Мне написали "ты выгораешь"»

### Type E - Провокация / контр-интуитивно
- «Это разозлит многих»
- «Инфобизнес наоборот»
- «Я перестал ставить цели»

**Универсальные emoji-маркеры для personal:** 🫠 (самоирония) / 💭 (раздумье) / 🔴🔴🔴 (патриотика) / ❤️ (эмоция). Используются точечно, не нагромождать.

## Slot 2 - Personal context (2-4 абзаца, 300-800 chars)

Сердце поста. Зачем нужен: hook обещает эмоцию - context её разворачивает. Это **не резюме событий**, а **внутренний слой** (что автор думал / чувствовал / переживал).

Что входит:
- Эмоция / переживание / момент
- Конкретные детали (имена / места / время)
- Personal verification (где автор это видел / чувствовал)
- Связь с предыдущим опытом (отец, дед, прошлая работа, начало пути)

**Правила:**
- НЕ резюме событий - внутренний слой
- Соответствует «Базовый прогрев к личности» из видения автора
- Конкретные детали > абстракции («погибли на глазах близких дома» > «много горя в семье»)
- Можно цитаты (библейская, известная, своя из прошлого)

**Verbatim:**
- «Половина погибли на войне, а половина прошли всю войну и вернулись раненными, быстро погибли на глазах близких дома» (пост 9 - конкретная тяжёлая деталь)
- «Огромная цена ради того, чтобы мы с вами жили» (пост 9 - переход к рефлексии)
- «Я не хочу жить в телефоне, но хочу делать только самые целевые действия для моментальных результатов» (пост 6 - credo-маркер)
- «Claude Code официально автоматизировал всю генерацию роликов… буквально забирает контроль курсора мыши и клавиатуры» (пост 4 - сцена с конкретикой)

## Slot 3 - Insight / lesson (1-2 абзаца, 200-500 chars)

Что входит:
- Что автор понял / переосмыслил / какой вывод
- НЕ нравоучение - рефлексия
- Может быть «открытый» - без однозначного ответа
- Перенос от частного (personal) к универсальному (универсальный принцип)

**Правила:**
- Не «вот вам урок» - а «я для себя понял»
- Можно цитата (библейская / литературная / собственное credo)
- Если есть pivot к продукту - он встроен в логику insight, не отдельно (как в посте 9: «борьба» из patriotic → «борьба» против алгоритмов)

**Verbatim:**
- «Когда я вижу трудности на своем пути, я вспоминаю отца, деда, прадеда, весь свой род. Я просто обязан ломать каждую трудность на моем пути в знак благодарности к подвигу нашего народа» (пост 9)
- «Никогда еще вход в мир ИИ не был настолько доступен» (пост 4 - close-aphorism)
- «"Нет больше той любви, как если кто положит душу свою за друзей своих" (Ин. 15:13)» (пост 9 - библейская цитата)

## Slot 4 - Invite engagement (CTA - light)

Personal-reflection НЕ должна закрываться жёстким sales-CTA. Только soft.

Выбрать ОДИН из 4:

### A. Reaction-CTA (light)
- «🔥 если откликается»
- «❤️ если в одной лодке»

### B. Question CTA
- «А у тебя так бывает?»
- «Что отзывается?»
- «Какая трудность сейчас перед тобой?»

### C. Soft-pivot к продукту (как в посте 9)
Только если pivot **встроен** в narrative-логику.
- «А вот мой скромный вклад в нашу борьбу против алгоритмов и блокировок -> здесь» (пост 9)
- «📱 Вся внутрянка в Мах»

### D. Минимум - просто close без CTA
Для самых сильных values-постов оставить без действия.
- «Сегодня праздник великой победы 🔴🔴🔴»
- «[твоя подпись] ❤️»

---

## Constraints (hard rules)

- [ ] Total 800-2500 chars (target 1000-1600)
- [ ] Архетип: Magician / Sage / Outlaw / Hero - НЕ Caregiver / Lover / Innocent
- [ ] Tone: на «ты», открытый, без позы эксперта
- [ ] ≥1 уникальный термин автора (но в hardcore values-постах допустимо БЕЗ - см. пост 9, где автор сознательно убирает термины)
- [ ] ≤1 восклицательный знак
- [ ] Em-dash «-» внутри строк ЗАПРЕЩЁН
- [ ] НЕТ «Instagram» - только «Нельзяграм»
- [ ] Allowed: эмоциональная лексика без хайпа («кайфовал», «сижу и не могу заснуть», «душу свою»)
- [ ] НЕ allowed: «успешный успех», «достижения», лайфстайл-флекс типа «40 стран / Bali / Golden Gate»
- [ ] НЕ allowed: позиция «я тут эксперт, расскажу как надо»
- [ ] НЕ allowed: travel-флекс (автор путешествует, но это упоминается в контексте «отдых + контент-завод», не как самоцель)
- [ ] Конкретные детали > абстракций (имена / даты / суммы / места)

## 2 примера из gold-standard

### Пример 1 - Пост 9 (День Победы, values, soft-pivot)
**URL:** https://<твой-tg-канал>/2295
**Length:** 857 chars
**Hook type:** A - голый personal-statement
**Archetype:** Hero (долг + жертва + соответствие)

```
У меня все деды воевали

Половина погибли на войне, а половина прошли всю войну и вернулись раненными, быстро погибли на глазах близких дома

Огромная цена ради того, чтобы мы с вами жили

«Нет больше той любви, как если кто положит душу свою за друзей своих» (Ин. 15:13)

Когда я вижу трудности на своем пути, я вспоминаю отца, деда, прадеда, весь свой род

Я просто обязан ломать каждую трудность на моем пути в знак благодарности к подвигу нашего народа

И быть опорой для семьи, близких, коммьюнити и общества

Сегодня праздник великой победы 🔴🔴🔴

А вот мой скромный вклад в нашу борьбу против алгоритмов и блокировок -> здесь
```

**Параметры:**
- Hook: голый personal-statement без emoji
- Archetype: **Hero** - pattern «прошлое поколение принесло жертву → я обязан соответствовать через борьбу со своими трудностями»
- Drama type: linear + final pivot (мастерский: «борьба» из патриотического narrative → «борьба» против алгоритмов; не разрушает торжественность)
- Value type: values-statement + personal-reflection
- CTA type: minimal soft-link («->здесь»)
- Specific tricks: библейская цитата с библиографической ссылкой (Ин. 15:13) - необычно для блогеров, конкретная тяжёлая деталь («погибли на глазах близких дома»), расширяющий список «семьи, близких, коммьюнити и общества» (от ближнего к дальнему), «🔴🔴🔴» вместо «🇷🇺», **сознательно НЕТ «контент-завод» / «вайбкодинг»** - автор убирает термины чтобы не разрушать торжественность

- Value type: personal-reflection + framework (3-актная хронология)
- CTA type: link + sales
- Specific tricks: «🫠 Меня уволили со СВОЕГО контент-завода…» (twist-заголовок), «остается отдыхать и заниматься монетизацией 😁» (punchline ironic), self-deprecation как hook → reveals power, «СиДэнс до Клинг и ВЕО» (русифицированные технонеймы), «буквально забирает контроль курсора мыши и клавиатуры» (почти SF-образ), close-aphorism «никогда еще вход в мир ИИ не был настолько доступен»
