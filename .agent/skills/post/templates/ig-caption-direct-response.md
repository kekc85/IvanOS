Что за просто полотно текста»).

## Назначение

Слайды карусели уже сделаны (машиной или вручную). Этот template пишет ТОЛЬКО текст под каруселью — то, что в IG идёт в поле описания. Цель текста: чтобы человек написал кодовое слово в директ/коммент и получил лид-магнит.

## Вход

- Тема карусели (из transcript оригинала + structure.json, либо из брифа).
- **Кодовое слово** — берётся с CTA-слайда карусели (совпадение обязательно). Если не передано — генерируется по теме (не generic ХОЧУ/ДА/СТАРТ/ИНФО).
  - 🔴 ОБЯЗАТЕЛЬНО до финала прогнать через единый реестр (иначе конфликт — слово занято / у магнита уже есть слово):
    - `python3 ~/.business/scripts/codewords.py for-magnet "<что выдаём по слову>"` — если магнит УЖЕ имеет активное слово → ПЕРЕИСПОЛЬЗУЙ его, не выдумывай новое.
    - иначе `python3 ~/.business/scripts/codewords.py reserve --magnet "<...>" --word <СЛОВО> --lang ru|en` — exit 0 = можно, exit 2 = занято, бери другое.
  - Публикация незарегистрированного слова блокируется хуком `codeword-collision-check.sh`.
- Выгода — что конкретно человек получит по код-слову (PDF / разбор / чек-лист / шаблон). Конкретный объект, не «расскажу как».
- Язык: RU (default) / EN.

## Жёсткий лимит длины

- **≤1100 символов всего.** Не превышать — IG у части аккаунтов режет на ~1100. Весь смысл, включая повтор CTA, влезает в 1100.
- Если не помещается — режем прогрев в Блоке 2, не CTA.

## 🔴 КАНОН СТРУКТУРЫ — `~/.claude/skills/_shared/lead-magnet-description-structure.md`

ОБЯЗАТЕЛЬНО читать перед написанием. Полная (TG) версия = 6 блоков из канона: **1 Хук (вопрос/парадокс) · 2 Суть одним абзацем (что собрал + механика) · 3 Конкретные примеры с якорями (что делает→что заменяет) · 4 Личный опыт «Я сам…» · 5 Что внутри ролика/карусели · 6 CTA код-слово**. Эталон — описание автора к github-ролику. Брак: общий тезис в лоб в хуке + тело-пересказ концепции без якорей + нет блоков 4-5.

IG-сжатая версия (≤1100) = 3 блока ниже; блоки 4-5 ужимаются, но не выкидываются.

## Структура (3 блока, IG-сжатая)

### Блок 1 — Вершина (призыв сразу, до обрезки)

- **Первая строка ≤125 символов** — она видна до «ещё» в ленте. В ней хук + уже намёк/призыв на кодовое слово.
- Сразу в первых строках — прямой призыв: «Напиши „КОД-СЛОВО" в директ (или в комменты), и пришлю [выгода]».
- Кодовое слово КАПСОМ, в кавычках-ёлочках.
- Принцип: даже если человек увидит только верх до обрезки — он уже знает, что делать и что получит.

### Блок 2 — Продающий прогрев (тело)

- Продаём не продукт, а **идею активировать кодовое слово**.
- Что внутри по код-слову (конкретный объект). Почему это стоит забрать. Снятие главного сомнения («это сложно» / «не получится» / «не для меня»).
- Методология: sales-launch + Hook-Story-Offer (см. `references/hook-story-offer.md`, `templates/sales-launch.md`). Прогрев короткий — лимит 1100 не даёт растекаться.
- 1/3/1 ритм: короткая первая, чередование в теле, короткий выход.

### Блок 3 — Финал (повтор CTA)

- Повтор призыва с тем же кодовым словом + куда писать (директ / коммент).
- Без новых сущностей, чистая активация.

## Финальный humaniser-gate (обязательно)

Перед выдачей — прогнать через `humaniser` (Skill, hard gate). Это публикуемый текст для аудитории. См. `~/.claude/skills/humaniser/prompt.md`, 15 категорий AI-tics. Особо: Triple-X parallel, fake-близость, рубленые staccato, AI-fact-invention.

## IG self-check (вместо отдельного review sub-stage — изолирован тут)

Перед output проверить по списку, каждый = PASS/FAIL:

1. Всего символов ≤1100? (FAIL → резать прогрев)
2. Первая строка ≤125 символов?
3. Кодовое слово присутствует ≥2 раз (Блок 1 + Блок 3)?
4. Призыв на кодовое слово в первых ~3 строках (до обрезки)?
5. Выгода — конкретный объект (PDF/разбор/чек-лист), не «расскажу как»?
6. Код-слово совпадает с CTA-слайдом карусели?
7. Нет em-dash внутри строк / нет «Instagram» вместо «Нельзяграм»?
8. humaniser пройден?

Любой FAIL → переписать, не выдавать.
