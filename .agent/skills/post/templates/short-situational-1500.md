# Template: Short Situational (≤1500 chars)

> **Назначение:** ежедневный ситуативный пост автора. Атомная единица контента канала <твой-хэндл>. ~80% daily выпусков.
>
> **Target:** 600-1500 chars (~120-300 RU слов). Sweet spot: 1000-1300 chars.
>
> **Архетип:** Magician (primary) / Sage / Hero. Banned: Caregiver / Lover / Innocent (исключение: Caregiver в tool-drop).
>
> **Когда применять:** daily пост, реакция на событие, личная ситуация → метод, micro-инсайт, прогрев к продукту.

---

## Slot 1 - Hook (первая строка, 6-12 RU слов)

Выбрать ОДИН из 7 типов заходов автора. Не повторять тип последние 3 поста.

### Type A - ВРЕМЯ И МЕСТО («вчера/сегодня я + действие»)
Привязка к конкретному дню → ощущение «свежак с фронта».

**Verbatim из gold-standard:**
- «Провел уже 3 шикарнейших дня в пригородах Геленджика и шикарно восстановился» (пост 6)
- «У меня в <город> он уже не работает ночью даже с VPN, в центре Москвы с мобильного интернета также ничего не работает» (пост 1, как 2-й абзац-anchor)

### Type B - ЗАХОД («недавно я наконец/решил/попробовал»)
Self-revelation про action момент назад.

**Verbatim:**
- «Я решил, что хочу помочь рынку пройти эту временную, но общую проблему» (пост 3)
- «Я сделал глубокий аналитический ресеч за последнюю неделю» (пост 7)

### Type C - ПОДЗАГОЛОВОК-ИНТЕРЕС («главная проблема X» / «лучший совет по Y»)
Numbered/categorical, listicle-вкус.

**Verbatim:**
- «❗️5 сдвигов на рынке ИИ в 2026» (пост 7)
- «Разбор монетизации на [твоя цифра] в месяц на ИИ-блогере» (пост 8)
- «📍 УНИКАЛИЗАТОР РОЛИКОВ + ВЫХОД ИЗ БАНА» (пост 3, CAPS вариант)

### Type D - ЦИТАТА (цитата отдельным абзацем + неожиданное продолжение)
Внутренняя речь подписчика / ученика / собственная фраза.

**Verbatim:**
- «💰Ученик ищет сотрудников в свой ИИ контент-завод с оплатой до [твоя цифра]/мес» (пост 5 - псевдо-цитата как заголовок)

### Type E - АНЕКДОТ / КОРОТКАЯ БАЙКА
1-2 строчки повествования без морали в первой строке.

**Verbatim:**
- «🫠 Меня уволили со СВОЕГО контент-завода…» (пост 4 - paradox-байка)

### Type F - ЛИЧНАЯ СИТУАЦИЯ («убирался / проснулся / ждал»)
Бытовой момент → внутренний инсайт.

**Verbatim:**
- «У меня все деды воевали» (пост 9 - голый факт без украшений)
- «Отдыхал, гулял, стрелял, кайфовал и много ел на природе» (пост 6 - сенсорная пятёрка глаголов)

### Type G - ПРОВОКАЦИЯ («это разозлит многих» / «инфобизнес наоборот»)
Контр-интуитивное утверждение.

**Verbatim:**
- «🆘 Завтра Telegрам может быть заблокирован! Что нужно сделать прямо сейчас?» (пост 1 - alarm с риторическим вопросом)
- «Как я вышел на такой результат на самом деле» (пост 10 - curiosity-reveal expectation)

## Slot 2 - Context (1-3 абзаца, разворачивает hook)

Что входит:
- Откуда инфа / personal verification (где автор это видел сам)
- Нюанс / разворот / уточнение
- Source-anchor (закрытый Мастермайнд / <город> / переписка с учеником)

**Правила:**
- Абзац 1-3 строки. Если длиннее - разбить.
- Конкретные числа везде (25.000 / 150к/мес / $100K - не «много»).
- 1-2 канонических термина: «Нельзяграм», «контент-завод», «вайбкодинг», «ферма».

**Verbatim примеры:**
- «Вот такое сообщение увидел сегодня в своем закрытом Мастермайнде для участников Сопровождения» (пост 5 - source-anchor + closed-circle FOMO)
- «Информация о возможной полной блокировке активно распространяется в СМИ, ссылающихся на источники в ведомствах и Кремле» (пост 1 - где автор это видел)
- «Мне в личку приходят сейчас каждый день запросы на контент-заводы из-за удорожания платного трафика и блокировок» (пост 5 - market-evidence)

## Slot 3 - Value (1-2 абзаца, микро-польза)

Что входит:
- Insight / framework / step-by-step / system
- Применимо за 24 часа
- Достаточная плотность чтобы читатель «готов заплатить 500₽» за это
- ИЛИ personal credo (если пост типа values/personal)

**Форматы value:**
- Нумерованный mini-список 1/2/3 (макс 3 пункта в коротком посте)
- Бинарный framework («или X, или Y, третьего не дано»)
- Метафора («дырка в ванной + кран + резервуар»)
- Прогноз рынка («к лету появится новый мини-рынок»)
- Конкретная формула («1 уникализатор → 20+ аккаунтов»)

**Verbatim:**
- «Я люблю такие изменения, потому что рынок не уменьшается, а число конкурентов - да… Я решил пойти против правил и паники и УДВАИВАЮ свои мощности» (пост 1)
- «1 с лицом и 2 без лица» (пост 2 - конкретная формула вместо абстракции)
- «к лету появится новый мини-рынок - покупка готовых аккаунтов» (пост 5 - прогноз)
- «Самое важное, что каждый человек может сейчас сделать - это все свободное время посветить вайбкодингу» (пост 10 - императив)

## Slot 4 - CTA (последний абзац, soft)

ОДИН из 4 типов. Не комбинировать больше одного.

### A. Reaction-CTA (🔥)
Собирает signal на тему следующего поста.
- «Ставьте 🔥 если хотите разбор Х»
- «🔥 если откликается»
- «Всем желаю ленивого продвижения 🔥»

### B. Dual-reaction (🔥/⚡️) - poll-механика
Разделяет аудиторию на 2 сегмента.
- «🔥 если ИИ-блог в реалиях банов / ⚡️ если вайбмаркетинг» (пост 8)

### C. Question CTA - invite engagement
- «А у тебя так бывает?»
- «Что выберешь?»

### D. Soft link на продукт / эфир / событие
Pivot встроен в narrative, не отдельной рекламной строкой.
- «📱 Вся внутрянка челленджа в моем Мах» (пост 1, 6)
- «👉🏻 внутрянка монетизации моих ИИ-роликов» (пост 10)
- «->здесь» (пост 9 - minimal pivot)

**Verbatim close-formulas:**
- «Берегите себя на этом рынке» (пост 7)
- «Всем желаю ленивого продвижения 🔥» (пост 6)
- «[твоя подпись] ❤️» (пост 1)

## Constraints (hard rules, regex auto-fail)

- [ ] Total ≤1500 chars (target 800-1300)
- [ ] 1 архетип per пост (не Magician+Sage+Hero смесь)
- [ ] Архетип НЕ повторяет последние 3 поста канала
- [ ] ≤1 восклицательный знак
- [ ] ≤1 список / буллет
- [ ] ≥1 уникальный термин автора (Нельзяграм / контент-завод / контент-ферма / вайбкодинг / вайбмаркетинг / автооплаты / Сопровождение / Мах / нейро-бабушки / денежный треугольник)
- [ ] 1/3/1 rhythm (короткая первая строка → 2-4 средних абзаца → короткий close + CTA)
- [ ] Em-dash «-» внутри строк ЗАПРЕЩЁН (только дефис «-» или запятая)
- [ ] НЕТ «Instagram» - только «Нельзяграм»
- [ ] НЕТ negative stats про учеников в public («20% доходят» - banned)
- [ ] НЕТ markdown-bold - разделение через пустые строки / emoji-маркеры / brail-spacers (⠀)
- [ ] Конкретные числа везде - не «много», а «25.000»
- [ ] Тон - на «ты» в action-блоке, «мы» для со-причастности
