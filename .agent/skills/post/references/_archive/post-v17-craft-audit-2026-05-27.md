### P1. Headline

**Original:**
> <твой-хэндл> у меня 6К подписчиков. Продаёт больше, чем чужие каналы с 20К

**Check:**
- U1 Presence: Y - «у меня»
- U2 Imagery: N - нет картинки
- U3 Emotion: N - нет reaction-маркера
- U4 Sensory: N
- U5 Rhythm: N - два средних предложения без contrast
- U6 Specific: Y - 6К / 20К
- U7 Voice: N - neutral

**Что отсутствует:** reaction-emoji (P2) ИЛИ paradox-marker как в 2231 «🫠 Меня уволили со СВОЕГО». Headline звучит как заявление, не как **удивление автора**.

**Rewrite:**
> 🤯 <твой-хэндл> у меня 6К подписчиков. А продаёт больше, чем чужие каналы с 20К
>
> Сижу офигевший

(Pattern 2331 «сижу офигевший» + reaction-emoji 🤯 inline)

### P2. «Сижу сейчас вечером в Краснодаре»

**Original:**
> Сижу сейчас вечером в Краснодаре, разбираю последние оплаты за выходные. Не верю что так получилось. Думал, нужны 50К подписчиков чтобы пошли первые оплаты. Оказалось не нужны

**Check:**
- U1 Presence: Y - 4 first-person маркера
- U2 Imagery: N - никакой картинки, нет «с видом на X / у окна / за ноутом»
- U3 Emotion: weak - «не верю» есть, но плоско
- U4 Sensory: weak - есть город+время, но нет activity-anchor
- U5 Rhythm: N - все 4 предложения средние (8-10 слов)
- U6 Specific: weak - «последние оплаты» абстрактно
- U7 Voice: N - нейтрально

**Что отсутствует:** sensory anchor P4 (где конкретно - балкон / кафе / офис?), reaction-state P3 («офигел / закайфовал»), one-word финал P8.

**Rewrite:**
> Сижу вечером на балконе в Краснодаре, открыл <твой-хэндл>, разбираю оплаты за выходные. 5 уведомлений за 2 дня
>
> Думал, нужны 50К подписчиков чтобы пошли первые оплаты
>
> Оказалось - нет

(Pattern P4 «балкон» / P6 specifity «5 уведомлений за 2 дня» - verbatim 2042 «по 5+ автооплат каждый день» / P8 one-word финал «нет»)

## 5-7 craft rules для добавления в _voice-TEMPLATE v2.1

Эти правила выводятся из паттерна провала именно ЭТОГО поста (build-in-public о собственной воронке). 4 из них уже есть в v2.0 8-уровневого ground truth, но v17 их пропустил - значит rule force недостаточный, нужно усиление.

### Rule R1. Build-in-public POST требует ≥1 sensory anchor в первых 2 параграфах

**Trigger:** post-type = personal-result / build-in-public / 6K vs 20K / любой «я что-то сделал».
**Mandatory:** P4 (place+time+activity) в hook ИЛИ во втором параграфе. Без него пост звучит как business-tweet.
**Verbatim модели:**
- 2186 «3 шикарнейших дня в пригородах Геленджика»
- 2227 «люди сидят до 3 утра в Claude Code»
- 2295 «вайбкодил с видом на море»

**Failure mode v17:** «Сижу сейчас вечером в Краснодаре» - city + time есть, но **где конкретно** (балкон / кафе / у окна) и **activity** (открыл бот / разбираю экран статистики) отсутствуют. Anchor получается полу-готовый.

### Rule R2. Сравнение «X vs Y» (мой результат vs чужой) требует имени/роли+ниши для X

**Trigger:** «один X», «у одного парня», «многие ребята».
**Mandatory:** P10 - заменить на «ученик по [ниша]» / «знакомый из [роль]» / реальное имя.
**Verbatim модели:**
- 2271 «<имя ученика>, <возраст>. Бывший <профессия>»
- 2287 «ученик по зарубежке вышел на $100к+»

**Failure mode v17:** «У одного парня» - ground truth прямо называет это ANTI-pattern. Не «один пацан / один парень / один эксперт».

### Rule R3. Tutorial-секция («большинство делает X, надо делать Y») требует «Я сделал наоборот» в первой строке

**Trigger:** prescriptive-сегмент в build-in-public посте.
**Mandatory:** P1 inject в первое предложение tutorial-секции. Без него tutorial звучит как третье-личный совет коуча.
**Verbatim модели:**
- 2293 «Я решил, что хочу помочь рынку»
- 2305 «Я сделал глубокий аналитический ресеч»

**Failure mode v17:** «Большинство копят... Наоборот работает лучше» - обезличенно. Превращается в «совет», не «свидетельство».

### Rule R4. Описание product/tool/process требует ≥1 авторский-глагол

**Trigger:** «собрал сайт», «настроил бота», «написал контент».
**Mandatory:** P7 - заменить generic verbs на специфичные («прокинул / залил / завайбкодил / прокидываю / залип / бахнул / допилил / выкатил»).
**Whitelist verbs:** прокинул, завайбкодил, залил, бахнул, допилил, прокидываю, выкатил, залип, поднял, снёс.

**Failure mode v17:** «Контент написал не сам, спросил Claude». «Спросил» - нейтрально. «Прокинул prompt» - авторское.

### Rule R5. Reaction-state в первом лице ≥1 mandatory в любом personal-result посте

**Trigger:** post-type = personal-result.
**Mandatory:** P3 один из этих оборотов: «сижу офигевший», «сижу не верю», «сижу и не понимаю», «закайфовал», «жестко включилось», «БЕДА» (CAPS), «офигел».
**Verbatim модели:**
- 2331 «сижу офигевший»
- 2094 «жестко включилось внутреннее FOMO»
- 2096 «БЕДА»

**Failure mode v17:** «Не верю что так получилось» - функционально equivalent, но плоско, без body-posture. «Сижу офигевший» = body + emotion в 2 слова.

### Rule R6. Народная метафора-картинка ≥1 mandatory в постах >1500 chars

**Trigger:** длина >1500 chars.
**Mandatory:** P5 - одна из whitelist метафор: разбитое корыто / коса по рынку / дырка в ванной / у моря погоды / пень колоду / ласточка / матрица / льётся (про трафик/деньги/просмотры).
**Verbatim модели:**
- 2195 «дырка в ванной + кран + резервуар»
- 2290 «коса пошла по рынку и рубит тысячами»

**Failure mode v17:** 1300+ chars, **0 метафор-картинок**. Полностью прямой бытовой язык. Это и есть «нет imagery, нет красочности».

### Rule R7. Скобочный meta-comment ≥1 для long-постов про tool/process

**Trigger:** длина >1500 chars И описание собственного workflow.
**Mandatory:** P9 - одна скобочная вставка авторского голоса.

**Failure mode v17:** 0 скобок, 0 авторских вставок. Пост звучит как linear argument, без «голоса на полях».

## Что v17 пропускает категорически (3 systemic absences)

### Absence 1 - Vivid imagery (U2 = 0/13 параграфов)
**Ни одной метафоры-картинки.** Ground truth даёт 9 verbatim моделей (разбитое корыто / коса / ванна / матрица / ласточка / пень колоду / море погоды / 5 глаголов отдыха / геолокации). v17 = 0. Это и есть пункт #1 в фидбеке автора «нет красочности».

### Absence 2 - Voice register (U7 = 0/13)
**Ни одного авторская просторечия.** Нет «прокинул / по зарубежке / залил / без надрыва / прокидываю / залип / БЕДА / офигел». Глаголы - «собрал / написал / спросил / разбираю» - нейтрально-стерильны. Это пункт #2 «лексика невкусная».

### Absence 3 - Emotional beats inside narrative (U3 = 0/13)
**Ни одной reaction-state в первом лице, ни одного reaction-emoji в narrative.** «Не верю» есть, но это констатация, не emotional beat. Нет «🤯 / 🔥 / 😁 / 🫠» внутри тела поста, нет «сижу офигевший», нет CAPS-маркера, нет «(это делает ИИ-агент)». Это пункт #3 «нет автора-как-человека».
