## Новые паттерны, не было в ru-author-patterns.md v1

1. **CAPS-headline tool-drop без emoji-anchor** (Халилов: «35 МОИХ АВТОРСКИХ УСИЛИТЕЛЕЙ, КОТОРЫЕ УБЕРУТ НЕЙРОСЕТЕВУЮ ШЕЛУХУ», «АГЕНТ ДАМИРА:...», «НАЧИНАЕМ НОВЫЙ СЕЗОН "ПРОМТА ДНЯ"»). CAPS вместо emoji в начале как visual anchor - отдельный приём, новый паттерн для автора (с учётом memory: emoji в начале headline устаревшее - CAPS может быть заменой для tool-drop).

2. **Тонкий-моно-хук-эмоция перед длинным постом** (Афонина «Мррррррррррр», ~20 chars как самостоятельный пост-разделитель). Микро-пост как pacing между длинными tool-drop'ами в фиде.

3. **Manifest-как-длинный-пост 2500+ chars без CTA** (Замесин «Вы обязаны быть экспертом в том, чему вы учите», «Я верю, что в ближайшие 10 лет...»). Чистая идеология без коммерции, доверие через позицию. Для автора переносимо: «манифест без CTA» как самостоятельный пост-тип.

4. **Build-in-public для подготовки практикума** (Петкова: «уровень подготовки презы», «пока только черновик»). Не готовый продукт, а процесс подготовки + 15-сек видео = build-in-public как промо без агрессивной продажи.

5. **Post-event gratitude цепочка** (Арина: 2 поста подряд про день рождения). Multi-post serial-storytelling вокруг одного события - переносимо для запусков автора (продолжение в следующем посте).

6. **Tool-drop с провокационным CAPS-title для prompt** (Нагорнова: «7 способов съесть трусы и обесшумить гречку», «Цыпа, ори втихаря!», «Волк овладел методом сократической иронии»). Абсурдный заголовок над серьёзным промптом - приём как curiosity-bait.

7. **"Хватит X" как edukative-hook** (Ширяев: «Хватит усложнять себе жизнь, пожалуйста 🙏»). Императив-запрет + вежливая формула + emoji = soft-aggressive opener. Можно адаптировать.

8. **Audio-podcast embed как primary медиа** (Палий, пост 1: «Послушайте аудиоподкаст»). Длинный пост + аудио - формат, который в v1 ru-author-patterns не был отмечен. автор может тестировать как замену text-only длинному.

## Применение для skill post

При выборе паттерна в `02-structure.md` skill должен учитывать:

1. **CAPS-headline tool-drop** - новый альтернативный приём для типа tool-drop, кроме emoji-anchor (учитывая memory: emoji в начале headline устаревшее).
2. **Манифест без CTA** - новый пост-тип «манифест», добавить в registry если ещё нет.
3. **Build-in-public for upcoming event** - отдельный sub-pattern промо: не «купи сейчас», а «вот как я готовлюсь».
4. **Tool-drop с провокационным абсурдным title** (Нагорнова паттерн) - curiosity-bait как замена прямому headline.
5. **Audio-podcast embedded** - формат для длинного контента, альтернатива чистому тексту.

Не применять:
- Чужие фирменные обороты Халилова (CAPS «35 МОИХ АВТОРСКИХ УСИЛИТЕЛЕЙ») - клонирование.
- Чужие фирменные обороты Нагорновой (абсурд-headlines типа «Цыпа, ори втихаря!») - узнаваемая подпись.
- Чужие фирменные CTA («велком на бесплатный разбор» Ширяева, «жду огонечков 🔥» Петковой).
