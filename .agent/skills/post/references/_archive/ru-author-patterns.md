# RU-Author Patterns - что переносимо в post / что НЕТ

**Last refresh:** 2026-05-27 - см. `references/competitors-refresh-2026-05-27.md` для свежих постов (5 на канал, 8 из 10 fetched, 2 полу-приватных).

## Источник

Применение: skill при структурной фазе `02-structure.md` обращается к этому файлу для (а) подбора приёма под тип поста, (б) проверки что выбранный приём не клонирует чужого автора. White-list / black-list patterns маркированы явно.

## 1. Илья Палий (@mirneyrosetey, 33.7K подписчиков)

### МОЖНО переносить
1. **`.skill` / PDF файл прямо в посте, без лендинга** (frictionless lead-magnet)
   - Пример verbatim: «Подготовил инструкцию, как создать ИИ-модель, которая будет вести блог за тебя» - раздача PDF без email-gate
   - Адаптация для автора: **`.skill` файл «Сборка цифрового продукта на Lovable» прямо в TG** + 30-сек видео-демо. Палий раздаёт текст промптов - автор раздаёт **рабочие сборки** (это на ступеньку выше по value).

2. **Хук «X больше не нужен / X за N минут»** (Пост 6 «Дизайнеры не нужны»)
   - Пример verbatim: «Дизайнеры больше не нужны! Вчера научил Claude делать карусели за 10 минут»
   - Структура: провокация + контр-обещание + личный опыт «вчера научил» + шоковая мерка времени
   - Адаптация: «Разработчики больше не нужны - вчера собрал работающий продукт за 2 часа» с реальным скрином / live-ссылкой (не пустой провокацией)

3. **Календарный инфоповод + подарок** (Пост 5 «Пасхальный пак промптов»)
   - Пример verbatim: «С праздником Светлой Пасхи! И пока вы отдыхаете, подготовил подарок»
   - Когда: на каждом известном празднике (НГ, 8.03, Пасха, день программиста, Хеллоуин)
   - Адаптация: «День программиста - собрал для тебя готовый билд X», «8 марта - промпт-пак для женщин-экспертов»

4. **Цифра-дисциплина в хуке** (Пост 7 «125 недель подряд»)
   - Пример verbatim: «125 недель подряд я публикую контент без остановки»
   - Функция: proof-of-discipline снимает возражение «у меня не получится»
   - Адаптация: «**X недель подряд я веду стрим «Билд за час»**» - автор как ритм. Цифра «X недель» = дешёвая authority.

5. **Скрин из лички ученика как UGC-кейс** (Пост 8 «Лиза заработала 940 000 ₽»)
   - Пример verbatim: «Лиза заработала 940 000 рублей за одну неделю» + форвард скрина сообщения
   - Когда: под open-cart и за 5-7 дней до запуска
   - Адаптация: скрин Telegram-диалога с учеником про «первый платёж 5К ₽» - **без плашки, без шаблонной маркетинговой обёртки**. Только скрин + 2 строки контекста + ссылка на live-продукт.

### НЕ переносить
1. **Tripwire 1 000 ₽** - затягивает в low-ticket гонку, противоречит модели автора (<твоя цена> курс)
2. **Лексика «Спринт / Реалити / Поток / учитель в США / забирай»** - клонирование = сливание с воронкой Палия
3. **Travel-флекс «Бали / SF / Golden Gate»** - триггерит возражение «инфоцыган»
4. **Громкие cifры выручки в первой строке без proof** - без UGC скрина выглядит как фейк
5. **Множественные лид-магниты** - Палий каждую неделю новый, автор играет в **один и тот же 2-3 недели** = удваивает регистрации

## 2. Ваня Замесин (@zamesin, 49.3K подписчиков, ER ~40%)

### МОЖНО переносить
1. **Манифест «[Профессия], пришло наше время»** (Пост 1)
   - Пример verbatim: «Продакты, пришло наше время.»
   - Структура: обращение к племени → история «X профукал эпоху» → инсайт «AI = аналогичная эпоха» → CTA
   - Адаптация: «Эксперты, пришло ваше время» - **смягчить агрессию методолога** (у Замесина «обязан», у автора - «можешь / пора / попробуй»)

2. **Цифра автора в первой строке** (Пост 3)
   - Пример verbatim: «Я два месяца вайбкожу - три навайбкоженных продукта продались на 3.7 млн рублей за январь.»
   - Когда: раз в 2-3 недели как proof-of-method
   - Адаптация: точные цифры из <число учеников> автора - «За 30 дней собрал 3 продукта учеников - общая выручка 230К ₽»

3. **Длинная личная эссе с philosophical inversion** (Пост 5 «Tudor watches»)
   - Пример verbatim: «Как я разблокировал свои желания через покупку дорогих часов»
   - Структура: контекст «давно был зажат» → событие → инсайт «желания первичны» → философский вывод
   - Адаптация: длинные эссе про «страх собрать что-то своими руками» / «зажатость эксперта», без манерности и агрессии

4. **Краудсорсинг название/идея через пост** (Пост 7, 10)
   - Пример verbatim: «Помогите придумать новое название для методологии AURA», «Есть шальная идейка сделать обучение по вайбкодингу для подростков»
   - Когда: при выводе нового модуля / продукта на тёплую базу
   - Адаптация: «Помогите назвать модуль курса - варианты в комментариях». Высокий ER через комментарии = pre-launch warm-up

5. **Видео-кейсы учеников с цифрами удовлетворённости** (Пост 6)
   - Пример verbatim: «96% не-программистов вайбкодят... удовлетворённость 9.6/10»
   - Адаптация: не просто кейсы, а **с цифрой satisfaction-score** + точным процентом «не-IT-эксперта дошли до конца»

### НЕ переносить
1. **Манифест-агрессия «должен вайбкодить»** - для аватара автора пугающе
2. **B2B-лексика** (сегменты, джобы, ROMI) - забивает поле «инженер-предприниматель», автор целится в эксперта-новичка
3. **Прямое называние конкурентов** («вам не нужны Lovable, Replit, n8n, Cursor») - автор играет в no-attack
4. **Tudor / status-flex / Москва-метания** - для аватара автора это рискованный lifestyle-фрейм
5. **«1+1=11» парадокс-формулы** - клонирование, у Замесина это идентичность

## 3. Мари Афонина (@mari_zapuski, 80.6K подписчиков)

### МОЖНО переносить
1. **Анафора «Я поняла, что…» × 3-5** (Пост 8)
   - Пример verbatim: «Я поняла, что окончательно е*нулась перешла на ai-first мышление…»
   - Структура: признание → 3-5 анафор «Я поняла, что…» → якорь в новой идентичности
   - Адаптация для мужского регистра автора: «**Я заметил, что…**» / «**До меня дошло, что…**» - один пост такого типа = эталон warmth-peak

2. **One-liner посреди продуктовых анонсов** (Пост 3 «надо что-нибудь завайбкодить»)
   - Пример verbatim: «😁 надо что-нибудь завайбкодить…» (10.6K просмотров на 8-15 слов!)
   - Когда: 1-2 раза в неделю как разгрузка
   - Адаптация: «**сегодня собрал бота-помощника за 25 минут**» / «**пятница = билд-пятница**» - без CTA, без объяснения

3. **Открытая декомпозиция цены продукта + доп. расходов** (Пост 6)
   - Пример verbatim: «39 990 руб + 4-12.5К ₽ на инструменты»
   - Адаптация: «**49 000 ₽ за курс + 2-5К ₽ на Lovable/Claude Pro в первый месяц**» - снимает возражение «сколько реально это всё стоит»

4. **«Самый быстрый X в моей жизни - N»** (Пост 7)
   - Пример verbatim: «Здесь был самый быстрый запуск в моей жизни - 2 часа 40 минут»
   - Адаптация: «**Самый быстрый билд в моей жизни - 47 минут**» (на стриме, со ссылкой на live)

5. **Бытовая деталь как identifying anchor** (Пост 4 «Два года ела роллы»)
   - Пример verbatim: «Однажды я два года ничего не делала, кроме просмотра сериалов и поедания роллов.»
   - Адаптация: автор использует свой быт - конкретные детали («хрущёвка во Владимире», название кофе, погода, бытовые мелочи). Без флекса, конкретика бытовая

### НЕ переносить
1. **«Девичий вайб» / «мур мур / малыш / поросёнок»** - женский регистр, не для автора
2. **Мат-эвфемизмы «е*нулась / ё*аный»** - её фишка, у автора инженерный регистр
3. **CAPSLOCK «АААААА»** - её impulse-маркер, для автора = непрофессиональность
4. **Геополитические манифесты** - поляризует и отравляет EN-расширение
5. **Хаос анонсов** - у неё «искренность», у автора = непрофессионально с тёплой базой
6. **Эзотерический слой подачи** (Ио, Депп, деймоны) - автор держит инженерно-практичный регистр

## 4. АРИНА АЛЕКС (@ArinaAlexx, 99.6K подписчиков, IG 1.1M)

### МОЖНО переносить
1. **Воронка «бесплатный МК» в каждом посте** (общая черта - почти 85-90% постов ведут на один лендинг)
   - Адаптация: **«бесплатный стрим Билд за час»** ссылается из почти каждого поста окна прогрева. Один единый CTA-якорь = удваивает регистрации

2. **«За X минут» как мерка результата** (Посты 1, 3, 7)
   - Пример verbatim: «Эти фото к 8 марта за 2 минуты нужно сделать каждому»
   - Адаптация: «**Собрал работающий чат-бот за 47 минут**», «**Деплой за 12 минут**», «**Первый платёж за 7 часов**» - конкретика + время = stop-scroll

3. **Календарный инфоповод + готовый AI-промпт прямо в посте** (Пост 7)
   - Адаптация: «**Промпт для 8 марта**», «**Билд для НГ-открытки родителям**», «**Приложение к 23 февраля**» - автор выкладывает рабочий **билд** (не текст промпта), который пользователь может зайти и попробовать

4. **Серийность «Часть N» / «Подборка №N»** (Пост 10)
   - Пример verbatim: «Список брендов, которые сотрудничают с микроблогерами» (Часть 5)
   - Адаптация: «**Билд дня №34**», «**Хроники первой продажи №7**», «**Скилл недели №12**»

5. **3-шаговый структурный пост через AI-инструмент** (Пост 3)
   - Пример verbatim: «3-шаговая инструкция через Kling AI bot» с эмодзи 1️⃣2️⃣3️⃣
   - Адаптация: «**3 шага: открыть Lovable → описать продукт → опубликовать**» с эмодзи 1️⃣2️⃣3️⃣ и ссылкой на live

6. **Шок-приз вместо цифры выручки** (Пост 8 «бесплатный айфон 17»)
   - Адаптация: **«Купила Mac за подписку на свой бот»** / **«Заплатил курс из первого деплоя»** - конкретный материальный приз = понятнее, чем «250К ₽»

### НЕ переносить
1. **Лексика «девочки / красотка / пользуемся своей красотой»** - её женский регистр
2. **«Афигеть / красотка / милашка»** - identity-маркеры её ниши, копировать = клонировать
3. **Тема «овуляция / цикл»** - её territory
4. **2-4 поста в день в постоянном режиме** - только в окне прогрева, не как baseline
5. **Self-deprecating provocation «Я девушка с невероятно красивой внешностью»** - её umbrage-bait paradox, мужская вариация требует other angle

## 5. Анжела Петкова (@anjela_p, 65.5K подписчиков, ER 10.5%)

### МОЖНО переносить
1. **Серия из 2-3 коротких постов FOMO-волной** (Посты 8-9)
   - Пример verbatim: «Анонс → не прошло часа, 25% мест → обвал лички 5...4...3...2...1»
   - Когда: в окне продаж (3-5 дней до закрытия cart), не для регулярного контента
   - **КРИТИЧНО:** если 30% мест за час - не выдумывать. Иначе бьёт по доверию

2. **Формула «Дайте мне X недель и я Y»** (Пост 6)
   - Пример verbatim: «Дайте мне 1,5 месяца и мы перестроим вашу работу так, что нейронка будет закрывать 80% задач за вас»
   - Адаптация: **«Дай мне 8 недель и я научу тебя собрать первый цифровой продукт + получить первые продажи в рублях»**

3. **«Кому НЕ стоит идти на X» - анти-кейс как hook**
   - Когда: для отстройки + квалификации лида в неделю до open cart
   - Адаптация: **«Кому НЕ нужен вайбкодинг»** = пост про криптанов / нанятых разработчиков / тех у кого «бизнес уже масштабирован»

4. **Бытовой женский вирал-промпт как side-channel** (Пост 1)
   - Адаптация для автора: **«промпт для презентации/резюме/lending за 5 минут»** или **«готовый билд для свадебного приглашения за час»** - выход за ядро вайбкодинга в боковую аудиторию
   - **НЕ копировать «девочки/вахвахвах»** - другой регистр

5. **UGC-скрин подписчика сразу за вирал-постом** (Пост 2)
   - Пример verbatim: «Вахвахвах) Анжела, спасибо огромное» + скрин сообщения
   - Когда: через 1-2 дня после вирал-поста для social-proof закрепления
   - Адаптация: скриншот сообщения ученика «спасибо, собрал свой первый продукт» + короткая обёртка 2-3 строки

### НЕ переносить
1. **DM-only воронка с ценой в личке** - не масштабируется для <твоя цена> ₽ при холодном трафике (автор играет в публичный лендинг)
2. **Хайп-сленг «вахвахвах / шоооке / круть полная / девочки»** - оттолкнёт мужскую часть аватара
3. **Лайфстайл-флекс ООН / Япония / Азия** - Анжела продаёт через статус; у автора пока такого капитала нет
4. **«Завайбкодили» в негативном контексте** (Пост 3 «балуются с нейронкой») - автор не должен подхватывать
5. **Тройные скобки «)))»** как маркер тона - её фишка

## 6. Наташа Нагорнова (@n_nagornova, 9.<N>K подписчиков, ER 21%)

### МОЖНО переносить
1. **Прозвища как замена технических терминов** (Посты 1, 3, 7)
   - Пример verbatim: «Веночек Собчак», «Зинаида Петровна выдаст рецепт», «5 цыпляток и курица-перфекционист»
   - Функция: снятие технологического страха у не-технической аудитории
   - Адаптация: автор **не повторяет «цыплёнок/хвостик»** (чужая лексика). Своя метафора: «**сборка**», «**билд**», «**мини-продукт**» в виде **персонифицированных билдов** («сборка-Психолог», «сборка-Юрист», «сборка-Нутрициолог»). 5-7 шаблонов с одной функцией каждый, не 60+

2. **«Часть 1 / Часть 2» серийность** (общий приём)
   - Адаптация: «**Билд дня №N**» (ежедневная нумерованная), «**Хроники первой продажи №N**» (еженедельный сериал одного героя), «**Цифры запуска №N**»

3. **«P.S. экшн-курс / отзывы / чат» подвал** (общий приём)
   - Когда: в окне прогрева, не на регулярном контенте 365
   - Адаптация: **тихий P.S.** в каждом посте окна продаж + ссылка на pinned-пост с галереей продуктов учеников

4. **Адресность по нишам** («Психологи и помогаторы, вы тут?»)
   - Адаптация: «**Юристы, вы тут?**» / «**Психологи, вы тут?**» / «**Нутрициологи, вы тут?**» - отдельный пост под каждую вертикаль с конкретным шаблоном

5. **«Я не Спилберг» - самоуничижение для снятия синдрома самозванца** (Пост 10)
   - Пример verbatim: «Почему я трачу на контент 1 день, хотя с цыплятами легко за 5 минут?»
   - Адаптация: «**Я не разработчик. Я гуманитарий, который собрал свой продукт за вечер**»

6. **Закрытый чат отзывов как отдельный лид-магнит**
   - Адаптация: отдельная TG-группа «**Продукты учеников**» с галереей кейсов - живой ленточный поток скриншотов

### НЕ переносить
1. **«Цыплёнок/хвостик/субботник»** - её лексика, клонирование
2. **Мат-эвфемизмы «г#вно/обос#$%ся/Ёпрст»** - смешает мужскую/женскую часть аватара автора
3. **Перегруз 60+ персонажей с именами** - путаница (5-7 шаблонов с одной функцией)
4. **«Цена в личке»** - не масштабируется
5. **«Топ-10 за месяц»** - у автора с большой базой работает хуже (низкое engagement на ретро-постах)
6. **«Хитроопый треугольник» / «Тайга»** - её фирменные фреймворки, не подхватывать

## 7. Павел Ширяев (@pavelshiriaev, 19.8K подписчиков)

### МОЖНО переносить
1. **Кодовое слово в ЛС как универсальный CTA** (общий приём)
   - Пример verbatim: «ДОСТУП» / «ТЕСТ-ДРАЙВ» - кодовые слова в ЛС
   - Адаптация: **«СБОРКА» / «ПРОТОТИП» / «БИЛД»** = одно слово в ЛС → бот выдаёт бесплатный курс / гайд / шаблон. Измеримо, теплит через DM, не требует лендинга

2. **Формат «диалог Паши с новичком»** (Пост 6)
   - Пример verbatim: «Паша, нужно ли мне с 200 подписчиков заморачиваться с нейронками?» + ответ Паши + 5 возражений отработано
   - Адаптация: **«автор, нужно ли мне с 0 подписчиков заморачиваться с вайбкодингом?»** = репост возражения от лица новичка → ответ → 5 возражений за один пост

3. **«Раньше / сейчас» с цифрами в рублях и часах** (Пост 2)
   - Пример verbatim: «Тильда больше не нужна... вчера собрал сайт голосовыми через Claude Code за 20 минут»
   - Адаптация: **«Раньше: 2 недели + 30К ₽ разработчику. Сейчас: 2 часа на Lovable, 0 ₽.»** - конкретика, шок-сравнение

4. **Глубокие статьи на сайте + slug-ссылки в каждом посте**
   - Адаптация: **сайт `<твой-домен>/blog/<slug>`** с глубокими статьями. Каждый TG-пост = тизер + ссылка. **НЕ Telegraph / Substack** (memory rule «Один сайт для всего контента»)

5. **Хук «X больше не нужен / X за 20 минут вместо 2 недель»** (Пост 2)
   - Пример verbatim: «Тильда больше не нужна»
   - Адаптация: **«Сценарист прогрева больше не нужен»**, но с реальным live-продуктом или скрином (не пустой провокацией)

6. **Тест-как-лид-магнит**
   - Адаптация: **«5 вопросов: на каком ты этапе вайбкодинга?»**

### НЕ переносить
1. **Лексика «связки/конвертеры/КЭВ/нейроагент/нейропаша/нейрокуратор»** = забитая маркетологами поляна
2. **Travel-флекс «40 стран / Япония / Бангкок»** - у Ширяева работает за счёт 12-летнего бэкграунда; у автора пока нет такого капитала
3. **«5-7 заявок в день»** - операционка, не актив
4. **«12 лет в маркетинге»** - Ширяев на этом стоит, автор не должен играть на этой поляне
5. **«Хватит какать в своём блоге»** - его просторечие, у автора инженерно-практичный регистр

   - Адаптация: 8 марта, НГ, день программиста (13 сентября), Пасха, Хеллоуин - каждый праздник имеет свой автор-билд

6. **Хэштег-рубрика #ШколаПромтИнжиниринга**

   - Адаптация: формат заголовка-шаблона работает. У автора **сильнее** - <число учеников> + <число> выпускников <метрики учеников>/мес

8. **Конкурс «X моей мечты»** (Пост 10)
   - Адаптация: **«Микро-SaaS моей мечты»** → победителю автор собирает MVP за вечер. UGC + социальное доказательство

2. **«Друзья!» / «Как Вы наверняка знаете»** - патерналистский регистр
3. **«Промт» через «т»** - его особенность после 168-ФЗ; автор: **«промпт»** нормально
4. **МОНО-фокус на промптах** - Дамир раздаёт текст, у автора **рабочие билды**
5. **«Прекрасные дамы»** - старо-русский почтительный регистр, не автора

## 9. Артемий Миллер (его методология, @etalon_channel, ~1M подписчиков)

### МОЖНО переносить
1. **Формула «Один X = N» парадокс** (Пост 1)
   - Пример verbatim: «Один человек. Эффективность команды.»
   - Адаптация: **«Один эксперт. Доход маленькой студии.»** или **«1 ученик + AI = команда из 5»** - но **подкреплено реальными кейсами** (<число учеников>, <число> выпускников)

2. **Тройной враг через конкретные цифры** (Посты 3, 8, 9)
   - Пример verbatim: «5-7 человек в штате от 500 000 ₽ в месяц», «Подрядчики: 200-500 000 ₽ и 2-3 месяца», «Открывал ChatGPT, Claude, Cursor. Получал какую-то фигню и бросал»
   - Адаптация для автора: **«Курсомания / продюсерская модель / профессионализация»** через конкретные цифры: «**40К на курсе - и что дальше?**», «**Продюсер забирает 30-50% прибыли**», «**6 месяцев в школе - и ты не вайбкодер, ты карьерист**»

3. **Шок-цифра в первой строке** (Посты 4, 5)
   - Пример verbatim: «3000 действий за сутки», «$100 себестоимость vs $2-3К»
   - Адаптация: **«13 570 ₽ за месяц с продукта психолога Ани»** или **«$340 MRR за 2 недели на Lovable»** - **рублёвые цифры, achievable планка, не миллионы**

4. **Формат «параллельная сборка» «Я делаю на эфирах. Ты делаешь рядом»** (Пост 7)
   - Пример verbatim: «Я делаю свой проект на эфирах. Ты делаешь свой рядом. 1+1=11»
   - Адаптация: **«Стрим «Билд за час»: я собираю продукт на экране. Ты собираешь свой параллельно»** - забираем формулу, **не Identity «Архитектор»**

5. **Bonus-stack под дедлайн с risk reversal** (Пост 10)
   - Пример verbatim: «5 дней без обязательств - возврат полный»
   - Адаптация: **«14 дней, полный возврат» + 4-5 бонусов с дедлайном**

### НЕ переносить
1. **Identity «Архитектор ИИ-систем»** - статусная игра, не первая продажа. автор: **«эксперт-ремесленник»** / **«цифровой ремесленник»**
2. **Двойной фейк-якорь (100К → 75К → 50К)** - инфоцыганский приём на одном лендинге одновременно
3. **«Перекладывай смыслы в код»** - его термин-метафора
4. **ЦА предприниматели/стартаперы** - его поляна; автор: эксперт-новичок без техфона
5. **«Балуются с нейронкой»** - клонирование с Анжелы Петковой
6. **Отсутствие кейсов учеников** - это слабая точка Миллера, у автора это сила
