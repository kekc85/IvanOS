# Hook-Story-Offer (Brunson) - Universal TG Scaffold

## Source
- Автор: Russell Brunson (co-founder ClickFunnels, $1B+ valuation)
- Где описано: книги "Traffic Secrets" + "Expert Secrets" + подкаст "The Russell Brunson Show"

## Главный принцип (Brunson verbatim)
> *"When you break it down, if there's an issue in your funnel, it's always related to either the hook, the story, or the offer."*

Если что-то не работает - проблема всегда в одном из этих трёх. Каждый TG-пост автора проходит check: Hook? Story? Offer (или mini-offer / CTA)?

## Структура (3 компонента)

### Hook (1-3 строки в начале)
**Brunson verbatim:** *"What grabs your audience's attention in a fraction of a second - provocative headline, bold promise, visually arresting image."*

**Функция:** pattern interrupt → curiosity → drives humans to want to know more

**Tactics:**
- Bold claim / contrarian statement
- Concrete number / result
- Question that hits pain
- Visual / image / pattern interrupt

**TG-адаптация:**
- Hook = 1-2 строки, помещается в preview-zone push-уведомления
- ≤180 символов (правило Maxwell Ross пункт 2)
- Emoji-маркер часто работает (🆘 💰 🫠 ❗️ 📍)

**Антипаттерны:**
- «Я хочу рассказать…» / «Сегодня мы поговорим о…» - vague
- Generic greeting («Привет, друзья!»)
- >2 строки до сути
- Несколько вопросов подряд

### Story (середина, 60-80% длины поста)
**Brunson verbatim:** *"Once your audience is hooked, story keeps them engaged. How you build connection, show empathy, position solution."*

**Функция:** retention + emotional connection + positioning

**Tactics:**
- Personal vulnerability / origin story
- Customer transformation
- "I was in your shoes" empathy
- Conflict → resolution arc

**TG-адаптация:**
- Story = личный момент, customer case, конкретная ситуация
- Конкретные числа, имена, места (per Maxwell Ross pt.7 «believable»)
- Single idea (per Bush + Cole atomic essay)
- 1/3/1 paragraph rhythm
- Rate of revelation: каждое предложение push forward

**Антипаттерны:**
- Сухая теория без личного момента
- 2 параллельные story в одном посте
- Generic claims без конкретики
- Самовлюблённость без Golden Intersection (вопроса читателя)

### Offer / CTA (финал, последние 1-3 строки)
**Brunson verbatim:** *"The irresistible offer that makes them want to buy - right now, packaged in a way that feels like a no-brainer."*

**Функция:** convert attention + trust → action

**Tactics (hard offer):**
- Stack value (multiple components)
- Reverse pricing (компонент A worth $X, B worth $Y, всё за $Z)
- Urgency / scarcity
- Guarantee
- Specific CTA

**TG-адаптация (4 типа CTA):**
- **Hard:** «Запись на <твоё событие> по ссылке» - sales-пост
- **Mini:** «Сохрани этот пост», «Ставь 🔥 если зашло» - engagement-пост
- **Soft:** «Что думаешь? Напиши» - comment / community-пост
- **Linker:** «Завтра разберём X, не пропусти» - retention / serial-пост

**Антипаттерны:**
- Hard sales offer в каждом посте (TG = mix, не funnel)
- 2 CTA одновременно (sales + share) → reader confused
- CTA без связи с темой поста (выпадение из narrative)
- Stack-value pricing для не-launch постов (overkill)

## Жёсткое правило для skill

Каждый пост = всегда HSO. Если хотя бы один элемент missing - не публикуем. Skill `04-review.md` проверяет наличие всех 3 компонентов.

## Diagnostic - какой компонент слаб

| Симптом | Слабый компонент | Fix |
|---|---|---|
| Низкие просмотры (push не открывается) | **Hook** | Переписать первую строку: добавить цифру / парадокс / pattern interrupt. Сократить до 1-2 строк. |
| Высокие просмотры, низкая дочитываемость | **Story** | Story слабая или generic. Добавить личную деталь, конкретное число, vulnerability moment. Проверить 1/3/1 rhythm. |
| Высокая дочитываемость, низкая конверсия (клики / ответы / реакции) | **Offer / CTA** | CTA не явный / не связан с темой / нет urgency. Сделать explicit ask, добавить mini-CTA если не sales. |
| Высокие просмотры, высокая дочитываемость, конверсия низкая, но реакции есть | **Offer mismatch** | Пост перевзел внимание, но CTA не подходит этой аудитории / этому моменту. Смягчить (soft → mini) или усилить (mini → hard). |

## Universal Frame для 8 типов post (mapping)

| Тип | Hook variant | Story variant | Offer variant |
|---|---|---|---|
| **short** (≤1500) | curiosity-promise / paradox / question | 1 личный момент / 1 быстрый кейс | mini-CTA: reaction / save |
| **long** (≤2500) | listicle с цифрой / shock-claim / news-jack | 3-act framework / step-by-step / разбор кейса | mini или hard: link на статью / лид-магнит |
| **tweet** (≤280) | one-liner провокация / question / aphorism | подразумевается, contained в hook | no-CTA или micro-reaction |
| **story** | paradox / cognitive dissonance | 3-актная narrative arc (был X, стал Y) | linker: «продолжение завтра» / mini |
| **personal** | personal-statement / values-claim | values + ethics + vulnerability | soft CTA или встроенный pivot (как 2295) |
| **build-in-public** | metric / milestone / shock-cifra | what I built + how + cost | mini-CTA или linker |
| **tool-drop** | product-name CAPS + benefit | альтруистическая рамка + 2-3 use cases | share-CTA («PS делитесь с товарищами») |
| **sales** | money-headline / urgency / scarcity | proof + transformation + value stack | hard CTA: link + dedline + guarantee |

## Примеры HSO из gold-standard автора

### Пример 1 - Crisis/News-jacking (Пост 2195, 2570 просмотров)

**Hook (verbatim):**
> «🆘 Завтра Telegрам может быть заблокирован! Что нужно сделать прямо сейчас?»

- Pattern interrupt: 🆘 emoji + alarm
- Bold claim: «может быть заблокирован»
- Question that hits pain: «Что нужно сделать прямо сейчас?»
- Лексический трюк: «Telegрам» (кириллическая «р») = обход + identity-маркер

**Story (verbatim фрагменты):**
> «Информация о возможной полной блокировке активно распространяется в СМИ, ссылающихся на источники в ведомствах и Кремле»
> «У меня в <город> он уже не работает ночью даже с VPN, в центре Москвы с мобильного интернета также ничего не работает»
> «99% "конкурентов" либо замедляют свой рост, либо просто ждут у моря погоды… Я решил пойти против правил и паники и УДВАИВАЮ свои мощности»

- СМИ + Кремль (proof, believability per Maxwell Ross pt.7)
- Personal verification (<город>, центр Москвы)
- Сравнение потерь и притока в цифрах (в исходнике оно шло образом «дырка в ванной + кран + резервуар» - это ПРИЁМ ДО правила п.49; работает в нём не картинка, а сопоставление двух потоков: сколько приходит против того, сколько уходит. Брать надо сопоставление с цифрами, картинку - нет, см. `references/metaphor-to-literal.md`)
- Reversal: тревога → паника → «я УДВАИВАЮ» (drama type contrast + reveal)

**Offer (verbatim):**
> «Ставьте 🔥»
> «📱 Вся внутрянка челленджа в моем Мах»

- Reaction-CTA (mini) + soft-link (linker)
- Двойной CTA, но они дополняют друг друга - reaction для общей публики + soft-link для тех, кто хочет deeper

**Comment:** классический HSO с pattern interrupt в Hook, persuasion arc в Story, layered CTA в Offer.

### Пример 2 - Build-in-public с twist (Пост 2231, 1940 просмотров)

**Hook (verbatim):**
> «🫠 Меня уволили со СВОЕГО контент-завода…»

- Paradox / cognitive dissonance: как можно уволить себя из собственного бизнеса?
- CAPS «СВОЕГО» подчёркивает парадокс
- 🫠 emoji + многоточие = cliffhanger

**Story (verbatim фрагменты):**
> «Claude Code официально автоматизировал всю генерацию роликов для контент-завода и сам создает трендовые форматы от СиДэнс до Клинг и ВЕО»
> «Claude сам зайдет в Хигсфилд, сам разработает промпт, сам сгенерит любой формат… буквально забирает контроль курсора мыши и клавиатуры»

- 3-актная хронология (2025 / начало 2026 / сейчас)
- Konkretika инструментов (Claude Code, Higgsfield, Seedance, Kling, Veo)
- Almost-SF образ «забирает контроль курсора мыши и клавиатуры»

**Offer (verbatim):**
> «👉🏻 Успеть забрать место и автоматизировать весь контент-завод с нуля»
> «Никогда еще вход в мир ИИ не был настолько доступен»

- Hard sales CTA (link + урдженси «успеть»)
- Aphorism close для emotional payoff

**Comment:** Hook=paradox самой высокой силы, Story делает payoff (хорошо, я не работаю - Claude работает), Offer pivot встроен в логику (если он автоматизировал - ты тоже можешь).

### Пример 3 - Personal/Values с мастерским pivot (Пост 2295, 1490 просмотров)

**Hook (verbatim):**
> «У меня все деды воевали»

- Personal-statement, голый факт без украшений
- Никаких эмодзи, никаких рамок
- Универсальный эмоциональный коннект (для RU-аудитории)

**Story (verbatim фрагменты):**
> «Половина погибли на войне, а половина прошли всю войну и вернулись раненными, быстро погибли на глазах близких дома»
> «Огромная цена ради того, чтобы мы с вами жили»
> «Нет больше той любви…» (Ин. 15:13)
> «я просто обязан ломать каждую трудность на моем пути в знак благодарности к подвигу нашего народа»
> «семьи, близких, коммьюнити и общества»

- Конкретные тяжёлые детали (proof)
- Библейская цитата с библиографической ссылкой
- Identity claim («обязан ломать каждую трудность»)
- Расширяющий список (от ближнего к дальнему)

**Offer (verbatim):**
> «а вот мой скромный вклад в нашу борьбу против алгоритмов и блокировок -> здесь»

- Мастерский pivot: слово «борьба» из патриотического narrative → «борьба» в смысле антибан-инструмента
- Soft-link, не push
- Pivot не разрушает торжественность, а вписан в narrative о «борьбе»

**Comment:** Самая высокая planka мастерства HSO. Story делает emotional load, Offer не торчит - он встроен в логику. Применимо для любого values / personal поста с soft-pivot к продукту.

## Применение в workflow

### `workflow/02-structure.md`:
- HSO = scaffold каждого поста
- Skill сначала planирует 3 компонента отдельно
- Mapping типа поста → HSO variant из таблицы выше

### `workflow/04-review.md`:
- Diagnostic - какой компонент слаб (если проблемы)
- Mandatory check: все 3 присутствуют, не missing

### При user-запросе «почему пост не зашёл»:
- Прогнать через diagnostic table
- Identify слабый компонент
- Apply fix
