## Как этим пользоваться (для 02-structure, platform=linkedin-en)

1. Определить ЦЕЛЬ поста (см. `distribution-algorithm.md` — viral / thought-leadership / lead-gen).
2. Найти категорию ниже под жанр (hot-take / knowledge / personal / motivation / humor / self-promo / announcement).
3. Взять **Learn-паттерн** как чек-лист структуры (не копировать текст — у нас канон автора для тела/голоса).
4. Зафиксировать в outline: какой decoded-паттерн взят (evidence для гейта 4.LI).

**Сквозной вывод по всем 50 (что делает пост сильным):**
- Hook несёт удивление/провокацию/конкретику в первой строке (без «see more»)
- **Specificity = credibility:** реальные компании, люди, данные, числа («10 лет» > «давно»)
- **Receipts/Evidence:** результат/скрин/число — иначе читают как AI
- Scan-ability: короткие строки, ✓/✗, стрелки, нумерация
- Визуал усиливает (инфографика/карусель даже «stick-figure» работает)
- Финал = конкретный вопрос/действие, не «Thoughts?»

## 7. ANNOUNCEMENT / MILESTONE (формула)

**Формула:** (1) Открыть эмоц./стратегическим смыслом, не фактом → (2) кратко что произошло → (3) ПОЧЕМУ это важно (что открывает) → (4) аутентичная личная эмоция (большинство пропускают — не пропускай) → (5) тег участников + forward-looking финал.

**Избегать:** «Excited to announce…» / новость в строке 1 без hook / абзац корпоративного языка без человечности / забыть «что это значит для аудитории».
