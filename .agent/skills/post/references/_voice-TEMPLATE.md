# Эталон голоса - ШАБЛОН (пустой по умолчанию)

> 🔴 **Это ШАБЛОН, а не канон.** Гейты скилла сверяют пост НЕ по этому файлу, а по внешнему канону автора - путям из `config.md` секция `voice_canon` (`voice_profile`, `voice_gold_standard`, `voice_corpus_dir`, `checklist_ivana`). Пути читаются условно: сперва `[ -f <путь> ]`, потом `Read`.
>
> **Пока эти ключи пусты (или файлы по ним не читаются), гейты голоса печатают `UNVERIFIED`, а не `PASS`.** Пустой шаблон = сверка не проводилась. Прежняя схема, где гейты ссылались на «раздел 3 / раздел 5 / разделы 8-10» ЭТОГО файла, была фикцией: таких разделов здесь никогда не было, и проверка формально «проходила» на пустоте.
>
> **Что делать ученику:** заполнить разделы ниже своим материалом (или собрать свои файлы где угодно), затем прописать пути к ним в `config.md` → `voice_canon`. После этого гейты начнут сверять по-настоящему и перестанут печатать `UNVERIFIED`.
>
> **Чего НЕ делать:** оставлять разделы пустыми и считать, что скилл «пишет твоим голосом». Он будет писать нейтрально - это честный режим, а не брак, но и не твой голос.
