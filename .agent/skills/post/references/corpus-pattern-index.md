# Corpus Pattern Index - at-write-time lookup

> **Назначение:** searchable bank verbatim паттернов из corpus 65 + gold-standard 10, organised by **situation / intent / sentence-position**. Used at WRITE time (Pass 2.7) и REVIEW time (Sub-stage 4.11), not at READ-only stage. Решает root cause «collection ≠ implementation» - раньше скилл READS corpus, но не USES corpus на уровне sentence-pattern matching.
>
> **Source corpora:**

> - `examples/_TEMPLATE.md` (10 reference posts)
>
> **Verification rule:** ВСЕ patterns ниже - verbatim extracts с post ID. НЕ выдумывать. Если новая ситуация требует pattern которого нет - flag для human-add, не fabricate.

## How to use this file

### At write-time (Pass 2.7 in `03-write.md`):

1. После draft (Pass 1) + Living Language (Pass 2.5) - для каждого sentence в draft:
2. Identify intent: opener / transition / verb-object pair / temporal pivot / negative outcome / closing.
3. Grep соответствующую категорию ниже.
4. **Match found** (≥70% structural similarity) → preserve sentence as-is.
5. **No match** → flag «sentence X: no corpus precedent. Replace through closest pattern Y».
6. **Output target:** ≥70% sentences match corpus patterns. <70% → return к Pass 1.

### At review-time (Sub-stage 4.11 in `04-review.md`):

1. Quantitative count: sentences matching corpus pattern / total sentences ratio.
2. ≥70% → PASS / 50-70% → WARNING / <50% → FAIL.

### Matching definition

A draft sentence «matches» a corpus pattern if it shares:
- Same **structural shape** (subject + verb-class + object/qualifier pattern), AND
- Same **intent** (opener / transition / negative outcome / etc.), AND
- Either verbatim glagol-marker из corpus ИЛИ analogous pattern shell.

Pure topic overlap is NOT a match. «Я завайбкодил X» matches «Я допилил Y» (same shell: я + glagol-маркер + object). «Этот продукт помогает решать задачи» does NOT match anything - generic AI-shell.

## Edge cases (synonyms / paraphrase)

**Q: Если sentence - синоним verified pattern, но НЕ verbatim?**
A: Match по shell (subject + verb-class + object pattern), не по точным словам. «Я залил сайт» матчит V16 «Залил сайт» - same shell, ОК. «Я задеплоил приложение» НЕ матчит - другой glagol-class (англицизм), нет в corpus → flag.

**Q: Что если sentence имеет смешанные shells (часть match, часть нет)?**
A: Split sentence по запятой / коннектору. Каждая часть проверяется отдельно. Минимум 70% частей должны match.

**Q: Что если новый темп требует нового pattern?**
A: НЕ выдумывать. Flag в output: «Pattern gap detected for situation X. Suggest human-add to corpus-pattern-index.md». Use closest existing pattern as fallback.

**Q: «Без надрыва, по 4-5 часов в день» - это match или нет?**
A: NOT match. Verified 0/65 в corpus. Это AI-stencil formula . Closest verified shell: V18 «Хер@чил неделями напролёт» (если хочется передать интенсивность) ИЛИ V7 «Закинул [объект] для [scope]» (если описывается сама работа без интенсивности).
