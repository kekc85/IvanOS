# Промпт урока «Карусели» — ОДИН цельный мастер-промпт (копипаст ученику)

Ученик копирует ВЕСЬ блок ниже в Claude Code (в папке IvanOS). Claude поднимает узел каруселей
по шагам, проверяя КАЖДЫЙ живым прогоном, и останавливается там, где нужен аккаунт ученика.

---

```
Ты - мастер-настройщик моей системы каруселей. Подними узел до рабочего состояния и проверь КАЖДЫЙ шаг реальным прогоном (не «файл на месте», а «команда отработала»). Иди строго по шагам, после каждого показывай вывод проверки. Где нужен мой личный аккаунт - останавливайся и проси подключить моё, чужие ключи не подставляй. Ничего не запускай в фоне и по cron - только ручной прогон.

ШАГ 1. Playwright MCP (браузерный движок для рендера слайдов)
Выполни: claude mcp add -s user playwright -- npx @playwright/mcp@latest
Проверь: claude mcp list
Жду: playwright = Connected. Если «npx: command not found» - сначала поставь Node LTS с nodejs.org и повтори. Внутри сессии проверка - команда /mcp

ШАГ 2. Браузер для рендера
Убедись, что есть Chromium для Playwright: npx playwright install chromium
Покажи, что установка прошла

ШАГ 3. Парсер Instagram через Apify (канон, аккаунт вне риска бана)
Проверь ~/.claude/.env на строку APIFY_TOKEN=
Если её нет или пусто - СТОП, скажи мне дословно: «Заведи бесплатный аккаунт на apify.com, зайди в Settings → Integrations, скопируй Personal API token и пришли его мне»
Когда дам токен - впиши строку APIFY_TOKEN=<мой токен> в ~/.claude/.env, поставь chmod 600, и проверь ЖИВЫМ вызовом на любом публичном профиле:
  python3 ~/.business/scripts/ig-fetch/apify_ig.py profile <публичный_профиль> 3
Работает = печатает посты и строку [cost] в stderr. Ошибка «APIFY_TOKEN не найден» = токен не подхватился, разберись

ШАГ 3-альт (по желанию, РИСК бана своего аккаунта). Instagram через cookies
Только если хочу парсить под своей сессией. Проверь ~/.claude/skills/_shared/bin/account.py и выполни:
  python3 ~/.claude/skills/_shared/bin/account.py onboard instagram
Проведи меня по входу в МОЙ IG в открывшемся окне (включая 2FA), cookies сохрани в ~/.business/processes/.ig-cookies.json (chmod 600). Не уверен - оставайся на Apify: cookies под живой сессией это как раз то, за что банят

ШАГ 4. Кастомка (Custom GPT, который рисует слайды) - уже подключена
Слайды рисуешь НЕ ты - их рисует Custom GPT в браузере ChatGPT, которым рулит Playwright. Ссылка кастомки уже вписана в config, создавать её НЕ надо. Нужен только вход в мой ChatGPT. СТОП, проведи меня:
  1) запусти python3 ~/.business/scripts/auto-uniqualize/carousel_setup.py - он поднимет браузер на CDP, я войду в свой ChatGPT (нужен Go или Plus)
  2) кастомка: https://chatgpt.com/g/g-6a18ce2cbacc8191b6410b0bb6810d03-carousels-<твой-бренд>
  3) подтверди, что залогинен и Custom GPT открывается
Ключей тут нет, только моя залогиненная сессия

ШАГ 5. Скилл каруселей - сухой прогон
Проверь, что на месте: ls ~/.claude/skills/carousel-uniqualizer/ и папка ~/.business/scripts/auto-uniqualize/. Возьми ОДИН тестовый пакет слайдов и прогони драйвер БЕЗ доставки:
  python3 ~/.business/scripts/auto-uniqualize/driver_parallel.py <пакет> 1 --parallel 1
Покажи, что он реально дошёл до Custom GPT и вернул слайд (PNG сохранён)

ФИНАЛ
Выведи чек-лист:
  готово (проверено живым прогоном): ...
  ждёт моего действия (какой токен/логин): ...
Ни один шаг не помечай готовым без реальной проверки

Кастомка - https://chatgpt.com/g/g-6a18ce2cbacc8191b6410b0bb6810d03-carousels-<твой-бренд>
```

Требование: **ChatGPT Go или Plus** (кастомки работают только на платном). Всё остальное узел ставит сам.
