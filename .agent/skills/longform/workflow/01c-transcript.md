# 01c - Mode C (Transcript)

> Разбор надиктовки в 1-3 longform arcs. Сохраняет лексику и интонацию автора дословно.

## Когда срабатывает

- Input длиннее 500 знаков
- Фразы: «надиктовал», «вот мысли», «разверни это», «сделай статью из этого», «вот черновик»

## Шаги

### Шаг 1 - нормализовать транскрипт

- Удалить плотные filler-слова на границах («ну», «короче», «эээ») если их >3 на абзац
- НЕ переписывать лексику - сохранять как есть
- НЕ убирать оговорки если они несут смысл - они могут быть hook'ами

### Шаг 2 - извлечь longform arcs

Longform arc = (hook + 1 main thesis + 1-3 supporting + payoff + CTA-readiness). Из надиктовки можно извлечь 1-3 arcs.

Критерии arc:
- В надиктовке есть **раскрученная мысль** на ≥150-200 слов (если короче - это TG-post, не longform)
- Есть **personal anchor** (история / момент / opinion)
- Есть **outcome shift** (читатель что-то понимает по-новому)

Если в надиктовке только 1 arc - генерим 1 longform. Если 2-3 arcs - показываем выбор пользователю.

### Шаг 3 - если arcs > 1, показать выбор

Plain text список:

```
В надиктовке нашёл 3 longform-arc'а:

1. <topic 1> - <main thesis 1 строкой> (≈<word count>)
2. <topic 2> - <main thesis 1 строкой> (≈<word count>)
3. <topic 3> - <main thesis 1 строкой> (≈<word count>)

Какой развернуть? (1-3 / все по очереди / другой)
```

### Шаг 4 - собрать brief

```yaml
mode_c_brief:
  transcript_excerpt: "<релевантный кусок надиктовки, verbatim>"
  topic: "<главный смысл arc>"
  main_thesis: "<цитата из надиктовки + лёгкая нормализация>"
  audience_pain: "<вывести из контекста>"
  outcome_shift: "<вывести>"
  personal_anchor: "<verbatim quote из надиктовки>"
  type_preferred: "<teaching | story | framework по структуре arc>"
  voice_signals:
    - "<характерные обороты автора из этой надиктовки>"
    - "<запретные термины которые надо ОСТАВИТЬ потому что автор их использует>"
  language: "<from router>"
  platform: "<from router>"
```

### Шаг 5 - pass дальше

В `01-finalize.md` с маркером `source=transcript`. Это критично для `03-write.md` - там будет особый Pass 0 «mandatory verbatim preserve» - обороты и цитаты из надиктовки переносятся дословно.

## Что критично сохранить из надиктовки

1. **Лексику** - конкретные термины которые автор использует (даже если они в banned list - добавить override на эту статью с пометкой «verbatim from transcript»)
2. **Структуру мысли** - порядок аргументов автора. Не переставлять.
3. **Эмоциональные маркеры** - «бесит», «обалдеть», «представляешь» - переносить
4. **Конкретные числа/имена/цитаты** - если автор сказал «один ученик заработал 300К» - это идёт в статью verbatim. НЕ перефразировать в «один из учеников добился значительного результата».

## Что фильтровать

1. Повторы одной мысли 3+ раз - оставить один раз, лучшую формулировку
2. Filler с границ предложений (>3 на абзац)
3. Незакрытые сюжетные линии («хотел сказать ещё про X, но не успел...») - выкинуть либо помечать [TODO]

## Edge cases

- **Транскрипт совсем сырой** (одно предложение растянуто на 2 страницы) → попросить пользователя дать тему / main thesis отдельно
- **Транскрипт = пересказ чужого** (без personal anchor) → warn, что longform без personal anchor получится слабый, спросить добавить ли personal moment
- **Транскрипт смешанный RU+EN** → выбрать canonical язык по объёму, остаток адаптировать в `03-write.md`
