# Reference - Longform Structures

> Каноничные структуры longform от reference creators. Используется в `02-structure.md` Step 2 как backbone для 3-section outline.

## Dan Koe - 3-section essay (default backbone)

Источник: thedankoe.com letters + The 2 Hour Writer course.

```
INTRODUCTION (15-20%)
- Hook (controversial / counterintuitive)
- Relatable problem
- Personal experience (anchor)

INSIGHT (40-50%)
- Novel "aha" (counter-intuitive mechanism)
- Why this works (psychology / first principles)
- Concrete examples (data + specifics > vague)

PROCESS (35-40%)
- Practical step-by-step
- Actionable from day 1
- Common pitfalls + how to avoid
- CTA (subscribe / next / community)
```

**Применение в longform skill:** baseline для teaching и framework. Story essay использует pacing-override (INTRODUCTION 35-45%).

**Длина по Koe:** 800-2000 слов, ~15-20 min «time under attention».

**Production cycle Koe:** 2 часа на эссе (морния scheduled writing), 477K views на лучший essay.

## Justin Welsh - 5-step Saturday Solopreneur

Источник: Justin Welsh newsletter 175K, 59% open rate.

```
STEP 1: One-liner hook (problem statement)
STEP 2: 3-sentence personal context
STEP 3: The framework / lesson (with 3-5 bullet points)
STEP 4: How to apply (1-2 paragraphs)
STEP 5: CTA + next week tease
```

**Применение:** Story essay (Welsh-leaning) + framework essay (5-step layout).

**Welsh hallmarks:**
- Saturday-only publishing (weekly cadence consistent)
- 1000-1500 слов sweet spot
- 5-step formula каждый раз - predictability builds expectation
- Subject line patterns: «Saturday Solopreneur #N: <topic>»

## Rowan Cheung - news-driven essay

Источник: The Rundown (2M daily newsletter).

```
LEAD (TL;DR - 2-3 строки)
- Что произошло (news anchor)
- Почему это важно (1 строка)

CONTEXT (3-5 параграфов)
- Background (что было до)
- Trigger (что изменилось)
- Stakeholders (кто affected)

ANALYSIS (4-6 параграфов)
- Implications (что значит)
- Counterargument (opposing view)
- Data / examples

WHAT TO DO (2-3 параграфа)
- Action items для разных segments
- Resources / further reading

CTA
```

**Применение:** Not для v1.0 longform skill (новостной формат не подходит teaching/story/framework). Может быть использован для contrarian breakdown в v1.1 (myth vs reality = news-driven re-framing).

**Cheung hallmarks:**
- Daily cadence (требует news-driven topic)
- 800-1200 слов
- AI for research / structure, NOT для prose

## Sahil Bloom - 4x/week mixed format

Источник: Curiosity Chronicle 800K newsletter, 4-week publishing rhythm.

```
MIX:
- Mon: long-form essay (1500-2000 слов)
- Wed: short story / observation (500-800 слов)
- Fri: framework / mental model (1000-1500 слов)
- Sun: weekly digest / recommendations
```

**Применение:** не структура, а cadence pattern. Подсказка для production cycle автора.

**Bloom hallmarks:**
- Iconic naming для frameworks (The 1-3-1 Rule, The 80/80 Rule)
- Story + framework hybrid (most popular)
- CTA = invite to community / paid track

## Tim Ferriss - long-form mechanism essay

Источник: Tim Ferriss blog (>1000 essays since 2007).

```
INTRO (10-15%)
- Context / experiment setup

EXPERIMENT (40-50%)
- What I tried (detailed)
- What I expected vs what happened
- Results (specific data)

ANALYSIS (25-35%)
- Why it worked / didn't
- First principles
- Counter-cases (когда не работает)

LESSONS / APPLICATION (15-20%)
- Generalizable lessons
- How reader can apply
- Resources / next experiments
```

**Применение:** Deep-dive template (v1.2), case study (v1.1).

**Length:** 2000-3000+ слов (Tim не боится длины).

**Ferriss hallmarks:**
- Self-experimentation as proof
- Specific numbers / supplements / tools / books mentioned
- Footnotes / sidebars для tangential context

## Naval Ravikant - first-principles essay (синтез)

Источник: Naval.al (compact essays + threads).

```
PREMISE (1-2 строки)
- Counterintuitive claim или first principle

UNPACKING (3-5 параграфов)
- Why this is true
- 3-5 supporting principles
- Each with example

IMPLICATION (1-2 параграфа)
- What follows from this
- What to do differently

CLOSING (1 строка)
- Aphorism / quotable summary
```

**Применение:** Framework essay (compact version, 600-1000 слов вместо 1500-2000).

**Naval hallmarks:**
- Compactness - short essays с большой density
- Aphoristic closing (твитабельный)
- First-principles reasoning
