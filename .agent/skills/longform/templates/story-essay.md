# Template - Story Essay

> Story-driven long-form. Personal arc с payoff. Главная цель - читатель эмоционально вовлекается, и в payoff момент получает outcome shift через урок автора, а не через инструкцию.

## Когда применять

- Тема имеет сильный personal moment / arc (не абстракция)
- Хочется создать эмоциональную связь до того как давать tactical content
- В Mode A - найден сильный personal anchor в story bank
- В Mode C - надиктовка построена как нарратив

## Длина

- Target: 1000-1600 слов
- Floor: 800
- Ceiling: 1800

## Структура (story-first, INTRODUCTION expanded)

```
INTRODUCTION (35-45%)  - ~400-700 слов [STORY ARC]
├─ Hook (момент / scene / tension)
├─ Setup (контекст: где / когда / кто / что было до)
├─ Inciting moment (то что заставило задуматься / изменить)
├─ Conflict / tension (что было непонятно / что не получалось)
└─ Bridge (1 строка перехода к payoff)

INSIGHT (35-40%)       - ~400-600 слов [PAYOFF + AHA]
├─ Realization (что автор понял в момент или после)
├─ Why it matters (почему это relevant для читателя)
├─ Reframe (как этот опыт изменил mental model)
└─ One supporting reference (книга / разговор / data - НЕ обязательно)

PROCESS (20-25%)        - ~250-400 слов [LESSONS]
├─ 3-5 lessons learned (не how-to steps, а принципы)
├─ Что бы я сделал иначе (если применимо)
└─ CTA (subscribe / DM / next в серии)
```

## Hook patterns для story

| Pattern | Пример |
|---|---|
| Scene opener | «<Дата>. Я сидел в <place> и смотрел на <thing>.» |
| Quote / dialogue | «"Ты сейчас всё разрушишь", сказала она.» |
| Confession | «Я <time> молчал об этом, потому что стыдно было признать.» |
| Specific moment | «В тот четверг в 11:47 я понял что больше так не могу.» |
| Mystery | «Я не должен был это узнать. Но узнал.» |

## Voice quirks (автор-specific)

- Personal anchor = весь INTRODUCTION (не локальный момент в 1 параграф)
- Sensory details (видел / слышал / почувствовал / запомнил конкретное место)
- Лексика разговорная: «понял», «дошло», «зацепило», «не поверил»
- Числа / даты / имена - оставлять конкретными (тот четверг → именно «9 марта в четверг»)
- Не давать moral в лоб - payoff должен быть show, не tell

## INSIGHT - story-specific pacing

INSIGHT в story-essay не доминирует (как в teaching). Главное - payoff читается как естественное продолжение истории, не как блок «вот мой урок».

1. **Realization** - ~150-200 слов. Конкретный момент когда дошло.
2. **Why it matters** - ~150-200 слов. Связь с пейном читателя.
3. **Reframe** - ~100-150 слов. Как изменилось видение.

## PROCESS - что делать НЕ так как в teaching

В story-essay PROCESS - это **lessons** (принципы), не **steps** (инструкция).

Format:

```
Что я понял после этого:
- <принцип 1, 1-2 строки>
- <принцип 2>
- <принцип 3>

Что бы я сделал иначе:
<1-2 строки>

<CTA>
```

НЕ превращать story-essay PROCESS в numbered step-by-step - это убивает story-эффект.

## Anti-patterns specific to story

- **«Эта история научила меня X»** - formulaic moral в лоб
- **«Сейчас расскажу историю»** - formulaic story intro, banned
- **Story без conflict / tension** - flat narrative не работает
- **Story без realization** - anecdote без payoff
- **Moral подменяет story** - если payoff >50% длины, это teaching, а не story
- **Имена / даты / места абстрактные** («один из учеников», «однажды», «где-то») - story-killer

## Output format markers

```html
<!-- SECTION: INTRODUCTION -->
<!-- STORY_ARC: setup → moment → conflict → bridge -->
<!-- SENSORY_DETAILS_COUNT: <N> (target ≥3) -->

<!-- SECTION: INSIGHT -->
<!-- PAYOFF_TYPE: realization | reframe -->
<!-- TELL_vs_SHOW_RATIO: <subjective, target ≤30% tell> -->

<!-- SECTION: PROCESS -->
<!-- LESSONS_COUNT: <N> (target 3-5) -->
<!-- CTA_TYPE: subscribe | dm | next-in-series -->
```
