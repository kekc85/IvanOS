## Как использовать anchors при ревью (L8)

Перед заявлением «визуал готов» - поставить наш собранный сегмент РЯДОМ с anchor того же типа:
- Реальный UI-сегмент → сравнить с reference-2: у нас тоже чистый живой скринкаст реального
  инструмента (курсор, скролл, клик), НЕ рисованный HTML-мок, ноль оверлеев поверх?
- Hook b-roll → сравнить с reference-1: реальный экран на чистом фоне с движением, пруф с 1с?
- Дешевле/статичнее/рисованный мок вместо реального → НЕ готово, переделка (закон 2 - совпасть
  по качеству, не только механике)
