# Фаза 04: storyboard визуального ряда 16:9

Цель: на каждый сегмент скрипта/главу назначить источник визуала (реальный скринкаст / hyperframes-абстракт / higgsfield-абстракт / лицо) по real-footage-роутеру, выдержать motion-floor и аватар-букенд под long-form, пруф с 1-й секунды. Выход - `storyboard.md`, вход для фазы 05 (промпты отрисовки)

## Вход

`$PROJECT_DIR/script.md` (скрипт + секция `## Главы` 5-9 + CTA) из фазы 03. Роль из `project.json`. Метрики/эстетика донора из `$PROJECT_DIR/card.md` (для бенчмарка динамики)

## Шаги

1. **Разбить скрипт на сегменты по главам** (секция `## Главы` из `$PROJECT_DIR/script.md`) + отдельно хук и CTA/аутро. Каждому сегменту - **сквозной номер** `seg-01`, `seg-02`, ... (этот № - ключ, проходит через фазы 04→05→06, по нему совпадают файл клипа и строка manifest) + таймкод (по хронометражу скрипта). Это строки будущей таблицы

2. **Назначить источник визуала по real-footage-роутеру** (`knowledge/engine-boundary.md`, закон №3 SKILL.md). Строгая граница:
   - сегмент показывает РЕАЛЬНЫЙ инструмент / сайт / UI → тип `real-screencast` (живой screen-record / CDP / официальный футаж тула, с провенансом URL). Рисованный HTML-мок реального UI = брак (,)
   - абстракция / диаграмма / метафора / титр / число → тип `hyperframes-abstract` или `higgsfield-abstract` (ТОЛЬКО абстракции, НЕ реальный UI)
   - лицо автора в кадре → тип `face`
   Реальный UI в таблице ОБЯЗАТЕЛЬНО помечен как `real-screencast` (скринкаст), не как рисованный

3. **Аватар-букенд под long-form** (закон №6,): лицо автора (`face`) видно на хуке + CTA + опорных точках глав (вход/payoff главы). Середина главы = визуал-носитель с VO поверх. НЕ говорящая голова 20 минут подряд - проверить, что нет непрерывного блока `face` длиннее опорной точки

4. **Motion-floor** (закон №5,): динамика визуала каждого сегмента НЕ ниже эталона-донора - новое визуальное событие примерно каждую секунду, не статичный слайд с медленным зумом. Помечать сегменты, где визуал рискует стать статикой, требованием «≥N событий на сегмент». Бенчмарк динамики против донора добьёт `scripts/motion-floor-check.sh` уже на собранном черновике (фаза 06/07)

5. **Пруф с 1-й секунды** (закон №9,): у сегмента-хука в колонке визуала - наглядный пруф на экране (реальный результат/цифра/экран), не пустая текст-карточка

6. **Собрать `$PROJECT_DIR/storyboard.md`** - таблица (16:9, все сегменты по порядку скрипта, столбец № = сквозной ключ):

   | № | Сегмент | Таймкод | Тип визуала | Что показать | Источник футажа |
   |---|---|---|---|---|---|
   | seg-01 | Хук | 00:00-00:40 | face + real-screencast | пруф-результат на экране | screen-record + лицо |
   | seg-02 | Глава 1 вход | ... | face | мини-хук главы | лицо |
   | seg-03 | Глава 1 тело | ... | real-screencast | реальный UI тула | CDP / screen-record + URL |
   | ... | ... | ... | hyperframes-abstract | диаграмма/метафора | hyperframes клип |
   | seg-NN | CTA/аутро | ... | face | CTA по роли | лицо (аутро последним) |

   Тип визуала - строго из роутера. Источник футажа - конкретный (URL для скринкаста, «hyperframes клип», «higgsfield абстракт»). № сегмента = ключ для фаз 05/06.
   **Формат вставки** (устраняет неоднозначность PNG-vs-mp4 для фазы 06): помечать каждый визуальный
   сегмент - `клип` (движущийся футаж → рендерится в `seg-NN.mp4`, тип overlay-video), `статика`
   (титр/пилюля без движения → `seg-NN.png`, overlay-png) или `fullscreen` (UI-демо на весь экран,
   голова уходит в VO → replace). Motion-floor требует движения, поэтому `статика` - только для
   коротких титров, не для несущих UI-сегментов

## Выход

- `$PROJECT_DIR/storyboard.md` с таблицей: № · сегмент · таймкод · тип визуала · что показать · источник футажа
- каждый сегмент имеет сквозной № и назначенный источник

## Гейт

Дальше только когда: КАЖДЫЙ сегмент имеет источник футажа; реальный UI помечен как `real-screencast` (не рисованный мок); лицо (`face`) не идёт 20 минут подряд (букенд соблюдён - хук+CTA+опорные точки глав, середина = визуал+VO); хук несёт пруф с 1-й секунды; аутро - последним сегментом. Провал любого пункта = переназначить, не пускать в отрисовку
