# Фаза 07: verify-гейт (ОБЯЗАТЕЛЬНО перед «готово»)

Скилл сам себя верифицирует ДО любого заявления «готово / собрал / реплицировал». Не полагаться на
внешний хук. Без зелёного verify задача НЕ закрыта. verify проверяет что артефакт физически
СУЩЕСТВУЕТ и цел, а не что «по замыслу должен быть»

## Цель

Дать exit 0 от `scripts/verify.sh` (структура пакета цела) плюс два содержательных бенчмарка
(против источника по структуре удержания, против эталона по motion-floor) - и только тогда заявлять
готово, приложив вывод как улику

## Вход

- `$PROJECT_DIR` (единая папка): `card.md` (копия из фазы 02), `storyboard.md`, `production-package/`,
  (если второй проход) `out.mp4` - все артефакты в одном дереве, verify.sh собирает их одним `find`
- URL источника (провенанс из card.md) - для бенчмарка структуры
- Эталон продакшна (visual-anchors) - для motion-floor

## Шаги

1. **Прогнать `scripts/verify.sh` и показать exit-код:**
   ```bash
   bash ~/.claude/skills/youtube-viral-remake/scripts/verify.sh "$PROJECT_DIR"; echo "exit=$?"
   ```
   verify.sh проверяет: `card.md` существует, `storyboard.md` существует, `production-package/`
   непустой, (если есть) `out.mp4` валиден через ffprobe. Печатает чек-лист PASS/FAIL. exit 0 = всё
   на месте, exit 1 = чего-то нет

2. **Бенчмарк против источника - структура удержания совпала.** Открыть `card.md` (деконструкция
   источника) и storyboard/скрипт. Сверить: hook на месте, число глав и их мини-хуки повторяют
   структуру источника, ретеншн-петли перенесены. Реплицируем структуру КОНКРЕТНОГО источника, не
   выдуманный формат. Если
   структура разошлась - это не готово, вернуться к фазе 03/04

3. **Бенчмарк против ДОНОРА - motion-floor (блокирующий).** Если собран `out.mp4` - сравнить динамику
   НЕ с фикс-порогом, а с реальным донором (закон: наш не ниже эталона-источника). Донор-mp4 лежит в
   ingest (путь в `project.json.ingest_dir`):
   ```bash
   DONOR=$(ls "$(jq -r .ingest_dir "$PROJECT_DIR/project.json")"/*.mp4 2>/dev/null | head -1)
   bash ~/.claude/skills/youtube-viral-remake/scripts/motion-floor-check.sh \
     "$PROJECT_DIR/out.mp4" --donor "$DONOR"; echo "exit=$?"
   ```
   Порог = донор × 0.8 (наш минимум 80% динамики эталона). **exit 1 = FAIL блокирующий** - наш ролик
   статичнее эталона, вернуться к фазе 05 добрать движение (не пускать «мы слабее», 
  ). Без донора скрипт падает в слабый
   фикс-режим (WARN) - но у нас донор всегда есть, гнать с `--donor`

4. **L8 Visual-anchor сверка качества (обязательный шаг, не только motion).** Открыть
   `visual-anchors/manifest.md`, извлечь кадр НАШЕГО скринкаст-сегмента из out.mp4 и поставить рядом
   с `reference-2` (эталон чистого скринкаста):
   ```bash
   ffmpeg -y -ss <середина-скринкаст-окна> -i "$PROJECT_DIR/out.mp4" -frames:v 1 "$PROJECT_DIR/qa-frame.png" -loglevel error
   ```
   Прочитать `qa-frame.png` и `visual-anchors/reference-2-*.jpg`, честно оценить: наш кадр выглядит
   так же дорого/цельно или дешевле/статичнее? Реальный UI = чистый скринкаст без оверлеев (не
   рисованный мок)? Дешевле → НЕ готово, вернуться к фазе 05.
   Улику-кадр показать в чат

5. **Проверка role-доставки.** По config: acquisition = черновик открываемый, публичный YT только
   по команде · launch = localhost+бот, НЕ публичный домен. Смешение (acquisition-CTA в launch или
   наоборот) = брак

6. **Финальное правило.** Качество видео (эстетика, синхрон, lip-sync) оценивает ГЛАЗ автора, не
   verify.sh и не motion-floor. Скрипты проверяют СТРУКТУРУ и ЦЕЛОСТНОСТЬ пакета, не «красоту».
   verify зелёный = можно отдавать черновик автору на финальный просмотр, не «идеал без ревью»

## Выход

- Вывод `verify.sh` с exit 0 (или список FAIL если 1)
- Результат бенчмарка структуры (совпала / разошлась + что) и motion-floor (PASS/WARN)
- Заявление «готово» ТОЛЬКО при exit 0 + структура совпала + role соблюдена, с приложенной уликой

## Гейт (жёсткий, exit 0)

- [ ] `scripts/verify.sh "$PROJECT_DIR"` → exit 0 (иначе НЕ заявлять готово, прочитать FAIL, починить,
      прогнать снова - до зелёного, red не маскировать)
- [ ] Бенчмарк источника: структура удержания (hook / главы+мини-хуки / петли) совпала с card.md
- [ ] Бенчмарк ДОНОРА: motion-floor `--donor` exit 0 (если out.mp4 собран) - наш не статичнее эталона.
      exit 1 = FAIL блокирующий, добрать динамику в фазе 05
- [ ] L8 Visual-anchor: наш кадр не дешевле reference-2, реальный UI = чистый скринкаст, улика-кадр в чат
- [ ] Role-доставка чистая, без смешения acquisition/launch
- [ ] Улика приложена в чат (вывод скриптов + путь к черновику). Качество смотрит автор
