| «Вам не нужен OpenClaw - напишите свой» /1029326/ | +223, 63K, 557 закладок |

Паттерны (каждый на 3+ статьях):

1. «Я»-заголовок с конкретным поступком и НЕКРУГЛОЙ цифрой (300к, 483 сессии, 1,29 млн, 50 строк) - некруглое число = сигнал реального опыта
2. Контрарность к собственной ленте = главный ускоритель: топ-1 года - статья ПРОТИВ ИИ-контента. Хабр наградил усталость от ИИ-хайпа сильнее самого ИИ
3. Выбор ставки ДО написания: конфликт/история → комменты (888 у моральной дилеммы), туториал с кодом → закладки (557 у «напишите свой»)
4. Демистификация: «это не магия, а один паттерн» - снять пафос, показать механику
5. Пруфы обязательны: код целиком, таблицы замеров, фото железа. Без пруфов закапывают
6. Первый абзац = удар-признание ЛИБО регалии за 2 строки. Середины в топе нет
7. Длина - две крайности: 2-4 мин чистой эмоции ИЛИ 13-20 мин исчерпывающего разбора

Анти-паттерны: SEO-обзоры «топ-10 нейросетей», кликбейт без покрытия, восторженный тон («ИИ изменит всё» в топе отсутствует, только скепсис/ирония/сухой эксперимент), обезличенность

> «Десять лет в девопсе. Десять. И я гуглю tar -xzf. Не раз в год - раз в неделю»

## VC.RU

Якорные статьи:

| Статья | Метрики |
|---|---|
| «Я 25 лет настраивал фотоаппарат... а потом пришла нейросеть» vc.ru/life/1996760 | 242K просмотров (максимум выборки) |
| «40 лучших ИИ-инструментов и нейросетей в 2025» /ai/1735732 | 108K, 587 закладок (№1 года) |
| «Google выкатил 68-страничный гайд по промптам. Я прочитал его за вас...» /ai/2069607 | 119K, 453 закладки |

Паттерны:

1. КОПИРУЕМЫЙ АРТЕФАКТ = закладки = годовой топ: официальный топ-10 по закладкам почти целиком «забери и используй». VC сохраняет инструмент, не мысль - противоположность Хабру
2. «Я прочитал/протестировал ЗА ВАС»: чужой авторитет + объём-барьер + сжатие до N правил
3. Деньги в заголовке с точной цифрой = валюта площадки («30 млн», «300 000 ₽»). Даже ИИ продаётся через деньги, не через технологию
4. Драма профессии против ИИ бьёт рекорды охвата: стаж + угроза ремеслу + разворот «как приручил» = 242K, вдвое больше любого гайда
5. Рамка запретности/секрета: обычный контент + табу-упаковка = кратный охват
6. Обезвреживание скепсиса В ПЕРВОМ АБЗАЦЕ - раньше циничного читателя
7. Микрозаметка-находка (250 слов): «появился инструмент X + команда установки» = 22K за 3 дня

Анти-паттерны: техничка с кодом мертва (разбор Claude Code = 690 просмотров против «запретных промптов» = 33K), нейтральные заголовки-описания, длиннее 3-4 тыс. слов, заголовок без «я» или конфликта

Хуки verbatim:

> «Вам надоели шаблонные списки ИИ инструментов, которые читаются так, будто их написала нейросеть? Мне тоже»

> «Меня зовут Никита, и я ушел из Газпрома, чтобы продавать женские сумки. Звучит как заголовок инфоцыганского курса, но за этим пять лет в одной нише, больше 500 тысяч проданных сумок и очень много таблиц»

> «Полгода назад один знакомый скинул мне промт, который буквально перевернул мой способ работы с ChatGPT»

Паттерны:

1. АЛГОРИТМ ВАЖНЕЕ БАЗЫ: 449 подписчиков → 3,3К читали, велоканал вне ниши → 29,4К. Лента раздаёт за дочитывания, не за размер канала. Ноунейму на Дзене можно
2. Комменты драйвит УГРОЗА И СПОР, не польза: «заменили разработчика» 154, «ИИ выиграл у писателей» 152. Полезные гайды - 0-10 комментов
3. Хук = конфликт в первых 2 предложениях + недосказанность («о чём предпочитают молчать»)
4. Герой с именем («Саша пишет код 8 лет») - персонализация превращает обзор в историю
5. Стандарт лонгрида-топа: 7-10 мин (9-13К знаков), оглавление, 9-13 картинок-скринов, подзаголовок каждые 2-3 абзаца
6. Два рабочих формата: лонгрид-история ИЛИ новость-детонатор (1 мин + одна шок-цифра). Середина проседает
7. Тон простой/бытовой даже у СМИ. Канцелярита в топах нет

Анти-паттерны: GPT-листикл «20 способов заработка» - 1 коммент; SEO-гайд без личности - охват только из поиска; «продающая» структура без холиварного крючка = 0 комментов (прямой конкурент: 877 читали, 0 комментов)

Паттерны:

2. Формула топа: «N способов/схем + личный опыт + ЦЕНЫ В РУБЛЯХ за каждый пункт»
3. Вовлечение встроено механикой: опрос, прямой вопрос в финале
4. Конверсия БЕЗ внешних ссылок: продажа прямо в теле (курс + цена + промокод), «ссылка в комментариях», «напишите в личку», витрина = профиль с регалиями
5. Статья = SEO-актив через Афину: клиенты «приходят со статей годичной давности»
6. Тон деловой + личный: «друзья/ребята», эмодзи в деловом тексте, регалии рядом с разговорностью

Анти-паттерны: корпоративный блог-визитка с «читайте на нашем сайте» - 13 просмотров; SEO-простыня при пустом профиле - 27; обзор-агрегатор без опыта - 165; продажа в лоб при пустом профиле не разгоняется

## ГЛАВНАЯ ВИЛКА

- Хабр награждает СКЕПСИС + ПРУФЫ + НЕКРУГЛЫЕ ЦИФРЫ; восторг и SEO-списки закапывает
- VC награждает ДЕНЬГИ В ЗАГОЛОВКЕ + КОПИРУЕМЫЙ АРТЕФАКТ + ДРАМУ ПРОФЕССИИ; техническую глубину игнорирует
- Дзен награждает ИСТОРИЮ-КОНФЛИКТ С ГЕРОЕМ + ХОЛИВАРНЫЙ КРЮЧОК; алгоритм вытащит ноунейма без базы
- TenChat: ПРОФИЛЬ РЕШАЕТ + ЦЕНЫ В РУБЛЯХ + ПРОДАЖА В ТЕЛЕ; без прокачанного профиля лента не разгонит

Одна тема = ЧЕТЫРЕ разные статьи. Хабр: «я сделал и вот замеры». VC: «я сжал/нашёл/заработал - забирай». Дзен: «история человека, у которого всё изменилось». TenChat: «N схем с ценами от эксперта с регалиями»
