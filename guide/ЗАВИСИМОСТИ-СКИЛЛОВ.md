# Зависимости скиллов: что и зачем доустановить

Базовые писательские скиллы (post, tweet, email, longform, carousel-текст, lead-magnit-текст) работают сразу. Часть скиллов требует доустановки - вот что и для чего

Документные скиллы (pdf, pptx, xlsx) и базовая работа с картинками тоже работают сразу: их Python-пакеты установщик кладёт автоматически

🟢 **Системные инструменты теперь ставит сам установщик** (на Mac он же при необходимости сам ставит Homebrew): ffmpeg, yt-dlp, tesseract, node, **gh, whisper-cli (whisper-cpp), poppler**, LibreOffice + Python-пакеты для OCR, парсинга, Gemini/OpenAI-клиентов и playwright (с браузером chromium). Руками brew-команды ниже гнать НЕ нужно - они оставлены как запасной вариант, если авто-установка где-то не прошла

По месту (под конкретный скилл) остаётся только то, что заранее тянуть нельзя: **тяжёлые модели** (whisper-модель ~1.6 ГБ, ollama-модели - скачиваются при первом запуске скилла) и **платные аккаунты + API-ключи** (Higgsfield, ElevenLabs, HeyGen) и **личные доступы** (cookies соцсетей, FTP) в `connections.md`. Эта таблица нужна, чтобы ты понимал, почему скилл иногда просит что-то доставить

## Таблица: что нужно каждому скиллу

| Скилл / группа | Что нужно доустановить | Как поставить (Mac / Windows) | Без этого |
|---|---|---|---|
| pdf, pptx, xlsx (документы), single-image (картинка) | Python-пакеты: pypdf, pdfplumber, Pillow, python-pptx, openpyxl, markitdown | Ставит установщик автоматически в `~/IvanOS/.venv`. Руками ничего не нужно | Скиллы документов не запустятся (нет библиотек чтения/сборки файлов) |
| ingest-reel, reel-to-script, replicate-viral, competitors-daily-scan (разбор видео) | ffmpeg, yt-dlp, whisper-cli + модель ~1.6 ГБ | Mac: `brew install ffmpeg yt-dlp`. Windows: `winget install Gyan.FFmpeg` и `winget install yt-dlp.yt-dlp`. whisper-cli + модель скилл подскажет отдельно при первом запуске | Не скачать чужой ролик, не вытащить звук и не сделать транскрипт |
| pdf (ветка распознавания текста с картинки, OCR) | tesseract (системный, НЕ pip) | Mac: `brew install tesseract`. Windows: `winget install UB-Mannheim.TesseractOCR` | PDF-скилл прочитает обычный текст, но не распознает текст внутри картинок/сканов |
| pptx, xlsx (визуальная проверка результата) | LibreOffice / soffice | Mac: `brew install --cask libreoffice`. Windows: `winget install TheDocumentFoundation.LibreOffice` | Файл соберётся, но скилл не сможет отрендерить превью и проверить, как он выглядит глазами |
| pr-to-video, lead-magnit (публикация/гитхаб) | gh (GitHub CLI) | Mac: `brew install gh`. Windows: `winget install GitHub.cli`. После установки один раз `gh auth login` | Не получится работать с репозиторием на GitHub из скилла |
| website, video и связанные видео-скиллы | Node.js (npm) | Mac: `brew install node`. Windows: `winget install OpenJS.NodeJS`. Проверка: `node -v` | Не соберутся фронтенд/видео-сборки, которые работают на Node |
| higgsfield-generate (картинки/видео-генерация) | Платный аккаунт Higgsfield + ключ | Завести платный аккаунт и вписать ключ HIGGSFIELD в `connections.md` | Скилл не сгенерирует картинку/видео |
| voice-generate (озвучка) | Платный аккаунт ElevenLabs + ключ | Завести платный аккаунт и вписать `ELEVENLABS_API_KEY` в `connections.md` | Нет генерации голоса |
| avatar-generate, replicate-viral (цифровой двойник) | Платный аккаунт HeyGen + созданный аватар + ключ | Завести платный аккаунт, создать аватар, вписать `HEYGEN_API_KEY` в `connections.md` | Не собрать видео с говорящим двойником |
| website (дизайн-фаза) | MCP Stitch / 21st.dev (подключение к Claude Code) | Подключить MCP-сервер Stitch / 21st.dev по инструкции скилла. Это не pip и не brew, а настройка соединения | Дизайн-фаза не запустится, сайт соберётся без дизайн-стека |
| ig-carousel-radar, threads-radar, competitors-daily-scan (радары по соцсетям) | Cookies/сессия Instagram / Threads | Вписать свои cookies/сессию в `connections.md` по инструкции скилла. Это твой личный доступ, нигде наружу не уходит | Радар не зайдёт в ленту и не соберёт виральное |
| lead-magnit, website (выгрузка на сайт по FTP) | FTP-доступ к своему сайту | Вписать `IVANOS_FTP_PASS` в `connections.md`. Нужен только если публикуешь на свой домен | Локально всё соберётся, но не зальётся на твой сайт |

## Команды одной строкой - ТОЛЬКО запасной вариант (обычно не нужны)

Установщик ставит всё это сам. Команды ниже - на случай, если авто-установка где-то не прошла (нет интернета, отвалился brew/winget)

Mac (если Homebrew нет - установщик ставит его сам, либо вручную с brew.sh):

```bash
brew install ffmpeg yt-dlp tesseract node gh whisper-cpp poppler
brew install --cask libreoffice
```

Windows (через встроенный winget):

```powershell
winget install Gyan.FFmpeg yt-dlp.yt-dlp UB-Mannheim.TesseractOCR GitHub.cli OpenJS.NodeJS
winget install TheDocumentFoundation.LibreOffice
```

## Про платные скиллы

Скиллы higgsfield-generate, voice-generate, avatar-generate, replicate-viral работают на платных сервисах. Для каждого нужен платный аккаунт + API-ключ, прописанный в `connections.md`

Это не разовая установка, а подписка/баланс на стороне сервиса. Подключай такой скилл только когда реально дошёл до задачи, где он нужен, чтобы не платить заранее

## Коротко

- Тексты и документы: работают из коробки
- Видео, OCR, сайты: один раз поставить системные инструменты командой выше
- Генерация картинок/голоса/аватара: платный аккаунт + ключ в `connections.md`
- Радары и выгрузка на сайт: свой личный доступ (cookies / FTP) в `connections.md`
