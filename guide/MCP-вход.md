# MCP-серверы: что стоит и как войти

MCP-сервер - это инструмент, который Claude умеет вызывать сам (браузер, генерация дизайн-макетов, нарезка видео). Установщик регистрирует их за тебя - ничего докупать и настраивать руками не надо

| Сервер | Зачем нужен | Вход |
|---|---|---|
| **playwright** | браузер: сайты, карусели, парсеры, скриншоты | не нужен, работает сразу |
| **playwright-webkit** | второй движок браузера (WebKit/Safari-рендер) | не нужен, работает сразу |
| **stitch** | генерация дизайн-макетов | нужен вход в Google, один раз |
| **reap** | нарезка длинных видео на виральные shorts (скилл cut-from-long-form) | вход в свой аккаунт reap.video, один раз (free = 1 час видео) |

## Проверить, что MCP на месте

Открой Claude Code и набери:

```
/mcp
```

Увидишь список серверов. `playwright` и `playwright-webkit` должны быть **Connected** сразу после установки

## Войти в stitch и reap (один раз, по 30 секунд)

Оба живут на чужих серверах и просят войти в ТВОЙ аккаунт:

1. В Claude Code набери `/mcp`
2. Выбери **stitch** (вход Google) или **reap** (вход/регистрация на reap.video - free-тариф даёт 1 час видео в месяц)
3. Войди в свой аккаунт в открывшемся окне и подтверди доступ
4. Готово: сервер станет **Connected**

Если рядом написано «Needs authentication» - просто пройди шаги выше. Это нормально до первого входа

## Если чего-то нет

Набери в терминале:

```
claude mcp list
```

Это покажет все серверы и их статус. Нет `playwright` - выполни:

```
claude mcp add -s user playwright -- npx @playwright/mcp@latest
```

Всё остальное уже работает из коробки, отдельно ставить ничего не нужно
