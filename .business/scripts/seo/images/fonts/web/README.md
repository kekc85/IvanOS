# web/ - шрифты живых страниц (зеркало /assets/fonts/ на проде)

Ровно те бинарники, что раздавал Google Fonts (сабсеты latin / latin-ext /
cyrillic), поэтому рендер после перехода на самохостинг совпал пиксель-в-пиксель.
Лицензия всех трёх семейств - SIL Open Font License 1.1, самохостинг разрешён.

`fontface.css` - готовый блок @font-face, он же вставлен в
`growth/seo/article-template/tokens.css`. Пути абсолютные: `/assets/fonts/...`.

Кириллицы у Fraunces и Newsreader НЕТ ни в одном сабсете - русский текст
штатно рендерится в Georgia, так же было и на Google. Не добавлять кириллические
файлы этих семейств: поедет вся типографика статей.

Начертания italic объявлены, но пока не применяются ни одной страницей.
Объявленный и неиспользуемый @font-face браузер НЕ качает - 0 байт трафика.

Соседние файлы уровнем выше (`Fraunces-300-900-normal-latin.woff2` и т.п.) -
для рендера картинок, не для веба, их не трогать.
