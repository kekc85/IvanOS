# Solo Launch OS — навигатор сквозного пути (idea → удержание)

> **Что это.** Карта пути, по которому система ведёт соло-предпринимателя от сырой идеи до удержания — под любой формат (консультации / мини-продукт / клуб / группа / интенсив / мастермайнд / бесплатник), не только «школа». Один проход = один продукт.
>
> **Как работает.** Это НАВИГАТОР, а не методология. Тела фаз (HOW) живут в `prompts.md` — навигатор только задаёт порядок, гейты и маппинг «концептуальная фаза → живой промпт». Источник истины по содержанию фаз = `prompts.md`; навигатор не дублирует, а ссылается.
>
> **Статус сборки.** Собрано (v1.0): слой контента (`prompts.md`), навигатор, статус-движок (`launch-status.py` + шаблон-манифест), скилл-вход `/os`. Запуск: `/os` ведёт по таблице ниже (статус → промпт фазы → гейт → дальше).

## Принцип слияния двух осей
- **Старт (ось «построить»):** архетип → проверка спроса — *продай руками ДО постройки.*
- **Середина (ось «продать», авторская методология запуска):** рынок → бренд → метод → оффер → продукт → смыслы → запуск.
- **Хвост (ось «довести»):** доставка → удержание → пост-запуск.
- **Замыкание:** кейсы из доставки питают прогрев следующего цикла.

## Ветвление по архетипу (reframe «школа → любой соло-бизнес»)
Архетип выбирается в Фазе 1 и параметризует все фазы (см. таблицу в `Pre-Фаза 0.4`):
- `one_on_one` (консультации) — доставка = календарь; удержание (12) пропуск; запуск = диагностика-сессия.
- `tripwire` (мини-продукт) — оффер с таймером; мост в основной/клуб.
- `intensive` (марафон/cash event) — полный путь; дедлайн = двигатель.
- `group` (поток) — недельный drip + чат; удержание частично (полное только если recurring).
- `club` (подписка) — ★ удержание (12) полная; авто-напоминание (11) критичен.
- `mastermind` (премиум) — селекшн-анкета; high-ticket.
- `lead_magnet` (бесплатник) — оффер пропуск; ведёт в трипвайр/клуб.
**Лестница (5–7 архетипов как экосистема)** = последовательность проходов, каждый продукт = новый цикл, бренд-ассеты (Фаза 4) переиспользуются один раз.
