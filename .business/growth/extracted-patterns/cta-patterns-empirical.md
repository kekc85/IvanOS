# CTA patterns — empirical

5 types CTA observed в 30 top viral шортов. Каждый связан с конкретной funnel mechanic.

---

## CTA Type 1 — «Comment [TRIGGER_WORD]» (DM trigger / lead capture)

**Mechanic:** trigger word в комментариях запускает auto-DM с lead magnet. Используется через ManyChat / similar bot.

**Examples:**

Riley #26 (19K):
> «if you're interested in that 47 minute video that I was talking about earlier, **comment video**»

Greg #2-style (повторяется в его контенте):
- Обычно ведут на startup-ideas-pod.link (newsletter signup) — менее explicit «comment X»

**Funnel:** Comment → DM → Free resource → Email list → Nurture → Sales

**Replication для автора:**
- «Коммент `СБОРКА` — пришлю полный гайд по skills»
- «Коммент `ВОРОНКА` — пришлю шаблон контент-завода» 
- Trigger words: одно слово ALL CAPS, легко напечатать

**Critical:** trigger должен быть СПЕЦИФИЧЕН для конкретного видео. Generic «коммент» = low engagement.

---

## CTA Type 2 — «Go to [URL] for free [X]» (direct traffic to lead magnet)

**Mechanic:** прямой переход на landing с free product → email/subscription.

**Examples:**

Sabrina #10 (284K / 18K):
> «Go to this website, **sabrina.dev slash p slash free**, and get all of this free AI education»
> (повторяет URL дважды — в начале и в конце)

Sabrina #24 (25K):
> «Check it out at **Sora.com**»

**Funnel:** Watch → URL → Landing → Email opt-in → Free product → Upsell

**Replication для автора:**
- «Зайди на <твой-домен>/skills — там полный конструктор бесплатно»
- «vibemarketing.ru/free — забери методологию которую разбирал тут»

**Critical:** URL должен быть memorable + повторён 2 раза (в начале промосегмента и в конце). Лучше slug который легко напечатать на мобильном.

---

## CTA Type 3 — «Save this video / bookmark for later» (engagement boost для алгоритма)

**Mechanic:** запрос на save увеличивает algorithmic signal. Часто стоит в СЕРЕДИНЕ шорта, не финал.

**Examples:**

Sabrina #12 (136K):
> «**But first, save this video and bookmark it for later.**»
> (стоит после hook, перед прокручиванием промпта)

Sabrina #19 (36K):
> «**but first hit follow and save this video.**»
> (после hook, перед walkthrough)

**Funnel:** Save → algorithmic boost → larger reach → more leads downstream

**Replication для автора:**
- «Сохрани этот шорт прямо сейчас — текст промпта длинный, понадобится перечитать»
- «Перед тем как продолжу — сохрани, иначе потеряешь»

**Critical:** ставится в beat 2-3 (не финал). Justification = «текст длинный» / «не успеешь сохранить ссылку».

---

## CTA Type 4 — «I'll explain more in the [next video]» (series cliffhanger)

**Mechanic:** open loop → follow для следующего видео. Иногда выглядит как abrupt ending.

**Examples:**

Riley #3 (562K / 32K):
> «**And I'll explain more in the** [SCRIPT END]»
> (буквально оборвано — это намеренный cliffhanger)

Riley в #16 / #22 — open loops в финалах («I'll keep you updated», «I expect these tools to get really good»).

**Funnel:** Follow → next video → consistent retention → subscriber loyalty → sales

**Replication для автора:**
- «А как именно сделал контент-завод за выходные — покажу в следующем»
- «Полную методологию запуска я разобрал отдельно — подпишись чтобы не пропустить»

**Critical:** должен быть РЕАЛЬНО следующий видос с этой темой. Иначе trust loss.

---

## CTA Type 5 — Implicit / Drop-mic (no explicit CTA)

**Mechanic:** финал = emotional / intellectual close без explicit action. Сила в payoff.

**Examples:**

Greg #4 (523K):
> «And that's how Claude connects the dots for you.» [END]

Greg #2 (563K):
> «That's how you can turn a four-hour task into a single instruction.» [END]

Riley #22:
> «And the result will change the world of content creation forever.» [END]

Sabrina #21:
> «Check out Kling, RunwayML, Vsub.io, and my own app, Blotato.com.» [END]
> (имплицитный CTA на Blotato.com — но без explicit «go to»)

**Funnel:** Strong payoff → emotional brand association → future content engagement → organic discovery

**Replication для автора:**

Для шортов где основной value — это методология сама по себе:
- «Вот как один человек обгоняет агентство»
- «Вот почему 2026 — год соло-предпринимателей»

Drop-mic финал работает для **conviction шортов** где брeнд = главная ценность.

## Когда какой CTA применять

| Тип шорта | Recommended CTA |
|---|---|
| Tutorial / how-to с полным методом | Drop-mic (Type 5) ИЛИ Save + URL |
| Tutorial / how-to с teaser части | Comment trigger (Type 1) |
| Сериальный (часть N из K) | Series cliffhanger (Type 4) |
| Промо free product / lead magnet | Direct URL (Type 2) |
| Сложный prompt / workflow | Save mid-roll (Type 3) |
| Brand-defining content | Drop-mic (Type 5) |

## Funnel-awareness требования

КАЖДЫЙ шорт должен знать **куда ведёт зрителя**:

1. **End-of-funnel target.** Что автор хочет чтобы зритель сделал в течение 7 дней после просмотра?
   - Подписка на TG канал <твой-хэндл>
   - Регистрация на марафон
   - Запись на cash event
   - Покупка курса
   - Зайти на site и забрать lead magnet

2. **CTA должен быть mapped на target.** Если target = подписка на TG, то CTA = «Подпишись на TG, ссылка в био». Не «save this video».

3. **One CTA per video.** Multiple CTA dilutes action.

4. **Lead magnet ready.** Если CTA = «коммент X», то auto-DM ManyChat должен быть настроен И lead magnet (PDF / видео / промпт-файл) готов.

---

## Anti-patterns observed

1. **«Подпишись если про вайбкодинг»** (generic) — нет stake, low conversion
2. **«Спасибо за просмотр»** (politeness) — нет CTA вообще
3. **Multiple CTAs в одном финале** («like, save, comment, share, follow») — viewer не делает ничего
4. **CTA без lead magnet** — promise без delivery → trust loss
5. **«Свой» / «мой» без specifics** — «покажу свои skills» = что? Из моего failed test.
