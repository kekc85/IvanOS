# Voice markers — empirical per creator

Verbatim phrases / cadence specifics / signature moves каждого top creator из corpus.

Используется как cross-reference в content-skills — не для копирования, а для **calibration** авторского voice (чем Ivan отличается, что общего).

## Greg Isenberg (@gregisenberg) — 4 в top 10

**Funnel:** YouTube → startup-ideas-pod.link → newsletter → community → cash events

**Hooks signature:**
- «Why would you X when Y» (rhetorical challenge)
- «Here's a [N]-step system that turns X into Y»
- «Imagine [scenario]. That's how little [X]»

**Body signature:**
- 4-step walkthrough (First / Next / After that / Finally)
- Frequent «I sat down with [name]» (collab interview frame)
- Tool names explicit (agents.md / context folder / memory.md / skills folder)

**Voice rhythm:** measured, teacher-like. Каждое предложение = 1 actionable insight.

**Verbatim signature phrases:**
- «Here's how to [outcome]»
- «I sat down with [person] for a [deep] walkthrough»
- «Here's a [N]-step system»
- «You can [action] in under [time]»
- «That's how Claude connects the dots for you»

**Что НЕ делает:**
- Не использует «I guarantee»
- Не вставляет swearing
- Не делает emotional outbursts

**Russian adaptation для автора (только то что переносимо):**
- «4-шаговая система которая превращает X в Y»
- «Я сел с [учеником/коллабой] разобрать»
- «Сейчас покажу как [outcome] за [time]»

## Riley Brown (@rileybrown.ai) — 5 в top 30

**Funnel:** TikTok → YouTube long-form → app/SaaS (vibecode.dev)

**Hooks signature:**
- «X is coming whether you like it or not» (inevitability)
- «Whether you like it or not, [transformation] is here»
- «99% of the [thing] will soon be [transformed by AI]»

**Body signature:**
- Authority name-drop в первые 5 sec после hook («according to the founder of Anthropic», «CEO of Gumroad thinks»)
- Tool ecosystem listing (Cursor / Windsurf / Lovable / V0 / Bolt / Replit)
- Adversarial frame («defensive nerds in the comments saying...»)
- Personal conviction («I'd bet my life on it»)

**Voice rhythm:** confident, declarative. Высокая energy. Короткие punchy предложения.

**Verbatim signature phrases:**
- «I'd bet my life on it»
- «I guarantee you»
- «Whether you like it or not»
- «You are now a [category]»
- «Defensive nerds in the comments saying...»
- «Congratulations, [transformation has happened]»

**Что НЕ делает:**
- Не делает long disclaimers
- Не извиняется за provocative claims
- Не использует hedging («I think», «maybe») — только assertions

**Russian adaptation для автора:**
- «Хочешь или нет — [transformation]»
- «Гарантирую — [outcome]»
- «Поздравляю, теперь ты [category]»
- «А в комментах будет [archetype] кричать [objection]»

**Iваная opportunity:** Riley voice == закрытый match для авторской «Outlaw» registry. Этот стиль работает для контентного направления «vibemarketing наступает».

## Cross-creator patterns (universal)

**Что используют ВСЕ топ-creators:**

1. **Конкретные tool names** (Claude Code / Cursor / Obsidian / etc) — каждые 10-15 sec
2. **Каждый body beat = actionable** — не abstract
3. **Mid-roll engagement boost** (save / follow ask) — для длинных шортов
4. **Authority backup** — либо name-drop, либо verified numbers
5. **One main idea per video** — не «10 советов», а 1 method shown end-to-end

**Что НЕ используют:**

1. Em-dashes в captions
2. Hashtag spam в speech
3. «Subscribe для more» как single CTA
4. «Hope you enjoyed»
5. Generic intros («hey guys, today we're going to talk about»)

## авторский voice (для cross-reference)

Чтобы content-skill output соответствовал авторскиму voice, output должен:

**Inherit:**
- Greg-style 4-step walkthrough structure
- Riley-style inevitability framing для Outlaw register
- Sabrina-style direct URL + mid-roll save для lead magnet шортов

**Avoid:**
- Cleo-style polished cinematic (production above автора's solo setup)
- Riley-style swearing / aggressive frame (не автора persona)
- Greg-style heavy collab dependency (автор соло-creator)

**Распаковка voice — см.** `~/.business/Распаковка бренда.md` для авторских specific markers.

## Cutoff правила

В content-skill review:

1. Output должен использовать минимум 3 verbatim transition phrases из этого файла (для cross-recognition с corpus)
2. Output не должен copy whole voice creator — это plagiarism + voice loss
3. Output должен PASS автора voice rules (см. `~/.business/Распаковка бренда.md`) AND empirically validated transitions
