## Benchmark Gate algorithm (для content-skill review)

```
INPUT: generated script + chosen archetype + tier

STEP 1: Filter corpus by length tier
- if tier == short-15-30s: filter durations 15-30 sec
- if tier == short-30-60s: filter durations 30-60 sec
- if tier == short-60-180s: filter durations 60-180 sec
- if tier == mid-3-10min: NO match (corpus только shorts)

STEP 2: Filter by hook archetype
- match hook pattern из 9 categorized в corpus
- get 3-5 nearest matches

STEP 3: Compare structural fidelity
- body structure (N steps?)
- mini-hook count (если 60+ sec)
- CTA type alignment with funnel target
- visual format match

STEP 4: Score
- 4+ structural similarities = PASS
- 2-3 = WARN (escape с обоснованием)
- 0-1 = FAIL (rewrite)

STEP 5: Provide top-3 closest matches как reference for rewrite
```
