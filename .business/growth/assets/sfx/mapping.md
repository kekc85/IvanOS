# Правила применения SFX (для скилла replicate-viral)

Цель — добавить «жизнь» роликам, где сейчас ноль аудиоэффектов, **не скатываясь в дешёвый перебор**. SFX — приправа, а не основное блюдо. Если звук слышен на каждом движении — это читается как AI-слоп. Меньше = дороже.

## Карта: событие → категория звука

| Событие в кадре | Звук | Файлы (пример) |
|---|---|---|
| Смена сцены / переход / слайд-карточка уезжает | **whoosh** | `whoosh/whoosh-*` (короткие 1-2с на быстрый рез, `deep-transition`/`cinematic` на крупный переход) |
| Появление UI-элемента / иконки / буллета | **click** или **pop** | `click/click-01-tap`, `pop/pop-03-pluck`, `pop/pop-01-glass` |
| Переключатель / тоггл / выбор пункта меню | **ui** | `ui/ui-01-select`, `ui/ui-02-switch`, `ui/ui-03-toggle` |
| Прокрутка / лента уезжает | **ui** | `ui/ui-04-scroll` |
| Появление результата / готовой генерации / «вот что вышло» | **ding** | `ding/ding-01-confirm`, `ding/ding-04-chime` |
| Нарастание напряжения перед панчем / ревилом / цифрой | **riser** | `riser/riser-01-build-up` (длинный), `riser/riser-03-short-sweep` (короткий) |
| Набор текста / печать в терминале / «пишу промпт» | **keyboard loop** | `keyboard/keyboard-01-typing-loop` (под длительность сцены печати) |
| Ошибка / «вот как НЕ надо» / старый-сломанный вариант в before/after | **negative** | `negative/negative-01-failure` (редко, только на «было/сломано», НЕ под речь) |

## Designed-звуки (пак UISFX, по решению автора) — отдельная дисциплина
10 «дизайнерских» звуков с характером (`whoosh-07/08`, `click-05/06`, `ui-05`, `pop-05`, `ding-05/06`, `riser-04`, `negative-01`). Слышнее и «продюсернее» сырых Kenney-блипов → ставить на **ключевые** моменты (главный ревил / результат / крупный переход), а не на рядовые движения.
- Короткие (`whoosh-08`, `click-05/06`, `ui-05`, `pop-05`) — можно как обычные подкладки по правилам ниже.
- 🔴 **Длинные мелодические** (`ding-05-notification` 1.8с, `ding-06-system-alert` 1.25с, `riser-04-data-load` 2.0с, `negative-01-failure` 5.5с) — это музыкальные фразы, НЕ короткие транзиенты: ставить **только соло в паузе речи**, не подкладкой под голос (иначе спорят с речью и читаются дёшево). `negative-01` — максимум 1 раз на ролик, только на «было/сломалось».

## Громкость
- **SFX на −18 dB относительно голоса.** Голос — главный слой, SFX подкладка. Файлы уже нормализованы к I=-18 LUFS; если голос громче, дополнительно приглушать SFX-трек, а не задирать.
- Riser — исключение по динамике: может выходить почти в уровень голоса на пике перед панчем, затем резко падать на самом панче (классический «build → drop»).

## Плотность (жёсткое правило против дешёвки)
- **Не чаще 1 SFX на ~1.5 секунды.** Два звука впритык = каша.
- **НЕ вешать звук на каждое слово / каждый буллет.** Озвучивать только смысловые акценты: главный ревил, ключевой переход, момент «вот результат».
- Ориентир на 30-секундный ролик: **6-10 SFX суммарно**, не больше. Если насчитал 20+ — режь.
- Один тип события — один-два варианта звука за ролик, не перебирать всю категорию (иначе звучит как звуковая раскладка, а не цельный ролик).

## Реализация в HyperFrames
SFX подключаются как **отдельные `<audio>` элементы с `data-start`** (а не миксуются в дорожку голоса заранее — так их можно двигать и регулировать независимо):

```html
<!-- whoosh на смене сцены в момент 3.0с -->
<audio src="assets/sfx/whoosh/whoosh-02-fast-cut.wav" data-start="3.0" data-volume="0.16"></audio>

<!-- ding на появлении результата в 7.5с -->
<audio src="assets/sfx/ding/ding-01-confirm.wav" data-start="7.5" data-volume="0.16"></audio>

<!-- keyboard loop под сцену печати 4.0–8.0с -->
<audio src="assets/sfx/keyboard/keyboard-01-typing-loop.wav" data-start="4.0" data-volume="0.14"></audio>
```

- `data-start` = тайм-код события (привязывать к реальному моменту движения в кадре, не «на глаз»).
- `data-volume` ≈ 0.14–0.18 — это и есть −18 dB подкладка относительно голоса (≈1.0).
- Каждый SFX = свой `<audio>`-элемент, чтобы дёргать тайминг/громкость независимо от голоса и музыки.

## Анти-паттерны (не делать)
- Звук на каждом буллете списка → каша, дёшево.
- Whoosh на каждый микро-движение текста → перебор, режет внимание.
- SFX громче голоса → ломает иерархию, выглядит любительски.
- Длинный riser без последующего «drop»-панча → повисает, обманывает ожидание.
- Перебор всех вариантов категории в одном ролике → теряется цельность.
