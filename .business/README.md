# .business - твой бизнес-контекст

Это твоя база. Скиллы читают отсюда: кто ты, твоя ниша, твой голос, твоя аудитория, твои продукты. Сейчас папка пустая - её наполняет ОНБОРДИНГ (см. `../ОНБОРДИНГ.md`), читая твой блог и отвечая на вопросы. Руками заполнять не обязательно, агент делает это сам.

## Что куда ложится (наполняет онбординг)
- `voice-corpus/_voice-profile.md` - твой голос, вытащенный из твоих реальных постов (скилл `stil-golosa-po-postam`). Все скиллы-писатели берут стиль отсюда
- `Распаковка экспертности.md` - твой метод, принципы, табу (скилл `raspakovka-ekspertnosti`)
- `audience/` - сегменты аудитории, боли, желания
- `products/` - твои продукты, тарифы, офферы
- `growth/materials/Ресёрчи/` и `Дайджесты/` - ресёрч-файлы по нише (скилл `resyorch-nishi`)
- `growth/done-carousels/` - реестр сделанного (дедуп для парсеров)
- `проекты/<имя>/` - проектные пакеты, если ведёшь несколько направлений
- `processes/` - методология запуска (приходит готовой в пакете)

## Принцип
Скиллы НЕ хранят твои данные внутри себя. Они тянут их отсюда относительными путями. Поэтому один и тот же скилл работает у любого эксперта: меняется `.business`, движок скилла не трогается.
